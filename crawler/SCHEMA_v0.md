# 表头大纲 v0（待确认，2026-11-02）

前提（按建议口径起草，未获确认的已标出）：时间窗 2026-01-01—2026-10-31 为完整月，11 月单列未完整月（待确认）；HDP 各取自然前 100、不展开（待确认）。
交付：一个 Excel（6 个 sheet，分类列带数据验证下拉）+ 同结构 CSV/JSON + 原始响应目录。

空值约定：**空 = 未取到/不适用**；**0 = 已确认为零**；“未知/unknown”= 有数据但无法判定。失败不记 0。

## Sheet 1 商品表 —— 一行 = 一个入口里的一个列表位置（同商品在两个入口出现则各一行）

| 表头 | 下拉选项／填写方式 |
|---|---|
| 平台 | Lowes／HomeDepot／Wayfair（单选） |
| 入口 | Lowes带台面榜／Lowes无台面榜／Wayfair主类目／Wayfair无台面类目／HDP带台面／HDP无台面（单选） |
| 排名口径 | 官方BSR／Recommended自然顺序／TopSellers自然顺序（单选） |
| 页码 | 数值 |
| 原始位置 | 数值；页面卡片出现顺序，含广告 |
| 排名/自然序号 | 数值；Lowe's 为原始 BSR，不因排除重排；Wayfair/HDP 为去广告后的自然序号，排除行留空 |
| 是否纳入 | 纳入／排除（单选） |
| 排除原因 | 广告／独立台面或台盆／镜柜／侧柜或储物柜／配件／重复主链接／其他（单选；纳入行留空） |
| 商品ID | 标识文本（Lowe's itemId、HDP itemId、Wayfair SKU 如 W002013747） |
| 型号 | 标识文本，可空 |
| 选中配置ID | 标识文本；Wayfair piid，其他平台留空 |
| 品牌 | 自由文本 |
| 标题 | 自由文本 |
| 选中颜色/尺寸 | 自由文本，按页面原文 |
| 商品链接 | 链接 |
| 价格(USD) | 数值，取页面当前展示价 |
| 页面评分 | 数值 0—5，商品总评分，不等于单条评分 |
| 页面累计评论数 | 数值；页面未显示则留空，仅辅助校验 |
| 主图URL | 链接 |
| 地区/邮编 | 文本，如 90013 |
| 列表抓取时间 | 日期时间（UTC） |
| 评论采集状态 | 完整／部分／失败／未采集（单选，来自覆盖表） |
| 2026评论数 | 公式：映射表中该行商品的 2026 唯一评论数 |
| VP数 / non_VP数 / unknown数 | 公式：同上分 VP 状态计数（3 列） |

## Sheet 2 评论明细 —— 一行 = 一条去重后的评论（同一评论挂多个商品只出现一次）

| 表头 | 下拉选项／填写方式 |
|---|---|
| 评论唯一键 | 标识文本：平台+来源站点+原评论ID；无原ID时为 sha256 内容指纹 |
| 标识方式 | 原评论ID／内容指纹（单选） |
| 原评论ID | 标识文本，可空 |
| 平台 | Lowes／HomeDepot／Wayfair（单选） |
| 原评论ProductId | 标识文本；评论接口返回的归属商品，可能≠请求商品 |
| 评论日期原值 | 文本，平台原样（如 04/01/2026、2026-04-01T13:22:10.000+00:00） |
| 评论日期 | 日期 YYYY-MM-DD（按原值，不做时区平移） |
| 评论月份 | 文本 YYYY-MM |
| 月份状态 | 完整月／未完整月（单选；11 月为未完整月） |
| 单条评分 | 数值 1—5 |
| 评论标题 | 自由文本，可空 |
| 评论原文 | 自由文本 |
| 评论时选中规格 | 自由文本（Wayfair choices / BV 规格字段原文） |
| VP状态 | VP／non_VP／unknown（单选） |
| VP判定依据 | 徽章=Verified Purchase／徽章=Verified Buyer／BV验证字段=true／BV验证字段=false／BV完整徽章结构无verified／仅Pro或其他徽章／无验证字段／证据冲突（单选） |
| VP原始证据 | 自由文本：badge、badgeDescription 或 BV 字段原值 |
| Pro标记 | 是／否／未知（单选） |
| 激励/赠品 | 是／否／未知（单选） |
| 转载状态 | 本渠道原生／转载／来源待核实（单选） |
| 转载来源站点 | 自由文本，可空 |
| 有图 | 是／否／未知（单选） |
| 原始响应文件 | 文本，raw 目录相对路径 |
| 抓取时间 | 日期时间（UTC） |

## Sheet 4 按月计数 —— 一行 = 一个入口商品 × 一个月份（2026-01 至 2026-11）

| 表头 | 下拉选项／填写方式 |
|---|---|
| 平台 / 入口 / 商品ID / 排名或自然序号 / 标题 | 取商品表（5 列） |
| 月份 | 2026-01……2026-11（单选） |
| 月份状态 | 完整月／未完整月 |
| 评论数(含转载) | 公式：该商品该月映射评论数 |
| VP | 公式 |
| non_VP | 公式 |
| unknown | 公式 |
| 其中转载 | 公式 |
| 其中来源待核实 | 公式 |
| 覆盖状态 | 完整／观察值（不完整）（单选；覆盖不完整时数字只是观察到的下限） |

说明：共享评论池会让同一评论计入多个商品，**跨商品、跨入口不可直接加总**；入口级汇总在 Sheet 6 用去重口径另算。
