## Sheet 1 商品 —— 一行 = 一个入口里的一个商品

| 表头 | 下拉／填写 |
|---|---|
| 平台 | Lowes／HomeDepot／Wayfair |

| 表头 | 下拉／填写 |
|---|---|
| 平台 | 同上 |
| 入口 | 同上 |
| 商品ID | 文本，关联 Sheet 1 |
| 评论ID | 文本（无原 ID 时为指纹） |
| 评论日期 | 日期 |
