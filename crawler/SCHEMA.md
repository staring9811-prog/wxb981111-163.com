# 表头大纲 v1（精简版，待确认，2026-11-02）

只交 2 个 sheet。原始响应、分页记录、指纹等技术证据放 JSON，不进 Excel。
空 = 没取到；0 = 确认为零；失败不记 0。

## Sheet 1 商品 —— 一行 = 一个入口里的一个商品

| 表头 | 下拉／填写 |
|---|---|
| 平台 | Lowes／HomeDepot／Wayfair |
| 入口 | Lowes带台面榜／Lowes无台面榜／Wayfair主类目／Wayfair无台面类目／HDP带台面／HDP无台面 |
| 排名 | 数值；Lowe's 为官方 BSR，Wayfair/HDP 为去广告后的自然顺序 |
| 商品ID | 文本（Wayfair 附 piid） |
| 品牌 | 文本 |
| 标题 | 文本 |
| 商品链接 | 链接 |
| 价格(USD) | 数值 |
| 页面评分 | 数值 |
| 页面累计评论数 | 数值，仅参考 |
| 纳入情况 | 纳入／排除-广告／排除-非整柜／排除-重复 |
| 2026评论数 | 数值 |
| VP | 数值 |
| non_VP | 数值 |
| unknown | 数值 |
| 其中转载 | 数值 |
| 采集状态 | 完整／部分／失败 |
| 备注 | 文本（失败原因等） |

## Sheet 2 评论明细 —— 一行 = 一个商品下的一条 2026 年评论

| 表头 | 下拉／填写 |
|---|---|
| 平台 | 同上 |
| 入口 | 同上 |
| 商品ID | 文本，关联 Sheet 1 |
| 评论ID | 文本（无原 ID 时为指纹） |
| 评论日期 | 日期 |
| 月份 | 2026-01……2026-11 |
| 评分 | 1—5 |
| 评论标题 | 文本 |
| 评论原文 | 文本 |
| VP状态 | VP／non_VP／unknown |
| VP证据 | 文本（徽章原文） |
| 转载 | 否／是／待核实 |
| 多商品共享 | 是／否（同一评论也挂在其他商品下，汇总时别重复算） |

按月统计：在 Sheet 2 用“月份 + VP状态”透视即可。
