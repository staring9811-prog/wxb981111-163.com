# 翡翠博弈 · 发布方案（先闲鱼，后微信小游戏、Steam）

写于 2026-11-14。主机和平台的规则会变，标了“需自测”“以平台当时规则为准”的地方请以实际为准。

## 一、要交付给买家的东西

买家拿到两样：**一个网址** 和 **一个激活码**。手机、电脑浏览器打开网址就能玩，免费试玩到第 3 天，之后输入激活码继续（存档不丢）。

发布包是 `jade-game/dist/` 整个文件夹（6 个文件，纯静态，不需要服务器程序）。生成方法：

```bash
cd jade-game && python3 build.py --dist
```

## 二、网址放在哪

GitHub Pages、claude.ai 的分享链接在国内网络下不稳定或打不开，不适合卖给闲鱼买家。按“先能用、再稳定”分两步：

| 阶段 | 方案 | 成本 | 优点 | 风险 |
|---|---|---|---|---|
| 先测试 | Cloudflare Pages：注册后新建项目，直接把 `dist` 文件夹拖上去，得到 `xxx.pages.dev` | 免费 | 十分钟搞定 | 国内访问速度和稳定性**需自测**，让移动、联通、电信的朋友各试一次 |
| 正式卖 | 买一个域名，用腾讯云 COS 或阿里云 OSS 的**香港地域**开“静态网站托管”，上传 `dist`，绑定域名并开 HTTPS | 域名约 10–60 元/年，流量每月几元 | 国内访问较稳，香港节点不需要备案 | 必须绑定自己的域名（云厂商的默认域名打开网页会变成下载） |
| 做大后 | 域名备案 + 国内地域 + CDN | 备案 1–3 周 | 最快最稳，微信里也能直接打开 | 备案需要实名主体 |

微信里点链接：未备案或新域名可能被拦截提示，卖家话术里写“复制到浏览器打开”。

## 三、激活码

- 生成：`python3 tools/gen_codes.py 100 /你电脑上的私有路径/codes.txt`。明文只写进你指定的文件；仓库里的 `licenses.js` 只有哈希。生成后重新 `build.py --dist` 并上传，新码才生效。
- 第一批 60 个已生成，明文不在仓库里（见交付说明里的文件路径）。
- 一个码可以在多台设备上用，不绑定设备。发现某个码被到处转发，就从 `licenses.js` 删掉对应哈希、重新发布，再给原买家换一个。
- **重要**：现在仓库是公开的，任何人都能看到全部源码并绕过激活码。正式开卖前把仓库改成私有（或把游戏拆到一个私有仓库）。改私有后，`play.html` 的联网自动更新会失效，本机改用 `git pull`。
- 这套校验挡的是普通用户，挡不住会改代码的人。要更严就得加一个验证服务器（按设备数限制、可吊销），等销量起来再做。

## 四、闲鱼上架

- **类目与规则**：虚拟商品、游戏激活码在闲鱼有专门的规则和限制，**以上架当时的类目要求为准**；被判违规就换成“网页游戏体验码”“独立游戏试玩”之类描述，或改走小红书、B 站引流到网址。
- **标题**：独立游戏《翡翠博弈》赌石经营模拟 手机电脑网页即玩 激活码
- **首图**：切面透绿的那张；后面放打灯、成品托盘、种色图鉴各一张。
- **描述要点**：不用下载，浏览器打开即玩；先试玩 3 天再决定买；一码永久；写明“虚拟商品，发码后不退”；写明是模拟游戏，不涉及真实翡翠交易和真钱赌博。
- **发货**：销量小先手动发；多了用闲鱼支持的自动发货或卡密工具，把码一行一个导进去。发货话术：

  > 网址：https://你的域名/ （复制到手机或电脑浏览器打开）
  > 激活码：XXXX-XXXX-XXXX-XXXX
  > 玩到第 3 天点“收工”会让你输码，输一次就行。存档在你自己的浏览器里，换设备、清浏览器数据会丢。

- **定价**：先 9.9–19.9 元试水，看转化和差评点再调。
- **售后最常见的三类**：打不开（让对方换浏览器、关省流模式）；卡（右上角菜单把画质调到“省电”）；存档没了（说明存在本机浏览器里）。

## 五、之后两步的门槛（先知道，不急着做）

- **微信小游戏**：需要主体认证和软件著作权；带付费的游戏类目可能要版号；“赌石”题材审核有风险，文案要改成“鉴石、开料、经营”；渲染用的 WebGL2 在小游戏环境里支持不完整，需要专门适配，工作量不小。
- **Steam**：Steamworks 入驻费 100 美元；用 Electron 或 Tauri 把网页包成桌面程序；成就接 Steam 成就；需要英文或至少完整的商店页素材。

## 六、你需要亲自做的事

1. 注册一个主机账号并上传 `dist`（我没有你的账号，做不了）。
2. 用自己的手机和两三个朋友的手机测一遍：能否打开、帧率、触屏操作。这一步我在云端验证不了。
3. 决定仓库是否改私有。
4. 保管好激活码明文文件。
