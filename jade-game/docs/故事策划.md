# 《翡翠博弈》故事策划

状态：策划稿，待确认后分期实现。现有的六章主线、往事、支线任务会按这份稿子重新编排。

## 一、这是一个什么故事

**一句话**：一个欠着父债的打工仔，靠一支旧手电，用三十年时间从夜市地摊走到一代货主；他赢来的每一样东西，都要拿另一样东西去换。

**主题**：石头不骗人，骗人的是你想赢的那个念头。

**玩家的核心问题**：这一刀切不切？这笔钱借不借？这个家顾不顾？这门手艺传给谁？——每个阶段都是同一个问题换了筹码：**你愿意拿什么去赌**。

**人生视角**：游戏里一天等于家里一个月，孩子按月长大。一局完整的人生大约 360 个游戏日（30 年）：主角 28 岁开局，58 岁收官。玩家看着孩子从抱在怀里到接班或远走，看着自己从蹲着看石头到蹲不动。

## 二、设计方法（参考了哪些做法）

- **三幕八段**：不再是六个平铺的“章”，而是三幕、八个阶段，每个阶段有一个明确的戏剧问题和一个转折事件。
- **三层目标**：任何时候屏幕上都有短期（今天这块料）、中期（这一阶段要办成的事）、长期（这辈子想成为什么人）三层目标，解决“玩着玩着不知道干啥”。
- **关键人物弧光**：每个重要 NPC 有自己的愿望和变化，不是功能按钮。
- **分支与后果**：分支不靠选项菜单，靠玩家平时怎么做（借不借、卖不卖假、顾不顾家）累积成三个隐藏倾向值，在关键节点结算。
- **节奏曲线**：每一幕“上升—受挫—再上升”，每幕结尾一次大的失去。
- **多结局**：结局由财富、名声、家庭、传承四条线的完成度组合决定，不分“好坏”，只分“你成了什么样的人”。

## 三、人物

| 人物 | 身份 | 他想要什么 | 弧光 |
|---|---|---|---|
| **你** | 28 岁，玉器厂零工，欠着父亲留下的债 | 不再让家里人过穷日子 | 从“想赢”到“知道什么不能输” |
| **牛叔** | 夜市老摊主，60 岁 | 找个人把看石头的本事传下去 | 师父→退场→一支手电→（第三幕）你成了下一个牛叔 |
| **阿秀** | 妻子 | 一个安稳的家 | 支持→担忧→摊牌；她是家庭线的晴雨表 |
| **小满** | 长子，开局 8 岁 | 被父亲看见 | 童年崇拜→青春期对抗→接班或远走 |
| **小宝** | 次子，开局刚出生 | —— | 他的整个成长期都在你最忙的时候；他像不像你，看你陪了多少 |
| **老周** | 同行，比你早入行十年 | 赢 | 对手→可以联手也可以翻脸→（结局）一起喝茶或老死不相往来 |
| **岩温** | 缅甸货主，口岸认识 | 把矿上的好料卖个公道价 | 第二幕的货源线：信任他，他带你进矿区；坑他一次，这条线断 |
| **苏师傅** | 苏工玉雕师 | 做一件能留下来的东西 | 手艺线：从“给钱就做”到愿意为你的料熬三个月 |
| **父亲** | 老家，当年赌石输光家产 | 儿子别走他的老路 | 只在信里出现；第三幕来瑞丽看你一次 |
| **林姐** | 直播公司的人 | 把你做成 IP | 第三幕的诱惑：流量、带货、人设 |

## 四、三幕八段

### 第一幕 入行（约第 1–60 天，28–33 岁）

**戏剧问题：我能不能靠这个吃饭？**

| 阶段 | 做什么 | 转折事件 |
|---|---|---|
| 1 路边看客 | 围观、猜、练眼。牛叔给手电 | 第一次猜对，赢到彩头 |
| 2 二道贩子 | 小本倒手，不切 | **第一次打眼**：买到假货或切垮，赔掉大半本钱。牛叔不骂，带你看他床底下那块染色料 |
| 3 第一刀 | 学下刀、做货 | **幕终事件「父亲的信」**：老家来信，债主上门了。你必须在某一天前凑够一笔钱——第一次面对“借不借、赌不赌” |

第一幕结尾的失去：**牛叔的本钱**。无论你怎么选，这一幕结束时你要把牛叔借你的钱连本带利还上，他说“以后我帮不了你了”。

### 第二幕 立业（约第 60–200 天，33–45 岁）

**戏剧问题：我要做多大？拿什么换？**

| 阶段 | 做什么 | 转折事件 |
|---|---|---|
| 4 开铺面 | 柜台、熟客、订单、口碑 | 老周把店开到你对面 |
| 5 走出去 | 口岸、矿区、公盘；认识岩温 | **「矿上的事」**：岩温给你一批来路说不清的好料，价钱低得不正常。收，还是不收 |
| 6 直播间 | 直播、粉丝、代赌、鉴定；林姐出现 | **幕终事件「那一年」**：三件事同时到——小满中考、一块能改变身家的公盘标王、阿秀生病。时间只够顾两头 |

第二幕结尾的失去：**三选二里没选的那一样**。没顾小满，他去了外地的学校，几年不怎么回家；没拍标王，老周拍走了，从此压你一头；没顾阿秀，家和永久降一档，离婚线打开。

### 第三幕 传承（约第 200–360 天，45–58 岁）

**戏剧问题：这些东西最后留给谁？**

| 阶段 | 做什么 | 转折事件 |
|---|---|---|
| 7 连锁 | 分店、员工、贷款杠杆、被清算的风险 | **「牛叔走了」**：牛叔在老家去世，留给你那支手电和一句话。同时行业大洗牌：一次全行业的假货风波，你的选择决定口碑 |
| 8 交棒 | 培养接班人，或者卖掉，或者守到最后 | **终章「最后一块石头」**：一块你这辈子见过最好的蒙头料，要价是你的全部身家。买不买、切不切、谁来切 |

## 五、三个隐藏倾向

不显示数值，只通过别人对你的称呼和态度让玩家感觉到。

| 倾向 | 怎么涨 | 怎么掉 | 影响 |
|---|---|---|---|
| **稳** | 看准才买、按时还贷、订单不违约 | 高杠杆、熬夜、借民间贷 | 银行额度、熟客回头、老周对你的评价 |
| **义** | 不卖假、照实鉴定、帮同行、还牛叔的情 | 把假货卖给不知情的人、坑岩温、带货烂货 | 岩温线、苏师傅线、假货风波里有没有人替你说话 |
| **家** | 陪家人、开家长会、歇业、不熬夜 | 婚外情、长期忽略、孩子辍学干活 | 阿秀线、孩子接不接班、父亲来不来看你 |

## 六、支线（每条都有头有尾）

| 线 | 起点 | 中段 | 终点 |
|---|---|---|---|
| **师徒线（牛叔）** | 一支手电 | 他收摊、回老家 | 你把手电递给下一个蹲在摊边的年轻人 |
| **对手线（老周）** | 对面开店 | 抢标王、抢客人、可以联手做一单大的 | 一起喝茶 / 被他收购 / 收购他 |
| **货源线（岩温）** | 口岸第一笔交易 | 矿上的事 | 他把矿主介绍给你（缅北矿区长期低价）/ 他消失 |
| **手艺线（苏师傅）** | 第一件雕件 | 他拒绝做一块你硬要做的料 | 一件传世之作，署两个人的名 |
| **父子线（小满）** | 蹲在摊边问“里面有没有绿” | 青春期：他想学 / 你不让，或你逼他学 / 他不想 | 接班、另立门户、或彻底离开这行 |
| **幼子线（小宝）** | 出生 | 整个成长期你都在忙 | 他成为什么样的人，取决于你陪的时间；可能是最像你的，也可能是最不认你的 |
| **夫妻线（阿秀）** | “别把这十万当赌本” | 摊牌：“这个家你还管不管” | 白头 / 离婚 / 各过各的 |
| **父债线** | 开局的欠条 | 父亲的信 | 父亲来瑞丽，站在你铺子门口不进去 |
| **流量线（林姐）** | 七个人的直播间 | 签不签约、带不带烂货 | 成为 IP / 翻车 / 退网 |
| **信用线** | 第一笔贷款 | 杠杆越加越大 | 无债一身轻 / 被清算后东山再起 |

## 七、意外与隐藏

- **行业级意外**（每幕一次，所有人都受影响）：封矿涨价、假货风波、直播监管收紧。
- **个人级意外**：仓库进水、被偷、被告、贵人、视频爆火（已有 6 条，按幕分配）。
- **隐藏事件**（特定条件才触发，不提示）：
  - 连续 30 天不熬夜、不借钱：阿秀偷偷给你攒了一笔钱。
  - 把假料标本攒到四种：一个记者来采访，你成了“打假的人”。
  - 被清算后信用回到 60：当年的银行经理请你吃饭。
  - 第一幕就还清父债：父亲提前来看你。
  - 从没卖过一件假货走到终章：假货风波里全行业只有你的铺子没被查。

## 八、结局

终章之后，按四条线的完成度出结局画面，每条线一段文字，拼成你的一生：

| 线 | 高 | 低 |
|---|---|---|
| 财富 | 一代货主 | 守着一节柜台，也够吃饭 |
| 名声 | 行里人提起你都点头 | 没人记得你卖过什么 |
| 家庭 | 过年一桌坐不下 | 一个人吃年夜饭 |
| 传承 | 有人接着你的手电 | 手艺到你这里断了 |

另有三个特殊结局：**「牛叔」**（四线都不高但师徒线走完：你在夜市摆摊，教下一个年轻人）、**「一刀」**（终章全押切涨）、**「回家」**（终章不买，带阿秀回老家）。
