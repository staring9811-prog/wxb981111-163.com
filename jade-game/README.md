# 翡翠博弈（浏览器版）

接手自 2026-11-13 的 Godot 原型交接。玩法目标不变：在同一块固定三维内部结构的原石上，靠皮壳、打灯、开窗、切片去博弈色带深度、种水、裂和现金流。实现路径改为 WebGL2 体渲染，原因是可以在无显卡的云端真实截图验证画面，玩家也不需要安装引擎。

## 文件

- `index.html`：页面与样式（发布为 Artifact 时作为页面主体，本地打开需包一层 `<!doctype html>`）。
- `core.js`：内核，无 DOM 依赖，可在 Node 里 `require`。原石真相生成、体数据烘焙、磨削、切片、公开证据估值、买家报价、议价、换日、复盘。
- `shader.js`：片元着色器。视线求交后沿视线向内步进，累积室内光与手电光的散射；手电光按材质分通道衰减，被裂面遮挡。
- `ui.js`：三维工作台交互与右侧面板。

## 信息分层

- 真相：`genStone` + `truthAt`，完全由种子决定；`bake` 烘成体数据（距离场、皮厚、色、种水、棉、脏）。裂是解析曲面，不受体素分辨率限制。
- 公开证据：只有磨穿皮壳的表面和切面算露肉（`evalPiece`）。
- 市场认知：买家对看得见的部分按实际成色算，对看不见的部分用“露面外推 + 场口先验 + 灯下浅层表现”估，并打风险折价（`estimate`、`quotes`）。
- 玩家判断：不做模拟，玩家自己用眼睛看。

## 已验证与未验证

已做：Node 里跑通生成、议价、切片、报价；无头浏览器里跑通买入→开窗→打灯→切片→出售→复盘并人工看过截图；80 块样本上“按中间价闭眼买、全部切 12 mm 片”的总回收约为成本的 0.7–1.1（取决于 `ECON.priorScale`，当前 1.0）。

未做：10,000 局策略对照、反套利证明、首月存活率；真实显卡和手机上的帧率；光学参数没有实物标定，按可读性调的。首饰、雕刻、画圈取镯不在本期范围。

## 第二轮（2026-11-13）

- 一块料由任意切面定义：拖线下刀或从正对面按厚度切片；估值、手镯位、缩略图都跟着切面走。
- 每块货源有“赌什么”标签（赌种水、赌色、赌裂、赌镯位、有雾层），只根据外部迹象给出。
- 送加工做成件：结果由真相决定，压镯有失败率；成品可批发（零售的六成，现结）或寄卖（接近零售，6–14 天回款）。
- 数值按 `research/value-chain.md` 的建议表校准：无色手镯零售价豆 0.1 万到玻璃 90 万，色系数从淡绿 1.5 倍到帝王绿满色 100 倍；毛料按零售的六成起算。该表的来源质量和内插部分见文件末尾。
- 阿牛视频：原有 20 条案例摘要之外，新增 43 条只拿到标题和评论区转述，没有字幕或口述原文，证据等级在调研文件里逐条标注。

## 第三轮（2026-11-13）

- 画质：皮壳凹凸与砂粒、软阴影、环境遮蔽、玉肉菲涅耳反光、手电眩光、ACES 色调。
- 裂：数量上调；到皮的裂在皮上显示为带锈边的线，露肉面上是暗线加白雾；灯下仍会挡光。
- 种水：光学衰减改为指数曲线（豆 0.27/mm → 玻璃 0.005/mm），室内光下种嫩发白、种老发深。
- 切割：每块料最多 16 个切面，切出的料可以继续切。
- 做件：玩家选路线（手镯、牌子挂件、蛋面、珠串、雕件）、师傅（机雕厂、街边师傅、平洲镯师、揭阳高货师、苏工玉雕师）和题材（素面、观音佛公、山水、花鸟龙凤，或交给师傅）。料的棉、裂、色决定哪条路值钱；题材有行情冷热。
- 成品盘：成品逐件摆在托盘里用同一画布渲染，可转动欣赏，单件或整盘批发、寄卖；另有种水与颜色对照盘。

## 在本机打开与自动更新

- 拉代码后双击 `jade-game/play.html` 即可玩，不需要服务器，也不需要装别的东西。Windows 可双击 `start.bat`（先 `git pull` 再打开），macOS/Linux 用 `start.sh`。
- `play.html` 每次打开会联网读 GitHub 上的 `version.json`（本分支和 main 取版本号大的）。线上版本更新时，页面直接加载线上的页面和脚本运行，并提示本地文件需要 `git pull`；断网时用本地文件。右下角显示当前版本。
- 发版步骤：改 `version.json` 的 `version`（+1）和 `notes` → `python3 build.py` → 提交并推送。`index.html` 是发布到 Claude Artifact 用的页面主体，`play.html` 由它生成，不要手改。
- 存档在浏览器本地（按文件路径区分），换电脑不会跟过去。
