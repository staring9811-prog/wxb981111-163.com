## 页面

- 页面模板 `{% extends "base.html" %}`，从对应原型 HTML 搬结构和 class，原型里的示例数字换成真实数据；页面私有 `<style>` 放 `{% block head %}`。
- `render(request, "xxx.html", "PAGE-Fxx-xx", "页面名", **ctx)`；meta page-id 由 base 输出。
- 路径：/ 工作台 · /accounts · /settings/keys · /settings/budget · /data/amazon · /data/channels · /tagging · /models · /scan · /cards · /cards/{id} · /tools/vp · /tools/profit · /approvals · /strategies · /ledger · /settings/category。
- 原型里的页面互链 `PAGE-Fxx-xx.html` 一律换成上面的路径。
- 权限：服务端用 `auth.operator_only / approver_only / any_user` 依赖；只读角色的非 GET 已被中间件统一拒绝。无权限入口不渲染（不是置灰）。
- 表单提交后 `redirect(url, msg)` 显示顶部提示；JSON 接口返回 `{"detail": "..."}`。

## 数据口径（各模块共用，不得各自另算）

- 标签名（Tag.tag）：`尺寸段`、`装`（拆装 / 整装）、`形态`（落地式 / 悬浮式 / 柱状盆 / 转角式）、`台面材质`、`元素`（多值，用 `|` 分隔）、`主色`、`柜体材质`。
- 框键：`f"{尺寸段} · {装} · {形态}"`，例 `30″ · 拆装 · 落地式`。扫描只用落地式 / 悬浮式。
- 一切份额、溢价、评分差、新品占比只在同一渠道、同一框内计算（AC-F20-02、AC-F29-02）。
- 被标为"不是本品类"的商品（Product.excluded）不进入任何分析。
- 标签取值：已确认值优先，其次自动值；queued 状态的自动值也参与（打标完成即可扫描，确认后重算覆盖）。
- 其他渠道月销 = VP × vp_coef + 非 VP × nonvp_coef（品类配置当前版本），合计按评论 ID 去重。

## v8 数据侧接口（小平台回测增量，给模型侧开发者）

> 需求：requirements revision 8 的 REQ-F23-02、REQ-F28-03、REQ-F18-04、AC-F27-04、NFR-013；做法与数字基准见 `../solution-v2/开发建议/小平台_HD回测小试.md`。

### 渠道重建面板

- 取数：`pdt.core.panel.load_panel(channel)`（`channel` ∈ homedepot / lowes / wayfair），列与 Amazon 相同（见上文）。回补重建过的渠道从回补起始月（默认 2024-01）到采集日上一个月逐月都有行；Home Depot 用小试缓存导入后为 2024-01 至 2026-10、34 个月、184 个有销量家族。
- 行 = 月 × 商品页；`units` = 该商品页当月 VP 条数 × `vp_coef` + 非 VP 条数 × `nonvp_coef`（品类配置当前版本，读取时换算）；每条评论只记在写它的商品页上一次（站点评论带 ProductId）。
- `family_key` = **评论家族键**（形如 `F203486567`，F + 家族里并查集根商品页 ID），同时写在 `Product.series` / `Product.family_key`；家族是该渠道份额与新品计算的单位（相当于 Amazon 父体）。
- `listed_at` = 商品页首条评论日期（≈ 上架，通常比真实上架晚 1–2 个月）；`age_months` 由它算。首评早于“起始月 − 6 个月”的商品页视为老品。
- `price` = 采集日当天价（快照 `raw.price_is_current = True`），不是历史价；`rank` 只在最后一个完整月有值（采集日的类目榜单排名）。
- `装` 没有依据时为空（未知），`frame` 为空、不进框（不再默认拆装）；`scan.frame_rows` 已按 `装.notna()` 过滤。
- 存储方案：沿用 Batch / Snapshot。每个重建月份一个批次（`Batch.source = 'backfill'`、`status = 'merged'`、`checks.rebuild = True`），同渠道同月原有的月度追踪批次与上一次重建批次改为 `superseded`，不重复计数。快照 `raw`：`vp_d / nonvp_d / family_key / entry / source='backfill'`。
- 重建摘要：`pdt.core.backfill.last_rebuild(channel) -> {at, params, stats}`；`stats` 含 `start / end / n_months / pages_listed / pages_all / families / fam_status / reviews_all / reviews_window / vp_share / truncated_pages / sharded / coverage{类目: {segments, b, cover, cover200, …}} / overlap[{key, label, top50, top20}] / quarters / tags / config_version`。HTTP：`GET /data/channels/{channel}/history`。
- 明细表（`pdt/models_data.py`，DATA-F28-02）：`ChannelHistReview`（评论 ID 唯一，`item_id` = 写评论的商品页，`family_key`、`date`、`month`、`stars`、`vp`）、`ChannelPageSpec`（商品页规格 `specs`、`listed`、`entry`、`rank`、`price`）、`ChannelFamily`（`members` 前 N 内成员、`variants` 起始月以来有评论的全部商品页、`best_rank`、`first_review`、`status` 完整 / 截断 / 无评论、`complete_to`、`sharded`）、`ChannelRebuild`（摘要）。
- 截断家族（分片后仍到翻页上限）：`ChannelFamily.status == '截断'`，`complete_to` 之前的月份评论不全；回测时这些家族早于 `complete_to` 的月份应剔除或标注。

### 回补与打折参数（品类配置，`catconfig.DEFAULT["channels"][渠道]`）

- `backfill.start`（回补起始月份，默认 `"2024-01"`）、`backfill.n`（每个类目取前 N 个商品页，默认 300）——回补任务 `channel_backfill` 读。
- `discount.rank_corr`（秩相关减值，默认 0.1）、`discount.high_pp`（把握 ≥ 70% 档“之后变大”比例减值，百分点，默认 15）、`discount.dir_cap`（方向对上限，%，默认 60）——**模型侧渠道回测的打折后读法读这三个键**。
- 读取：`catconfig.channel_params(channel) -> (参数版本, {"backfill": {...}, "discount": {...}})`；旧版本配置里没有这两组键时自动补默认值。结果上要注明参数版本。

### 渠道证据等级存哪里（建议）

- 建议模型侧按 DATA-F19-02 新建表（如 `ChannelModelRun`：渠道、数据截至月、参数版本、原值与打折后指标、证据等级“经回测（打折）/ 未验证”、有效性判定），放在模型组自己的 models 文件里，不改 `ModelRun` 已有字段含义；`Opportunity.evidence` 写入时从该表取该渠道当前等级。
- 回测的前置：`last_rebuild(channel)["stats"]["n_months"] ≥ 20`；没有重建的渠道（Lowe's / Wayfair 当前）证据等级保持“未验证”。

### 其他

- 回补任务：`costgate` 类型 `channel_backfill`，`target = "backfill:<渠道>"`，`params = {channel, start, n}`；采集缓存在 `data/backfill/<渠道>/`（与小试缓存同结构），续采不重复请求已完成的商品页。HD 直连的请求器 `backfill.Polite`（可注入假站点与假时钟，测试见 `tests/test_backfill.py`）。
- 导入现有缓存：`python tools_import_v2.py --channel-history homedepot`（只导 HD 回补缓存并重建）；或页面“按当前参数重建”（`POST /data/channels/{channel}/rebuild`）。
- 打标来源：`Tag.source` 新增 `spec`（页面“规格”）；`rule` 页面显示“标题”；已确认的显示“人工”。其他渠道“装”为空 = 未知，在确认队列“装：未知”里，候选不预选。
