## 目录与归属

```
app/
  run.py                 启动（只监听局域网地址）
  pdt/config.py db.py models.py security.py auth.py costgate.py services.py catconfig.py   ← 共用，只做追加式修改
  pdt/clients/           外部服务真实客户端（sellersprite / brightdata / apify / llm）
  pdt/core/              业务计算，不引用 FastAPI，便于单测
  pdt/web/routes_*.py    每个模块一个文件，router = APIRouter()，已在 main.MODULES 登记
  pdt/web/ui.py          render() / redirect() / 过滤器 num pct dt；侧栏按角色隐藏
  pdt/templates/         base.html、_cost_modal.html、各页面模板
  pdt/static/            tokens.css app.css icons.js app.js costgate.js（来自原型，不改）
  tests/                 pytest；conftest 提供 client / wen / login_as / make_user
  data/                  运行数据（gitignore）
```

共用文件需要新增表或字段时，只追加，不改已有字段含义；在交付说明里列出。

## 页面

- 页面模板 `{% extends "base.html" %}`，从对应原型 HTML 搬结构和 class，原型里的示例数字换成真实数据；页面私有 `<style>` 放 `{% block head %}`。
- `render(request, "xxx.html", "PAGE-Fxx-xx", "页面名", **ctx)`；meta page-id 由 base 输出。
- 路径：/ 工作台 · /accounts · /settings/keys · /settings/budget · /data/amazon · /data/channels · /tagging · /models · /scan · /cards · /cards/{id} · /tools/vp · /tools/profit · /approvals · /strategies · /ledger · /settings/category。
- 原型里的页面互链 `PAGE-Fxx-xx.html` 一律换成上面的路径。
- 权限：服务端用 `auth.operator_only / approver_only / any_user` 依赖；只读角色的非 GET 已被中间件统一拒绝。无权限入口不渲染（不是置灰）。
- 表单提交后 `redirect(url, msg)` 显示顶部提示；JSON 接口返回 `{"detail": "..."}`。

## 花钱任务（费用闸门）

- 模块在 import 时 `costgate.register(kind, 中文名, estimator, runner)`。
- 页面按钮：`<button data-cost-kind="amazon_pull" data-cost-month="2026-10" data-cost-target="" data-cost-params='{}'>`，并 `{% include "_cost_modal.html" %}`；确认后触发 `pdt:job-started` 事件，页面轮询 `GET /jobs/{id}`。
- runner 内：每次外部调用前 `ctx.allow(service, amount=, qty=)`，调用后 `ctx.charge(service, qty, amount, task)`；分片用 `ctx.shard_done(key)` / `ctx.mark_shard(key)`，重跑跳过已完成分片。
- 外部服务一律 `services.client(name)` 取得；测试用 `services.set_fake(name, obj)`（仍要求设置页保存过密钥，否则 NotConnected）。

## 数据口径（各模块共用，不得各自另算）

- 标签名（Tag.tag）：`尺寸段`、`装`（拆装 / 整装）、`形态`（落地式 / 悬浮式 / 柱状盆 / 转角式）、`台面材质`、`元素`（多值，用 `|` 分隔）、`主色`、`柜体材质`。
- 框键：`f"{尺寸段} · {装} · {形态}"`，例 `30″ · 拆装 · 落地式`。扫描只用落地式 / 悬浮式。
- 一切份额、溢价、评分差、新品占比只在同一渠道、同一框内计算（AC-F20-02、AC-F29-02）。
- 被标为"不是本品类"的商品（Product.excluded）不进入任何分析。
- 标签取值：已确认值优先，其次自动值；queued 状态的自动值也参与（打标完成即可扫描，确认后重算覆盖）。
- 其他渠道月销 = VP × vp_coef + 非 VP × nonvp_coef（品类配置当前版本），合计按评论 ID 去重。

### `pdt/core/panel.py`（分析组提供，决策卡组调用）

- `load_panel(channel) -> DataFrame`：列 month, item_id, parent, family_key, series, brand, title, image_url, link, listed_at, price, units, revenue, rank, rating, ratings_count, age_months, frame, 及各标签列。
- `unit_timeseries(channel, frame, attr, value) -> list[dict]`：逐月 {month, units, share, newshare, frame_newshare, premium, median_price, rating, frame_rating, star}。
- `unit_skus(channel, frame, attr, value, top=20) -> list[dict]`：{item_id, link, image_url, brand, title, spec, first_month, months_listed, peak_month, peak_units, best_rank, first_top50, series:[{month, price, price_ratio, rating, units, rank}]}。
- `price_bands(channel, frame, attr, value) -> list[dict]`。

### `UnitScore.data`（模型组写，决策卡与台账读）

`{grasp, grade, share_now, pred_share, pred_lo, pred_hi, extra_units, k_months, prob_raw, prob_adj, n_families, made_rate, made_p, sources:{frame, months, n}}`

### `Opportunity.metrics`（扫描组写，决策卡读）

`{units, share, share_prev, dlog_share, families, per_family, per_family_ratio, rating, frame_rating, rating_diff, premium, median_price, newshare, frame_newshare, newshare_diff, newfam, newmade, frame_newfam, frame_newmade, frame_units, flags:{增长型, 评分缺口型, 价格缺口型, 坑}}`

## 测试

- 每个验收行（FLOW / RULE）至少一个 pytest 用例证明，文件名 `tests/test_<模块>.py`，用例 docstring 写对应 TDD ID。
- 期望值来自需求规则或第二轮结果文件，不用被测函数生成。
- 测试数据用真实中文业务数据（如 `30″ · 拆装 · 落地式`、品牌、商品标题），不用占位符。
- 运行：`cd app && python -m pytest -q`。
