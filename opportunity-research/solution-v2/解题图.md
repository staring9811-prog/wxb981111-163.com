# 解题图 · 第二轮（2026-10-28，草稿，待 wen 确认）

```
[决策] 立项评审：给候选机会排序，先做前几个（一年约 10–十几款，老板 + wen 拍板）
[机会单元] 语境 × 取值，逐月看。例：30″ · 落地 · Shaker × 岗石台面（主流是陶瓷台面）
[信号：第 t 月看得到的]
    溢价：比同语境主流取值贵多少
    供给：在卖占比、占比在变大还是变小、新进入速度
    成交：单位 ASIN 贡献
    现有产品没做好：评分低、差评集中在能改的问题
    外在：关键词增速、集中度、大牌
    **佐证：站内同类柜子上的同一元素、站外社媒和 Google Trends、国际大牌的产品线（wen 2026-10-29）**
  → [起量曲线] 信号出现后第 0–6 个月，这类产品（老品 + 新品）有没有起来、起来多少
        强度：信号越强，起来的比例高多少
        有效期：优势能持续几个月，之后被新进入者摊薄
  → [排序] 立项时（离上架约 3 个月）仍有效的信号，按"一般新品能成的比例"给机会排序
[结果] "起来了"两种都算、分开看：到线（第一次 BSR ≤ 50 或 SPU 月销售额 ≥ $10 万）、销量明显跳升；老品新品都看
       ↑                                                                   │
       └── 回测：只用当时看得到的数据 ←──────────── 每月回流 ←──────────────┘
外部环境：品类整体需求（关键词同比 2026 年持续为负）、平台政策
```

已清楚：
- 主题型更像预测/排序（两段新讨论；题型库"预测/排序"）。
- 成功线：BSR ≤ 50 或 SPU 月销售额 ≥ $10 万（2026-10-26）。
- 用法：给候选机会排序，先做前几个（2026-10-28）。
- 机会是"语境 + 换一个取值"，不是某个尺寸、颜色、元素本身重要（wen 以岗石台面为例，2026-10-28）。
- 老品也要分析：老品起来说明市场变了（2026-10-28）。
- "起来了"两种都算、分开看：到线和销量明显跳升（2026-10-28）。
- wen 能拉：2025 年月度商品表、新品全量导出、按属性为入口的关键词、竞品关键词。

还不清楚：
- **题型是否为"能力复制 + 预测"**：信号常突然出现、样本少，wen 目前 case by case 判断；AI 提议按语境类型各做一张证据卡，信号跟自身正常波动比分档，先用 wen 的分量合成，再用回放和台账校准。
- **语境类型**：新兴元素、成熟元素里的变体、同概念里的替代取值、规格/价位空白、老品复苏，是否覆盖、有无遗漏。
- **起量曲线是不是要的"更好的逻辑"**。
- 岗石台面案例的时间线：看到信号是哪个月，后来这类产品起来了没有。
- 执行（价格、评分、图片、广告）影响真的很小吗：wen 认为很小，待数据检验。
- 差评内容（如"容易碎"）从哪来：现有数据里没有评论原文。
