## 1. 四个词

- **候选**：一个维度的一个取值，如"台面材质 = 岗石""元素 = Fluted""尺寸 = 28″"。
- **基准**：拿来和候选比的那群产品。
- **信号**：候选在基准里能算出来的一个数（份额、溢价……），每月一个。
- **模式**：几个信号同时比平均高（或低）。一个模式对应一条开品路线。

## 2. 基准：一把梯子，不是一张固定格子

1. 从同尺寸开始，按"对价格影响从大到小"一层层加：尺寸 → 整装/拆装 → 柜体材质 → 台面材质 → 元素 → 台盆材质 → 形态 → 台盆位置 → 颜色 → 盆数。
2. 比哪个维度，就跳过哪一层（比台面材质时：尺寸 → 整装/拆装 → 柜体材质 → 元素 → …）。
3. 每加一层算一次信号；格子里其他家族少于 3 家就停。
4. 信号在每一层都成立才算稳；只在某一层成立，说明是那一层的属性带出来的。
5. 不随意两两、三三配对：组合有几百种，总有几个碰巧好看；梯子每个候选只比 3–5 次，顺序固定、能解释。
6. 机会本身带价位时（如 wen 的"把台面盆以同价做进现有形态"），价位段进基准：比的是同一价位里带不带这个属性。

排序依据（2026-01 至 09，同尺寸段里每个维度单独能解释多少价格差异）：

| 维度 | 解释价格差异 | 有标签的行 |
| :--- | ---: | ---: |
| 台面材质 | 60% | 47% |
| 整装/拆装 | 51% | 100% |
| 柜体材质 | 44% | 92% |
| 元素 | 20% | 26% |
| 台盆材质 | 18% | 74% |
| 形态 | 14% | 100% |
| 台盆位置 | 10% | 100% |
| 颜色 | 8% | 87% |
| 盆数 | 6% | 100% |

- 台面材质影响最大，但一半没标签，暂排在整装/拆装、柜体材质之后，补标后提到第二层。
- 品牌能解释 75%，但它不是产品属性，不进梯子，单独看集中度（候选的销量是不是一个大牌撑起来的）。
- 整装 = 到货已组装，拆装 = 要自己组装（打标规则 D2）。
- 例：岗石的溢价沿梯子是 全品类 2.71 倍 → 同尺寸 1.84 → 加整装/拆装 1.17 → 加柜体材质 1.30，与 wen 说的"比陶瓷贵一点"一致。

## 3. 信号

| 信号 | 怎么算 | 备注 |
| :--- | :--- | :--- |
| 份额 | 候选件数 ÷ 基准件数 | |
| 增长比 | 近 3 个月份额 ÷ 前 3 个月份额 | 要 6 个月历史 |
| 进入倾斜 | 新家族（上架 ≤ 3 个月）里选这个取值的比例 ÷ 现有家族里的比例 | 大于 1 = 新进来的人偏爱它 |
| 新品起量 | 上架 ≤ 3 个月就进前 100 的新家族数 | |
| 溢价 | 同一格子里候选与其他产品按件数加权的价格之比，各格再按候选件数合 | 量价格时不分价档 |
| 评分差 | 候选评分 − 同格其他产品评分（按件数加权） | 6–9 月评分是快照 |
| 单位 ASIN 贡献 | 份额 ÷ 家族数占比 | |
| 破顶销量占比 | 本月卖出的件数里，价格高过它自己同尺寸以前各月按件数算的前 10% 价格的比例 | 用子体自己的件数；要 3 个月历史 |
| 高价卖爆（单品） | 子体价格高过基准以前卖出件数的 90%，同时进前 100 | 用子体自己的销量，不用家族 BSR |
| 低价卖爆（单品） | 子体价格低于基准以前卖出件数的 10%，同时进前 100 | |
| 关键词缺口 | 搜索份额 − 销量份额，同一维度的各取值之间比 | 现在只有尺寸和少数词 |
| 关键词增速 | 同一批词近 3 个月比去年同期 | 要按属性打标的关键词 |
| 集中度 | 候选销量里第一大品牌占多少 | 分辨是"取值"还是"大牌" |
| 新品成功率（wen 原表） | 新品销量占比 ÷ 新品数量占比 | 三个月、半年、一年三档 |
| 平均新品渗透率（wen 原表） | 三档新品成功率之和 ÷ 3 | 原表排优先级的主指标 |
| 评分数贡献（wen 原表） | 销量 ÷ 评分数，一条评论带多少销量 | 越高，新品越不用堆评论，进入门槛低 |
| 新品单位 ASIN 贡献（wen 原表） | 新品销量 ÷ 新品 ASIN 数 | 三档 |
| 评级贡献（wen 原表） | 单位 ASIN 贡献 ÷ 平均评分 | 越高越不靠高评分也能卖，有改善空间 |
| 搜索转化率（wen 原表） | 月搜索 ÷ 月销 | |
| 佐证 | 站内其他柜类、站外：AI 读材料转成"有没有、从哪月开始、每月多少帖" | 数据待补 |

"比平均高"：和同月所有候选（维度 × 取值）一起排百分位。展示时用前 1/3；回放试"高于平均 / 前 1/3 / 前 10%"，档位只在 2025 年上半年挑。

## 4. 模式 = 信号组合（A 路规则）

| 模式 | 对应路线 | 什么时候算亮 | 现在能不能算 |
| :--- | :--- | :--- | :--- |
| 冒头 | 更好看（新元素、新材质、新尺寸） | 进入倾斜、新品起量、增长比在前列；佐证：关键词增速、站外 | 能；元素标签只覆盖约 1/4 |
| 需求被验证但没做好 | 更好用 | 起量或单位 ASIN 贡献高，溢价高，评分差为负 | 能；评分 6–9 月是快照 |
| 空档 | 填补空白 | 关键词缺口在前列；或份额低但单位 ASIN 贡献高 | 尺寸能，其他维度缺词 |
| 天花板被突破 | 更高端 | 破顶销量占比高，或出现高价卖爆的单品 | 能；"同元素里破顶"要元素标签 |
| 价格下探 | 更便宜 | 出现低价卖爆的单品，或便宜一档的份额在涨 | 能 |
| 跨品类冒头 | 场景创新 | 同一元素或功能先在别的柜类起来 | 要另拉其他柜类数据 |
| 存量结构变化、老品复苏 | 给上面加分 | 份额大幅移动；老家族排名大幅上升 | 能 |
| 技术突破、新物种 | — | 站内没有可比的历史 | 量化不了，人判断 |

模式量化的是路线适用条件里市场那一半；成本、设计、技术那一半由人判断。模式灵不灵，由 2025 年回放算：模式亮了以后，产品起来的比例是平均的几倍。
