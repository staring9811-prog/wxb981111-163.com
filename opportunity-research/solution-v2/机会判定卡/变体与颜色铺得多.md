# 机会判定卡：变体与颜色铺得多

> 判定日期：2026-11-02。依据：回归第四版（solution-v2/回归_新家族_第四版.md，冻结文件 留出检验_冻结_第四版.json）、第一次留出检验（留出检验_结果.md）。
> 品类：亚马逊美国浴室柜。变体数 = 首个在榜月家族里的子体数（尺寸 × 颜色等）；颜色数 = 首个在榜月家族里不同柜体颜色的个数。

## 一句话

**同尺寸、同价位档、同半年批次上架的新家族里，首月就铺了 ≥ 4 个子体、或 ≥ 2 个颜色的，6 个月内起来的比例比只有 1–2 个子体、或 1 个颜色的高 15–30 个百分点。** 变体和颜色说的是同一件事（颜色多，变体就多），合成一张卡。

## 判定

| 项 | 内容 |
| :--- | :--- |
| 方向 | 正面信号：新品起来的机会偏高 |
| 可信度 | **较可信**（变体数、颜色数两条都是） |
| 适用语境 | 落地 / 悬浮浴室柜新品；在同主尺寸段、同价位档、同半年批次里比 |
| 怎么量 | 首个在榜月的子体数、颜色数；高的三分之一 = 变体 ≥ 4、颜色 ≥ 2，低的三分之一 = 变体 ≤ 2、颜色 ≤ 1 |
| 有效期 | 到 2026-05 批留出检验出结果前有效；之后每批复核一次 |

## 证据

| 条目 | 同格差 前段 / 后段 | 格内能对上的品牌：高 / 低（前段；后段） | 碰巧的概率 | q |
| :--- | :--- | :--- | ---: | ---: |
| 变体数 | +21 / +14 | 39 / 49；33 / 50 | 0.018 | 0.12 |
| 颜色数 | +18 / +29 | 51 / 45；48 / 45 | 0.004 | 0.11 |

单位是百分点。前段 = 2024-10 至 2025-06 上架，后段 = 2025-07 至 2026-03 上架。

不分格时的起来比例（只作参考）：

| | 前段：高 / 低 | 后段：高 / 低 |
| :--- | :--- | :--- |
| 变体数 | 59%（51 家）/ 39%（75 家） | 45%（42 家）/ 29%（76 家） |
| 颜色数 | 53%（62 家）/ 43%（74 家） | 49%（65 家）/ 27%（67 家） |

按半年批次看：
- 颜色数三批都是高的起来得多：58% 对 41%，49% 对 39%，48% 对 25%。
- 变体数在 2025-04 至 09 这批反过来：高的 41%，低的 47%。

## 稳健性

| 检查 | 变体数 | 颜色数 |
| :--- | :--- | :--- |
| 换成"子体排名中位数 ≤ 50"判起没起来 | +16 / +4 | +13 / +13 |
| 只看首个在榜月还没过线的家族 | +25 / +17 | +12 / +29 |
| 逐个去掉每个品牌，最弱的一次 | +21 / +11（去掉 LIKIMIO），仍过初筛 | +14 / +29（去掉 Aitjunz），仍过初筛 |

- **"只看首月没过线"那一行最关键**：变体、颜色都是首月量的，首月就起来的家族，可能是起来以后才补的变体，倒因为果。去掉这些家族，差距仍在，说明不全是倒因为果。
- **变体数换成子体排名中位数判，后段只剩 +4**：家族排名取的是子体排名里最好的一次，子体越多，读到好排名的机会越多。这一项口径因素没法完全排除，所以颜色数这条更稳。

## 留出检验

- 第三版在 2026-04 批，方向都一致：颜色数 +32（能对上 10 / 4 个品牌），变体数 +57（5 / 4 个品牌）。样本小，只作记录。
- 第四版从 2026-05 批开始检验。

## 可能的解释（不是因果）

- 尺寸、颜色铺得多，能接住更多搜索：不同尺寸是不同的搜索词。家族排名按全部变体合计，铺得多更容易冲上去。
- 也可能是有实力的卖家才铺得多：备货、广告预算更足。这一点回归分不开。

## 限制和反例

- 有的家族是起来以后才补变体的，这一点已用"只看首月没过线"复核过，但没法完全排除。
- 变体数在 2025-04 至 09 那批方向相反。
- 子体多 → "最好一次排名"更容易好看，这个口径因素对变体数影响更大。
- 回归只说明先后和强弱，不说明铺得多就会起来。

## 开发怎么用

1. **立项方案里写清首发的子体规划**：至少 2 个颜色；尺寸 × 颜色合计 4 个子体以上，作为加分项。
2. **优先多铺颜色，而不是只堆尺寸**：颜色数这条更稳，而且三批方向都一致。
3. **和"陶瓷一体盆台"那张卡一起用**：做陶瓷一体时，多颜色、多变体是首选的差异化。
4. **成本另算**：铺得多要备更多货，这张卡只说起来的机会，不算库存风险。

## 什么情况下这张卡要改

- 2026-05 起的留出批次里方向连续反过来，或累计差距不到 5 个百分点。
- 用 2024-10 至 2025-12 补拉的子体销量能看到首月之后才补的变体：如果起来的家族大多是先起量、后扩变体，这张卡要降档。
