# 机会判定卡：陶瓷一体盆台

> 判定日期：2026-11-02。依据：回归第四版（solution-v2/回归_新家族_第四版.md，冻结文件 留出检验_冻结_第四版.json）、子体销量核对（数据准备/子体核对_主尺寸与36寸.md）、第一次留出检验（留出检验_结果.md）。
> 品类：亚马逊美国浴室柜。数据：卖家精灵 2024-10 至 2026-09，打标技能 v12.2，看图标签覆盖全市场。

## 一句话

**同尺寸、同价位档、同半年批次上架的新家族里，配陶瓷一体盆台的，6 个月内起来的比例比配其他台面的低约 20 个百分点；在 36″、24″ 格子里差得更多，30″ 看不出差别。**

这是"挤进来的人太多"的信号，不是"陶瓷一体卖得不好"：陶瓷一体的销量份额一直在涨，从 22% 到 39%。开发上的意思是：**新品如果只是"又一个陶瓷一体"，起来的机会偏低，要靠别的差异化。**

## 判定

| 项 | 内容 |
| :--- | :--- |
| 方向 | 负面信号：新品起来的机会偏低 |
| 可信度 | **较可信**（单条和 36″、24″ 三条都是；30″ 没过初筛） |
| 适用语境 | 落地 / 悬浮浴室柜新品；比的是同主尺寸段、同价位档（同月同尺寸段中位价 ±15% 为中档）、同半年上架批次 |
| 成功线 | 上架后 6 个月内任一月小类 BSR ≤ 50，或 SPU 月销售额 ≥ $10 万 |
| 有效期 | 到 2026-05 批留出检验出结果前有效；之后每批复核一次 |

## 稳健性

| 检查 | 陶瓷一体（前段 / 后段） | 陶瓷一体 × 36″ |
| :--- | :--- | :--- |
| 换成"子体排名中位数 ≤ 50"判起没起来 | −19 / −27 | −39 / −35 |
| 只看首个在榜月还没过线的家族 | −11 / −24 | −27 / −38 |
| 逐个去掉每个品牌，最弱的一次 | −14 / −21（去掉 SOLIDEE），仍过初筛 | −40 / −35（去掉 AmbroVania），仍过初筛 |
| 36″ 占家族销量的高低 | — | 36″ 占一半以上的 20 个家族起来 35%，不到一半的 27 个起来 33%，差不多 |

最后一项说明，36″ 那条不是 36″ 特有的，是陶瓷一体整体的规律在 36″ 格子里的表现。

## 留出检验（真正没参与筛选的数据）

- 第三版在 2026-04 批：15 个家族，陶瓷一体单条同格差 −17，方向一致；格内只对上 6 / 3 个品牌，只作记录。
- 第四版从 2026-05 批开始检验，要等真正的 10 月数据。

## 可能的解释（不是因果）

- 陶瓷一体是主流做法，份额和新家族数一直在涨，同一价位里挤进来的人多，每个新家族起来的机会就小。
- 后段比前段差距更大，和"进来的人越来越多"一致。

## 限制和反例

- 有一部分陶瓷一体是按"盆材已知、没写台面 → 一体盆台"推断出来的（打标规则 v12.2）。
- 陶瓷一体照样有起来的：两段合计 40 个，几乎都是靠排名进前 50。反例：Aitjunz 单位 B0DM28THG8，30″，中位价 $300，2024-11 上架，最好排名第 1，最高月销售额 $123k。
- 30″ 看不出差别（前段 +5、后段 −20），这个规律不是每个尺寸都成立。
- **和 wen 2026 年规划的回放有张力**：回放里"陶瓷一体盆 + fluted"（SPU5）被验证了。第四版没有检验"台面 × 元素"组合，因为它不在预先指定的三组里，所以这张卡不能否定"陶瓷一体 + 有辨识度的元素"这条路。要验证它，只能当新候选，在留出批次上检验。
- 回归只说明"有它的新家族后来起来得少"，不说明是陶瓷一体造成的。

## 开发怎么用

1. **立项打分**：候选方案是陶瓷一体的，在同尺寸、同价位的基础胜率上**扣分**，扣多少等留出检验累计后再定。在评审会上列为"需要差异化理由"的项。
2. **要做陶瓷一体时，至少要有一项差异化**，而且最好是在回归里本身就有正面信号的：
   - 颜色、变体铺得多：颜色数、变体数都是较可信的正面信号；
   - 看得见的元素：竖棱、农场风饰条，目前是有迹象或存疑；
   - 避开最挤的尺寸价位格。
3. **同尺寸可以考虑树脂一体盆台**：36″ 的信号最强，但前后段各只有 5 个品牌，先小批量试，不要当成确定结论。
4. **不要据此砍掉陶瓷一体的老款**：这条只说新进来的家族，老款的销量份额还在涨。

## 什么情况下这张卡要改

- 2026-05 起的留出批次里，同格差方向连续反过来，或累计后差距不到 5 个百分点。
- 打标规则改了"一体盆台"的推断方式。
- 陶瓷一体的新家族数明显减少，进来的人少了，"挤"的解释就不成立了。
