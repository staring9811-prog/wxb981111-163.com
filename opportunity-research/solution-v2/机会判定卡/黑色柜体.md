# 机会判定卡：黑色柜体

> 判定日期：2026-11-02。依据：回归第四版（solution-v2/回归_新家族_第四版.md，冻结文件 留出检验_冻结_第四版.json）、第一次留出检验（留出检验_结果.md）。主色 = 首个在榜月家族里最多的柜体颜色。

## 一句话

**同尺寸、同价位档、同半年批次上架的新家族里，主色是黑色的，6 个月内起来的比例比其他颜色低约 20 个百分点。** 黑色的销量份额在涨，但涨的多是已经在榜的老款，新进来的黑色家族起来得少。

## 判定

| 项 | 内容 |
| :--- | :--- |
| 方向 | 负面信号：新品起来的机会偏低 |
| 可信度 | **较可信**，但样本小，前段的稳健性偏弱 |
| 适用语境 | 落地 / 悬浮浴室柜新品；在同主尺寸段、同价位档、同半年批次里比 |
| 有效期 | 到 2026-05 批留出检验出结果前有效；之后每批复核一次 |

## 稳健性

| 检查 | 同格差 前段 / 后段 |
| :--- | :--- |
| 换成"子体排名中位数 ≤ 50"判起没起来 | −35 / −14 |
| 只看首个在榜月还没过线的家族 | −13 / −7 |
| 逐个去掉每个品牌，最弱的一次 | −11 / −20（去掉 DWVO），仍过初筛 |

只看首月没过线的家族时，差距缩到一半左右。部分黑色款可能是起来以后才加的颜色，前段尤其要小心。

## 留出检验

- 第三版在 2026-04 批：同格差 −100，方向一致，但只对上 1 / 2 个品牌，说明不了什么。
- 第四版从 2026-05 批开始检验。

## 可能的解释（不是因果）

- 黑色份额在涨，涨的多是已在榜的老款，新进来的黑色家族要和这些老款抢。
- 黑色的中位价在往上走（$229 → $300），新款可能在价位上不占优。

## 限制和反例

- 每段只有 10–14 个品牌，样本小。
- 起来的黑色家族只有 7 个，其中 5 个靠排名、3 个靠销售额。
- 反例：YITAHOME 单位 B0F4XR6CJ2，主色黑，18″/24″/36″，中位价 $200，2024-12 上架，最好排名第 2，最高月销售额 $155k。
- 主色只取首月最多的那个颜色，多色家族里黑色只是其中一个颜色的，不算"黑色"。

## 开发怎么用

1. **黑色不宜作为新品唯一的主色**：首发以其他颜色为主，黑色作为补充色。这也和"颜色铺得多"那张卡一致。
2. **立项时如果主打黑色**：要有价位或尺寸上的理由，比如老款覆盖不到的尺寸，并在评审会上说明。

## 什么情况下这张卡要改

- 2026-05 起的留出批次方向反过来，或累计差距不到 5 个百分点。
- 黑色新家族数明显增加、而且起来的比例回升。
