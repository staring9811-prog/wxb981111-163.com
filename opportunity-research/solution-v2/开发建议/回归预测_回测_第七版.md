## 1. 回归式（站在 2026-01 估出来的系数）

训练样本：4,965 个（单元 × 时点 × 预测窗口），时点 2025-04 至 2025-10，结果都在 2025-12 前已知。

份额对数变化 = a + θ·(k/3) + Σ (b + c·(k/3))·x。k = 往后第几个月起的 3 个月（0 = 下个季度，3 = 立项后上架那 3 个月，6 = 再往后）。

| 特征 | 意思 | b（k = 0 时） | c（每多 3 个月加的） |
| :--- | :--- | ---: | ---: |
| b6 | 份额斜率（近 6 个月每月对数变化） | +0.793 | +0.468 |
| x2 | 新进家族（相对增长） | -0.104 | -0.074 |
| x3 | 搜索同比 | -0.003 | +0.106 |
| x4 | 体量（ln 月均销，中心化） | +0.015 | -0.001 |
| 截距 | | a = -0.060 | θ = -0.053 |

80% 区间（训练残差 10% / 90% 分位，对数）：
- 300–1,000 件：-0.45 至 +0.37（约 ×0.64 至 ×1.44），标准差 0.33，1517 个样本
