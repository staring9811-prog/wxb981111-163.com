## 3. 实测：前 N 覆盖与换手

### 3.1 前 N 覆盖（评论量随排名递减 → 外推长尾）

做法：每个类目按 Top Sellers 排名，家族按它最靠前的商品页排名计一次（同一家族不重复算）；看各排名段家族 2026-01 至 10 的重建月销合计。再用排名 51–300 的家族拟合 ln(月销) = a + b·ln(排名)（只用有评论的家族，0 评论的单列），外推到类目里全部家族。类目家族总数 = 页面显示的商品总数 ÷ 每个家族平均有评论的变体数（样本里算的），这一步只能给量级。

- **带台面**：前 300 个商品页合并成 100 个家族（其中 1 个 2026 年没有评论）；拟合斜率 b = -1.27；每个家族平均 10.9 个有评论的变体，类目约 4,448 个家族；外推的长尾月销约 6,363，前 300 覆盖约 **73%**，前 200 覆盖约 **66%**（前 200 占前 300 的 91%）。
- **无台面**：前 300 个商品页合并成 119 个家族（其中 48 个 2026 年没有评论）；拟合斜率 b = -0.80；每个家族平均 8.1 个有评论的变体，类目约 767 个家族；外推的长尾月销约 1,853，前 300 覆盖约 **58%**，前 200 覆盖约 **52%**（前 200 占前 300 的 91%）。

外推的不确定性：斜率按幂律外推到上万个家族，长尾量对 b 很敏感（b 越接近 −1，长尾越大）；页面"商品总数"含大量零销量的第三方页，按它算家族数会高估长尾。所以外推覆盖率是**下限的量级**，更可靠的是"201–300 名占前 300 的比例"这个直接观察。

## 7. 结论

**Home Depot 能不能用回测思路**（判据：秩相关全部单元 ≥ 0.15 / 大单元 ≥ 0.25，打折后仍为正；D 档 ≥ 20 个且打折后变大比例比全部单元低 ≥ 10 个百分点）：
- 框 × 属性：每个 T0 平均 257 个单元（大单元 75 个）；预测秩相关 全部 / 大 +0.12 / +0.39（打折后约 +0.02–+0.07 / +0.29–+0.34）；把握 ≤ 30% / 30–50% / 50–70% / ≥ 70% 之后变大 36% / 43% / 53% / 61%（全部单元 43%）；D 档 22%（193 个）；方向对（大）67%。→ 全部单元排序弱（打折后接近 0），不能用；大单元排序可用；坑（D 档）认得出。
- 只按框：每个 T0 平均 22 个单元（大单元 15 个）；预测秩相关 全部 / 大 +0.09 / +0.10（打折后约 -0.01–+0.04 / +0.00–+0.05）；把握 ≤ 30% / 30–50% / 50–70% / ≥ 70% 之后变大 50% / 39% / 59% / 38%（全部单元 46%）；D 档 41%（27 个）；方向对（大）57%。→ 全部单元排序弱（打折后接近 0），不能用；大单元排序不可用；坑（D 档）认不出。 每个 T0 单元数 < 30，样本太少，只能参考。
- 大属性（不分框）：每个 T0 平均 43 个单元（大单元 34 个）；预测秩相关 全部 / 大 +0.18 / +0.28（打折后约 +0.08–+0.13 / +0.18–+0.23）；把握 ≤ 30% / 30–50% / 50–70% / ≥ 70% 之后变大 44% / 49% / 56% / 71%（全部单元 53%）；D 档 38%（8 个）；方向对（大）62%。→ 全部单元排序可用；大单元排序可用；坑（D 档）个数太少，不可读。
- **能支持的最小粒度**：框 × 属性每个 T0 有约 257 个单元（≥ 30），粒度够；只按框只有约 22 个，太少。概率（把握的绝对值）、方向对、A 档都按偏差模拟的打折规则看，不直接用。

**要多大的 N**：
- 带台面：前 200 名占前 300 重建销量的 91%，即 201–300 名还贡献 9%；外推覆盖 前 200 约 66%、前 300 约 73%（量级）。
- 无台面：前 200 名占前 300 重建销量的 91%，即 201–300 名还贡献 9%；外推覆盖 前 200 约 52%、前 300 约 58%（量级）。
- 偏差模拟的要求是"前 N 占类目当前销量约 90% 以上"。按外推（量级），前 300 还达不到；201–300 名仍贡献约一成，说明前 300 还没到饱和。在本次数据上 N = 300（每个类目）是下限，再深要看 400–500 名的增量；小单元受长尾缺失影响最大，所以只看大单元。
- 换手：今天前 300 的家族里，2026-04 至 06 与 08 至 10 前 50 名重合约八成（§3.2），这是幸存者口径的上限。

**哪些信号可用**：
- 框 × 属性：仅 b6 秩相关 全部 / 大 +0.10 / +0.16；仅 x5 +0.14 / +0.28。

## 8. 局限

1. 评论 × 系数换算月销：VP × 50、非 VP × 20 是系统默认，没有按 HD 校准（不同价位、品牌的留评率不同）；品牌站转载评论按 hdp.py 口径计入（占比见 §1）；1 条 VP 评论 = 50 件，小单元月度颗粒很粗。
