# 跨渠道供给丰富度差距：在 Home Depot 重建面板上的检验

> 由 `trial/跨渠道供给差_HD检验.py` 生成，数字都是脚本实际输出。HD 面板与 `小平台_HD回测小试.md` 同口径（评论重建 2024-01 至 2026-10，框 × 属性，T0 = 2025-04 至 2026-02，目标 = 立项后第 6–8 个月份额相对近 6 个月的对数变化 y6）；Amazon 用第九版同一张统一打标表（2024-10 至 2026-09）。

> 面板核对：重建后仅 b6 秩相关 全部 / 大 +0.10 / +0.16，仅 x5 +0.14 / +0.28（小试报告 §5.1：+0.10 / +0.16，+0.14 / +0.28），与小试一致。

## 0. 摘要

- 定义：G家族 = ln((Amazon 家族数 + 1) / (HD 家族数 + 1))，同一尺寸段 × 形态 × 属性取值（忽略装），T0 前 6 个月；另有价位段差、子体差、主色差、份额差、"需求已证明 × 稀缺"交互等版本。
- 回归（加在 b6、x5、x2、x4 之上，T0 × 属性类型固定效应，按单元聚类）：G家族 +0.117（t +3.52，p 0.000）；拆开后 Amazon 侧 +0.148（t +4.32），HD 侧 +0.066（t +2.00，方向与"稀缺"相反）。
- 区分力（跨单元 5 折交叉验证，11 个 T0 平均秩相关 全部 / 大）：基础 +0.11 / +0.11 → 加 G家族 +0.17 / +0.20；只加 Amazon 侧家族数 +0.22 / +0.21、Amazon 外观组合 +0.23 / +0.26（事后比较）；严格同装对齐无提升；只看大单元无提升（"需求已证明 × 稀缺"交互例外）。
- 结论：有中等强度、需要打折的证据说明"Amazon 侧款多、份额大 → HD 之后份额上升"（HD 结构向 Amazon 靠）；"HD 少所以会涨"不成立。决策卡上作"经回测（打折）"的证据和全部单元的排序加分，不作独立立项理由；大单元和 HD 完全没有的单元只作参考。

## 1. 信号定义

单元 u = 框 × 属性取值（属性：台面材质 / 元素 / 主色 / 柜体材质）；时点 T 只用 T−6 至 T−1 这 6 个月。两侧丰富度都只数窗口内**有销量**的家族 / 子体（HD：有评论 → 重建销量 > 0；Amazon：导出里月销 > 0）。

| 量 | 公式（两侧同口径） |
| :--- | :--- |
| 家族数 N_fam | 窗口内单元里有销量的不同家族（HD 评论家族 / Amazon 家族键 ≈ 父体） |
| 有效家族数 N_eff | 1 / Σ_f s_f²，s_f = 家族在单元窗口销量里的占比（小家族几乎不计，抗"导出深浅、评论门槛不同"） |
| 子体数 N_var | 有销量的不同子体（HD 商品页 / Amazon 子 ASIN）= 颜色、尺寸等变体 |
| 价位段数 N_pb | 子体价格落在几个绝对价位段：$0–200 / 200–300 / 300–450 / 450–650 / 650–900 / 900–1,300 / 1,300+（7 段，两渠道共用） |
| 相对价位段数 N_pr | 价格 ÷ 同渠道同尺寸段 × 装 中位价，按 <0.7 / 0.7–0.85 / 0.85–1.15 / 1.15–1.5 / >1.5 分 5 档，覆盖几档 |
| 主色数 N_col | 有销量子体的已知主色种类（属性 = 主色的单元记 0 差距） |
| Amazon 外观组合 | Amazon 单元内 看图元素 × 主色 的组合数（只 Amazon 单侧：HD 元素靠文字只认出约 6% 销量，量不出，不做差） |
| Amazon 需求 | 框内份额 s_AZ = 单元销量 ÷ Amazon 同框该属性已知销量；框内斜率 = 近 6 个月 ln(框内份额 + 0.01) 的线性斜率 |

差距信号（越大 = Amazon 越丰富、HD 越少）：

- **G家族** = ln((N_fam^AZ + 1) / (N_fam^HD + 1))（主定义）；G有效家族、G子体 同式；
- **G价位段** = N_pb^AZ − N_pb^HD；G相对价位段 = N_pr^AZ − N_pr^HD；G主色数 = N_col^AZ − N_col^HD；
- **D份额** = ln(s_AZ + 0.01)（Amazon 需求已证明的程度）；**D斜率** = Amazon 框内斜率（需求在涨）；**D份额差** = ln((s_AZ + 0.01) / (s_HD + 0.01))，s_HD = HD 同框内份额（需求结构差）；
- **交互**：z(D份额) × z(G家族)（需求已证明 × 供给稀缺）；另一版用 1[s_AZ 在样本上半 且 D斜率 > 0] × G家族。

**框的对齐**。2026 年 HD 重建销量 80% 是整装、Amazon 90% 是拆装，按"尺寸段 × 装 × 形态"严格对齐时，HD 的大框（30″ / 24″ / 36″ 整装）在 Amazon 只对上很薄的整装市场。所以给两种：
- **忽略装（主口径）**：两侧都按 尺寸段 × 形态 × 属性取值 汇总丰富度和框内份额（整装、拆装合并），再挂到 HD 单元上（同尺寸同属性的 HD 整装单元、拆装单元拿到同一个差距值）；
- **严格**：尺寸段 × 装 × 形态 × 属性取值 两侧各自算；Amazon 同框窗口内没有销量的单元，差距照算（Amazon 记 0），另报 Amazon 同框有销量的子样本。
- 标签：两侧都用 v12.2 打标规则的同一套取值（台面材质 D8、主色 D6 → 主色、柜体材质 D7（价格复核前）→ 归类、宽 → 尺寸段）；元素 Amazon 用看图标签归到 HD 文字规则能认的 6 类（夏克式 / 竖棱 / 农场风装饰饰条 / 玻璃门 / 木条格栅 / rattan），其余 Amazon 元素不参与对齐。价格：Amazon 用当月价；HD 只有 2026-11-03 当天的价（历史价拿不到），所以 HD 价位段是"今天的价套到过去"。

## 6. 推导：为什么会有用、为什么"稀缺"本身不起作用

1. **起作用的是 Amazon 那一头，不是 HD 那一头**。把 G家族拆成两头（§2.1），Amazon 家族数 +0.148（t +4.32），HD 家族数 +0.066（t +2.00）——HD 家族多的单元之后**不是**更差，反而略好；份额差也一样：Amazon 框内份额 +0.096（t +3.19），HD 框内份额 -0.051（t -1.70）。所以数据支持的读法是"**HD 的结构在往 Amazon 的结构靠**"（Amazon 上款多、份额大的尺寸 × 属性，HD 之后份额往上走），而不是"HD 供给少 → 有缺口 → 会涨"。差距信号有效，是因为它里面装着 Amazon 侧的丰富度；单看 Amazon 侧丰富度，区分力反而更好（§3 表：只看 Amazon 家族数 全部 / 大 +0.22 / +0.21，只看 Amazon 外观组合 +0.23 / +0.26，G家族 +0.17 / +0.20）。这两个"只看 Amazon"的版本是看到拆开结果后加的比较，属于事后选择，按同样的打折读。
2. **靠拢一部分靠新家族进来，一部分靠老家族变大**（§3.3）：差距高的 1/3，第 6–8 个月单元销量里新家族占 22%，低的 1/3 只有 13%；只算老家族的 y6老 对 G家族 仍为 +0.055（p 0.034），为全 y6 系数的 47%。进来的是谁：2026 年 HD 重建销量里自有品牌（Glacier Bay / Home Decorators Collection）占 74%，非自有品牌里同时在 Amazon 表里出现的品牌占全部销量的 21%（51 个家族 / 共 170 个）；2025 年起才有销量的新家族，销量里 7% 来自这些 Amazon 也在卖的品牌、84% 是自有品牌。§5 的例子里 HD 30″ / 24″ 黑色柜的主要家族也有 eclife、DELUXE DL LIVING 这类两边都卖的品牌，但量小。合理的推断：HD 的新款主要由买手通过自有品牌上（新家族销量大头是自有品牌），买手跟的是整个市场的款式走向，Amazon 款多、卖得多的尺寸 × 属性正好是这个走向更早、更全的读数；第三方 / 直发卖家把 Amazon 款搬过来是次要通道。于是 HD 的尺寸 × 属性结构滞后地向 Amazon 靠。这是推断，数据只能说明"先后和同向"，不能说明因果。
3. **"稀缺"本身为什么不起作用**：HD 的结构不是由"消费者想要但没货"决定的，而是由门店模式和买手决定的——重建销量 80% 是整装（门店 / 送货上门、免组装）、自有品牌占约 74%、按销量加权的价格中位数 $699（Amazon $260；HD 用今天的价）。HD 某个单元家族少，常常是有意不做（例如陶瓷一体台面、木板台面在 HD 前 300 里几乎没有，§5.2），不等于有一块没满足的需求；HD 家族多的单元往往是 HD 正在加码的方向，所以 HD 侧系数为正。
4. **严格对齐（同装）时差距基本失效**（G家族 +0.043，p 0.191；交叉验证 全部 / 大 +0.11 / +0.11 → +0.11 / +0.11）：Amazon 整装只占约 10%，同装对齐后 Amazon 侧家族数很薄、噪声大。信息来自 Amazon 整个"尺寸段 × 形态 × 属性"的偏好（主要是拆装货），不是同装的一对一对照。严格对齐下仍然显著的是 D份额差（+0.116，p 0.000），拆开是 Amazon 框内份额 +0.094（t +3.12）和 HD 框内份额 -0.110（t -3.98）两头都有：同装框里 HD 份额低的单元之后回升，这一半是 HD 内部的变化（也可能是均值回归），不是跨渠道信息；跨渠道的那一半仍是 Amazon 侧。
5. **大单元里不一样**：只看大单元（≥ 200 件），G家族单独不显著（+0.051，p 0.160），交叉验证也没有提升；倒是"需求已证明 × 供给稀缺"的交互显著（+0.112，p 0.001），把交互放进去交叉验证从 +0.32 到 +0.35。也就是说，在已经有量的 HD 单元里，只有"Amazon 份额大且 HD 家族少"同时成立时才多涨一点；12 个稳健性设定里交互 p < 0.05 的只有 1 个，又是事后看到的，只能当线索，不能当结论。大单元里只看 Amazon 外观组合为 +0.064（p 0.093）。
6. **幸存者偏差会把它往好看的方向推**：HD 面板只看得到今天在前 300 的家族。差距高的单元里约两成之后销量来自新家族，而新家族里进来又掉出前 300 的失败者看不到，所以"新家族进来"那一半最容易被高估；老家族那一半（y6老）受影响小一些。按偏差模拟的打折规则，秩相关减 0.05–0.1。

## 7. 结论与决策卡用法

- **能检验出来的**：在 HD 框 × 属性面板上，扣掉 b6、x5、x2、x4 和 T0 × 属性类型固定效应后，跨渠道差距（忽略装，G家族）系数 +0.117（每 1 个标准差），t +3.52，p 0.000；11 个 T0 的偏相关 11/11 为正（+0.07 至 +0.23）；去掉最大单元 / 最大框、按框聚类、截尾、去掉元素单元都还显著（8 个忽略装设定 p < 0.05）。跨单元交叉验证的秩相关 全部 / 大 +0.11 / +0.11 → +0.17 / +0.20（+0.06 / +0.09），五分档"之后变大"从低到高更单调。打折后（减 0.05–0.1）约 +0.07–+0.12 / +0.10–+0.15。
- **站不住或没检验到的**：严格同装对齐不显著；只看大单元不显著；拆装单元只到 p ≈ 0.1；不显著的设定：严格，全部、严格，Amazon 同框有销量、忽略装，只看大单元（≥ 200 件）、忽略装，只看拆装单元。"需求已证明 × 供给稀缺"交互在全部单元上为 0（+0.012，p 0.729），只在大单元里显著。Amazon 份额走势（D斜率）没有作用。HD 侧"家族少"本身没有正向作用。只有 11 个相互重叠的 T0、一个渠道一个品类，交叉验证是跨单元的、不是跨时间的。
- **怎么命名**：数据支持的是"**Amazon 结构领先**"（Amazon 上款多、份额大的尺寸 × 属性，HD 之后往那边靠），不是"HD 供给缺口"。卡片上主读数用 Amazon 侧丰富度（家族数、外观组合），差距值（G家族）和 HD 侧家族数作对照展示；解读写成前者。
- **决策卡上怎么用**：
  1. 作为 HD 机会卡的**证据项，等级"经回测（打折）"**：展示 Amazon 与 HD 两侧的家族数、子体数、价位段、框内份额和走势，以及差距值；用于 HD 全部单元的排序加分（同等 b6、x5 下优先 Amazon 侧丰富的单元），不单独作为立项理由；
  2. **大单元只作参考**：大单元里单独的差距不加分；"Amazon 份额大 + HD 家族少"同时成立时标"线索"，等下一个渠道（Lowe's / Wayfair）或滚动到 2026 年后的新 T0 复验；
  3. **HD 完全没有的单元**（如 36″ / 48″ 陶瓷一体台面、木板台面）在回归样本外，差距最大但不能外推；要回答的是"HD 买手为什么不做"（门店整装、品类规划、退货率），属于渠道调研问题，卡上写"未验证"；
  4. 用的时候按忽略装对齐（尺寸段 × 形态 × 属性取值），HD 主色约三成认不出、元素几乎认不出，主色 / 元素单元的 HD 侧家族数要标"可能少算"。

## 8. 局限

1. 两侧的"家族数"都不是全市场在售数：Amazon 表是每月导出的头部（2024-10 至 2026-09 每月 151–274 个有销量的家族，2026 年导出更深），HD 是今天两个类目前 300 个商品页所在的家族（幸存者）。差距是"头部丰富度"的差距；Amazon 导出深浅随月变化的部分被 T0 固定效应吸收，不同单元受影响不同的部分吸收不了。
2. HD 只有 2026-11-03 当天的价，价位段是今天的价套到过去；Amazon 用当月价。
3. HD 主色约三成、元素九成以上认不出（只用文字规则），主色 / 元素单元的 HD 侧丰富度偏低、差距偏大；去掉元素单元结论不变（§4），主色单元没单独去掉。
4. 只有 11 个相互重叠的 T0（2025-04 至 2026-02），同一单元跨时点重复，t 值按单元聚类仍可能偏乐观；交叉验证是跨单元的，不是跨时间的；只有一个渠道、一个品类。
5. HD 月销 = VP 评论 × 50 + 非 VP × 20，没有按 HD 校准；小单元月度颗粒粗（1 条 VP 评论 = 50 件）。
