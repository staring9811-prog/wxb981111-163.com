# 逻辑拆解 v1（解题 v2，2026-10-28，待 wen 拍板）

## 1. 对象
- 候选 = （语境 C，动作 A）。语境是固定下来的变量取值，动作是要改的变量取值；两者合起来是一个（可能不完整的）产品规格。
- 结果 Y：6 个月内小类 BSR ≤ 50 或 SPU 月销售额 ≥ $100,000（用户确认，只看销量和排名）。
- 过程 Y′：第 3 个月销量 ÷ 同语境新品中位数（候选：首月表现、增长、实现溢价）。

## 2. 核心公式
P = 成功概率(C, A)，由模型从过去新品的属性、价格位置、环境变量和结果估出。
- 锦囊：Δ = P(C, A) − P(C, A₀)，A₀ 为该语境的默认做法；附样本量、可信度。
- 排序：按 P(C, A) 排，辅助评审会决策。
- 验证：结果回流后比较预测 P 与实际命中率，更新可信度与锦囊状态。

## 3. 粒度
锦囊可在任意粒度（宏观：只固定尺寸；中观：固定材质改元素；微观：固定多数变量改一个），形态相同。粒度由数据决定：样本够且子语境间有差别才继续切。

## 4. 规则
1. 粒度由数据定，不由人定。
2. 粗锦囊必须在子语境里不反转，有反转就降到更细层级输出。
3. 动作永远相对默认做法。
4. 可信度低于门槛不出锦囊，门槛由留批次检验确定。
5. 人工锦囊与 AI 锦囊同一对象、同一验证方法；模型不学人的经验。

## 5. 模型输入
进：打标属性、价格相对语境位置、变体数、配送方式、品牌实力、上架月份、上架时语境的市场统计量（机械计算）。
不进：人的结论。

## 6. 软件分工
固定在软件里：结果定义、变量清单与表头、模型种类、检验规则、可信度门槛、锦囊模板。
每次重算：变量重要性、分量、锦囊内容、可信度、失效锦囊。锦囊带版本与状态。
