# A 路判断标准（第二稿，2026-10-29，对齐 wen 的原分析表）

> 来源：wen 的飞书表"vanity 市场分析"（公开只读；用 2025-09 数据，结论约 2025-11 写成）。指标公式从原表透视表的计算字段读出，判断方式从"尺寸 / 元素 / 形态市场分析""两个大机会方向"各页的结论、机会点、方向动作读出。
> 用途：在 2025 年数据上逐月按这套标准回放（A 路），和 B 路（模型从历史里学）比较。
> 门槛：仍不设固定数字。原表的比法是和同一维度的其他取值、品类平均比（"全尺寸最高""持平品类平均 9.1"）；回放时试"排第一 / 前 1/3 / 高于平均"几档，档位只在 2025 年上半年挑，2025 下半年至 2026 年只用来检验。

## 1. 分析单元与时点

- 单元：一个维度的一个取值，维度用原表的：尺寸范围、元素、形态、颜色、是否带台面。原表的"形态"有 9 种：站立四角、镂空收纳、四方封闭、封闭立脚、侧边开放、拐角、悬浮式、悬浮+侧边、pedestal。
- 交叉格：元素 × 形态、元素 × 尺寸、形态 × 尺寸、价格段 × 尺寸 / 元素 / 是否带台面，用来找还没铺开的地方。
- 时点：每月一个快照（原表用 9 月）。新品按上架时间分三档：三个月、半年、一年新品（相对快照月）。
- 销量用 ASIN（子体）销量，评分数用评分总数。

## 2. 指标（原表公式）

| 组 | 指标 | 公式 | 原表怎么读 |
| :--- | :--- | :--- | :--- |
| 体量 | ASIN 数、平均价格、销量、销售额 | 销售额 = 销量 × 价格 | |
| 效率 | 单位 ASIN 贡献 | 销量 ÷ ASIN 数 | 越高越好；老品高说明这个取值经过一段时间有了跃升，新品高说明上架后很快拿到销量 |
| 效率 | 新品单 ASIN 贡献（三档） | 新品销量 ÷ 新品 ASIN 数 | |
| 新品 | 新品占比、新品销量占比（三档） | 新品 ASIN 数 ÷ 全部 ASIN 数；新品销量 ÷ 全部销量 | |
| 新品 | 新品成功率（三档） | 新品销量占比 ÷ 新品占比 | 例：fluted 三个月新品 4% 的数量撬动 28% 的销量，成功率 658% |
| 新品 | 平均新品渗透率 | 三档新品成功率之和 ÷ 3 | 排优先级的主指标 |
| 口碑 | 平均评分、三档新品评分 | | 新品评分和存量持平说明口碑稳 |
| 口碑 | 半年新品评分变化 | （半年新品平均评分 − 全部平均评分）÷ 全部平均评分 | |
| 门槛 | 评分贡献（综合、三档新品） | 销量 ÷ 评分数 | 全部链接越低，竞争越激烈；新品越高，越不用堆评论 |
| 改善空间 | 评级贡献（综合、三档） | 单位 ASIN 贡献 ÷ 平均评分 | 越高，说明不靠高评分也能卖，有改善空间 |
| 需求 | 月搜索量、24–25 年 CAGR | | 尺寸、关键词类别（材质、颜色、场景、配置、尺寸、风格） |
| 需求 | 超额增长 | 关键词增长率 − 平均增长率 | 看哪些词获得了超额增长 |
| 需求 | 搜索转化率 | 月搜索 ÷ 月销 | |
| 需求 | 搜索销量 Gap | 搜索量占比 − 销量占比 | 原表"尺寸关键词-销量对比"；28″ 的缺口就是这样看出的 |
| 竞争 | 链接数；新品扎堆在哪几个形态；自然位 | | 例：fluted 66 个链接、夏克式+纹路 11 个；小众元素拿到高自然位的权重高 |
| 可行性（人判断） | 成本、利润率、低于市场均价 %、运输破损、广告占比 | | 例：台面要先突破"成本""运输技术" |

## 3. 判断步骤（原表的做法）

1. **每个维度给取值排优先级。**
   - 第一优先级"抓短期红利"：平均新品渗透率、三个月新品成功率、新品单 ASIN 贡献、新品评分贡献在同维度最高。原表例子：尺寸 30″、元素 fluted、形态镂空收纳。
   - 第二优先级"体量大又活跃"：销量第一，渗透率高于平均。例：站立四角（销量 5,475，一年新品 10% 的数量撬动 35% 的销量）。
   - 第三优先级"有短板可补"：评级贡献最高、平均评分最低、新品进入少。例：pedestal（评级贡献 49 全形态第一，评分 3.91 全形态最低）。
   - 新冒头的取值也在这一步出现：几乎全是新品（夏克式+纹路一年新品占 91%）且渗透率高。
2. **找白地。** 对排在前面的取值，在交叉表里找它还没铺开、但那个格子本身卖得好的地方。例：fluted × pedestal、拐角柜；fluted × 黑白色；夏克式+纹路 × 24″；老形态 × 新元素（镂空 × 夏克式（纹路））。
3. **找"同价做到"的缺口。** 价格段 × 配置里，某价位带这个配置的 ASIN 少、但卖得不差。例：30/36″ 在 300–350 美金，带石材台面的 ASIN 只占 7%，销量是无台面的 24%。
4. **看竞争和可行性。** 链接数，新品是不是已经扎堆（"短期将会有大量 fluted 紧接着跟上"），成本、运输、广告占比。

## 5. 回放 2025 年前要补的

1. **打标**：原表的"形态"9 种、是否带台面、柜脚、储物空间，我们现在没有（我们的形态只有落地、悬浮、柱状盆）。2025 年数据要按原表的分类补打标。
2. **评分数逐月**：卖家精灵导出有评分数；新品评分数可用相邻月份相减。
3. **评论内容**：原表"整合评论"用于找差评点，导出里没有，要另下载。
4. **关键词**：原表用 2021–2025 年按类别打标的关键词逐月搜索量；新拉的按属性打标关键词要和这套类别对齐。
5. **第一次回放的现成材料**：原表的"26 年产品规划表"有 11 个 SPU（如 Pedestal+fluted、大理石纹台面+fluted / 夏克式 / 自然木纹、陶瓷一体盆+fluted、壁挂+自然木纹、石英石台面+自然木纹），是这套标准的产出，可直接拿 2026 年数据看这些方向后来怎样。
