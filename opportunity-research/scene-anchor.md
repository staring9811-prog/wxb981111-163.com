# 场景锚点（第二轮 V1）· 品类机会判定台

> 上游：`output/解题方案书.md`（第二轮，2026-11-03）。方案书已确认的内容直接引用，这里只补产品层。
>
> 第一轮场景锚点留在 git 历史中。

**产品名（暂定）**：品类机会判定台

**一句话定位**：
- 一个在 wen 电脑上运行、局域网共享的网页系统。
- 每月自动拉卖家精灵的 Amazon 数据，自动打标，wen 确认元素和低置信度标签。
- 按"尺寸 × 拆装 × 形态"分框扫出机会，对选中的机会生成决策卡：做不做、怎么做、在赌什么、看到什么就停、具体 SKU 实证、差评要改的点、利润。
- 老板在系统里审批，立项后登记预测台账，6 个月后对账。
- 利润测算台、评论月度 VP 追踪器并入同一个系统，功能全部保留。

**核心用户与角色结论（多角色）**：

| 角色 | 是谁 | 能做什么 | 不能做什么 |
| :--- | :--- | :--- | :--- |
| 操作者 | wen | 配置密钥和预算；拉数据；确认打标；运行扫描；生成和编辑决策卡；利润测算；评论采集；登记台账；建账号 | — |
| 审批者 | 老板 | 看全部；审批策略库条目（三种状态）和立项决策卡；留意见 | 不改数据和卡片内容 |
| 只读 | 运营、采购、研发 | 看机会扫描、决策卡及展开项、台账 | 不能改、不能审批 |

拆成三类的理由：三者能做的操作和责任不同。未登录的人看不到任何内容。

**核心场景**：
1. **每月初**：系统拉上月数据 → 核对（月份误标、来源切换、标签覆盖率）→ 自动打标 → wen 确认低置信度标签 → 重算评分和机会扫描。
2. **立项评审前**：wen 从机会扫描里选机会 → 生成决策卡（拉 SKU 实证、差评归类、带入利润测算）→ 编辑叙述部分 → 发给老板审批。
3. **评审会**：投屏决策卡，展开 SKU、趋势、差评；老板审批立项 → 登记预测台账。
4. **6 个月后**：系统对账，更新策略库状态。

**当前替代方案**：wen 手动导出、AI 在会话里跑脚本、写 Markdown 决策卡；利润测算和评论 VP 是两个独立工具。

**核心痛点**：
- 立项要提前约 8 个月判断，做错一次损失 30–40 万元以上；
- 判断口径不固定，常出错，比如不分形态、误用 9 月数据；
- 结论散在文件里，没法回看是否说对了。

**成功定义**（方案书第 6 节）：
- 市场层：把握分档后实际变大的比例逐档上升，D 档之后变大 ≤ 30%；
- 新品层：前 20% 做到率 ≥ 平均的 2 倍（目前未达标）；
- 每次立项都有决策卡和台账，6 个月后能对账；
- 产品层面：wen 每月从拉数据到出扫描结果，不需要 AI 会话介入。

**功能边界**：
- **第一版做**（wen 确认全部要做）：
  1. 卖家精灵自动拉数据 + 导入核对 + 自动打标 + 人工确认；
  2. 分框机会扫描（四类）；
  3. 决策卡（十项内容 + 展开项）；
  4. 差评自动拉取与归类（Amazon 走卖家精灵，Lowe's / HD / Wayfair 走 VP 追踪器）；
  5. 预测台账 + 策略库审批；
  6. 利润测算并入，并回写决策卡；
  7. 模型更新与回测；
  8. 账号与角色；
  9. 密钥设置页；
  10. 费用评估、确认和上限。
- **品类**：第一版只做浴室柜。分框维度、属性列表、打标规则做成可配置。
- **渠道**（wen 2026-11-03 追加）：Amazon + Home Depot、Lowe's、Wayfair。每个渠道单独按框扫描，决策卡并排给出分渠道结论，并做跨渠道印证。其他渠道的销量用评论换算（VP × 50 + 非 VP × 20，可改；另有榜单排名平滑法）。
- **不做**：
  - 自动立项或自动下单（只给建议）；
  - 公网访问；
  - 结合搜索词预测销量（wen：先放着）。

**方案前置能力与外部配置责任**：

| 能力 | 用途 | 状态 | 负责人 | 配置 | 不可用时 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 卖家精灵接口 | Amazon 月度数据、Amazon 评论、关键词 | 账号存在（本会话 MCP 可用） | wen | 系统设置页，wen 填写、测试、更换 | 数据停在上月，系统提示 |
| Bright Data | Lowe's / Wayfair 列表页 | 账号存在（VP 追踪器在用） | wen | 同上；IP 白名单需放行 wen 电脑 | Lowe's / Wayfair 评论跳过，HD 不受影响 |
| Apify | Lowe's / Wayfair 评论 | 账号存在（免费计划，每月 $5） | wen | 同上 | 同上 |
| 大模型 | 看图打元素、差评归类、决策卡叙述草稿 | 兼容多家（Claude / OpenAI 等），设置页里选 | wen | 同上 | 元素进入人工确认；差评只显示原文 |

**交付约束**：
- 实现由 AI 负责；
- 在 wen 电脑上运行，局域网共享，wen 负责启动和电脑开机；
- 密钥只存在本机，不进仓库；
- 产品拍板和最终验收由 wen 负责。

**最大不确定性**：
- 新品层前瞻区分力（8 个月口径 AUC 0.45–0.60）；
- 卖家精灵接口能否每月稳定拿到全量小类数据；
- 打标准确率，以及人工确认的工作量。

**最不该做的方向（防跑偏）**：
- 不要把所有组合拉平排名；
- 不要跨尺寸、拆装、形态下结论；
- 不要让大模型打分；
- 不要把没回测过的指标当决策依据。
