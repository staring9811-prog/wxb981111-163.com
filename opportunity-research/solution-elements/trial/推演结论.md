# 推演结论：只勾选想看的变量，能不能得到正确结论

脚本：`trial/推演_勾选变量.py`（模拟数据，答案已知；每种样本量重复 300 次）。只能检验方法，不代表浴室柜真实效果。

设定的真相：岩板台面只在中价带有用（+11.9 个百分点），低价、高价带没用；双盆、颜色完全没用；高价、强品牌、≥48″ 本身更容易命中；岩板多出现在高价，双盆多出现在大尺寸。

| 用法 | 600 个样本：估计 / 真相（波动） | 200 个样本 |
| :--- | :--- | :--- |
| A 只勾选台面 | 岩板比陶瓷高 12.3 / 4.8（±4.4） | 12.0 / 4.8（±7.9） |
| A 只勾选盆数 | 双盆比单盆高 9.8 / 0（±4.1） | 9.3 / 0（±7.4） |
| B 固定中价带再勾选台面 | 11.8 / 11.9（±7.2） | 11.3 / 11.9（±13.3） |
| C 勾选台面，系统自动控制价格、尺寸、品牌等 | 6.0 / 4.8（±4.8） | 5.9 / 4.8（±8.9） |
| C 盆数被误判为有用的比例 | 10%（检验水平本身就是 10%） | 10% |
| D 再按价格带分开看岩板：中 / 低 / 高 | 11.6 / 0.3 / 0.7，真相 11.9 / 0 / 0 | 波动 ±13 / ±17 / ±24 |

结论：
1. 只勾选想看的变量（A）会系统性出错：岩板的效果被夸大 2.5 倍，完全没用的双盆显示"+9.8 个百分点"，因为它们借了价格和尺寸的功劳。
2. 勾选的思路可以保留，但变量要分三种角色：条件（先圈定比较范围，如中价带）、关注（勾选想判断的）、控制（价格、尺寸、品牌实力、上架月份等，不管勾不勾选，系统都自动带上）。这样（B、C、D）就能回到真相附近。
3. 平均值会掩盖"只在某些条件下有用"：岩板总体 +4.8，其实是中价 +12、其他价带 0。所以要能按条件分开看（D）。
4. 样本量决定能看多细：200 个样本时，分价带的估计波动 ±13 到 ±24 个百分点，分不清"有用"和"没用"；600 个也只是勉强。必须有样本量闸门，不够时只报"数不够"。
