## 1. 现在有什么、差什么

| 层 | 现在程序里 | 差的 |

| 页面 | 变量关系页列了三类变量和逐个效应 | 没有"关系图"，没有模型结果，没有"模型发现 vs 人工经验"并排 |

你截图里信号列全是"无数据"，原因是你的截面包没有关键词表（C5）和评论表（C6），需求在涨 / 痛点 / 高销低评算不出；现用指标有值但效应"无数据"，是因为现用指标只在老品上算、按细分取值，和新品一一对应后方差太小。这不是板块坏了，是数据限制，第二版会把这类原因直接写在表里。

## 2. 目标形态

```
[变量 X]                         [过程指标 M]                        [结果 Y]
属性取值（10 维）  ──┐            新品早期轨迹：首月/次月销量、BSR、评分数     命中（6 个月内）
价格位置、上架月   ──┼─ 模型 1 ─▶  细分信号：需求在涨、进得去、痛点、高销低评 ─▶ 次级：起量月龄、累计 GMV
品牌层级、变体数   ──┘   总效应          └──── 模型 2：X→M、M→Y|X（路径分解）────┘
配送、重新上架                            模型 3：规则发现（X 组合 → Y），与策略库并排
控制：固定在模型里，不单独当"经验"输入
```

三个模型都只吃**原始数据 + 结果**，不吃人工规则（润总的要求）；人工规则（策略库里的）只在结果页**并排对照**，由人判断信哪边。

### 模型 1 · 总效应：Y ~ X（回答"该立什么"）
- 主模型：岭回归 logit（现有）扩成多变量，全部属性取值哑变量 + 价格位置 + 上架月 + 品牌层级 + 变体数 + 配送。
- 辅模型：梯度提升树（scikit-learn HistGradientBoosting，离线包可装；XGBoost 另加 ~100 MB，暂不用），用来抓非线性和交互。
- 验证：沿用回测的时间切分（前 2/3 批次训练、后 1/3 检验），报检验组 AUC、前 20% 命中率倍数、校准曲线。
- 输出：每个变量的重要性（置换重要性，带 90% 区间）；每个属性取值的边际效应（固定其他变量）；两模型方向一致的变量标"稳"，不一致标"待核"。

### 模型 2 · 路径：X → M、M → Y | X（回答"为什么"）
- 对每个过程指标 M，算 X→M 的效应和 M→Y 控制 X 后的效应，给出"直接 / 经 M 间接"的分解（线性近似的中介分解，写明近似）。
- 用途：告诉你某个属性是因为"需求在涨"还是"没人做好"才命中；也能看出哪些 M 根本不传导，以后不必再算。

### 模型 3 · 规则发现（润总说的"妙计"）
- 从梯度提升树 / 浅决策树抽 2–3 个条件的组合规则："宽度 30–48 且 落地 且 价格 $500–900 → 命中率 46%（n=22，全类目 15%，倍数 3.0）"。
- 每条规则在检验组上重算支持数、命中率、倍数、Wilson 区间；只保留检验组仍成立的；按可信度分 高 / 中 / 低 三档（样本量 + 区间下界 + 两组一致）。
- 与策略库里的人工规则**同表并排**：命中率、倍数、样本、来源（模型 / 人工）。模型规则不自动进策略库，由人在页面上"采纳为待验证规则"。

### 可信度口径（页面上每个数都带）
- 样本量 n、90% 区间、训练 / 检验两组是否同方向。
- 数据限制逐条写：幸存者偏差（只收 ≥ 60 件的父体）、观察期长度、缺 C5/C6、属性"未知"占比。
- 低可信度的只显示不建议采信（润总：25% 可信度的不采）。

## 3. 页面怎么改（变量关系页，第二版）

1. **关系总览**：三栏图（变量 / 过程指标 / 结果），每个格子显示"可算 / 不可算（原因）"，箭头上显示模型 1、2 的总体效果（检验组 AUC、前 20% 倍数）。
2. **模型 1 结果**：变量重要性条形表；属性取值边际效应表（现有表升级：多变量同时控制，不再逐个对比）。
3. **路径分解**：每个过程指标一行：X→M 强弱、M→Y 强弱、经它传导的比例。
4. **发现的规则**：模型规则 + 策略库规则并排，可信度分档，按钮"采纳为待验证规则"。
5. **模型说明与数据限制**：用的样本、切分、模型、版本号、数据缺口清单（对应需要补的数据）。
6. 导出：Excel 加一张"变量关系"表；判定卡页引用模型版本号。
