## 2. 页面概述

### 2.1 一句话定位

一个机会的立项建议：评审会上能直接拍板，每个数字都能点开看出处。

### 2.2 存在理由

1. 立项决定每次 30–40 万元，结论必须能追到框、月份和样本数。
2. 同一机会在不同渠道方向可能相反，需要并排看后分渠道下结论。
3. （v8）其他渠道有了渠道回测，各渠道证据分量不同（Amazon 经回测、Home Depot 经回测（打折）、Lowe's / Wayfair 未验证），并排时要同时写清证据等级和打折后怎么读；Amazon 侧丰富度是 Home Depot 检验出的加分信号，要在卡上作对照展示（方案书 §10.7）。
4. 低评分是可改的问题还是材料问题，决定"做好就能起量"是否成立。
5. 没有审批记录和快照，事后无法对账"当时为什么上"。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 完整 | 十项内容 100% 齐全（AC-F21-01） |
| 可追溯 | 每个数字可点开来源（框、月份、样本数）（AC-F21-02） |
| 生成 | 不含外部调用时 30 秒内生成（NFR-010） |
| 审批留痕 | 审批人、时间、结论、意见 100% 记录 |

### 2.4 不做什么

- **不做**直接改数字——wen 只能改叙述（AC-F21-02）。
- **不做**在卡里算利润——在 PAGE-F24-01 测算后回写。
- **不做**跨渠道比较绝对销量（AC-F29-02）。

## 3. 用户与场景

### 3.1 目标用户

| 角色 | 能做什么 |
| :--- | :--- |
| 操作者（wen） | 编辑叙述、拉差评、改判、起草叙述、测算利润、提交审批、另存为新草稿 |
| 审批者（老板） | 看全部；批准 / 驳回 / 退回修改并留意见；不能编辑 |
| 只读 | 只看；所有操作按钮隐藏 |

没有权限的按钮直接隐藏，不置灰（蓝图 §3）。原型右上"视角"切换用于演示三种状态：操作者 · 草稿、审批者 · 待审批、已批准。

### 3.2 核心使用场景

**场景 A：完善草稿并提交（操作者）**
- 前置：从机会扫描生成草稿。
- 动作：看十项 → 拉差评（确认费用）→ 改判个别评论 → 起草 / 编辑"为消费者解决了什么问题"→ 测算利润并回写 → 提交审批。

**场景 B：评审会上审批（审批者）**
- 动作：投屏逐节看，点数字看来源，点 SKU 看逐月 → 右侧"审批"批准 / 退回修改 / 驳回并写意见。
- 结果：批准后卡锁定为只读版本并登记预测台账。

**场景 C：批准后有新数据**
- 表现：顶部"有新数据"横幅，数字保持批准时快照并带"快照"标签；可"另存为新草稿"。

### 4.2 区域内容（十项）

**01 分框决策**
- 结论块："上"+ 具体方案（$230–260、农场风或竖棱、主色原木或白、首月 ≥ 2 色 ≥ 4 子体、评分目标 ≥ 4.3、按差评清单改）+ 一句话理由。
- 四渠道并排表：渠道、框内份额 前 → 近、趋势（近 4 季迷你线）、分级 / 把握、证据等级 · 打折后读法（v8，同一列：徽章 + 下方小字）、样本量（家族数 · 月销）、这个渠道"上 / 不上 / 观察"。示例：Amazon 8.4% → 11.5%、B · 把握 57%、经回测、不打折、上；Home Depot 6.1% → 9.8%、C · 把握 52%、经回测（打折）、"只看排序与坑：框内第 3 / 9；把握不当概率用（渠道回测同档之后变大 53%，大单元秩相关打折后 +0.29）"、观察；Lowe's 3.0% → 4.1%、分级不显示、未验证 · 未回补、样本不足、不上；Wayfair 14.2% → 10.6%、分级不显示、未验证 · 未回补、不上。
- 未验证渠道（AC-F19-06）：分级 / 把握列显示"不显示"，打折后读法写原因（"历史未回补（10 个月），不显示把握与分级"）；份额方向照常用于印证 / 分歧。
- Amazon 侧丰富度对照（v8，AC-F29-05）：同尺寸段 × 形态 × 本卡属性取值（不分拆装）近 6 个月，每个其他渠道一行：Amazon 家族 / 价位段、Amazon 份额 前 → 近、本渠道家族 / 价位段、差距 G = ln((Amazon 家族 + 1) / (本渠道家族 + 1))（小标签看公式与依据）、证据等级（随该渠道）、读法。示例（树脂，30″ · 落地式）：Amazon 38 / 4、8.1% → 11.2%；Home Depot 6 / 2、G +1.72、经回测（打折）、"Amazon 结构领先：作加分信号，不作独立立项理由"；Lowe's 2 / 1、G +2.56、未验证、只作事实对照；Wayfair 9 / 3、G +1.36、未验证、只作事实对照。下方说明"本渠道少不等于机会"。
- 样本外（AC-F29-06）：本卡单元在某渠道前 N 里没有家族时，该渠道行标"该渠道样本外，仅参考"，只显示 Amazon 侧事实，不给把握与分级。

## 5. 界面内容

### 5.1 元素清单

**数字来源小标签**
- 位置：每个关键数字后。

- 显示：审批者 + 待审批；"批准"（主按钮）、"退回修改"、"驳回"；弹窗写意见，退回和驳回必须写意见。

- 大模型起草后显示；wen 编辑后去掉（AC-F21-06）。

**有新数据横幅**
- 已批准且依据的数据更新时显示；"另存为新草稿"。

**版本与审批记录**
- 时间线：生成草稿（含用时）、提交、退回、编辑、批准，含审批人、时间、意见。

## 6. 交互流程

### 6.1 页面加载

- 默认 Amazon；目录随滚动高亮当前节。
- 有效性未通过时顶部显示"市场评分本月未通过有效性检验"（AC-F19-04）。

### 6.2 核心操作流程

```
拉差评 → 费用评估弹窗 → 确认
   └─ 卖家精灵拉 SKU 1–3 星（每个 ≤ 30 条）+ 合并 F23 其他平台明细 → 大模型归类 → 占比刷新

改某条评论归类 → 占比立即重算，该条标"人工修改"

起草叙述 → 费用评估弹窗 → 确认 → 文本替换并标"AI 草稿" → 编辑 → 标记去掉

测算利润 → PAGE-F24-01（预填 30″、$240）→ 关联本卡并保存 → 回到本卡，"钱"一节显示各渠道利润

提交审批 → 状态"待审批"，叙述锁定
   └─ 审批者：批准 → 锁定只读版本 + 数字快照 + 自动登记 PAGE-F26-01 → 状态"已批准"
            退回修改（必填意见）→ 回到草稿
            驳回（必填意见）→ 状态"已驳回"

已批准后数据更新 → "有新数据"横幅 → 另存为新草稿（第 3 版，用新数据重新生成数字）
```

### 6.3 辅助操作

- 渠道切换只换大数据层和 SKU 层内容；分框决策始终四渠道并排。
- SKU 行回车或点击打开抽屉，Esc 关闭。
- 离开页面时有未保存叙述会拦截（蓝图 §5）。

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 未配置大模型 | 差评只显示原文、不归类；"起草叙述"不显示，叙述手写 |
| 某渠道本月无数据 | 并排表该渠道显示"该渠道本月无数据"，其他渠道照常 |
| 某渠道样本不足 | 分级显示"无数据"，标"样本不足" |
| 某渠道经回测（打折） | 证据等级"经回测（打折）"，打折后读法写排序与同档回测比例，把握不当概率用 |

| 某渠道样本外 | 丰富度对照该行标"该渠道样本外，仅参考"，只显示 Amazon 侧事实 |
| 某 SKU 没有差评 | 按 SKU 表显示"无数据"，不显示 0 |

| 达到预算上限 | 自动停，已拉评论保留 |
| 审批时卡被编辑 | 以提交时锁定的版本为准（PRD §5.2） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 把握 / 分级 | 第九版市场层评分 |
| 做到概率原值 / 扣偏差值 | 新品层原值；减当月模型偏差（本例 1.2） |
| 渠道结论 | 上 / 不上 / 观察 |

### 8.3 特殊业务规则

- 数字由系统计算，不可编辑；叙述可编辑并自动保存。
- 其他渠道月销为评论换算估算，只在渠道内比较；证据等级按该渠道最近一次回测（AC-F19-06）：达标为"经回测（打折）"，按打折规则（秩相关减 0.1、把握 ≥ 70% 档减 15 个百分点、方向对按 ≤ 60% 看，参数版本注明）给读法；不达标或未回测为"未验证"，不显示把握与分级。
- Amazon 侧丰富度（AC-F29-05）：显示 Amazon 同尺寸段 × 形态 × 属性取值（不分拆装）近 6 个月家族数、价位段数、份额走势与本渠道家族数、价位段数、差距值；证据等级随该渠道。
- 批准后锁定版本，数字快照不随新数据变化（AC-F25-01、AC-F25-02）；批准即登记台账（AC-F25-03，台账在 PAGE-F26-01）。
