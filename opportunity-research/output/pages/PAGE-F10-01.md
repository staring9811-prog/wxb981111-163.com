## 2. 页面概述

### 2.1 一句话定位

把每次生成的排序、锦囊和判定卡版本原样封存，作为 6 个月后对账时"当时的预测"。

### 2.2 存在理由

1. **对账要比当时的预测**：判定卡和锦囊每月都可能变。6 个月后对账，必须拿当时封存的排序，不能拿现在的（US-F10-01、AC-F10-01）。
2. **同月会重算**：确认合并建议、改字段约定后要重算，同一个月会有多版快照。必须说清哪一版用于对账（DEC-006）。
3. **要证明没被改过**：快照带锁标识和内容指纹，台账才经得起对账。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 不可改 | 全部快照只读，没有修改或删除入口；每份快照显示内容指纹 |
| 对账取版清楚 | 每份快照都有对账状态；同月不用于对账的版本写明原因 |
| 可回看 | 任一快照一次点击即可看到当时的排序、锦囊和版本号 |

### 2.4 不做什么

- **不修改、不删除快照**：AC-F10-01 要求保存后不可改；第一期也没有删除业务数据的功能。
- **不在本页手动生成快照**：快照在排序生成时自动保存（回测完成后，或"全部重算"后）。
- **不在本页算对账**：对账结果在 PAGE-F10-05，本页只显示状态并链接过去。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 月更导出前后；立项复盘；对账结果有疑问时 |
| 使用设备 | Windows，宽 1366–1920 |

- **场景 A：导出前确认版本**：本月已重算过，看最后一版是哪一版；导出后这一版就是本月的对账版本。
- **场景 B：回看当时的判断**：复盘某个立项时，打开对应月份的快照，看当时的排名、区间和锦囊，核对指纹。
- **场景 C：对照同月两版**：例如 2026-11 第 1 版与第 2 版的前 20% 不同（第 2 名从观察细分变为立项候选细分），确认对账用的是导出的第 2 版。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题"台账"、副标题，操作"列"、"导出本月报告"。
2. 台账标签：月度快照（当前）/ 立项记录 / 到期对账，标签上带条数。
3. 规则横幅（常驻）。
4. 筛选：对账状态、口径。
5. 快照列表。
6. 页脚。
7. 快照详情抽屉（页内）。

### 4.2 区域内容

**规则横幅**：快照保存后不可修改。每次生成排序自动保存一份快照（月份 + 第 n 版），连同锦囊和判定卡版本号一起封存；同月重算另存新版本，旧版本保留；对账用当月最后一次导出的那版，当月从未导出时用当月最后一版。

**快照列表**（新的在上，每页 50 行）

| 列 | 内容 | 次要列 |
| :--- | :--- | :--- |
| 快照 | 月份 + 第 n 版；说明，如"本月 · 当前最后一版""同月最后导出的版本""配置 v2 后的首份快照""首跑""样例包 · 截面口径" | |
| 判定卡 | 版本 + 状态（已达标 / 达标（截面）/ 未验证） | |
| 口径 | 历史 / 截面 | |
| 生成时间 | 精确到分钟 | |
| 导出 | 已导出 / 未导出 | |
| 对账状态 | 未到期（预计月份）/ 可对账（待本月计算）/ 已对账（对账日期 · 倍数，链接到期对账）/ 已对账（截面）/ 不用于对账（原因） | |
| 内容指纹 | 前 8 位 | 是 |
| 操作 | 查看快照 | |

**快照详情抽屉**（只读）

1. 抽屉头：快照名，副标题"月度快照 · 历史口径 · 生成于 2027-05-08 10:46 · 只读"。
2. 锁标识区："快照保存后不可修改"，内容指纹前 8 位；点"SHA-256"小标签看算法、完整指纹、封存内容（细分数、锦囊条数、判定卡版本）和保存时间。
3. 截面快照另有常驻横幅："截面口径，待历史回测确认"，并说明截面卡已被历史结论取代。
4. 版本与对账：判定卡（版本 + 状态）、数据包（含数据截止月）、字段约定、品类配置（含维度说明）、导出、对账（状态、预计月份或对账结果、对应的立项记录）。
5. 排序：有效细分按快照中的排名逐行列出——细分、预期命中率区间条（90% 区间 + 样本量）、得分、锦囊动作与规则编号；样本不足的细分汇总为一行（数量与说明）。区块说明写细分总数、有效与样本不足数、前 20% 为前几名、全类目平均。
6. 锦囊：每条写规则编号、动作、快照保存时的状态、触发条件、预期命中率区间、依据批次、样本量；未经回测的经验规则区间显示"无数据"。
7. 抽屉脚：已对账→"在到期对账中查看"；本月未导出→"导出本月报告"；"关闭"。

## 6. 交互流程

### 6.1 加载与初始化

- 默认显示全部快照，新的在上；筛选为"全部"。
- 本月尚未导出时，本月最新一版的对账状态写"导出后以导出版为准"。

### 6.2 核心操作流程

```
进入台账（默认月度快照）
  ├─ 点筛选标签 → 列表即时过滤，显示条数
  ├─ 点"查看快照" → 右侧抽屉显示只读快照
  │    ├─ 点"SHA-256" → 浮层显示指纹算法、完整值与封存内容
  │    ├─ 已对账快照点"在到期对账中查看" → PAGE-F10-05
  │    └─ 关闭 / Esc / 点遮罩 → 回到列表原位置
  ├─ 点"日期 · 倍数"（已对账行）→ PAGE-F10-05
  ├─ 点"导出本月报告" → PAGE-F12-01（导出后该版成为本月对账版本）
  └─ 点标签"立项记录""到期对账" → PAGE-F10-04 / PAGE-F10-05
```

### 6.3 辅助操作

- "列"：窄屏下调出"内容指纹"列。
- 证据小标签可点开看来源。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空 | 还没生成过排序 | 空状态："还没有月度快照。完成回测、生成本月排序后，这里会自动保存第一份快照。"按钮"去本月工作台"（PAGE-F03-01） |
| 正常 | 有快照 | 横幅、筛选、列表 |
| 本月未导出 | 本月快照都未导出 | 本月最后一版写"导出后以导出版为准"；较早的同月版本标"不用于对账（同月有更晚的版本）" |
| 判定卡未验证 | 快照保存时判定卡未验证 | 判定卡列"未验证"；抽屉顶部常驻"未验证，不可作为立项结论"（AC-F08-03） |
| 截面快照 | 快照来自截面回测 | 口径列"截面"；抽屉常驻"截面口径，待历史回测确认"（AC-F07-11） |
| 筛选无结果 | 当前筛选下没有快照 | "没有符合条件的快照"，提供"清除筛选" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 导出后又重算 | 新版本标"未导出"；对账仍用已导出的那版，直到新版本也被导出（DEC-006） |
| 某月从未导出 | 用该月最后一版对账，列表照常显示 |
| 品类配置已变更 | 旧快照保留当时的细分划分（例：2026-11 快照按配置 v1 的 5 个维度），不按新配置改写 |
| 样本不足的细分 | 抽屉排序中排在有效细分之后，区间很宽（AC-F09-01、AC-F09-02） |

## 8. 业务规则与校验

- **快照内容**（AC-F10-01）：当月全部细分的排序（含样本不足）、锦囊及其当时的状态、判定卡版本号；同时记录数据包、字段约定、品类配置版本（NFR-003）。
- **编号**：月份 + 第 n 版，同月每生成一次排序加 1（DEC-006）。
- **对账取版**（DEC-006）：当月最后一次导出时的快照；当月从未导出，取当月最后一版。其余同月版本为"不用于对账"。
- **预计可对账月份**：快照月份 + 6 个月，即对应批次（快照月份当月上架的新 SPU）6 个月判定窗口结束后的那次月更。例：2026-12 快照 → 2027-06。
- **内容指纹**：保存时对快照全部内容计算 SHA-256，列表与抽屉显示前 8 位。
- **只追加**：快照不可修改、不可删除（DEC-014）。

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 自动保存 | 每次生成排序后列表新增一份快照（月份 + 第 n 版），内容含排序、锦囊和判定卡版本号（AC-F10-01） |
| F-02 | 不可修改 | 列表和抽屉没有修改、删除入口；内容指纹与保存时一致（AC-F10-01） |
| F-03 | 同月多版 | 同月重算生成新版本，旧版本保留且可查看（DEC-006） |
| F-04 | 对账取版 | 同月有导出版时，只有最后导出的那版参与对账，其余标"不用于对账"并写明原因；从未导出时取最后一版（DEC-006、AC-F10-04） |
| F-05 | 预计月份 | 未到期快照的预计可对账月份 = 快照月份 + 6 个月 |
| F-06 | 截面标注 | 截面快照在列表与抽屉中标截面口径，抽屉显示"截面口径，待历史回测确认" |
| U-01 | 一次查看 | 每行一次点击打开只读快照；关闭后回到列表原位置，筛选不变 |
