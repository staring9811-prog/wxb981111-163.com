## 2. 页面概述

### 2.1 一句话定位

按渠道看小平台每个"尺寸段 × 拆装 × 形态"框的体量、份额与走势，并一眼看出哪些框的数据够下结论。

### 2.2 存在理由

1. 小平台还不能回测（Lowe's / Wayfair 没有足够历史），立项需要同框的观察证据。
2. Wayfair 等渠道有大量商品分不进框、销量有一部分是估算，不标可读性会把方向参考当成结论。
3. 调研数据的商品范围和销量口径与机会扫描不同，单独成页避免混读（PRD §3.3.17）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 响应 | 打开某渠道框列表 ≤ 5 秒（NFR-014） |
| 口径 | 100% 的框带可读性标签；含估算的月均 100% 标"估算"并给低估计 |
| 不混读 | 页面不出现把握、分级、"上 / 不上"结论，不出现跨渠道绝对销量比较 |

### 2.4 不做什么

- **不做**机会类型判定和决策卡生成——调研不进机会扫描（AC-F30-08）。
- **不做**跨渠道合计或排名。
- **不做**门槛与可读性阈值的修改入口（框月均 200、单元 20、覆盖 95%、有月度 60% 为已确认规则）。
- **不做**本期的系统内抓取（第二版 planned，本期界面不出现入口）。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者、审批者、只读都能看；只有操作者看到"去导入""分框待确认"入口（AC-F30-09，无权限按钮隐藏） |
| 使用时机 | wen 导入新一批调研数据后；评审会前讨论"上哪个渠道、哪个框" |

### 3.2 核心使用场景

**场景 A：看 Wayfair 哪些框能下结论（主场景）**
- 动作：左侧栏"渠道调研"→ 页签 Wayfair → 看框列表。
- 表现：23 个达门槛的框全部列出；30″ · 拆装 · 落地式、72″+ · 拆装 · 落地式标"可读"；24″ · 拆装 · 落地式（月均 5,456 估算）整行降灰、标"不下结论（分框覆盖 93.7%）"；30″ · 整装 · 落地式标"趋势不下结论（有月度 33%）"。
- 打开"只看可读框"只剩 2 行。

**场景 B：看 Home Depot 并进入框详情**
- 动作：页签 Home Depot → 15 个框全部可读 → 点"30″ · 整装 · 落地式"→ 进入 PAGE-F30-02。

**场景 C：Lowe's 还没补齐**
- 表现：Lowe's 页签标"数据不足"；页面不显示框列表，显示已落框销量 1.1% 与原因构成（多尺寸未拆 98.4% 等）和待确认数。

**场景 D：去处理分框待确认**
- 动作：操作者点"分框待确认 83 个 · 占渠道销量 11.9%"→ 打开打标确认，已筛 Wayfair + "分框未知（渠道调研）"→ 确认后返回本页，数据条显示"重算时间"。

### 3.3 用户核心诉求

- 先看清"这个框的数据够不够"，再看数字。
- 大框即使不能下结论也要看得到体量。

## 4. 信息架构

### 4.1 区域划分

1. 页头（面包屑 工作台 / 分析 / 渠道调研；标题；操作者看到"导入调研数据"按钮）
2. 渠道页签（Home Depot / Lowe's / Wayfair，每个带状态小标签）
3. 数据条（窗口、导入时间与操作人、商品数 / 家族数、有月度销量占比、已落框销量占比、证据等级"历史观察"、重算时间）
4. 口径说明（折叠）
5. 分框待确认条（操作者）
6. 框列表（工具条："只看可读框"开关、可读性图例；表格；未达门槛汇总行）

### 4.2 区域内容

- **渠道页签状态**：`可读 2 / 达标 23 框`；`尚未导入`；`数据不足`。
- **数据条**：`窗口 2026-01 至 2026-10（10 个完整月）· 2026-11-04 14:20 wen 导入 · 633 个商品 / 633 个家族 · 有月度 60% · 已落框 88.1% · 历史观察 · 重算 2026-11-04 15:02`。
- **口径说明**（AC-F30-24）：商品范围 = "bathroom vanity" 与 "bathroom vanity with sink" 自然位前 300 并集 + 类目节点商品；销量 = 逐月评论 VP × 50 + 非 VP × 20；没有逐月评论的商品按同来源、同评论数档换算（中估计 / 低估计）；价格 = 采集日价，评分 = 页面评分按评论数加权，各渠道口径不同；家族 = Home Depot 评论家族 / Lowe's 父体 / Wayfair listing；只含今天仍在榜的商品（幸存者偏差：早月份偏低，"在涨"偏乐观）；只在同渠道、同框内比较。
- **框列表列**：框 · 月均（估算时标"估算"，下行小字低估计）· 渠道内份额 · 近 3 ÷ 前 3（框涨 / 框跌）· 家族 · 单款月均 · 新家族（销量占比）· 中位价 · 评分 · 台面 / 主色 / 柜体 / 元素已知 · 分框覆盖（期望）· 有月度占比 · 可读性。
- **未达门槛汇总行**（AC-F30-11）：`未达门槛的框 5 个，合计月均 714 件`。

## 6. 交互流程

### 6.1 页面加载

- 默认渠道：上次查看的渠道（本机记住），首次为 Home Depot；地址带 `channel` 时以地址为准。
- 加载中：数据条和表格显示骨架屏。

### 6.2 核心操作流程

1. 切渠道页签 → 地址 `channel` 更新 → 刷新数据条与框列表。
2. 表头排序（默认月均降序）。
3. 点框行 → PAGE-F30-02（地址带渠道与框）。不下结论的框同样可进入，详情页只显示体量与份额。
4. 点"分框待确认 N 个"→ PAGE-F18-01（`channel` + `reason=frame` + `from=research`）。

### 6.3 辅助操作

- "只看可读框"开关；口径说明折叠 / 展开；"导入调研数据"（操作者）→ PAGE-F30-03。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 条件 | 表现 |
| :--- | :--- | :--- |
| 正常 | 有达门槛的框 | 数据条 + 框列表 |
| 尚未导入 | 该渠道没有调研导入 | 空状态"尚未导入"；操作者另有"去导入"按钮，其他角色显示"等操作者导入"（AC-F30-22） |
| 数据不足 | 已导入但没有框达门槛 | 不显示框列表；显示已落框销量占比、原因构成条（尺寸段未知 / 多尺寸未拆 / 装未知 / 形态未知各占渠道销量）、待确认数与入口（AC-F30-23） |
| 有导入待确认（操作者） | PAGE-F30-03 有核对完成未确认的导入 | 顶部提示"有一次导入核对完成、待确认"→ PAGE-F30-03 |
| 重算中 | 分框确认后正在重算 | 保留上次结果，数据条显示"重算中…"（AC-F30-29） |
| 重算出错 | 重算异常 | 保留上次结果，红色提示"重算出错：原因；显示的是 时间 的结果"（DEC-106） |
| 只看可读为空 | 打开开关后没有可读框 | 空状态"这个渠道没有可读的框，关掉开关看全部" |

### 7.2 边界与容错

- 单渠道没有估算销量时，不显示低估计。
- 窗口少于 6 个完整月时，近 3 ÷ 前 3 显示"—（月份不足）"（AC-F30-13）。

## 8. 业务规则与校验

| 规则 | 内容 | 来源 |
| :--- | :--- | :--- |
| 渠道内份额 | 框销量 ÷ 该渠道已落框销量 | AC-F30-12 |
| 分框覆盖（期望） | 本框已落框 ÷（本框已落框 + 待确认销量中按已知维度可能落到本框、按候选框已落框比例分摊的部分） | AC-F30-19 |
| 已确认优先 | 打标确认中已确认的分框标签优先于导入值 | AC-F30-10 |
