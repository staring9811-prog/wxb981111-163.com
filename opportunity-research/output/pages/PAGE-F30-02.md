## 2. 页面概述

### 2.1 一句话定位

把一个框里每个属性取值的指标放在同一行，横向对照份额走势、新家族、价格、评分和 Amazon 结构。

### 2.2 存在理由

1. "模式 = 指标组合成的信号"：只有同一行横向看才能看出"抢份额 + 新家族进入 + 评分低于同框"这类组合（蓝图 12.6-2A）。
2. 评审会投屏讨论某个框，需要可分享的独立链接和上一框 / 下一框（蓝图 12.6-1A）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 响应 | 打开 ≤ 3 秒（NFR-014） |
| 口径 | 所有指标的分母与比较对象只来自本框、本渠道 |
| 可读性 | 不下结论框只显示体量与份额；趋势不下结论框趋势与新品显示"—" |

### 2.4 不做什么

- **不做**机会类型、把握、分级（只显示扫描里已有的"回测"标记）。
- **不做**"做决策卡"——决策卡从机会扫描生成。
- **不做**跨框、跨渠道合并。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 全部角色可看，页面无写操作 |
| 使用时机 | 评审会前后，逐框讨论 |

### 3.2 核心使用场景

**场景 A：Home Depot 30″ · 整装 · 落地式（可读，主场景）**
- 表现：框头 月均 3,787、渠道内份额 18%、近 3 ÷ 前 3 = 1.04（框平）、可读。
- 看"台面材质：卡拉拉大理石"：份额 13% → 4.4%，走势"丢份额"，溢价 3.03，评分差 −0.16；"台面材质：石英石"新家族 1 个且卖起来，评分差 +0.71。
- "台面材质：岗石"行有"回测：经回测（打折）· B"标记，点击到机会扫描 Home Depot 同框。

**场景 B：Wayfair 24″ · 拆装 · 落地式（不下结论）**
- 表现：框头标"不下结论（分框覆盖 93.7%）"；单元表只有体量与份额两组列，表头说明"分框覆盖 < 95%，其他指标不显示"；月均旁"估算"与低估计。

**场景 C：Wayfair 30″ · 整装 · 落地式（趋势不下结论）**
- 表现：趋势和新品列显示"—（有月度 33%）"，供给、价格、评分、Amazon 对照照常。

## 4. 信息架构

### 4.1 区域划分

1. 页头：面包屑（渠道调研 / Home Depot / 30″ · 整装 · 落地式）、标题、上一框 / 下一框
2. 框头指标条：月均、渠道内份额、近 3 ÷ 前 3（框涨 / 框跌 / 框平）、家族、可读性、分框覆盖、有月度占比、"历史观察"
3. 属性筛选：全部 / 台面材质 / 元素 / 主色 / 柜体材质（chip）
4. 单元宽表：按属性分组（组标题行），组内月均降序；首列冻结；表头两层（指标组 / 指标）
5. 表注：口径（份额分母含该属性未知；价位段 7 段；Amazon 对齐不分拆装、元素按 6 类）

### 4.2 区域内容（单元宽表列）

| 指标组 | 列 |
| :--- | :--- |
| 单元 | 属性：取值（冻结） |
| 体量份额 | 月均（估算 + 低估计）、框内份额 |
| 趋势 | 逐月份额迷你折线（悬停显示月份与份额）、近 3 对前 3（百分点）、走势（抢份额 / 丢份额 / 随框 / 新出现）、斜率（pp / 月）、波动（CV） |
| 新品 | 新家族（个，卖起来个数）、新家族销量占比（同框）、进入月份 |
| 供给 | 家族、价位段、单款 ÷ 同框 |
| 价格 | P25–P75、溢价 |
| 评分 | 评分（同框差） |
| Amazon 同框对照 | 家族 · 价位段 · 份额前 3 月 → 近 3 月 + 方向箭头；或"Amazon 无" |
| 回测 | 有时显示"经回测（打折）· 分级"链接（AC-F30-25） |

## 6. 交互流程

### 6.1 页面加载

- 加载中表格骨架屏；地址的框不存在或未达门槛 → 提示"这个框没有达到月均 200 件的门槛"并给"回到渠道调研"。

### 6.2 核心操作

1. 属性 chip 筛选（单选，默认全部）。
2. 表头排序（组内排序）。
3. 上一框 / 下一框：按 PAGE-F30-01 当前排序（默认月均降序）切换同渠道达门槛的框；到头时按钮不可用。
4. 横向滚动时首列与表头保持可见。
5. 点"回测"标记 → PAGE-F20-01（`channel` + `frame`）。

## 7. 状态与边界

| 状态 | 条件 | 表现 |
| :--- | :--- | :--- |
| 可读 | 覆盖 ≥ 95% 且有月度 ≥ 60% | 全部列 |
| 趋势不下结论 | 覆盖 ≥ 95%，有月度 < 60% | 趋势、新品列"—（有月度 x%）"（AC-F30-21） |
| 不下结论 | 覆盖 < 95% | 只显示单元、体量份额两组；其余组整列不出现，表头上方说明原因（AC-F30-20） |
| 无单元 | 框内无单元 ≥ 20 件 | 空状态 |
| 重算中 / 重算出错 | 同 PAGE-F30-01 | 顶部提示，显示上次结果 |

## 8. 业务规则

| 规则 | 内容 | 来源 |
| :--- | :--- | :--- |
| 框内份额 | 单元销量 ÷ 整框销量（分母含该属性未知） | AC-F30-12 |
| 走势 | ln(近 3 ÷ 前 3 份额) ≥ 0.3 抢份额，≤ −0.3 丢份额，其余随框；前 3 为 0 新出现 | AC-F30-13 |
| 卖起来 | 进入月至窗口末在该单元月均 ≥ 同框每家族月均 | AC-F30-14 |
| 溢价 | 单元加权中位价 ÷ 同框加权中位价 | AC-F30-15 |
| Amazon 方向 | ln 变化 ≥ 0.2 上升，≤ −0.2 下降，其余持平 | AC-F30-16 |
