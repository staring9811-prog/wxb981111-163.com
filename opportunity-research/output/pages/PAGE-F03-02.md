## 2. 页面概述

### 2.1 一句话定位

每次导入后的一份固定体检，让父子体口径混用、重新上架这类问题在算结论之前暴露出来。

### 2.2 存在理由

1. **口径问题会悄悄改变结论**：首评日期是父体口径、老父体挂新子体、销量估算偏低，都会让新品判定和命中率出错，而且不会报错（US-F03-01）。
2. **预警要有人看过并留下理由**：超过阈值的项一直在首页提示，直到 wen 写明为什么可以接受（AC-F03-02），这份说明之后可查。
3. **体检要证明自己没动数据**：体检完成后核对文件指纹（AC-F03-03），后续结论才能追溯到原始数据包。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 固定 | 每个通过校验的数据包都运行同样的 6 项，每项有数值、分母和不超过 5 条样例 |
| 不漏 | 超过阈值且未知晓的项 100% 出现在首页待处理区 |
| 只读 | 体检后每个文件的指纹与导入时 100% 一致，并在页面上显示比对结果 |

### 2.4 不做什么

- **不修改、不修正数据**：只提示。
- **不改阈值**：阈值在 PAGE-F13-01 品类配置中设置。
- **不改字段口径**：口径在 PAGE-F02-01 字段约定中确认。
- **不阻止计算**：预警不阻断计算，由 wen 判断是否可以接受。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 每次导入后（月更第 3 步）；工作台出现体检预警时 |
| 使用设备 | Windows，Chrome / Edge，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：处理体检预警（主场景）**
  - 时机：工作台提示"首次评分早于上架超过 7 天的子体占比 23.4%"。
  - 动作：进入本页 → 看样例（新子体挂在老父体下，带上了父体早年的评论）→ 判断可以接受（字段约定已按父体口径处理）→ "标为已知晓"并写说明 → 首页预警消失。
- **场景 B：看数据质量有没有变差**
  - 动作：对照阈值看各项数值，例如"元素"维度的"未知"占比 38.9%，已接近 40%，细分加入元素维度前先补标签。
- **场景 C：确认体检没有改数据**
  - 动作：看页面下方的指纹比对。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题、副标题、"预警阈值设置"。
2. 预警横幅（有未知晓的预警时）。
3. 体检项：6 项，固定顺序。
4. 指纹比对。
5. 页脚。
6. 弹窗：标为已知晓。

### 4.2 区域内容

**页头**
- 标题"数据体检"。
- 副标题：数据包版本、运行时间、阈值来源（品类配置版本）、"体检只提示，不修改源数据"。
- "预警阈值设置"进入 PAGE-F13-01。

**预警横幅**（常驻，不可关闭）
- 标题"n 项预警待知晓"；正文写出每项的数值与阈值，并说明"标为已知晓并填写说明之前，首页会一直提示"。

**体检项**（每项一行）
- 序号与名称、状态徽章（正常 / 预警 / 已知晓 / 不适用）。
- 数值（比例旁带样本量标签）、分子、分母、预警阈值。
- 一句话说明这项问题会怎样影响结论，以及相关字段。
- 样例：可展开，不超过 5 条；预警项默认展开。
- 预警项右侧"标为已知晓"；已知晓后显示"已知晓 · 操作人 · 时间 · 说明"。

| # | 体检项 | 数值与分母（P-0008） | 预警阈值 | 样例列 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 首次评分日期早于上架日期超过 7 天的子体占比 | 2,318 / 9,906 个有首次评分日期的子体 = 23.4% | 20% | 子 ASIN、父 ASIN、品牌、上架日期、首次评分日期、早于上架天数 | 预警 |
| 2 | 同一父体内子体上架日期跨度超过 180 天的家族数 | 412 个 / 1,977 个有 2 个以上子体的家族（20.8%） | 25% | 父 ASIN、品牌、子体数、最早上架、最晚上架、跨度 | 正常 |
| 3 | 子体月销量低于"过去一个月购买"标签下界的比例 | 1,204 / 19,733 个有标签的子体-月 = 6.1% | 10% | 子 ASIN、月份、子体月销量（估算）、标签、标签下界、低于下界 | 正常 |
| 4 | 各属性维度"未知"占比 | 形态 18.2%、安装方式 21.5%、柜体材质 9.8%、元素 38.9%（分母 41,325 个子体） | 每个维度 40% | 子 ASIN、品牌、"未知"的维度、证据状态、上月销量（估算） | 正常 |
| 5 | 跨月父 ASIN 发生变化的子体数 | 137 个 / 28,604 个出现在 2 个月以上的子体（0.5%） | 300 个 | 子 ASIN、品牌、变化月份、原父 ASIN、新父 ASIN | 正常 |
| 6 | 主键重复数 | 0 行 / 665,504 行（7 个文件） | 出现 1 行即预警 | 文件、主键值、行号 | 正常 |

- 第 4 项用横向条形图显示各维度占比，并画出阈值线；每个数值旁带样本量标签。

**指纹比对**（AC-F03-03）
- 结论："导入时与当前 7 个文件指纹全部一致"，以及比对时间。
- 表格：文件、导入时指纹、体检完成后指纹、结果（一致 / 不一致）。指纹显示前 12 位与后 4 位。

**页脚**：数据包、品类配置（预警阈值）、字段约定版本；"体检只读取只读副本，不修改源数据"。

## 5. 界面内容

### 5.1 元素清单

**标为已知晓（预警项上的按钮）**

## 6. 交互流程

### 6.1 页面加载与初始化

- 显示最近导入并通过校验的数据包的体检结果；口径切换不影响本页。
- 有未知晓的预警时，预警横幅置顶，预警项的样例默认展开。

### 6.2 核心操作流程

```
数据包通过校验 → 系统自动运行 6 项体检（AC-F03-01）→ 完成后比对文件指纹（AC-F03-03）

进入本页
  ├─ 展开样例 → 看具体记录
  ├─ 预警项"标为已知晓" → 弹窗
  │     ├─ 说明为空 → 提示"请填写说明"，不提交
  │     └─ 已填写 → 状态变为"已知晓"，记录说明、操作人和时间
  │                → 预警横幅消失，首页不再显示该预警（AC-F03-02）
  ├─ "预警阈值设置" → PAGE-F13-01 品类配置
  └─ 相关字段 → PAGE-F02-01 字段约定
```

### 6.3 辅助操作

- 第 4 项的条形可悬停或用键盘聚焦，查看分子与分母。
- Esc 或点遮罩关闭弹窗，已填写的说明不提交。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未体检 | 还没有通过校验的数据包 | 空态"还没有体检结果。数据包通过校验后会自动体检。"按钮"去导入数据包"→ PAGE-F01-01 |
| 体检中 | 体检正在运行 | 各项显示进度；顶栏任务指示同步 |
| 全部正常 | 没有超过阈值的项 | 不显示预警横幅 |
| 有预警 | 至少一项超过阈值且未知晓 | 预警横幅；该项"预警"与"标为已知晓"；工作台待处理区同步 |
| 已知晓 | 预警项已标为已知晓 | 该项"已知晓"，显示说明、操作人、时间；首页不再提示 |
| 不适用 | 数据包没有"过去一个月购买"标签 | 第 3 项显示"不适用"，不给数值与样例 |
| 指纹不一致 | 体检后某文件指纹与导入时不同 | 阻断横幅，列出不一致的文件，提示重新导入该数据包；该数据包不能用于计算（DEC-022） |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 导入新数据包 | 重新体检；上一个数据包的"已知晓"不延续，新数据包超过阈值会再次提示（DEC-022） |
| 修改预警阈值 | 品类配置保存新版本后，按新阈值重新判定各项的正常 / 预警 |
| 样例不足 5 条 | 有几条显示几条；没有时写"没有样例" |
| 分母为 0 | 例如数据包没有首次评分日期：该项数值显示"无数据"，不显示 0 |
| 第 4 项某个维度超过阈值 | 任一维度超过阈值，该项即为预警，横幅写明是哪个维度 |

## 8. 业务规则与校验

### 8.1 体检项口径

| # | 分子 | 分母 |
| :--- | :--- | :--- |
| 1 | 首次评分日期早于上架日期超过 7 天的子体 | 有首次评分日期的子体（按子 ASIN 去重） |
| 2 | 家族内子体最晚与最早上架日期相差超过 180 天的家族（家族 = 同一父 ASIN） | 有 2 个以上子体的家族 |
| 3 | 子体月销量低于标签下界的子体-月（"100+ bought in past month"的下界为 100） | 有标签的子体-月；没有标签时"不适用" |
| 4 | 每个维度标签为"未知"的子体 | C4 中的全部子体；每个维度分别与阈值比较 |
| 5 | 不同月份"当月父 ASIN"不同的子体 | 出现在 2 个月以上的子体 |
| 6 | 按各文件约定主键统计的重复行 | 7 个文件的总行数 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 说明 | 点"标为已知晓"时 | 不能为空 | "请填写说明，说明会和操作人、时间一起记录"，弹窗不关闭 |

### 8.3 特殊业务规则

- **阈值来源**：预警阈值在品类配置中设置（REQ-F03-01、REQ-F13-01）；超过阈值即为预警。
- **样例选取**：按偏离程度从大到小取前 5 条（第 4 项按上月销量从高到低，第 5 项按变化月份从近到远），同一数据包每次结果相同。
- **已知晓**：说明必填，记录操作人和时间（NFR-004）；只对当前数据包的该项有效，导入新数据包后重新判断（DEC-022）。
- **只读**：体检只读取只读副本；完成后重新计算每个文件的 SHA-256，与导入时比对（AC-F03-03）。
- **不阻断**：体检预警不阻止计算。
