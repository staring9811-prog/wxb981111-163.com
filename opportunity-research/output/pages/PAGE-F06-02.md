## 2. 页面概述

### 2.1 一句话定位

把一个细分"为什么得这个分"摊开：每个信号的值、分子分母、来源和趋势。

### 2.2 存在理由

1. **核对数字**：排序和锦囊只给结论。wen 立项前要核对支撑数字是否可信——样本多少、回填多少、有没有"无数据"。
2. **看回填占比**：父体回填会影响细分归属，回填占比必须能看到（AC-F06-02）。
3. **定位问题**：痛点构成和细分内新 SPU 能直接把"现有产品没做好""新品进得去"落到具体问题和商品上。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可追溯 | 每个信号都显示分子、分母或参与数量，并能点开证据小标签看来源 |
| 不打断 | 抽屉打开时保留所在页面的筛选与滚动位置，关闭后回到原处 |

### 2.4 不做什么

- **不编辑细分定义**：在品类配置（PAGE-F13-01）修改。
- **不重算信号**：重算在工作台进行。
- **不展示子体级月度明细**：在 SPU 成败明细中查看。

## 3. 用户与场景

- **用户**：产品经理 wen，在 1366–1920 宽屏幕上查看。
- **场景 A**：排序第 1 名的细分要立项前，核对它的"新品进得去"是 9/24 还是更少，回填是否过高。
- **场景 B**：某细分"结构类痛点占比"很高，展开看具体是哪几类痛点，作为立项锦囊的产品改进点。

## 4. 信息架构

1. **抽屉头**：细分名称、"细分详情 · T = 2027-05 · 历史口径"、关闭按钮。
2. **细分定义**：各维度取值与边界说明；"未知"档说明（AC-F06-01）。
3. **当月信号**：
   - 三类信号：需求在涨、新品进得去、现有产品没做好（结构类痛点占比、高销低评占比）。
   - 四个候选信号：标"候选"。
   - 每项显示值、分子 / 分母或参与数量，以及证据小标签。
4. **父体回填**：回填占比、各维度回填比例；注明颜色、尺寸、盆数不回填（AC-F06-02、AC-F06-09、AC-F06-10）。
5. **信号趋势**：需求在涨、新品进得去最近 6 个月的折线，附表格视图。
6. **结构类痛点构成**：按痛点类别的占比条形图，附分子分母。
7. **细分内新 SPU**：判定窗口已结束的新 SPU 列表（编号、批次、成败），以及观察中的数量。
8. **适用锦囊**：当前判定卡下适用的锦囊卡片。
9. **抽屉脚**："在本月排序中查看"、"关闭"。

## 6. 交互流程

```
所在页面点"查看细分"或点击行 → 从右侧推入抽屉
  ├─ 点证据小标签 → 浮层显示字段、来源文件、版本与记录数
  ├─ 悬停或聚焦趋势点 → 提示当月值与分子分母
  ├─ 点新 SPU → SPU 成败明细（PAGE-F05-01）
  ├─ 点锦囊 → 立项锦囊（PAGE-F08-02）
  └─ 点关闭、按 Esc 或点遮罩 → 抽屉收起，回到原页面原位置
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 细分有信号结果 | 全部区块 |
| 部分无数据 | 某信号所需月份缺数据 | 该信号显示"无数据"小标签，不显示 0 |
| 样本不足 | 细分检验组新 SPU < 20 | 抽屉头加"样本不足"徽章，并提示可合并的相邻分档 |
| 截面口径 | 顶栏为截面 | "新品进得去"显示"截面模式不适用"，候选信号注明"老品 n=" |
| 需重算 | 依赖版本已变 | 抽屉头显示"需重算"徽章 |

**边界**：父体级评论只计入该父体上月销量最大的子体所在细分，痛点占比的分母已按此去重（REQ-F06-05）。

## 8. 业务规则

- 第 T 月的信号只使用早于 T 月第一天的数据（AC-F06-03）。
- 属性"未知"的子体归入该维度的"未知"档，不会出现在本细分（AC-F06-01）。
- 类型属性缺子体值时使用父体候选值，并标"父体回填"；颜色、尺寸、盆数不回填（AC-F06-09、AC-F06-10）。
