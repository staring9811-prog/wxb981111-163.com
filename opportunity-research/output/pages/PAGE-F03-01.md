## 2. 页面概述

### 2.1 一句话定位

每月打开系统的第一屏，一眼看清本月进度、要处理的事和当前结论。

### 2.2 存在理由

1. **防止漏处理**：月更要走 8 个步骤，没有总览就容易漏掉。阻断、未确认字段、体检预警这些事一旦漏掉，结论可能用错数据。
2. **体检预警必须在首页常驻**：AC-F03-02 要求在首页显示，直到 wen 标为"已知晓"。
3. **效率目标要看得见**：月更 ≤ 4 小时（D-20）需要随时可见，F14 记录的时间要在这里汇总。
4. **结论可用性一眼可辨**：判定卡"未验证"或"截面口径"时，wen 和看报告的人都必须一眼看到，不能误当正式结论（AC-F08-03、AC-F07-11）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 进度可见 | 8 个步骤的状态与本月实际进度一致，任何未完成或需处理的步骤都显示出来 |
| 待处理零遗漏 | 阻断、未确认字段、未"已知晓"的体检预警、待审合并建议、需重算、到期对账、备份失败，每一类只要存在就出现在待处理区 |
| 去处理更快 | 每个待处理项一次点击即可到达处理页面 |
| 效率可核对 | 月更用时与 F14 运行记录一致（同一口径：导入到导出） |

### 2.4 不做什么

- **不在首页直接确认字段、审核建议或标记"已知晓"**：这些操作要看证据，放在各自页面完成，首页只负责提醒和跳转。
- **不显示完整排序**：只显示前 5 个有效细分，完整排序在 PAGE-F09-01。
- **不自动重算**：只提示"需重算"，由 wen 点"全部重算"（DEC-016）。
- **不做多品类汇总**：第二期 planned 的 PAGE-F15-03 多品类总览负责。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen（第一期唯一操作者） |
| 使用频次 | 每月月更时多次回到首页；立项评审前查看结论 |
| 使用设备 | Windows 笔记本或外接大屏，Chrome / Edge，宽 1366–1920 |
| 熟练度 | 熟悉业务数据，不是开发者 |

### 3.2 核心使用场景

- **场景 A：月更推进（主场景）**
  - 时机：导入新数据包后。
  - 动作：看进度条确认做到哪一步，按"待处理"逐项清掉，最后去导出。
  - 期望：不漏步骤，不必记流程。
- **场景 B：立项评审前快速取数**
  - 动作：看"本月结论"的前 5 个细分和判定卡状态，必要时进入完整排序。
- **场景 C：首次使用**
  - 前提：还没有任何数据包。
  - 页面表现：显示 8 步说明和"导入第一个数据包"。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题、本月信息、操作按钮。
2. 状态横幅区：仅在需要时出现。
3. 8 步进度条。
4. 主栏："待处理"、"本月结论"。
5. 侧栏："用时"、"备份"、"口径与成功线"。

### 4.2 区域内容

**1. 页头**
- 标题"本月工作台"。
- 副标题："2027-05 月更 · 数据至 2027-04"（DEC-005：排序月份 = 数据最新月的下一个月），并显示当前口径和判定卡状态徽章。
- 操作：
  - "全部重算"：次按钮，没有需重算时禁用，悬停提示"当前没有需重算的结果"。
  - 主按钮：随当前步骤变化，例如本月处于第 8 步时为"导出本月报告"。

**2. 状态横幅**（常驻，不可关闭；多条时按下列顺序叠放）
- 阻断：当前数据包有阻断项时显示"数据包 P-xxxx 有 n 个阻断项，不能计算"，并链接到校验报告（AC-F01-02）。
- 需重算：字段约定、SPU 归并或品类配置变了以后显示，列出受影响的结果类型，并提供"全部重算"（AC-F02-07、AC-F04-05、AC-F13-02）。
- 未验证：判定卡未验证时显示"未验证，不可作为立项结论"（AC-F08-03）。
- 截面口径：判定卡来自截面回测时显示"截面口径，待历史回测确认"（AC-F07-11）。

**3. 8 步进度条**（DD-1）

| 序号 | 步骤 | 对应页面 | 状态来源 |
| :--- | :--- | :--- | :--- |
| 1 | 导入校验 | PAGE-F01-01 / PAGE-F01-02 | 当月数据包的校验结论 |
| 2 | 字段约定 | PAGE-F02-01 | 变化字段是否已确认；未确认数 |
| 3 | 数据体检 | PAGE-F03-02 | 是否有未"已知晓"的预警 |
| 4 | SPU 归并 | PAGE-F04-02 | 待审合并建议数 |
| 5 | 成败与信号 | PAGE-F06-01 | 计算是否完成、是否需重算 |
| 6 | 回测 | PAGE-F07-01 | 回测是否完成及结论 |
| 7 | 判定卡与排序 | PAGE-F09-01 | 排序与快照是否已生成 |
| 8 | 记录与导出 | PAGE-F12-01 | 本月是否已导出 |

- 每步显示：序号或状态图标、步骤名、一行状态说明（例："已完成 · 4 分钟"、"1 项预警待知晓"、"待导出"）。
- 状态取值：已完成 / 当前 / 需处理 / 阻断 / 未开始 / 需重算。

**4. 待处理**（主栏）
- 按严重度排序：阻断 → 需重算 → 体检预警（未已知晓）→ 未确认字段 → 待审合并建议 → 到期对账 → 备份失败。
- 每项显示：状态图标与徽章、一句话说明（带数字）、"去处理"链接。
- 没有任何待处理项时显示"本月没有待处理的事项"。

**5. 本月结论**（主栏）
- 判定卡已达标时：显示前 5 个有效细分。
  - 列：排名、细分、预期命中率（区间条加文字区间、样本量小标签）、锦囊动作。
  - 表头注明"竖线为全类目平均 17.2%（n=186）"。
- 判定卡未验证时：表格照常显示，但区块顶部有未验证横幅。
- 底部固定说明参照人群："参照人群：起量新品（任一月父体月销 ≥ 60 件）"（AC-F05-11）。
- 链接"查看完整排序"，进入 PAGE-F09-01。

**6. 用时**（侧栏）
- 本次月更：从导入起算的已用时长，对照 4 小时目标，用进度轨显示；超过 80% 变预警色，超过目标变阻断色。
- 首跑：首跑用时，对照 5 个工作日目标。
- 链接"运行记录"，进入 PAGE-F14-01。

**7. 备份**（侧栏）
- 上次成功备份时间、备份目录。
- 上次失败时：显示失败原因和上次成功时间（AC-F10-07）。
- 说明"导出本月报告后自动备份"（AC-F10-06）。
- 链接到 PAGE-F10-03。

**8. 口径与成功线**（侧栏）
- 当前口径：历史；截面结果见回测页。
- 成功线：6 个月内小类 BSR ≤ 50 或 SPU 任一月销售额 ≥ $100,000（配置 v2）。
- 参照人群：起量新品（≥ 60 件/月）。

## 6. 交互流程

### 6.1 加载与初始化

- **读取状态**：进入页面时读取本月状态，包括当前数据包、各步骤记录、待处理项、判定卡、本月快照、备份记录。
- **没有任何数据包**：显示空状态，即 8 步说明加"导入第一个数据包"。
- **有计算任务在运行**：对应步骤显示"进行中 · 42%"，顶栏任务指示同步显示。

### 6.2 核心操作流程

```
打开工作台
  │
  ├─ 有阻断 → 横幅 + 第 1 步"阻断" → 点击 → 校验报告（PAGE-F01-02）
  │
  ├─ 有待处理项 → 点"去处理" → 对应页面 → 处理后返回，进度条与待处理同步更新
  │
  ├─ 有需重算 → 点"全部重算" → 确认弹窗（列出将重算的结果）→ 后台任务 → 完成后轻提示
  │
  └─ 当前为第 8 步 → 点"导出本月报告" → 导出弹窗（PAGE-F12-01）→ 导出后自动备份 → 第 8 步变为已完成
```

### 6.3 辅助操作

- 点击任一步骤卡片可进入对应页面（不限当前步骤）。
- 点击证据小标签可查看来源（字段、文件、版本、记录数）。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 首次使用 | 尚无数据包 | 空状态：8 步说明加"导入第一个数据包"；不显示结论、用时 |
| 正常 | 本月流程进行中 | 进度条、待处理、结论按数据显示 |
| 计算中 | 有任务在运行 | 对应步骤"进行中 · 百分比"；"全部重算"与运行类按钮禁用 |
| 步骤失败 | 计算或回测失败 | 该步标为阻断，显示失败原因和"重试"；仍显示上一次成功的结果 |
| 阻断 | 当前数据包有阻断项 | 阻断横幅；第 2–8 步不可运行 |
| 需重算 | 依赖的版本已变 | 需重算横幅；受影响的步骤显示"需重算" |
| 未验证 | 判定卡未验证 | 未验证横幅；结论区仍显示排序，但标"未验证" |
| 截面口径 | 判定卡来自截面回测 | 截面横幅；结论区带"截面"小标签 |
| 已导出 | 本月已导出 | 第 8 步已完成；主按钮变为"查看本月排序" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同月多次导出 | 第 8 步显示最近一次导出时间；对账采用当月最后一次导出的快照（DEC-006） |
| 跨月未导出 | 新数据包导入后，上月未导出的快照保留并在台账中标"未导出"，不阻止新月份 |
| 备份失败 | 待处理区出现"备份失败"，显示原因和上次成功时间；不影响导出文件本身 |
| 月更超时 | 用时超过 4 小时：进度轨变为阻断色，并显示"已超出目标 x 分钟"，不打断操作 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 排序月份 | 数据包最新月份的下一个月（DEC-005） |
| 月更用时 | 本月首次导入到本月导出之间的时长；未导出时为"导入至现在"（REQ-F14-01） |
| 首跑用时 | 本品类首次导入到首次生成回测报告之间的工作日数（周一至周五） |
| 步骤状态 | 来自运行记录（AC-F14-01）与各业务对象的当前状态 |

### 8.2 特殊业务规则

- **体检预警**：只要存在未"已知晓"的预警，就在待处理区出现，直到在 PAGE-F03-02 标为已知晓并填写说明（AC-F03-02）。
- **未确认字段**：不阻止计算，但在待处理区提示"不参与计算"（AC-F02-04）。
- **待审合并建议**：不阻止计算；提示相关子体暂按父 ASIN 计（AC-F04-03）。
- **全部重算**：依次重算受影响的结果（成败、信号、回测、排序），完成后生成新的排序快照（序号加 1）。

## 11. 验收标准

### 11.1 功能验收
