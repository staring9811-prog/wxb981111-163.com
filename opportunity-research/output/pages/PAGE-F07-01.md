## 2. 页面概述

### 2.1 一句话定位

用历史批次检验判定卡和各个信号能不能挑出更容易成功的细分，给出达标与否、倍数、区间、样本量和局限。

### 2.2 存在理由

1. **只有检验过的判定卡才能指导立项**：达标才生成判定卡新版本；未达标时判定卡为"未验证"（US-F07-01、REQ-F07-01）。
2. **不确定性要写在数字旁边**：命中率给 Wilson 90% 区间，倍数给重抽样 90% 区间，并附样本量（AC-F07-02）。
3. **要和现用指标比**：判定卡必须高于每个可计算的现用指标各自排序的命中率才算达标；数据包缺数据、算不出的指标写明原因，不参与比较（AC-F07-03、AC-F07-14）。
4. **两种口径并存时要说清以谁为准**：截面结论较弱，必须标注并让位于历史结论（AC-F07-11、AC-F07-12）。
5. **局限要固定可见**：广告投入、站外引流无法观测，结论旁必须写明（AC-F07-07）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 一屏看懂结论 | 首屏并列两种口径的结论、倍数、区间和局限 |
| 可诊断 | 未达标时给出原因分类与对应数值；样本不足的细分给出可合并的分档 |
| 可复现 | 显示随机种子与数据包、字段约定、品类配置版本；同样输入结果一致 |

### 2.4 不做什么

- **不调整判定卡**：入选信号、阈值、权重在判定卡（PAGE-F08-01）查看，由回测生成。
- **不改切分比例和细分分档**：在品类配置（PAGE-F13-01）修改。
- **不导出**：导出在 PAGE-F12-01。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen；结论随导出物给老板看 |
| 使用时机 | 每月计算后运行回测（工作台第 6 步）；配置或归并变化后重新运行；判定卡状态有疑问时 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：月更回测（主场景）**：运行回测后看结论卡是否达标、倍数多少、区间是否跨过 2 倍，再看评估表里判定卡与各现用指标的差距。
- **场景 B：未达标找原因**：看原因分类（数据不足 / 细分样本不足 / 信号无区分度）和数值；样本不足时按"可合并的相邻分档"去品类配置调整。
- **场景 C：样例包阶段**：只有截面数据包时看截面结论和细分 × 月龄达标率表，知道结论"待历史回测确认"。

## 6. 交互流程

### 6.1 加载与初始化

- 显示最近一次回测；两种口径都有结论时，结论区并列，下方报告随顶栏口径切换，默认历史（DEC-011）。
- 只有截面结论时，历史卡显示"还没有历史回测结论"，判定卡状态取截面结论并标"截面口径，待历史回测确认"。

### 6.2 核心操作流程

```
进入回测
  ├─ 点"运行回测"
  │    ├─ 有其他计算任务在运行 → 提示"x 正在运行，完成后再试"
  │    ├─ 已判定批次 < 3 → 不切分，结论卡直接显示"未达标：数据不足"与已判定批次数
  │    └─ 正常 → 后台运行（顶栏任务指示）→ 完成后刷新报告，轻提示用时
  │           ├─ 达标 → 生成判定卡新版本 → "判定卡 v4"按钮更新
  │           └─ 未达标 → 判定卡标"未验证"，结论卡给出原因分类与数值
  ├─ 悬停区间条 / 条形 / 热力格 → 提示数值与样本量
  ├─ 切换顶栏口径 → 下方报告切换为截面口径（结论区不变）
  ├─ 点"判定卡 v4" → PAGE-F08-01
  └─ 点"运行记录" → PAGE-F14-01
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未运行 | 还没有回测结果 | 空状态："还没有回测结果。完成成败与信号计算后，在这里运行回测。"主按钮"运行回测" |
| 运行中 | 回测在后台运行 | 按钮显示步骤名；顶栏任务指示；报告保留上次结果；同时只能运行一个任务（DEC-010） |
| 运行失败 | 回测中断 | 显示失败原因与"重试"；保留上次成功的结果 |
| 达标 | 检验组判定卡前 20% 细分命中率 ≥ 全类目平均 2 倍，且高于每个可计算的现用指标的前 20% 命中率（至少 1 个） | 历史卡"达标"、倍数、区间、达标条件逐项打勾（AC-F07-03） |
| 未达标：数据不足 | 已判定（命中或未命中）批次少于 3 个 | 不切分；结论卡直接显示"未达标：数据不足 · 已判定批次 n 个（至少需要 3 个）"，不显示评估表（AC-F07-08、AC-F07-04） |
| 未达标：细分样本不足 | 检验组大部分细分新 SPU 少于 20，有效细分不足以评估 | 结论卡显示"未达标：细分样本不足"，写有效细分数与样本不足细分数；样本不足表给出可合并的分档（AC-F07-04、AC-F07-05） |
| 未达标：数据不足（无可比指标） | 4 个现用指标都因数据包缺数据无法计算 | 结论卡显示"未达标：数据不足 · 现用指标都无法计算"，评估表列出每个指标的原因（AC-F07-14） |
| 未达标：信号无区分度 | 能评估，但前 20% 命中率低于平均 2 倍，或不高于某个可计算的现用指标 | 结论卡显示"未达标：信号无区分度"，写前 20% 命中率、平均、倍数、最强现用指标的命中率（AC-F07-04） |
| 达标（截面） | 截面回测满足 2 倍且优于每个可计算的现用指标（至少 1 个） | 截面卡"达标（截面）"与"截面口径，待历史回测确认"（AC-F07-11） |
| 两种口径都有 | 同时有历史与截面结论 | 两张卡并列，历史卡"以此为准"，截面卡"已被历史结论取代"（AC-F07-12） |
| 需重算 | 字段约定、归并或品类配置在回测后变了 | 需重算横幅，按钮"重新运行"；旧报告仍可查看（DEC-016） |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 批次不能整除 | 检验组批次数向下取整，至少 1 个（REQ-F07-01）；区块说明写明 |
| 前 20% 细分数 | 有效细分数 × 20% 向上取整，至少 1 个；评估区说明"前 20% = n 个" |
| 样本不足的细分 | 不参与达标评估，但在样本不足表和热力表中照常显示 |
| 合并后仍不足 | 合并后新 SPU 仍少于 20 时注明"仍不足 20" |
| 快照字段 | 被标为"快照"的字段即使已确认，也不进入回测信号，列在"被拒绝的快照字段"中（AC-F02-05） |
| 现用指标在数据包上无法计算 | 例如 P-0001 不含评论痛点（C6），"低分高销"为无数据；观察期只有 4 个月，"属性趋势"为无数据；评估表照常列出、写"无数据"和原因，不参与达标比较（AC-F07-14）；历史数据包同样处理 |

## 8. 业务规则

- **切分**（REQ-F07-01）：已判定批次按上架月份排序，默认前 2/3 定规则、后 1/3 检验（品类配置可改）。
- **达标**（AC-F07-03）：检验组中判定卡排序前 20% 细分的命中率 ≥ 全类目平均命中率 × 2，且高于每个可计算的现用指标各自排序的前 20% 命中率。
- **无法计算的现用指标**（AC-F07-14，D-28）：数据包缺少所需数据的现用指标不参与比较，评估表写原因；可比较的少于 1 个时结论为"未达标：数据不足"。历史与截面两种口径相同。
- **样本不足**（AC-F07-05）：检验组新 SPU 少于 20 个的细分不参与达标评估，提示可合并的相邻分档。
- **区间**（REQ-F07-01）：命中率用 Wilson 90% 区间；倍数用对细分有放回重抽样 1,000 次的 90% 区间，随机种子固定。
- **干扰因素**（REQ-F07-02）：同时纳入 6 项可观察因素；广告投入、站外引流写为局限（AC-F07-07）。
- **截面回测**（REQ-F07-03）：以"新品-月"为一行建模，纳入上架月龄、细分属性和 6 项干扰因素，合成"上架 6 个月内命中概率"排序；细分比较按同一月龄结构标准化；按上架月份前 2/3 建模、后 1/3 检验；基线为只用老品计算、且可计算的现用指标（AC-F07-09、AC-F07-10、AC-F07-13）。
- **两种口径并存**：以历史结论决定判定卡状态（AC-F07-12）。
- **参照人群**：命中率均以起量新品为分母（AC-F05-11）。

### 10.3 明确排除的数据

- 不加载单个 SPU 的月度明细与评论。

**本例中的无法计算指标**（D-28）：截面数据包 P-0001 缺评论痛点（C6）、观察期只有 4 个月，"低分高销""属性趋势"无法计算；截面评估表照常列出这两行并写原因，BT-0007 只和可计算的 2 个指标比较，结论为"达标（截面）"。

**未达标原因的分界**（DEC-036）：已判定批次少于 3 个 → 数据不足（AC-F07-08）；检验组有效细分少于 5 个 → 细分样本不足（前 20% 只剩 1 个细分，无法稳定比较）；其余未达标 → 信号无区分度。原因旁给出对应数值。

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 批次切分 | 报告列出定规则组与检验组的批次月份范围和新 SPU 数（AC-F07-01） |
| F-02 | 评估数值 | 每个信号和组合规则都有前 20% 命中率、全类目平均、倍数、样本量和 90% 区间（AC-F07-02） |
| F-03 | 达标判定 | 满足 2 倍且高于每个可计算的现用指标时标"达标"（AC-F07-03） |
| F-04 | 未达标原因 | 未达标时按数据不足 / 细分样本不足 / 信号无区分度给出原因与数值（AC-F07-04） |
| F-05 | 样本不足 | 检验组新 SPU 少于 20 的细分标"样本不足"、不参与评估，并给出可合并的相邻分档（AC-F07-05） |
| F-06 | 控制前后 | 列出 6 项干扰因素和每个信号控制前后的效果（AC-F07-06） |
| F-07 | 局限 | 结论旁固定显示"广告投入、站外引流未纳入"（AC-F07-07） |
| F-08 | 批次太少 | 已判定批次少于 3 个时不切分，直接显示"未达标：数据不足"和已判定批次数（AC-F07-08） |
| F-09 | 截面切分 | 截面报告列出建模组与检验组批次范围和各组新品-月行数（AC-F07-09） |
| F-10 | 截面评估 | 截面报告给出前 20% 细分截面命中率、平均、倍数、样本量、90% 区间，并与老品计算、可计算的现用指标比较（AC-F07-10） |
| F-11 | 截面标注 | 截面达标显示"达标（截面）"与"截面口径，待历史回测确认"（AC-F07-11） |
| F-12 | 历史优先 | 两种结论并列显示，判定卡状态以历史为准（AC-F07-12） |
| F-13 | 月龄达标率表 | 显示每个细分在月龄 1–6 的达标率、达标数和被观察的 SPU 数（AC-F07-13） |
| F-14 | 快照字段 | 回测报告列出被拒绝的快照字段名（AC-F02-05） |
| F-15 | 参照人群 | 页面标明参照人群为起量新品（AC-F05-11） |
| F-16 | 无法计算的现用指标 | 缺数据的现用指标显示"无数据"和原因、不参与比较；可比较的少于 1 个时结论为"未达标：数据不足"（AC-F07-14） |
