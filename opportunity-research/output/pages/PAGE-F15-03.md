## 2. 页面概述

### 2.1 一句话定位

wen 在这里给同事开账号、分角色、重置密码、停用账号，并查看谁在什么时候做了关键操作。

### 2.2 存在理由

1. 系统不开放注册，账号只能由操作者创建（蓝图 §3），必须有地方建账号并指定角色。
2. 同事离职或换岗时要立即收回访问（AC-F15-05）。
3. 审批、密钥变更和花钱任务需要留痕可查（蓝图 §9 审计日志）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 建账号 | 新账号用设定密码登录后，只拥有所选角色的权限（AC-F15-04） |
| 停用生效 | 停用后该账号已登录会话在下一次请求时失效（AC-F15-05） |
| 留痕 | 登录、审批、密钥变更、花钱任务 100% 进入审计日志 |

### 2.4 不做什么（范围边界）

- **不做自助注册、找回密码、短信 / 邮件验证码**：没有对应需求；忘记密码由 wen 在本页重置。
- **不删除账号**：只停用，保留审批与审计记录的归属。
- **不做自定义角色或细粒度权限**：只有操作者 / 审批者 / 只读三类（REQ-F15-01）。
- **不做重新启用、改角色**：Source IDs 只要求新建、重置密码、停用。
- **审计日志只记四类**：登录、审批、密钥变更、花钱任务（蓝图 §9），不记浏览行为。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 仅操作者（wen）；审批者、只读看不到入口，直接访问显示"无权限" |
| 人数 | 1 人 |
| 使用频次 | 低频：有人入职、离职、忘记密码，或需要查审批留痕时 |

### 3.2 核心使用场景

**场景 A：给采购开只读账号**：点"新建账号"→ 填姓名、账号、初始密码、选"只读"→ 保存 → 把账号和初始密码当面告诉同事。
**场景 B：同事忘记密码**：在列表找到此人 → "重置密码"→ 设新密码 → 告知本人。
**场景 C：运营离职**：点"停用"→ 确认弹窗说明"该账号已登录的会话会在下一次操作时失效"→ 确认 → 状态变为"已停用"。
**场景 D：核对审批留痕**：切到"审计日志"→ 筛选"审批"→ 看到"周建国 10-20 批准策略库条目改为已验证"及其意见。

### 3.3 用户核心诉求

1. **分清角色**：每个人是什么角色一眼可见。
2. **立即生效**：停用后马上收回访问。
3. **可追溯**：关键动作谁做的、何时做的可查。

## 4. 信息架构

### 4.1 区域划分

1. 页头：面包屑"设置 / 账号"、标题、主按钮"新建账号"
2. 标签页：账号（5）｜审计日志
3. 账号列表
4. 审计日志：筛选条 + 表格 + 分页
5. 弹窗：新建账号、重置密码、停用确认

### 4.2 区域内容

**账号列表**：姓名、账号、角色、状态、最近登录、创建时间、操作（重置密码 / 停用 或 启用）。
**审计日志**：时间、账号、类型、内容、来源地址（局域网 IP）。

## 5. 界面内容

### 5.1 元素清单

**新建账号（主按钮，唯一）** → 打开"新建账号"弹窗。

**角色说明**（列表上方一行，帮助选角色）
- 操作者：全部操作，含设置；审批者：看全部，审批和留意见，不能编辑；只读：只看机会扫描、决策卡、台账。

**账号列表字段**

| 字段 | 内容 / 示例 |
| :--- | :--- |
| 姓名 | wen；周建国（老板）；李晓梅（运营）；陈志强（采购）；王磊（研发）；赵敏（运营） |
| 账号 | wen、zhoujianguo、lixiaomei… |
| 角色 | 操作者 / 审批者 / 只读（徽章） |
| 状态 | 正常 / 已停用 |
| 最近登录 | 2026-11-03 09:12；从未登录 |
| 操作 | 重置密码、停用；已停用的行不显示操作；当前登录的自己不显示"停用" |

**新建账号弹窗**
- 姓名*、账号*（不可与已有账号重复）、角色*（单选：操作者 / 审批者 / 只读，附一句权限说明）、初始密码*、确认密码*。
- 按钮：取消 / 创建账号。

**重置密码弹窗**
- 显示对象"李晓梅（lixiaomei）"；新密码*、确认密码*；说明"重置后此人需用新密码登录，已登录的会话不受影响"。
- 按钮：取消 / 重置密码。

**停用确认弹窗**
- 文案："停用 赵敏（zhaomin）？该账号已登录的会话会在下一次操作时失效并回到登录页。审批记录和审计日志保留。"
- 按钮：取消 / 停用（危险样式）。

**审计日志**
- 筛选：类型（全部 / 登录 / 审批 / 密钥变更 / 花钱任务）、账号、日期范围；导出 Excel。
- 每页 50 条，按时间倒序，可按时间排序。
- 示例：
  - 11-03 09:12 wen 登录成功（192.168.1.23）
  - 11-02 15:12 wen 花钱任务：卖家精灵拉取 Amazon 2026-10 续拉 930 次，$9.30
  - 11-02 14:05 wen 花钱任务：卖家精灵拉取 Amazon 2026-10（中断于 1,920 / 2,850）
  - 10-20 16:22 周建国 审批：批准策略库条目"Lowe's 以整装为主，拆装款份额低"改为已验证
  - 10-31 10:02 wen 密钥变更：更换 Bright Data 密钥（••••a91f → ••••7d3c）
  - 10-30 08:57 lixiaomei 登录失败（账号或密码不正确）
- 密钥只出现后 4 位（AC-F16-05）。

### 5.2 辅助信息

- 标签页旁注："审计日志只记录登录、审批、密钥变更、花钱任务。"

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者访问 → 显示无权限页（侧栏中本就没有入口）。
- 操作者 → 默认"账号"标签页。

### 6.2 核心操作流程

```
新建账号 → 填写 → 失焦校验 → 创建
   ├─ 账号重复 → "账号 lixiaomei 已存在"
   ├─ 两次密码不一致 → "两次输入的密码不一致"
   └─ 成功 → Toast"已创建账号 陈志强（只读）"，列表新增一行；写审计日志

停用 → 确认弹窗 → 停用
   └─ 状态改"已停用"；该账号下一次请求被带回登录页（AC-F15-05）

重置密码 → 新密码 ×2 → 重置 → Toast"已重置 李晓梅 的密码"
```

### 6.3 辅助操作

- 审计日志的花钱任务行可跳到 PAGE-F16-02 费用记录。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载态 | 首次进入 | 表格骨架条 |
| 正常态 | 有账号 | 列表如上 |
| 空状态（审计） | 筛选无结果 | "没有符合条件的记录。换个类型或日期范围试试。" |
| 提交中 | 点创建 / 重置 / 停用 | 按钮显示处理中，不可重复点 |
| 错误态 | 保存失败 | 弹窗内阻断提示"保存失败：无法连接服务，请重试"，已填内容保留 |
| 无权限 | 审批者、只读访问本页 | 空状态式提示"无权限：账号管理仅操作者可用。"按钮"回到工作台" |

> 本页无长任务。

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 停用自己 | 当前登录账号不显示"停用" |
| 最后一个操作者 | 系统至少保留一个正常状态的操作者，不允许停用（DEC-103，design-derived，防止无人能管理账号） |
| 账号重复 | 创建时拦截 |
| 停用后对方正在操作 | 对方下一次请求失效回到登录页，未提交内容不保存 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 角色 | 操作者 / 审批者 / 只读，决定可见页面与可做操作（AC-F15-02、AC-F15-03） |
| 状态 | 正常 / 已停用 |
| 审计类型 | 登录 / 审批 / 密钥变更 / 花钱任务 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 姓名、账号、角色、密码 | 失焦、提交 | 必填 | 请填写{字段} |
| 账号唯一 | 失焦 | 不与已有账号重复 | 账号 xxx 已存在 |
| 确认密码 | 失焦 | 与密码一致 | 两次输入的密码不一致 |

### 8.3 特殊业务规则

- 密码加盐哈希保存；页面任何地方不显示已保存的密码。
- 审计日志第一版只记四类（蓝图 §9）；新建、停用账号和重置密码不另设审计类型。

## 9. 页面流转

```
侧栏 设置 › 账号（仅操作者）
        │
        ▼
PAGE-F15-03 账号管理（本页）
   ├─ 停用账号 ─→ 对方会话 → PAGE-F15-01 登录

   └─ 审计日志·花钱任务 ─→ PAGE-F16-02 预算与费用记录
```

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 建账号 | 新建只读账号，用设定密码登录后只能看机会扫描、决策卡、台账（AC-F15-04） |
| F-02 | 角色边界 | 只读账号对决策卡 / 扫描 / 台账发起修改或审批被拒绝并提示"无权限"（AC-F15-02） |
| F-03 | 审批者 | 审批者账号编辑决策卡被拒绝，只能审批和留意见（AC-F15-03） |
| F-04 | 停用立即失效 | 停用后该账号已登录的浏览器下一次请求回到登录页（AC-F15-05） |
| F-05 | 重置密码 | 重置后旧密码登录失败、新密码登录成功 |
| F-06 | 审计日志 | 登录、审批、密钥变更、花钱任务各有记录，可按类型筛选 |

### 11.2 权限验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| P-01 | 入口隐藏 | 审批者、只读的侧栏没有"设置"分组 |
| P-02 | 直接访问 | 非操作者直接打开本页地址显示无权限，不返回账号数据 |

### 11.3 安全验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| S-01 | 密钥不外泄 | 审计日志中的密钥变更只出现后 4 位（AC-F16-05） |
| S-02 | 密码不可见 | 页面与导出中不出现任何密码 |
