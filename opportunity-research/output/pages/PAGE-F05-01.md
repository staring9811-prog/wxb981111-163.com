## 2. 页面概述

### 2.1 一句话定位

把一个新 SPU 为什么是"命中 / 未命中 / 观察中 / 数据不全"（截面口径为"截面命中 / 截面未命中 / 观察中 / 老品"）按月摊开，每个数字都能追到来源记录。

### 2.2 存在理由

1. **成败是回测的结果变量**：单个判定错了会传到命中率。wen 要能核对是哪个月、哪项指标达成（AC-F05-01、AC-F05-02）。
2. **新品口径的风险点要看得见**：上架日取的是哪个子体、哪些子体是新变体、是否疑似重新上架（AC-F04-06–AC-F04-08）。
3. **不进分母的状态要说清还差什么**：观察中还剩几个月、数据不全缺哪些月、截面未命中有哪些月龄没观察到（AC-F05-03、AC-F05-05、AC-F05-07）。
4. **结论要可追溯**：设计蓝图把"每个成败判定可查到所用版本与来源主键"的落点放在本页追溯区。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 一句话可读 | 页头下方一句话说清结论、月份、指标与阈值 |
| 可核对 | 达成金额能由子体表合计出来；最好 BSR 能对上子 ASIN |
| 可追溯 | 版本号与来源记录主键齐全，点开可逐条查看 |

### 2.4 不做什么

- **不改判定**：阈值和窗口在品类配置（PAGE-F13-01）中改。
- **不改归并**：在合并建议（PAGE-F04-02）中拆分或修改。
- **不编辑属性**：属性来自数据包 C4，只展示证据状态。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 抽查新批次的命中 SPU；排查疑似重新上架、新变体；回测结果异常时追到单个 SPU |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：抽查命中**：从新品与 SPU 点进 SPU-2611-007，看说明句和高亮格，再看子体表确认达成金额由哪些子体组成、有没有把新变体当成新品。
- **场景 B：排查口径**：疑似重新上架的 SPU，看最早首评早于上架日多少天、来自哪个子体。
- **场景 C：看还差什么**：观察中的 SPU 看还剩几个月；数据不全的 SPU 看缺哪个月的哪项数据。
- **场景 D：截面口径**：顶栏切到"截面"，看观察月对应的上架月龄和没有观察到的月龄。

### 4.2 区域内容

**面包屑与页头**
- 面包屑"新品与 SPU / SPU-2611-007"。

**判定说明句**（按状态变化，示例取自当前数据）

| 状态 | 说明句 |
| :--- | :--- |
| 命中（销售额） | 命中：第 3 个月（2027-01）SPU 销售额 $112,400 ≥ $100,000；并注明窗口内最好小类 BSR 63（第 3 个月，B0DK7QW3M1），未达到 ≤ 50 |
| 命中（BSR） | 命中：第 2 个月（2026-12）子 ASIN B0DLM2X8RT 小类 BSR 38 ≤ 50 |

| 截面未命中 | 截面未命中：新品期已结束，观察到的第 4–6 个月均未达到成功线水平；未观察到第 1–3 个月 |
| 截面观察中 | 观察中：新品期未结束（已到第 4 个月），还剩第 5–6 个月 |
| 老品 | 老品：观察月全部超出新品期（第 8–11 个月），不做截面判定 |

**判定依据**
- 左列：SPU 上架日及来源子 ASIN（"取全部子体上架日的最早值"）、批次、子体数与新变体数、疑似重新上架（是 / 否及原因）。
- 右列：判定窗口（起止月份、是否结束）、起量（是否起量、哪个月哪个父体达到 60 件）、首次达成（月龄与指标）、归并来源。
- 区块标题旁写当前口径与成功线（取当前品类配置）。

**月龄 1–6 网格**
- 列：第 1–6 个月，每列附自然月；上架当月为第 1 个月。
- 行：
  - 最好小类 BSR 及对应子 ASIN（实测）；
  - SPU 月销售额，即各子体合计（估算）；
  - 父体月销量，每个父 ASIN 一行（估算）。
- 达成格：底色高亮并写"达成"；第一个达成的月份就是判定月份。
- 缺数据：写"无数据"，不写 0；命中之后的缺失在区块说明中注明"不影响判定"。
- 观察中：窗口内还没到的月份写"未到"。
- 截面口径：早于或晚于观察期的月龄写"未观察"；超出新品期的观察月不进网格，在判定依据中注明"不参与截面判定"。

**子体表**

| 列 | 内容 |
| :--- | :--- |
| 子 ASIN | 子 ASIN |
| 父 ASIN | 所属父 ASIN |
| 颜色 · 尺寸 | 子体自己的值，不用父体回填 |
| 上架日 | 作为 SPU 上架日来源的子体注明"SPU 上架日来源" |
| 首评日 | 首次评分日期 |
| 标记 | 新变体（上架晚于 SPU 上架日），悬停说明不计为新 SPU |
| 类型属性 | 形态 · 安装方式 · 台面形态 · 元素；来自父体回填的加"回填"标签，点开看父体候选值、父 ASIN 和来源文件 |
| 月销量、月销售额 | 命中的 SPU 取达成月；其他状态取窗口内 SPU 销售额最高的月份；当月未上架的子体写"当月未上架" |

- 末行合计，等于该月 SPU 月销售额。

**归并来源**
- 来源：编号 / 已确认建议（编号）/ 暂按父体（"有待审建议 MS-xxxx，暂按父 ASIN 计"）。
- 已确认建议时：匹配依据与标题主干、涉及父 ASIN 与各自子体数、确认方式、操作人、时间、修改记录。

**追溯**
- 判定计算时间。
- 版本：数据包（含指纹前 8 位）、字段约定、品类配置。
- 来源记录主键：上架日（C2 · 子 ASIN）、达成金额（C3 · 月份 × 子 ASIN，点开逐条列出）、最好 BSR（C3）、起量（C1 · 站点 × 子 ASIN × 月份）、类型属性（C4）。截面口径为 S1–S3 与 C4。

### 5.1 元素清单

- **成败徽章**：命中、未命中、观察中、数据不全；截面命中、截面未命中、观察中、老品。都由图标和文字组成，未命中为中性色。

- **新变体提示**：例"上架日 2027-02-11 晚于 SPU 上架日 2026-11-03，不计为新 SPU，销量计入本 SPU"。

### 5.2 辅助信息

## 6. 交互流程

### 6.1 加载与初始化

- 按顶栏当前口径显示该 SPU 的判定；默认历史口径。
- 该 SPU 在当前口径没有结果时（例如截面口径下，它上架于截面观察期之后），显示"该 SPU 不在截面数据包 P-0001 的观察期内，没有截面判定"。原型中截面口径改用 SPU-2603-006 演示版式。

### 6.2 核心操作流程

```
从新品与 SPU / 细分详情 / 合并建议进入
  ├─ 看说明句 → 看网格中的高亮格 → 看子体表合计
  ├─ 点"回填"标签 → 浮层：属性、父体候选值、父 ASIN、来源文件
  ├─ 点来源记录小标签 → 浮层逐条列出主键
  ├─ 点"归并记录" / 归并来源 → PAGE-F04-02 合并建议
  ├─ 点面包屑 → PAGE-F04-01，保留原来的筛选
  └─ 切换顶栏口径 → 显示同一 SPU 的另一口径结果或无结果说明
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 命中 | 窗口内任一子 ASIN 小类 BSR ≤ 阈值，或任一月 SPU 销售额 ≥ 阈值 | 说明句写首次达成的月份与指标；BSR 达成时写对应子 ASIN（AC-F05-01），销售额达成时写当月金额（AC-F05-02）；达成格高亮 |
| 未命中 | 6 个月窗口已结束，每月都有销量与 BSR 且都未达标 | 说明句写窗口内最好 BSR 与最高月销售额（AC-F05-04）；无高亮格 |
| 观察中 | 上架至今不足 6 个月且尚未命中 | 说明句写已观察几个月、还剩几个月和窗口结束月；未到的月份写"未到"；注明不计入命中率分母（AC-F05-03） |
| 数据不全 | 尚未命中，且窗口内有月份缺销量或 BSR | 说明句列出缺失的月份与指标；对应格写"无数据"；注明不计入分母（AC-F05-05） |
| 疑似重新上架 | SPU 最早首评日早于上架日超过 7 天 | 页头附加"疑似重新上架"标记；判定依据写原因：最早首评日、来自哪个子体、早多少天（AC-F04-08）；成败照常判定 |
| 有新变体 | 有子体上架晚于 SPU 上架日 | 子体表标"新变体"；不计为新 SPU，销量计入本 SPU（AC-F04-07） |
| 截面命中 | 截面数据包中，任一新品期观察月达到成功线水平 | "截面口径（近似成功线）"横幅（AC-F05-08）；说明句写达成月份与当时月龄（AC-F05-06） |
| 截面未命中 | 新品期已结束，全部新品期观察月都有数据且都未达到 | 说明句列出新品期内未被观察到的月龄（AC-F05-07）；网格中这些月龄写"未观察" |
| 截面观察中 | 新品期未结束且尚未达到 | 说明句写剩余月龄；注明不计入截面命中率分母（AC-F05-09） |
| 老品 | 截面数据包中，全部观察月都超出新品期 | 徽章"老品"；只展示观察月数据，不显示说明句的判定部分和达成格，注明"不做截面判定"（AC-F05-10） |
| 未起量 | 可观察月份的父体月销都低于起量门槛（60 件） | 不出现在新品列表，也不计入命中率分母（AC-F05-12）；从链接直达时页头显示"未起量，不计入命中率分母"，网格照常显示 |
| 暂按父体 | 涉及的合并建议尚未确认 | 归并来源写"暂按父体"，链接到待审建议 |
| 需重算 | 归并、字段约定或品类配置变了 | 页头显示需重算横幅，仍显示旧结果 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 多个子体同为最早上架日 | 页头写其中一个子 ASIN，并注明"同日上架的另有 n 个子体"（取子 ASIN 排序后的第一个，DEC-037） |
| 命中之后缺数据 | 不改变判定；缺失格照常写"无数据"，区块说明写"不影响判定" |
| 同一个月两项都达成 | 说明句两项都写 |
| 有多个父体 | 父体月销量每个父 ASIN 一行；起量只要任一父体任一月达到门槛 |
| 首评日为父体口径 | 按字段约定的口径显示；子体共用父体首评日时如实显示 |

## 8. 业务规则

- **SPU 上架日**：取 SPU 内全部子体上架日期的最早值，并显示来自哪个子 ASIN（AC-F04-06）；新 SPU 按上架日所在自然月划入批次（REQ-F04-02）。
- **新变体**：上架日期晚于所属 SPU 上架日的子体，不计为新 SPU（AC-F04-07）。
- **疑似重新上架**：SPU 最早首次评分日期早于 SPU 上架日超过 7 天（AC-F04-08）。
- **历史口径成功线**（REQ-F05-01）：窗口为上架当月起连续 6 个自然月；任一子 ASIN 任一月小类 BSR ≤ 品类配置阈值（浴室柜 50），或 SPU 任一月各子体销售额合计 ≥ 品类配置月度阈值（浴室柜 $100,000），满足其一即命中。
- **截面口径**（REQ-F05-02）：按上架日算每个观察月的上架月龄，只用第 1–6 个月的观察月判断，阈值同上；结果标"截面口径（近似成功线）"（AC-F05-08）。
- **参照人群**：只判定起量新品，即任一可观察月父体月销达到起量门槛（浴室柜 60 件）的新 SPU（AC-F05-12）。

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 上架日来源 | 页头显示 SPU 上架日及其来自的子 ASIN，等于全部子体上架日的最早值（AC-F04-06） |
| F-02 | 新变体 | 上架晚于 SPU 上架日的子体标"新变体"，不作为新 SPU（AC-F04-07） |
| F-03 | 疑似重新上架 | 最早首评早于上架日超过 7 天时显示标记和原因（AC-F04-08） |
| F-04 | 命中说明 | BSR 命中写首次达成月份与子 ASIN，销售额命中写首次达成月份与当月金额；达成格高亮（AC-F05-01、AC-F05-02） |
| F-05 | 未命中 | 窗口结束、每月有数据且两项都未达标时判"未命中"（AC-F05-04） |
| F-06 | 观察中与数据不全 | 观察中写剩余月数，数据不全列出缺失月份，二者都注明不计入分母（AC-F05-03、AC-F05-05） |
| F-07 | 截面状态 | 截面命中写达成月份与月龄；截面未命中列出未观察月龄；观察中写剩余月龄；老品只展示不判定（AC-F05-06、AC-F05-07、AC-F05-09、AC-F05-10） |
| F-08 | 截面标注 | 截面口径下显示"截面口径（近似成功线）"（AC-F05-08） |
| F-09 | 起量 | 判定依据显示是否起量；未起量 SPU 注明不计入分母（AC-F05-12） |
| F-10 | 可追溯 | 追溯区显示数据包、字段约定、品类配置版本和来源记录主键 |
