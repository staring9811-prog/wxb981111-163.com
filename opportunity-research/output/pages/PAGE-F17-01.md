## 2. 页面概述

### 2.1 一句话定位

每月让系统用卖家精灵接口拉上月浴室柜类目全量，自动核对后再并入，不会把 9 月数据当成 10 月。

### 2.2 存在理由

1. 手动导出耗时且易错：2026-10 两次导出的"10 月"数据都是 9 月数据（PRD §3.3.3），没有核对就会污染全部评分和决策卡。
2. 数据来源切换（2026-06 至 09 来自 v11 表）会让家族键一致性下降、信号失真，必须标 * 提醒（AC-F17-05）。
3. 拉取几千个 ASIN 可能中途失败，要能续拉且不重复计费（AC-F17-02、NFR-011）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 拦截误标 | 满足 AC-F17-03 条件的批次 100% 标"疑似月份错误"且不并入 |
| 续拉 | 中断后再次发起只拉缺的部分，已成功部分 0 次重复调用 |
| 异常留痕 | 经确认并入的异常月份在所有图表和决策卡中 100% 带 * 和原因 |

### 2.4 不做什么（范围边界）

- **不做定时自动拉取**：都由 wen 手动发起（蓝图 §7）。
- **不在本页打标或重算**：并入后转到打标确认、模型与回测。
- **不在本页修改核对阈值**：阈值只展示（见 DEC-102）。
- **疑似月份错误的批次不提供"确认并入"**：AC-F17-03 要求不并入，只能重新拉取或手动上传。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 仅操作者 wen；审批者、只读无入口，直接访问显示无权限 |
| 使用频次 | 每月初 1–3 次 |

### 3.2 核心使用场景

**场景 A：月初拉上月（主场景）**：点"拉取数据"→ 月份默认 2026-10 → 弹出 CMP-F16-01（约 2,850 次、$28.50–$29.50、25–40 分钟）→ 确认 → 看进度 → 核对全部通过 → 点"并入"。
**场景 B：拉取中断**：拉到 1,920 / 2,850 时网络超时 → 批次显示"已中断，已拉 1,920"→ 点"继续拉取"→ 弹窗只评估缺的 930 个 → 确认 → 完成（AC-F17-02）。
**场景 C：数据其实是上月的（2026-11-03 的真实情况）**：核对发现"上月购买标"日期为 2026-09，且与 2026-09 小类排名完全相同的 ASIN 占 99.9% → 批次标"疑似月份错误"，不并入 → wen 等卖家精灵更新后"重新拉取"，或手动导出上传。
**场景 D：核对异常但可接受**：家族键月间一致率 86%（阈值 ≥ 90%），原因是卖家精灵变体字段改版 → wen 查看后点"确认异常并入"，填写说明 → 该月标 *，原因随数据显示在所有图表和决策卡中（AC-F17-04、AC-F17-05）。
**场景 E：接口不可用**：卖家精灵连续失败 → wen 用卖家精灵网页手动导出同格式文件 → "手动上传"→ 核对照常。

### 3.3 用户核心诉求

1. **不并错月**：错误月份拦得住、看得懂为什么。
2. **中断不白花钱**：续拉只拉缺的。
3. **异常有痕**：确认过的异常月份处处带 *。

## 4. 信息架构

### 4.1 区域划分

1. 页头：面包屑"数据 / Amazon 月度数据"、标题、次按钮"手动上传"、主按钮"拉取数据"
2. 流程条：选月份 → 费用评估 → 拉取 → 核对 → 并入（当前批次所在步骤高亮）
3. 当前批次：状态横幅（常驻）、拉取进度与续拉记录、核对结果表、并入 / 确认异常操作
4. 历史月份列表（* 标记与原因）
5. 弹窗 / 抽屉：选月份、CMP-F16-01、确认异常并入、手动上传

### 4.2 区域内容

**当前批次**
- 批次信息：月份、来源（卖家精灵接口 / 手动上传）、发起时间、ASIN 数。
- 拉取进度：已拉 / 总数、百分比、步骤名；续拉记录（每次发起时间、拉取数量、结束原因、计费）。
- 核对结果表：核对项、本批结果、上月对照、阈值、结论（通过 / 异常 / 阻断），每个比例带样本量。

**历史月份列表**
- 月份（异常月份带 *）、来源、ASIN 数、品类总月销、核对结论、状态、并入时间、异常原因、操作（查看扫描）。
- 至少保留 36 个月（NFR-012）；每页 50 条。

## 5. 界面内容

### 5.1 元素清单

**拉取数据（主按钮）**
- 打开"选择月份"弹窗：月份下拉（默认上一个自然月 2026-10；可选 36 个月内任一月），说明"拉取该月浴室柜类目全部商品的月度字段：ASIN、父体、品牌、价格、月销、小类排名、评分、评分数、上架日期、变体、图片、链接"（AC-F17-01）。
- "下一步"→ 弹出 CMP-F16-01（定义见 PAGE-F16-02）；确认后开始。
- 同一月份已有拉取任务在运行时，按钮不可用并提示"2026-10 正在拉取"。
- 卖家精灵未连接时：按钮旁提示"卖家精灵未连接，去设置"→ PAGE-F16-01，不发起调用（AC-F16-03）。

**手动上传（次按钮）**
- 打开抽屉：月份*、文件*（卖家精灵导出的同格式 .xlsx / .csv）、说明"上传后核对规则与接口拉取相同"。
- 文件字段缺失时阻断："文件缺少'小类排名'列（第 1 行表头），请用卖家精灵'类目选品'导出同格式文件"。

**当前批次状态横幅（常驻，不可关闭）**
| 状态 | 横幅 | 可用操作 |
| :--- | :--- | :--- |
| 拉取中 | 进度横幅"正在拉取 2026-10：1,824 / 2,850（64%）· 拉取商品月度字段" | 暂停 |
| 已中断 | 预警"拉取中断：已拉 1,920 / 2,850，原因：网络超时。已拉部分已保存" | 继续拉取（只拉缺的 930 个） |
| 已达上限暂停 | 预警"卖家精灵本月已达上限，已拉部分保留" | 调整上限（PAGE-F16-02）后继续 |
| 疑似月份错误 | 阻断"2026-10 疑似月份错误，未并入分析" + 原因 | 重新拉取、手动上传 |
| 核对异常 | 预警"核对有 1 项异常，需确认后才能并入" | 确认异常并入、放弃本批 |
| 核对通过 | 通过"核对全部通过" | 并入 |
| 已并入 | 通过"2026-10 已并入，已触发新商品打标" | 去打标确认 |

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者 → 无权限页。
- 有未完成批次 → 默认展示该批次；否则展示最近一个月份，月份下拉默认上一个自然月。

### 6.2 核心操作流程

```
拉取数据 → 选月份（默认上月）→ CMP-F16-01
   ├─ 取消 → 不调用
   └─ 确认 → 拉取（顶栏任务指示 + 本页进度）
        ├─ 中断 / 达上限 → 保存已拉部分 → "继续拉取" → CMP-F16-01（只评估缺的）→ 续拉
        └─ 完成 → 自动核对
              ├─ 月份误标 → 疑似月份错误：不并入，提示 wen → 重新拉取 / 手动上传
              ├─ 有异常 → 确认异常并入（带 * 与原因）/ 放弃本批
              └─ 全部通过 → 并入 → 触发打标（PAGE-F18-01）与重算（PAGE-F19-01）

手动上传 → 选月份 + 文件 → 格式校验 → 核对（同上）
```

### 6.3 辅助操作

- 历史月份"查看扫描"→ PAGE-F20-01（以该月为截止的扫描结果）。
- 续拉记录中的计费链接到 PAGE-F16-02 明细。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空状态 | 从未拉取任何月份 | "还没有 Amazon 月度数据。先拉取上一个自然月（2026-10），或手动上传卖家精灵导出文件。" + 拉取按钮 |

| 核对中 | 拉取完成 | "正在核对 5 项…"，按项依次给出结论 |
| 阻断（疑似月份错误） | AC-F17-03 | 阻断横幅，无并入按钮 |
| 异常待确认 | AC-F17-04 | 预警横幅，"确认异常并入" |
| 错误态 | 接口失败 / 文件格式不对 | 写明哪个服务或哪个文件、哪一列、哪几行，给出修复方式 |

| 无权限 | 非操作者 | "无权限：Amazon 月度数据仅操作者可用" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同一月份重复发起 | 同时只能运行一个拉取任务（PRD §5.2） |
| 已并入的月份再次拉取 | 生成新批次，核对通过并入时替换旧版本；旧版本保留可回看（NFR-012） |
| 续拉 | 已成功的 ASIN 不重复调用、不重复计费（NFR-011） |
| 卖家精灵接口失败 | 可手动上传同格式文件，核对照常（PRD §5.3） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 月份 | 数据所属自然月，默认上一个自然月 |
| 拉取字段 | ASIN、父体、品牌、价格、月销、小类排名、评分、评分数、上架日期、变体、图片、链接（AC-F17-01） |
| 批次状态 | 拉取中 / 已中断 / 已达上限暂停 / 核对中 / 疑似月份错误 / 核对异常 / 核对通过 / 已并入 / 已并入* / 已放弃 |
| * 标记 | 经 wen 确认并入的异常月份，附异常原因（AC-F17-05） |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 结果 |
| :--- | :--- | :--- | :--- |
| 上月购买标日期 | 核对 | 须在所标月份 | 不符 → 疑似月份错误 |
| 排名重合比例 | 核对 | 两月都出现的 ASIN 中小类排名完全相同的比例 ≤ 10% | > 10% → 疑似月份错误 |
| 品类总月销变化 | 核对 | 较上月在设定阈值内（DEC-102 默认 ±30%） | 超出 → 异常 |
| 家族键月间一致率 | 核对 | ≥ 设定阈值（默认 90%） | 低于 → 异常 |
| 标签覆盖率 | 核对 | 每个标签 ≥ 设定阈值（默认 95%） | 低于 → 异常 |
| 上传文件 | 上传 | 与卖家精灵导出同格式、字段齐全 | 缺列 → 阻断并指出列名 |

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 拉取上月 | 默认月份为上一个自然月；确认费用后拉取该月浴室柜全部商品的 12 个月度字段（AC-F17-01） |
| F-02 | 先评估 | 拉取和续拉前都弹出 CMP-F16-01，取消不调用（AC-F16-07） |
| F-03 | 断点续拉 | 中断后已拉部分保留，再次发起只拉缺的部分，不重复计费（AC-F17-02、NFR-011） |
| F-04 | 月份误标 | 上月购买标日期不在所标月份，或排名完全相同比例 > 10% 时，批次标"疑似月份错误"、不并入并提示（AC-F17-03） |
| F-05 | 来源与覆盖核对 | 并入前显示品类总月销变化、家族键月间一致率、各标签覆盖率；任一超阈值标"异常"，需确认后才并入（AC-F17-04） |
