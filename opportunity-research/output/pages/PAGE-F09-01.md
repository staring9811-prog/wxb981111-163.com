## 2. 页面概述

### 2.1 一句话定位

立项评审前的统一候选清单：按当前判定卡给全部细分排好序，每个细分带预期命中率区间和锦囊动作。

### 2.2 存在理由

1. **同一标准排序**：每月按同一张判定卡给全部细分打分排序，立项评审有一份可复现的候选清单（US-F09-01）。
2. **区间比排名更重要**：排名相近的细分区间可能大幅重叠，必须同时看到预期命中率区间和样本量（AC-F09-01）。
3. **小样本不能混在前面**：样本不足的细分得分可能虚高，必须放到最后并标明（AC-F09-02）。
4. **预测要留底**：本月排序生成即保存快照，6 个月后用它对账（AC-F10-01）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可复现 | 同一输入两次生成的排序完全一致，包括得分相同的细分 |
| 口径清楚 | 判定卡状态、参照人群、快照版本在页头始终可见 |
| 去处理快 | 从任一细分一次点击到细分详情或记录立项决定 |

### 2.4 不做什么

- **不手工调整排序**：排序只由判定卡决定；要改，重新回测生成新判定卡。
- **不在本页编辑锦囊**：锦囊在 PAGE-F08-02 查看，规则在策略库修改。
- **不展示信号明细**：每个细分的信号与分子分母在细分详情（PAGE-F06-02）查看。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 月更回测完成后；立项评审前后；导出报告前 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：立项评审前**
  - 动作：看前几名的区间和锦囊动作，点开细分核对信号，导出报告发给老板。
- **场景 B：记录评审结论**
  - 动作：评审后在对应细分行点"记录决定"，填立项或不立项及理由；快照自动带入。
- **场景 C：判断小样本细分**
  - 动作：看到分隔线后的"样本不足"细分，知道它们的区间很宽、锦囊动作只供参考，不据此立项。

### 4.1 区域划分

1. 页头：标题、月份与口径、判定卡状态、参照人群、快照状态、操作。

## 6. 交互流程

### 6.1 加载与初始化

- 读取当前月份 T（数据最新月的下一个月，DEC-005）的最新快照：排序、锦囊、判定卡版本与状态。
- 同月有多个快照时显示最新一版，页头写明版本序号（DEC-006）；旧版在台账中查看。

### 6.2 核心操作流程

```
进入本月排序
  ├─ 点击一行或"查看细分" → PAGE-F06-02 细分详情（抽屉，关闭后回到本页原位置）
  ├─ 点"记录决定" → PAGE-F10-02 记录立项决定（弹窗，自动带入该细分和本月快照）
  ├─ 点规则编号 → PAGE-F08-02 立项锦囊
  ├─ 点"导出报告" → PAGE-F12-01 导出报告（弹窗）→ 导出后自动备份
  └─ 点"在台账查看快照" → PAGE-F10-01 台账 · 月度快照
```

### 6.3 辅助操作

- 区间条悬停或键盘聚焦看点估计、区间与样本量。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未生成 | 本月还没有回测或判定卡 | 空状态："还没有 2027-05 的排序。运行回测生成判定卡后，系统会排序并保存本月快照。"按钮"去回测"（PAGE-F07-01）；"导出报告"不可用 |
| 正常 | 有本月快照 | 页头 + 排序表 |
| 未验证 | 判定卡未验证 | 预警色横幅"未验证，不可作为立项结论"（AC-F08-03）；排序照常显示；页头徽章为"未验证" |
| 截面口径 | 判定卡为达标（截面） | 截面横幅"截面口径，待历史回测确认"（AC-F07-11）；区间旁加"截面"小标签；参照人群后加"截面口径（近似成功线）" |
| 需重算 | 字段约定、归并或配置变了 | 需重算横幅；排序仍显示当前快照；重算完成后生成新快照，序号加 1 |
| 回测运行中 | 有回测任务在运行 | 页头提示"回测运行中，完成后生成新排序"；当前排序保持不变 |
| 已导出 | 本月快照已导出 | 快照状态后加"已导出 · 时间"；仍可再次导出 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 得分相同 | 按样本量从大到小，再按细分名称排序（REQ-F09-01），保证每次结果一致 |
| 样本量少于 20 个新 SPU | 标"样本不足"，排在全部有效细分之后，彼此按得分排序；仍显示区间与锦囊（AC-F09-01、AC-F09-02） |
| 细分没有适用锦囊 | 锦囊动作列写"无适用锦囊" |
| 同一细分适用多条锦囊 | 主行显示回测得出的锦囊；其余锦囊在下方另起一行显示动作与规则编号 |
| 同月重新生成排序 | 新存一个快照（第 n+1 版），旧快照保留不改（DEC-006、AC-F10-01） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 月份 T | 数据最新月的下一个月（数据至 2027-04 → 2027-05，DEC-005） |
| 得分 | 按当前判定卡的入选信号、阈值与权重计算 |
| 预期命中率 | 点估计与 90% 区间（Wilson），来自生成判定卡的回测 |
| 样本量 | 细分内已判定的起量新 SPU 数；少于 20 为样本不足 |
| 快照 | 本月排序、锦囊与判定卡版本号的只读副本，带序号与内容指纹 |

### 8.2 特殊业务规则

- **排序**：按当前判定卡对全部细分排序，每个细分显示排名、得分、预期命中率区间、样本量和适用锦囊（AC-F09-01）；得分相同时按样本量、名称排序（REQ-F09-01）。
- **样本不足**：样本量少于 20 个新 SPU 的细分标"样本不足"，排在全部有效细分之后（AC-F09-02）。
- **快照**：排序生成时自动保存当月快照，保存后不允许修改（AC-F10-01）。
- **参照人群**：命中率旁标明参照人群为"起量新品（任一月父体月销达到品类配置门槛，浴室柜 60 件）"（AC-F05-11）。
- **未验证与截面**：见状态表（AC-F08-03、AC-F07-11）；两种结论并存时以历史为准（DEC-011）。
