## 2. 页面概述

### 2.1 一句话定位

告诉 wen 这个数据包能不能用于计算；不能用时，具体错在哪个文件、哪个字段、哪几行。

### 2.2 存在理由

1. **不合格的数据不能悄悄进入计算**：用错数据得出的命中率会直接误导 30–40 万元的立项（US-F01-01）。
2. **少量坏行不该挡住整批数据**：不超过 1% 的坏行只警告并排除，但被排除的行号必须能查，避免"悄悄少算"（AC-F01-03）。
3. **出错要能修**：阻断项要给出文件、字段和示例行号，wen 才能交给数据项目修正后重新导入（AC-F01-02）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 结论先行 | 进入页面第一屏就能看到结论和能否计算 |
| 逐项可查 | 每个文件、每个必需字段都有结果和受影响行数 |
| 可修复 | 每个阻断项都有文件名、字段名和不超过 5 个示例行号；每个警告都列出全部被排除的行号 |

### 2.4 不做什么

- **不修改、不修复数据**：数据包只读；有问题由数据项目修正后重新导入。
- **不判断字段含义和用法**：在 PAGE-F02-01 字段约定中确认。
- **不做口径体检**：首评早于上架、"未知"占比等在 PAGE-F03-02 数据体检中查看。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 每次导入后自动进入；工作台出现阻断时回来查看 |
| 使用设备 | Windows，Chrome / Edge，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：导入后确认能否计算（主场景）**
  - 动作：看结论条 → 有警告时展开被排除的行号核对一下 → 点"去确认字段约定"。
- **场景 B：数据包有阻断**
  - 动作：看阻断明细 → 把文件名、字段名和示例行号发给数据项目 → 修好后回到数据包页重新导入。
- **场景 C：截面样例包没有评论痛点表**
  - 页面表现：结论条注明"缺少痛点信号，回测先用另两类信号"，仍可计算。

## 4. 信息架构

### 4.1 区域划分

1. 页头：面包屑、标题、副标题、操作。
2. 结论条。
3. 摘要数字。
4. 逐项检查矩阵。
5. 问题明细：阻断 / 警告两个标签。
6. 必需字段逐项结果：按文件分标签。
7. 下一步卡片。
8. 页脚。

### 4.2 区域内容

**页头**
- 面包屑"数据包 / P-0008"。
- 标题"校验报告 · P-0008"。
- 副标题：类型与所用约定、覆盖月份、导入时间与操作人、校验完成时间。
- 操作："数据体检"（次按钮）、"去确认字段约定"（主按钮）；有阻断时主按钮换为"重新导入"。

**结论条**（三选一）

| 结论 | 标题 | 正文 |
| :--- | :--- | :--- |
| 通过 | "通过 · 可以计算" | 没有阻断项和警告；已成为当前历史 / 截面数据包 |
| 有警告 | "有警告 · 可以计算" | 警告数、被排除的总行数，说明都不超过所在文件的 1%；已成为当前数据包 |
| 阻断 | "阻断 · 不能计算" | 阻断项数；"修好数据包后重新导入"；不会成为当前数据包（DEC-011） |

- 截面数据包没有 C6 时，任一结论下都加一句"缺少痛点信号，回测先用另两类信号"（PRD §5.3）。
- 阻断结论条常驻，不可关闭。

**摘要数字**：文件数（实际 / 约定）、总行数、阻断项数、警告项数与排除行数。

**逐项检查矩阵**

| 列 | 内容 |
| :--- | :--- |
| 文件 | 文件名与主键说明；可选文件注明"可选" |
| 行数 | 文件总行数 |
| 必需文件 | 已提供 / 缺失 |
| 必需字段 | 通过的必需字段数 / 约定的必需字段数，受影响行数 |
| 主键唯一 | 重复的行数 |
| 日期与数值解析 | 无法解析的行数与涉及字段 |
| 月份覆盖 | 实际覆盖范围，是否满足约定（C7 显示"不适用"） |

- 每格为"结果徽章 + 受影响行数或说明"，通过时受影响行数为 0。
- 行：历史包为 C1–C7；截面包为 S1–S3、C4，以及提供了的 C5–C7，未提供的可选文件显示"未提供（可选）"。

**问题明细**
- "阻断"标签：每个阻断项一行，显示文件、字段、问题、受影响行数与占比、不超过 5 个示例行号（AC-F01-02）。没有时显示"没有阻断项"。
- "警告"标签：每个警告一行，显示文件、字段、无法解析的行数与占比、示例值和约定格式；"被排除的 n 个行号"可展开，列出全部行号（AC-F01-03）。
- 默认选中有内容的标签；两者都有时默认"阻断"。

**必需字段逐项结果**（AC-F01-01）
- 按文件分标签（C1 14、C2 7、C3 5、C4 21、C5 4、C6 8、C7 3）。
- 每个必需字段一行：字段、格式、结果、受影响行数、说明。
- 表下注明已提供的可选字段，以及约定外字段（例：P-0008 的 C1 多了 Prime价格、优惠券，交给字段约定确认）。

**下一步卡片**：变化字段数与当前待确认数，例："P-0008 比 P-0007 多 2 个字段（C1 的 Prime价格、优惠券），其余 78 个沿用原约定。目前还有 1 个待确认：优惠券。"进入 PAGE-F02-01。

## 5. 界面内容

### 5.1 元素清单

**去确认字段约定（主按钮）**
- 有阻断时改为次按钮并不可用，悬停提示"存在阻断项，不能计算。修好数据包后重新导入"；主按钮换为"重新导入"，进入 PAGE-F01-01。

**数据体检（次按钮）**
- 有阻断时不可用，提示"有阻断项，没有运行体检"（体检在通过校验后运行，AC-F03-01）。

**行号**
- 按文件中的行计，表头为第 1 行；千分位显示，例"18,204"。

**证据小标签**
- 占比旁标该文件的总行数，例"0.009% n=412,806"。

### 5.2 辅助信息

页脚：校验报告生成时间、只读副本目录、数据包指纹，例"校验报告生成于 2027-05-08 09:18 · 只读副本 D:\机会判定台\数据包\P-0008\ · 数据包指纹 9f3c2a7e"。

## 6. 交互流程

### 6.1 页面加载与初始化

- 读取该版本的校验结果；从导入流程进入时直接显示结论。
- 默认展开第一个有问题的标签；被排除的行号默认收起。

### 6.2 核心操作流程

```
导入完成，自动进入本页
  │
  ├─ 无阻断、无警告 → "通过 · 可以计算" → 点"去确认字段约定" → PAGE-F02-01
  │
  ├─ 无阻断、有警告 → "有警告 · 可以计算"（警告行已在计算中排除）
  │      └─ 展开"被排除的 n 个行号"核对 → 点"去确认字段约定" → PAGE-F02-01
  │
  └─ 有阻断 → "阻断 · 不能计算"（常驻）
         ├─ 不能对该数据包启动任何计算步骤（AC-F01-02）
         └─ 看阻断明细 → 交数据项目修正 → 点"重新导入" → PAGE-F01-01
```

### 6.3 辅助操作

- 切换"阻断 / 警告"标签、切换文件标签。
- 点面包屑"数据包"回到版本列表。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载中 | 打开报告 | 结论条与表格显示骨架条 |
| 通过 | 无阻断、无警告 | 成功色结论条"通过 · 可以计算"；问题明细两个标签都为 0 |
| 有警告 | 某文件无法解析的行大于 0 且不超过该文件 1% | 预警色结论条"有警告 · 可以计算"；"警告"标签默认选中，行号可展开 |
| 阻断 | 至少一个阻断项 | 红色常驻结论条"阻断 · 不能计算"，写明阻断项数和"修好数据包后重新导入"；"阻断"标签默认选中；"去确认字段约定""数据体检"不可用并提示原因，主按钮换为"重新导入"；工作台第 1 步显示阻断，计算类按钮对该数据包不可用 |
| 缺少痛点信号 | 截面包没有 C6 | 结论条加"缺少痛点信号，回测先用另两类信号"；矩阵中 C6 显示"未提供（可选）" |
| 清单阻断 | 清单缺失或类型无法识别 | 只有一项阻断："清单文件缺失"或"类型无法识别"，矩阵不展开逐文件检查（AC-F01-06） |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 阻断项涉及整列或整个文件 | 字段缺失、文件缺失时受影响行数写"整列"或"整个文件"，不列示例行号 |
| 一个文件既有警告又有阻断 | 按最严重的结果显示该格；问题明细分别列出 |
| 被排除的行号很多 | 按升序排列，可展开查看全部；超过 1% 时已是阻断，示例行号只列 5 个 |
| 空值 | 缺失留空不算"无法解析"（约定 v1：缺失留空，不填 0） |

## 8. 业务规则与校验

### 8.1 检查项与分级

| 检查项 | 规则 | 结果 |
| :--- | :--- | :--- |
| 必需文件 | 约定要求的文件都在 | 缺失为阻断 |
| 必需字段 | 每个必需字段都在 | 缺失为阻断 |
| 主键唯一 | 按约定主键无重复（例 C1：站点 × 子 ASIN × 月份） | 重复的行按"无法解析的行"计：≤ 该文件 1% 为警告并排除，> 1% 为阻断（待确认，见 8.3） |
| 日期与数值解析 | 日期为 YYYY-MM-DD，月份为 YYYYMM，数值字段为数字 | 无法解析的行 ≤ 该文件 1% 为警告并排除，> 1% 为阻断（REQ-F01-01） |
| 月份覆盖 | C1 自 2024-10 起至最新月；C2 上架日自 2024-04-01 起；C3 每个新品自上架起至少 6 个月或至最新月；C4 覆盖 C1、C2 全部子 ASIN；C5 自 2023-12 起；C6 至最新月（PRD §10.4） | 不满足时为警告并说明影响（待确认，见 8.3） |

### 8.2 按类型选择约定

- 清单声明"历史"：按约定 v1 校验 C1–C7（C7 可选）。
- 清单声明"截面"：按约定 v1.1 校验 S1–S3、C4；C5–C7 可选（AC-F01-06）。
- 清单缺失或类型无法识别：记为阻断（AC-F01-06）。

### 8.3 特殊业务规则

- **有阻断时**：禁止对该数据包启动任何计算步骤，并显示每个阻断项的文件名、字段名和不超过 5 个示例行号（AC-F01-02）；该版本不会成为当前版本（DEC-011）。
- **警告行**：在后续所有计算中排除，报告列出全部被排除的行号（AC-F01-03）。
- **约定外字段**：不影响结论，列出后交给字段约定确认（AC-F02-06）。
- **分级规则**（DEC-019）：REQ-F01-01 只对"无法解析的行"规定了 1% 警告线，主键重复与月份覆盖不足按以下两条处理：主键重复的行与无法解析的行一样按 1% 线分级（体检第 6 项"主键重复数"统计它们，见 PAGE-F03-02）；月份覆盖不足为警告并说明影响（例：C5 缺早期月份时，早期批次的"需求在涨"显示"无数据"，PRD §10.4）。

## 9. 页面流转

### 9.1 流转图

```
PAGE-F01-01 数据包 ──（导入完成 / 点版本行）──→ 校验报告（本页）
PAGE-F03-01 工作台 ──（第 1 步 / 阻断横幅）────→ 校验报告（本页）
```

- 工作台第 1 步"导入校验"的状态取自本页结论；有阻断时工作台显示阻断横幅并链接到本页。
- 数据体检只在通过校验后运行（AC-F03-01）。

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 逐项报告 | 每个文件、每个必需字段都显示结果（通过 / 警告 / 阻断）和受影响行数（AC-F01-01） |
| F-02 | 阻断禁止计算 | 有阻断项时结论为"阻断 · 不能计算"，不能对该数据包启动任何计算；每个阻断项显示文件名、字段名和不超过 5 个示例行号（AC-F01-02） |
| F-03 | 警告排除 | 无法解析的行大于 0 且不超过该文件 1% 时，该文件标为警告，报告列出全部被排除的行号，后续计算不含这些行（AC-F01-03） |
| F-04 | 按类型校验 | 历史包按 C1–C7、截面包按 S1–S3 与 C4 校验；清单缺失或类型无法识别记为阻断（AC-F01-06） |
| F-05 | 缺少痛点信号 | 截面包没有 C6 时，结论条注明"缺少痛点信号"（PRD §5.3） |
| U-01 | 结论先行 | 第一屏可见结论条与能否计算 |
| U-02 | 阻断常驻 | 阻断结论条不可关闭 |
