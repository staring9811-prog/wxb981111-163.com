## 2. 页面概述

### 2.1 一句话定位

把回测得出的"用哪些信号、阈值多少、各占多少权重"固定成一张带版本的判定卡，并写明它凭什么可用、是否可用。

### 2.2 存在理由

1. **标准要固定**：排序、锦囊都按当前判定卡算。卡上的信号、阈值、权重必须有明确版本，换月、换人都按同一标准判断（US-F08-01）。
2. **依据要摆出来**：判定卡是否可信取决于回测——检验了哪些批次、样本多少、倍数多少（AC-F08-01）。
3. **不可用时必须一眼看到**：回测未达标时判定卡为"未验证"；只有截面结论时为"达标（截面）"。两种情况都不能被当成正式立项结论（AC-F08-03、AC-F07-11）。
4. **版本要能回看**：快照、对账都记录当时用的判定卡版本，需要能看到每一版的来源和变化。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 状态无歧义 | 页面顶部始终显示当前判定卡的状态横幅，状态与回测结论一致 |
| 依据完整 | 当前版本同时显示入选信号、阈值、权重、批次范围、样本量、倍数与区间 |
| 可追溯 | 每个版本都能看到生成日期、口径、结论、来源回测编号和与上一版的差异 |

### 2.4 不做什么

- **不手工编辑判定卡**：判定卡只由回测生成（REQ-F08-01）；要改信号或阈值，改品类配置或数据后重新回测。
- **不运行回测**：回测在 PAGE-F07-01 运行，本页只给入口。
- **不展示锦囊全文**：只列本版锦囊的动作和条件，完整内容在 PAGE-F08-02。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen（第一期唯一操作者） |
| 使用时机 | 每月回测完成后确认判定卡；立项评审前说明"为什么按这个排序" |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：月更后确认**
  - 时机：本月回测完成、判定卡生成新版本后。
  - 动作：看状态横幅是否达标，对比与上一版的差异，再去看锦囊和排序。
- **场景 B：评审时说明依据**
  - 动作：向老板说明入选信号和权重、检验组批次和样本量、倍数及区间，以及与 4 个现用指标的对比。
- **场景 C：回测未达标**
  - 动作：看到"未验证，不可作为立项结论"和原因，回到回测页排查数据或配置。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未回测 | 还没有任何回测结果 | 空状态："还没有判定卡。完成成败与信号计算后，在回测页运行回测，达标后在这里生成判定卡。"按钮"去回测"（PAGE-F07-01） |
| 已达标 | 最近一次历史口径回测达标 | 成功色横幅；显示当前版本与依据 |
| 达标（截面） | 只有截面回测，且截面达标 | 截面紫横幅"截面口径，待历史回测确认"；回测依据显示"新品-月"行数；对照为只用老品的 4 个现用指标；倍数旁标"截面" |
| 未验证 | 最近一次回测未达标 | 预警色横幅"未验证，不可作为立项结论"，写明原因分类与数值；入选信号与依据仍显示，便于排查，但区块标题标"未验证" |
| 需重算 | 字段约定、SPU 归并或品类配置在判定卡生成后变了 | 需重算横幅（DEC-016），仍可查看当前版本；重算并回测后再生成新版本 |
| 回测运行中 | 有回测任务在运行 | 页头提示"回测运行中，完成后更新判定卡"；当前内容保持上一版 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 历史与截面结论并存 | 状态以历史为准（AC-F07-12）；截面卡在版本历史中标"已被历史结论取代" |
| 历史未达标、截面达标 | 显示"未验证"，不显示"达标（截面）"作为当前状态 |
| 批次少于 3 个 | 横幅原因写"未达标：数据不足"，并显示已判定批次数（来自 AC-F07-08 的回测结论） |
| 回测失败 | 保留上一版判定卡与状态，不生成新版本（DEC-010） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 判定卡版本 | 回测达标时生成新版本（AC-F08-01）；历史卡编号 v1、v2…，截面卡编号 截面 v1… |
| 入选信号、阈值、权重 | 由来源回测确定，生成后不可修改 |
| 回测依据 | 来源回测的批次范围（定规则组、检验组）、检验组样本量、前 20% 细分命中率与 Wilson 90% 区间、全类目平均、倍数与重抽样 90% 区间（REQ-F07-01） |
| 判定卡状态 | 已达标 / 达标（截面）/ 未验证 |

### 8.2 特殊业务规则

- **未验证**：回测结论为"未达标"时，判定卡标为"未验证"，本页和所有展示判定卡、排序或锦囊的页面都显示"未验证，不可作为立项结论"（AC-F08-03）。
- **截面标注**：截面回测达标时，判定卡状态为"达标（截面）"，并显示"截面口径，待历史回测确认"（AC-F07-11）。
- **历史优先**：同时存在两种结论时，以历史结论决定判定卡状态（AC-F07-12、DEC-011）。
- **只追加**：判定卡版本只追加，旧版本只读；快照记录所用版本号（DEC-014）。
