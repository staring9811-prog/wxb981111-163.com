## 2. 页面概述

### 2.1 一句话定位

老板和开发、采购、运营不装系统、不联网，双击一个文件就能看到本月结论和依据。

### 2.2 存在理由

1. **第一期没有服务器**：结果接收方只能通过文件看结论（US-F12-02）。
2. **先看结论，再看依据**：接收方多数只看前几名和判定卡是否可用；需要追问时再展开依据（DD-4）。
3. **口径不能在转发中丢失**：判定卡未验证、截面口径、参照人群必须写在首屏，文件被转给谁都看得到（AC-F12-02、AC-F07-11、AC-F05-11）。
4. **离线一致**：文件打开时显示的必须是导出时的结果，不能因为网络、字体或脚本而变样（AC-F12-03）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 一屏结论 | 1440×900 下不滚动即可看到判定卡状态、参照人群、成功线和全部有效细分（最多 10 个）；1024×768 下至少看到状态横幅与前 5 个细分 |
| 离线可读 | 打开时网络请求数为 0；断网与联网显示完全相同 |
| 可打印 | 打印时依据全部展开，A4 纸上表格不被截断 |
| 内容一致 | 数字、排序、锦囊、版本号与同一次导出的 Excel 一致 |

### 2.4 不做什么

- **不交互计算**：不排序、不筛选、不重算；所有数字导出时写入。
- **不链接系统**：接收方没有系统，文件内不出现指向系统页面的链接。
- **不含原始数据**：不含原始数据表、评论原文和任何密钥（设计蓝图 §9）。
- **不做深色版**：只有浅色，便于打印。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 结果接收方：老板、开发、采购、运营（只读）；wen 也用它在评审会上投屏 |
| 使用设备 | Windows 或 macOS 电脑上的 Chrome、Edge、Safari；偶尔在手机上查看 |
| 使用时机 | 收到月度报告时；立项评审会上 |

### 3.2 核心使用场景

- **场景 A：老板看结论**
  - 动作：打开文件，看判定卡是否达标、前几名细分和锦囊动作，不展开依据。
- **场景 B：开发、采购追问依据**
  - 动作：展开"锦囊"看触发条件，展开"回测摘要"看样本和区间。
- **场景 C：评审会打印**
  - 动作：直接打印，依据全部展开，存档。

## 4. 信息架构

### 4.1 区域划分

1. 报告头：报告名、品类与月份、数据截止月、快照、生成时间与操作人；右侧主数字（倍数）。
2. 判定卡状态横幅。
3. 口径：参照人群、成功线。
4. 本月结论：有效细分表（最多 10 个）。
5. 依据（可展开）：完整排序、锦囊、回测摘要、台账、版本信息。
6. 页脚：读数说明。

### 4.2 区域内容

**1. 报告头**
- 小标题"品类机会判定台 · 网页报告"。
- 标题："浴室柜 · 2027-05 细分机会排序"。
- 副标题："亚马逊美国 · 浴室柜（类目节点 6810202011）· 数据至 2027-04 · 快照 2027-05 第 1 版 · 生成于 2027-05-08 11:32 · 操作人 wen"。
- 主数字："2.24×"，说明"前 20% 细分命中率 ÷ 全类目平均"，下方"90% 区间 1.41–3.05 · 检验组 n=186"。

**2. 判定卡状态横幅**（三选一，见第 7 节）
- 本例：成功色横幅"判定卡 v4 已达标（历史口径）"，正文写检验组、前 20% 命中率、全类目平均、倍数，以及"高于 4 个现用指标"。

**3. 口径**
- 参照人群："起量新品：任一月父体月销 ≥ 60 件；未起量的新品不计入命中率"（AC-F05-11）。
- 成功线："上架 6 个月内小类 BSR ≤ 50，或 SPU 任一月销售额 ≥ $100,000"。

**4. 本月结论**
- 标题"本月结论 · 8 个有效细分"；说明"竖线为全类目平均 17.2%（n=186）· 另有 10 个细分样本不足，见完整排序"。
- 列：排名、细分、预期命中率（区间条 + "36%（27–46%）"+ n=）、样本量、锦囊动作（动作徽章 + 规则编号；另有适用锦囊时下方另起一行）。
- 有效细分超过 10 个时只列前 10 个，其余在完整排序中。

**5. 依据**（原生展开，默认收起；标题行显示条目摘要）

| 展开项 | 标题行摘要 | 内容 |
| :--- | :--- | :--- |
| 完整排序 · 18 个细分 | 排序规则 | 排名、细分、得分、区间、样本量、锦囊动作；样本不足的细分在分隔行之后，排名接续，用灰色区间条，锦囊动作仅供参考 |
| 锦囊 · 4 条 | 各动作条数 | 每条：建议动作、状态、规则编号与来源、触发条件、预期命中率区间、依据批次、样本量、状态说明、适用细分；人工经验规则的区间、依据批次、样本量为"无数据" |
| 回测摘要 · BT-0031 | 切分、倍数与区间、控制前后、局限 | 回测编号、口径、时间、种子；已判定批次与两组切分；前 20% 命中率与 Wilson 90% 区间；全类目平均；倍数与重抽样 90% 区间；结论；判定卡与 4 个现用指标的对照条形图（含 2 倍线）；控制 6 项干扰因素前后的优势比；局限"广告投入、站外引流未纳入"；未进入回测的快照字段；截面结论（标"截面口径（近似成功线）"、"以历史为准"） |
| 台账 | 各表条数 | 月度快照（快照、判定卡、口径、生成、导出、对账状态）；立项记录（编号、立项、决定、关联细分、对应快照、来源、立项日期、状态）；对账（竞品新品对账与自家立项对账） |
| 版本信息 | 主要版本号 | 品类与负责人、数据包（类型、覆盖月份、导入时间、指纹）、字段约定、品类配置、判定卡、回测与种子、快照、生成时间与操作人、文件名 |

**6. 页脚**
- 读数说明："n= 为样本量（已判定的起量新 SPU 数）；区间条中浅蓝带为 90% 区间，圆点为预期命中率，竖线为全类目平均 17.2%；'估算''实测'标明数据性质，'截面'标明截面口径。本报告为单个离线文件，由品类机会判定台导出，打开时不需要安装系统或联网。"

## 6. 交互流程

### 6.1 打开

- 双击文件，用默认浏览器离线打开；不加载任何外部字体、图标、脚本或图片。
- 首屏显示结论；依据默认收起。

### 6.2 核心操作

```
打开文件
  ├─ 看横幅、口径、本月结论（不需要任何操作）
  ├─ 点依据标题 → 原生展开 / 收起（不依赖脚本）
  └─ 打印 → 依据全部展开，按 A4 排版
```

### 6.3 辅助操作

- 键盘可聚焦每个展开项并用回车或空格展开。
- 区间条、条形图鼠标停留显示数值说明。

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 断网或公司内网隔离 | 不受影响：文件不请求任何网络资源（AC-F12-03） |
| 浏览器禁用脚本 | 不受影响：文件不含脚本 |

| 文件被转发、改名 | 内容不变；首屏仍显示状态与口径，生成信息写在报告头和版本信息中 |

## 8. 业务规则与校验

- **首页标记**：判定卡未验证时，首屏显示"未验证，不可作为立项结论"（AC-F12-02）；截面达标时显示"截面口径，待历史回测确认"（AC-F07-11）。
- **参照人群**：命中率与排序处标明参照人群为起量新品（AC-F05-11）。
- **截面标注**：截面口径的成败与命中率标"截面口径（近似成功线）"（AC-F05-08）。
- **离线一致**（AC-F12-03）：
  - 单个 HTML 文件，样式、图标、图形全部内嵌；不引用任何外部资源。
  - 不依赖脚本，展开用浏览器原生的展开元素。
  - 所有数字在导出时写入，打开时不再计算；与同一次导出的 Excel 取自同一快照。
- **版式**：单栏居中，最大宽 1200；1024 宽以上完整可读；可直接打印。
- **台账口径**：对账用该月最后一次导出的快照（DEC-006）；立项记录不可修改，录错追加更正（DEC-007），被更正的记录标"已更正"。
