## 2. 页面概述

### 2.1 一句话定位

把"每个字段代表什么、能不能用、怎么用"变成确认过、带版本的规则，计算只按确认过的规则执行。

### 2.2 存在理由

1. **字段含义理解错是最大风险**：上架日期、首次评分日期、子体销量的口径一旦用错，新品判定和命中率都会错（US-F02-01）。
2. **快照字段会让回测虚高**：当前价格、当前评分是采集时的值，用进回测等于带入未来信息（RA-004、AC-F02-05）。
3. **月更要快**：逐字段确认会拉长首跑和月更，所以新数据包只列变化字段（AC-F02-06），并可按建议批量确认（AC-F02-03，RA-006）。
4. **约定变了，旧结果不能继续当真**：保存新版本后，依赖旧约定的结果要标"需重算"（AC-F02-07，RA-007）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 草稿完整 | 每个字段都有含义、粒度、时点、性质、建议用法和来自本数据包的体检证据 |
| 月更只看变化 | 待确认只包含新增、缺少或类型改变的字段 |
| 可追溯 | 每次保存生成新版本，每个变动字段可查修改前后值、操作人和时间 |
| 不误用 | 未确认字段与快照字段在页面上一眼可辨，并有常驻提示 |

### 2.4 不做什么

- **不修改源数据**：只确定字段的解释和用法。
- **不定义细分维度、成功线和阈值**：在 PAGE-F13-01 品类配置中设置。
- **不自动重算**：只标"需重算"，由 wen 在工作台点"全部重算"（DEC-016）。
- **不处理体检预警**：在 PAGE-F03-02 数据体检中标为已知晓。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 每次导入数据包之后（月更第 2 步）；首跑时确认全部字段；发现口径问题时修改 |
| 使用设备 | Windows，Chrome / Edge，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：月更确认变化字段（主场景）**
  - 时机：导入 P-0008 后，C1 多了 Prime价格、优惠券两列。
  - 动作：展开"优惠券"→ 看体检证据（有值 18.7%，99.6% 的子体各月取值相同）→ 按建议确认为"快照 · 回测不用"→ "保存为新版本"→ 确认弹窗 → 生成 v8。
- **场景 B：首跑确认全部字段**
  - 动作：先逐项看"按规则用"和"快照"的字段，其余勾选后"按建议批量确认"，最后保存。
- **场景 C：修改已确认的字段**
  - 例：首跑后发现两成多子体首评早于上架，把 C1、C2 首次评分日期的粒度改为"父体（疑似）"并保存（v3）。
- **场景 D：查某个字段的历史**
  - 动作：打开"版本记录"，看它在哪个版本、被谁、从什么改成了什么。

## 5. 界面内容

### 5.1 元素清单

**保存为新版本**
- 打开确认弹窗，真正提交的是弹窗里的"保存为 v8"。
- 不可用：草稿与当前版本没有差异（提示"草稿没有修改"）；有计算任务在运行（提示"x 正在运行，完成后再保存"，DEC-010）。

**保存确认弹窗**
- 标题"保存为字段约定 v8"；副标题"在 v7 基础上保存 · 数据包 P-0008 · 操作人 wen · v7 保留可查"。
- 变动摘要：每个变动字段的项目、修改前、修改后，例"C1 优惠券 · 确认状态：未确认 → 已确认（逐项）""约定内容：草稿建议，未生效 → 子体 · 快照 2027-05-06 · 平台实测 · 回测不用"。
- 保存后待确认字段数；为 0 时说明常驻提示随之消失。
- 需重算提示（AC-F02-07）："依赖 v7 的结果将标为'需重算'"，列出成败判定、信号、回测、排序及各自的计算时间或编号；说明"系统不会自动重算，可在工作台点'全部重算'；已保存的月度快照不改动"。
- 按钮："取消"、"保存为 v8"。

**按建议批量确认弹窗**
- 标题"按建议批量确认"；副标题"确认来源记为'批量确认' · 保存为新版本后生效"。
- 提醒："建议先逐项看过'按规则用'的字段：它们的规则会直接影响成败判定和信号。"
- 按钮："取消"、"按建议确认"。

**版本记录抽屉**
- 标题"版本记录"；副标题"字段约定 · 共 7 个版本 · 只追加，不覆盖"。
- 每个版本：版本号（当前版本标"当前"）、保存时间、操作人、基于的数据包、变动字段数；逐个列出变动字段的项目、修改前、修改后；新字段的修改前写"新增字段"。
- 示例：v7（2027-05-08 09:41 · wen · P-0008）Prime价格确认为快照、回测不用，优惠券新增未确认；v6（2027-04-08）C6 痛点事件代码新增 S12"安装孔位不准"；v5（2027-01-07）C3 父体月销量新增并确认为"按规则用：只用于起量门槛"；v4（2026-12-04）C5 关键词属性标签补充"泛词标'通用'，不计入细分信号"。
- 更早版本（v1–v3）折叠显示一行摘要。

### 5.2 辅助信息

- 证据小标签：比例旁标样本量（n=…）；可点开的标签显示来源。
- 已知口径疑点中的"看体检"链接到 PAGE-F03-02。

## 6. 交互流程

### 6.1 页面加载与初始化

- 读取当前版本、本机草稿和本数据包的体检证据。
- 新数据包首次进入：系统已把新增、缺少、类型改变的字段生成草稿建议并列为待确认，其余沿用当前版本（AC-F02-06）。
- 默认筛选"全部"，待确认字段在最前；有待确认字段时展开第一个。

### 6.2 核心操作流程

```
进入页面
  ├─ 展开字段 → 看体检证据与草稿建议
  │     ├─ "按建议确认" → 草稿中该字段为已确认（来源：逐项）
  │     └─ 修改含义 / 粒度 / 时点 / 性质 / 用法 → "确认修改" → 草稿中为已确认（逐项）
  │
  ├─ 勾选字段 → "按建议批量确认" → 确认弹窗 → 草稿中为已确认（来源：批量确认，AC-F02-03）
  │
  ├─ "保存为新版本" → 弹窗：变动摘要 + 需重算提示 → "保存为 v8"
  │     ├─ 生成新版本号，记录每个变动字段的前后值、操作人和时间（AC-F02-02）
  │     ├─ 依赖旧版本的成败判定、信号、回测和排序标"需重算"（AC-F02-07）
  │     └─ 轻提示"已保存为字段约定 v8；成败、信号、回测和排序已标为需重算"
  │
  ├─ "版本记录" → 右侧抽屉 → 关闭后回到原位置
  │
  └─ 有未保存修改时离开 → 离开提示；草稿留在本机，回来后仍在
```

### 6.3 辅助操作

- 筛选标签与搜索即时过滤；表头全选只选当前显示的字段。
- 点体检证据的样本量标签，浮层显示体检项、分子、分母、阈值、状态和数据包版本。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空态 | 还没有数据包 | "还没有字段约定。导入第一个数据包后，系统会为每个字段生成草稿。"按钮"去导入数据包"→ PAGE-F01-01 |
| 首次确认 | 第一个数据包，全部字段待确认 | 待确认数为全部字段数；常驻提示照常显示 |
| 有待确认 | 存在未确认字段 | 常驻提示"未确认的字段不参与计算"（AC-F02-04）；工作台待处理区同步显示 |
| 全部已确认 | 没有未确认字段 | 不显示常驻提示；待确认为 0 |
| 有未保存修改 | 草稿与当前版本不同 | 页头"草稿有未保存的修改"；离开时提示 |
| 保存完成 | 新版本生成 | 轻提示；顶栏"约定"版本号更新；工作台与结果页显示需重算横幅 |
| 筛选无结果 | 当前筛选下没有字段 | "没有符合条件的字段"，并提供"清除筛选" |
| 最新数据包有阻断 | 最新导入的数据包没有通过校验 | 不为它生成草稿，页面仍显示当前版本 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 新数据包缺少某个字段 | 列为待确认并标"本包缺少"；确认后沿用原约定，计算中该字段按缺失处理（显示"无数据"） |
| 字段类型改变 | 列为待确认，显示前后类型；确认前不参与计算 |
| 时点选为"快照" | 建议用法固定为"回测不用"（AC-F02-05） |
| 批量确认的选择里有已确认字段 | 已确认字段跳过，不改变其约定和来源 |
| 有计算任务在运行 | "保存为新版本"不可用，提示"x 正在运行，完成后再保存"（DEC-010） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 粒度 | 子体 / 父体 / SPU / 关键词 / 评论（REQ-F02-01） |
| 时点 | 当月值 / 快照及快照日期 |
| 性质 | 平台实测 / 第三方估算 / 推导 / 人工标注 |
| 建议用法 | 直接用 / 按规则用（附规则）/ 回测不用 |
| 体检证据 | 来自本数据包：覆盖月份、缺失占比、各月取值是否相同、相关体检项结果、校验排除行数 |
| 确认来源 | 逐项 / 批量确认，以及确认时的版本号 |
| 变化字段 | 与当前版本相比新增、缺少或类型改变的字段（AC-F02-06） |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 含义 | 确认时 | 不能为空 | "请填写含义" |
| 快照日期 | 时点为快照时 | 必填，格式 YYYY-MM-DD | "请填写快照日期" |
| 保存 | 点"保存为新版本" | 草稿与当前版本至少有一处不同 | 按钮不可用，提示"草稿没有修改" |

### 8.3 特殊业务规则

- **未确认不参与计算**：任何计算步骤都不使用未确认字段，并在该次计算结果中列出被排除的字段名（AC-F02-04）。
- **快照不进回测**：时点为快照的字段拒绝用于回测信号计算，回测报告列出被拒绝的字段（AC-F02-05，见 PAGE-F07-01）。
- **保存即新版本**：每次保存生成新版本号，记录每个变动字段的修改前后值、操作人和时间（AC-F02-02）；版本只追加（DEC-014）。
- **需重算**：保存后，依赖旧版本的成败判定、信号、回测和排序标"需重算"（AC-F02-07），旧结果仍可查看，不自动重算（DEC-016）；月度快照不改动。
- **草稿**：确认与修改先进入草稿，存在本机，离开页面不丢；保存为新版本后才生效。
- **截面数据包**（DEC-021）：约定 v1.1 规定 S1–S3 的字段"同 C1 / 同 C2"，因此与 C1–C3 同名字段共用一条约定，字段表按 C1–C7 列出。

## 9. 页面流转

### 9.1 流转图

```
PAGE-F01-02 校验报告 ─┐
PAGE-F03-01 工作台 ───┼─→ 字段约定（本页）
侧栏 / 顶栏"约定 v7" ─┘        ├─ "版本记录" ──→ 本页抽屉
                                ├─ 体检证据 / "看体检" ──→ PAGE-F03-02 数据体检
                                └─ 保存新版本 ──→ PAGE-F03-01 工作台显示需重算，"全部重算"
```

### 9.2 与其他模块的关系

- 工作台第 2 步"字段约定"的状态与待处理"未确认字段"取自本页。
- 信号（PAGE-F06-01）列出本次计算排除的未确认字段；回测（PAGE-F07-01）列出被拒绝的快照字段。
- 结果记录所用的字段约定版本号（NFR-003）。

## 10. 数据需求

### 10.1 页面需要的数据

| 数据 | 来源 | 用途 |
| :--- | :--- | :--- |
| 当前字段约定版本与全部字段项 | F02 | 表格、摘要 |
| 本机草稿 | F02 | 未保存修改 |
| 变化字段（新增、缺少、类型改变） | F01 与 F02 比对 | 待确认 |
| 本数据包的字段级体检证据 | F01 校验、F03 体检 | 体检证据列、行内展开、已知口径疑点 |
| 依赖当前版本的结果（成败、信号、回测、排序）及时间 | F05–F09 | 保存确认弹窗 |
| 历史版本与变动记录 | F02 | 版本记录抽屉 |

### 10.2 页面提交的数据

| 数据 | 触发时机 | 用途 |
| :--- | :--- | :--- |
| 草稿修改（确认、修改、批量确认） | 每次确认或修改 | 本机草稿 |

- 不加载行级原始数据，体检证据只用汇总值与少量示例值。

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 草稿完整 | 每个字段显示含义、粒度、时点、性质、建议用法和本数据包的体检证据（AC-F02-01） |
| F-02 | 保存留痕 | 保存生成新版本号；版本记录中每个变动字段有修改前后值、操作人和时间（AC-F02-02） |
| F-03 | 批量确认 | 选中一组字段"按建议批量确认"并保存后，这些字段为已确认，来源为"批量确认"（AC-F02-03） |
| F-04 | 未确认不参与计算 | 有未确认字段时页头常驻提示；计算结果列出被排除的字段名（AC-F02-04） |
| F-05 | 快照不进回测 | 时点为快照的字段为"回测不用"，回测报告列出被拒绝的字段名（AC-F02-05） |
| F-06 | 只列变化字段 | 新数据包新增、缺少或类型改变的字段列为待确认，其余沿用当前版本（AC-F02-06） |
| F-07 | 需重算 | 保存新版本后，依赖旧版本的成败判定、信号、回测和排序标"需重算"（AC-F02-07） |
| U-01 | 离开拦截 | 有未保存修改时离开页面会提示 |
| U-02 | 证据可追 | 样本量标签可点开，显示体检项、分子、分母和数据包版本 |
