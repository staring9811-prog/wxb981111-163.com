## 2. 页面概述

### 2.1 一句话定位

把判定卡翻成"在什么条件下立项、观察或放弃"的几条锦囊，每条都写明预期命中率区间、依据和验证到哪一步。

### 2.2 存在理由

1. **结论要能直接用**：排序告诉 wen 先看哪些细分，锦囊告诉他看到之后怎么做（US-F08-01）。
2. **每条都要有依据**：没有区间、批次和样本量的规则只是经验，不能和回测结论混在一起（AC-F08-02）。
3. **验证状态要分开**：已验证、历史观察、未验证经验的可信度不同，立项时分量也不同（REQ-F11-01）。
4. **不可用时要说清**：判定卡未验证或只有截面结论时，锦囊同样不能当正式立项结论（AC-F08-03、AC-F07-11）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 内容完整 | 每张锦囊卡都有触发条件、建议动作、预期命中率区间、依据批次、样本量、状态六项；缺的一项显示"无数据" |
| 易于筛选 | 一次点击切换到某一类动作，标签上显示该类数量 |
| 可追到来源 | 每张卡一次点击到策略库中的规则，一次点击到适用细分 |

### 2.4 不做什么

- **不在本页新增或修改规则**：在策略库（PAGE-F11-01、PAGE-F11-02）完成，本页只读。
- **不排序细分**：细分排序在 PAGE-F09-01。
- **不记录立项决定**：在本月排序或台账中记录（PAGE-F10-02）。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 月更生成判定卡后；立项评审前准备"为什么建议立项 / 放弃" |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：评审前准备**
  - 动作：切到"立项候选"，看触发条件和区间，点适用细分核对信号。
- **场景 B：判断经验规则的分量**
  - 动作：看到 R-018 标"未验证经验"、区间"无数据"，把它当作提醒，而不是结论。
- **场景 C：查规则来历**
  - 动作：点卡片进入策略库，看规则的版本、修改记录和依据。

## 6. 交互流程

### 6.1 加载与初始化

- 读取当前判定卡下的全部锦囊、各自规则的当前版本与状态、适用细分。
- 默认"全部"，卡片按动作排列：立项候选 → 观察 → 放弃；同一动作内回测得出的在前、人工经验在后。

### 6.2 核心操作流程

```
进入立项锦囊
  ├─ 点筛选标签 → 只显示该动作的锦囊
  ├─ 点卡片 → PAGE-F11-01 策略库（定位到该规则）
  ├─ 点适用细分按钮 → PAGE-F06-02 细分详情（抽屉）
  └─ 点"查看判定卡" / "判定卡" → PAGE-F08-01
```

### 6.3 辅助操作

- 区间条悬停查看点估计、区间与样本量。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 无锦囊 | 还没有判定卡 | 空状态："还没有锦囊。回测达标生成判定卡后，这里会列出立项、观察、放弃的规则。"按钮"去回测"（PAGE-F07-01） |
| 正常 | 有当前判定卡 | 横幅 + 筛选 + 卡片 |
| 未验证 | 判定卡为未验证 | 预警色横幅"未验证，不可作为立项结论"（AC-F08-03）；卡片照常显示 |
| 截面口径 | 判定卡为达标（截面） | 截面横幅"截面口径，待历史回测确认"（AC-F07-11）；区间旁加"截面"小标签，依据写"新品-月"行数 |
| 某类动作为空 | 筛选后没有卡片 | "当前判定卡下没有'放弃'类锦囊" |
| 需重算 | 依赖版本已变 | 需重算横幅（DEC-016），仍显示旧锦囊 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 人工经验规则 | 区间、依据批次、样本量显示"无数据"，并写"人工经验，尚无回测依据"；状态为"未验证经验" |
| 规则条件涉及非细分维度 | 例如台面材质：适用细分按可对应的维度列出（宽度 ≥ 48″），并注明"限台面材质为岩板的商品" |
| 一个细分同时适用多条锦囊 | 每条锦囊各自列出该细分；本月排序在该细分行同时显示 |
| 规则在策略库被修改 | 锦囊显示规则当前版本；改了条件或动作的新版本状态为"未验证经验"（REQ-F11-01） |

## 8. 业务规则与校验

- **锦囊内容**：每条锦囊包含触发条件、建议动作（立项候选、观察或放弃）、预期命中率区间、依据批次、样本量和状态（AC-F08-02）。
- **状态来源**（REQ-F11-01）：
  - 由达标回测生成的规则为"历史观察"；
  - 在台账对账中达到验证条件的升为"已验证"（立项候选规则倍数 ≥ 2，放弃规则倍数 ≤ 0.5），并记录对账月份与规则倍数；观察规则对账只记录，不升级；
  - 人工新增的为"未验证经验"。
- **未验证与截面**：判定卡未验证时显示"未验证，不可作为立项结论"（AC-F08-03）；截面达标时显示"截面口径，待历史回测确认"（AC-F07-11）；两种结论并存时以历史为准（DEC-011）。
- **区间**：预期命中率为 90% 区间（Wilson），全类目平均来自同一回测的检验组。
