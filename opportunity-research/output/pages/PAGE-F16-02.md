## 2. 页面概述

### 2.1 一句话定位

给每个按量计费的服务设月度上限，并查每一笔调用花了多少钱、每月合计多少。

### 2.2 存在理由

1. 外部服务按量计费，没有上限时一次误操作可能刷掉一个月预算；到上限要自动停（AC-F16-06）。
2. 每个花钱任务都要先看到预计费用再确认（AC-F16-07）；本页定义这个共用弹窗。
3. 月底要知道钱花在哪个服务、哪个任务上（AC-F16-08）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 上限生效 | 当月累计达到上限后，该服务新调用 100% 被拒，已采数据保留 |
| 先评估 | 100% 的花钱任务在开始前弹出 CMP-F16-01，确认后才开始 |
| 记账完整 | 每一次按量计费调用完成后都有一条费用记录 |

### 2.4 不做什么（范围边界）

- **不对接服务商账单**：费用按系统记录的调用量和单价估算，不读服务商后台账单。
- **不做多级预算、按任务预算或预算审批**：只有每个服务的月度上限。
- **Home Depot 直连采集不计费**，不出现在本页。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 仅操作者 wen |
| 使用频次 | 月初设上限；每次花钱任务前看弹窗；月底看汇总 |

### 3.2 核心使用场景

**场景 A：月初调上限**：把 Bright Data 上限从 $80 调到 $100 → 保存 → Toast"已保存，本月起生效"。
**场景 B：花钱任务前确认**：在 Amazon 月度数据页点"拉取"→ 弹出 CMP-F16-01，显示预计 2,850–2,950 次、$28.50–$29.50、25–40 分钟，以及"预计超过本月上限"的预警 → wen 决定先调高上限或确认拉取（到上限自动停，已拉部分保留）。
**场景 C：月底查账**：切到"按月汇总"→ 看 2026-10 共 $174.80，大模型 $42.10 → 点 2026-10 看明细。

### 3.3 用户核心诉求

1. **花钱前有数**：调用量、费用区间、耗时一目了然。
2. **兜底**：到上限自动停，不会失控。
3. **查得清**：每一笔都能追到任务。

## 4. 信息架构

### 4.1 区域划分

1. 页头：面包屑"设置 / 预算与费用"、标题、"预览费用评估弹窗"按钮
2. 月度上限表（本月已花、占比、状态、上限输入、计费单位）+ 保存
3. 费用记录：标签页"明细"｜"按月汇总"
4. 共用组件 CMP-F16-01 费用评估确认弹窗

### 4.2 区域内容

**月度上限表**：服务、计费单位（美元 / 调用次数）、月度上限*、本月已花、已用比例条、状态。
**明细**：时间、服务、任务、数量、金额（AC-F16-08 五项），附"来源"链接到发起任务的页面。
**按月汇总**：月份、四个服务各自金额、合计；点月份筛选明细。

### 5.2 共用组件 CMP-F16-01 · 费用评估确认弹窗

**使用位置**：所有会花钱的任务——拉 Amazon 数据（PAGE-F17-01）、采评论（PAGE-F23-01）、拉差评（PAGE-F21-02）、看图打标（PAGE-F18-01）、差评归类与叙述草稿（PAGE-F21-02）（AC-F16-07）。

**内容**
| 项 | 说明 | 示例（拉取 Amazon 2026-10 重新拉取） |
| :--- | :--- | :--- |
| 任务 | 任务名称与范围 | 拉取 Amazon 2026-10 浴室柜类目月度数据 |
| 服务 | 计费的服务（可多个） | 卖家精灵 |
| 预计调用量 | 区间 | 2,850–2,950 次（约 2,850 个 ASIN；已拉部分不重复计费） |
| 预计费用区间 | 美元区间 | $28.50–$29.50 |
| 预计耗时 | 区间 | 25–40 分钟 |
| 本月额度 | 已花 / 上限，本次后预计 | 3,120 / 5,000 次；本次后预计 5,970–6,070 次 |
| 预警（条件出现） | 预计超过上限时 | "预计超过本月上限 5,000 次。达到上限时自动停止，已拉数据保留，调高上限后续拉不重复计费。"附"调整上限"链接到本页 |
| 阻断（条件出现） | 服务未连接或已达上限 | "卖家精灵未连接，去设置" / "本月已达上限"，确认按钮不可用 |

**按钮**：取消｜确认并开始（主按钮）。确认后任务开始，进度显示在顶栏任务指示与任务所在页面；完成后每次调用写入费用记录。

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者 → 无权限页。
- 操作者 → 读取上限与本月累计；默认显示"明细"标签、本月。

### 6.2 核心操作流程

```
修改上限 → 失焦校验 → 保存上限 → Toast"已保存上限，立即生效"
  └─ 新上限低于本月已花 → 提示"本月已花 $65.60，高于新上限，该服务将立即停止新调用"，需再次确认

任一花钱任务 → 弹出 CMP-F16-01
  ├─ 取消 → 不发起任何调用
  └─ 确认并开始 → 任务运行 → 每次调用完成写一条费用记录
        └─ 累计达到上限 → 停止新调用，保留已采数据，任务状态"已达上限暂停"，提示 wen（AC-F16-06）
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载态 | 首次进入 | 表格骨架条 |
| 正常态 | 有记录 | 见第 5 节 |
| 空状态 | 当月 / 筛选下无记录 | "这个月还没有花钱的调用。发起拉取、采集或打标后，每笔调用会记在这里。" |
| 接近上限 | ≥ 80% | 预警色比例条 + "接近上限" |
| 已达上限 | 100% | 阻断徽章"已达上限，已停止新调用"，提示可调高上限后续跑 |
| 未连接 | 密钥缺失 | 状态"未连接"，链接 PAGE-F16-01 |
| 保存中 / 保存失败 | 点保存 | 按钮"保存中…"；失败时提示原因，已改数值保留 |
| 长任务进行中 | 有花钱任务在跑 | 本月已花实时累加，顶栏任务指示显示进度 |
| 无权限 | 非操作者 | "无权限：预算与费用仅操作者可用" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 跨月 | 每月 1 日零点（北京时间）重新累计；上限值沿用 |
| 中断后续跑 | 已成功的调用不重复计费（NFR-011），费用记录不重复 |
| 预计超上限 | 弹窗预警，但允许确认；到上限自动停 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |

| 次数单位 | 失焦 | 整数 | 调用次数需为整数 |

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 月度上限 | 为服务设上限（美元或调用次数）后，当月累计达到上限即停止该服务新调用，已采数据保留，并提示已达上限（AC-F16-06） |
| F-02 | 先评估再确认 | 拉数据、采评论、打标、归类开始前都弹出 CMP-F16-01，显示预计调用量、费用区间、耗时，点确认后才开始；取消不发起调用（AC-F16-07） |
| F-03 | 记账 | 每次按量计费调用完成后新增一条记录（时间、服务、任务、数量、金额）（AC-F16-08） |
| F-04 | 按月汇总 | 汇总标签页按月显示各服务金额与合计，与明细合计一致（AC-F16-08） |
| F-05 | 续跑不重复计费 | 中断后续跑，已成功部分不再产生费用记录（NFR-011） |

### 11.2 体验验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| U-01 | 超上限预警 | 预计超过上限时弹窗内有预警和"调整上限"入口 |
| U-02 | 离开拦截 | 改了上限未保存就离开，浏览器提示 |

### 11.3 权限验收
