## 2. 页面概述

### 2.1 一句话定位

让 wen 核对"哪些是真正的新品、各自成没成"，这是全部命中率计算的分子与分母。

### 2.2 存在理由

1. **命中率靠新 SPU 判定**：老爆款的新颜色、新尺寸一旦被当成新品，命中率会虚高（US-F04-01）。必须能逐个看到新变体、疑似重新上架的标记。
2. **成败结果要可核对**：成败是回测的结果变量，每个"命中 / 未命中"都要能追到月份和指标（REQ-F05-01）。
3. **参照人群要看得见**：没起量的新品被排除在分母之外，排除数量必须显示出来，免得读者误以为是"所有新品"（AC-F05-11、AC-F05-12）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可核对 | 每个新 SPU 都能看到上架日来源子 ASIN、批次、成败、命中方式与月份 |
| 口径清楚 | 参照人群与"截面口径（近似成功线）"标注在两种口径下都常驻 |
| 分母透明 | 每个批次显示起量新品数、各成败状态数、未起量排除数 |

### 2.4 不做什么

- **不在本页审核或修改归并**：在 PAGE-F04-02 合并建议中完成，本页只提示未确认的数量。
- **不改成败判定**：成败由系统按成功线计算；要改阈值，去品类配置（PAGE-F13-01）。
- **不显示月度明细**：逐月数据在 PAGE-F05-01 查看。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 首跑核对新品口径；每月计算后抽查新批次；回测结果异常时追查 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：抽查新批次**
  - 动作：选批次（如 2026-11），看命中与未命中各几个，点开可疑的 SPU 看明细。
- **场景 B：排查口径问题**
  - 动作：筛"疑似重新上架"或"有新变体"，检查是否把老品当成了新品。
- **场景 C：看截面结果**
  - 动作：顶栏切到"截面"，看样例包里各上架月份新品的截面命中情况。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题、口径说明、参照人群。
2. 横幅：未确认合并建议提示；截面口径下另有"截面口径（近似成功线）"。
3. 批次概览条。
4. 筛选栏。
5. SPU 表与分页。

### 4.2 区域内容

**页头**
- 标题"新品与 SPU"。
- 副标题："按上架月份划分批次 · 参照人群：起量新品（任一月父体月销 ≥ 60 件）"。

**横幅**
- 未确认合并建议（存在时显示）："6 条合并建议未确认，涉及的 46 个子体暂按各自父 ASIN 计为 SPU。"操作"去审核"，进入 PAGE-F04-02（AC-F04-03）。
- 截面口径下显示："截面口径（近似成功线）· 数据包 P-0001（2026-06–09）· 只看新品期第 1–6 个月的观察月"（AC-F05-08）。

**批次概览**
- 历史口径：最近 6 个批次各一格，外加"更早批次"汇总。每格显示：
  - 起量新品数；
  - 命中 / 未命中 / 观察中 / 数据不全的数量；
  - 未起量排除数（AC-F05-12）。
- 截面口径：上架月 2026-01 至 2026-09 各一格，显示截面命中 / 截面未命中 / 观察中；另显示老品数和未起量排除数。截面数据包只含起量商品时，未起量排除数显示 0 并注明原因。

**筛选**
- 批次：全部、各月份。
- 成败：全部、命中、未命中、观察中、数据不全；截面口径为截面命中、截面未命中、观察中、老品。
- 标记：有新变体、疑似重新上架。
- 归并来源：编号、已确认建议、暂按父体。
- 搜索：SPU 编号、ASIN、品牌、标题。

**SPU 表（历史口径）**

## 5. 界面内容

### 5.1 元素清单

- **证据小标签**：
  - 最好 BSR 旁标"实测"；
  - 最高月销售额旁标"估算"；
  - 批次概览每个数字的总数旁标"n="。
- **成败徽章**：一律为"图标 + 文字"，命中为绿色，未命中为中性灰，观察中为描边，数据不全为预警色。
- **分页**：每页 50 行，显示"共 736 个起量新 SPU"。

### 5.2 辅助信息

页脚注明：数据包 P-0008 · 约定 v7 · 配置 v2 · 成功线：6 个月内小类 BSR ≤ 50 或 SPU 任一月销售额 ≥ $100,000。

## 6. 交互流程

### 6.1 加载与初始化

- **默认视图**：历史口径；批次为"全部"；按上架日从新到旧排序。
- **只有截面数据包时**：默认截面口径，顶栏不显示口径切换。

### 6.2 核心操作流程

```
进入页面
  ├─ 点批次概览中的某一格 → 等同于在筛选栏选中该批次
  ├─ 选筛选条件 → 表格即时过滤，显示条数
  ├─ 点 SPU 行 → SPU 成败明细（PAGE-F05-01）
  ├─ 点"去审核" → 合并建议（PAGE-F04-02）
  └─ 切换顶栏口径 → 概览、筛选、表格切换为对应口径
```

### 6.3 辅助操作

- 表头可排序：上架日、子体数、最好 BSR、最高月销售额。
- "列"按钮：窄屏下调出次要列。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未计算 | 还没运行成败计算 | 空状态："还没有新品判定结果。确认字段约定、审核合并建议后，在工作台运行计算。"按钮"去工作台" |
| 正常 | 有判定结果 | 概览、筛选、表格 |
| 需重算 | 归并、字段约定或配置变了 | 需重算横幅；表格显示旧结果并在页头标"需重算" |
| 筛选无结果 | 当前筛选下没有 SPU | 表格区显示"没有符合条件的新 SPU"，并提供"清除筛选" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 新变体 | 不作为新 SPU 出现在表中；只在所属 SPU 的"子体"列计数（AC-F04-07） |
| 未确认的合并建议 | 涉及的子体按各自父 ASIN 单独成行（AC-F04-03），行内标"暂按父体" |
| 观察中、数据不全 | 显示在表中，但不计入命中率分母（AC-F05-03、AC-F05-05） |
| 未起量新品 | 不出现在表中，只在批次概览显示排除数量（AC-F05-12） |

## 8. 业务规则与校验

- **批次**：SPU 上架日所在的自然月（AC-F04-09）。
- **SPU 上架日**：全部子体上架日的最早值（AC-F04-06）。
- **成败**：
  - 历史口径：按 REQ-F05-01，窗口为上架当月起连续 6 个月。
  - 截面口径：按 REQ-F05-02，只用新品期观察月。
- **疑似重新上架**：SPU 最早首评日早于上架日超过 7 天（AC-F04-08）。
