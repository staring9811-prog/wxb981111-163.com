# 页面名称：登录

## 1. 文档元信息

| 字段 | 内容 |
| :--- | :--- |
| 页面 ID | `PAGE-F15-01` |
| Source IDs | `REQ-F15-01, AC-F15-01`；关联 `AC-F15-05`（停用后会话失效回到本页）、`NFR-007` |
| 功能范围 | 账号密码登录；未登录访问任何页面都重定向到这里；停用账号的会话失效后回到这里 |
| 所属产品 | 品类机会判定台 |
| 所属模块 | 账号与角色 |

| 所属阶段 | 第一版 |
| 上游来源 | 局域网内直接打开系统任一地址（未登录重定向）；PAGE-F15-02 等任一页面"退出登录"；会话失效（账号被停用、会话到期）后的重定向 |
| 下游去向 | PAGE-F15-02 · 工作台；若由重定向进入，登录后回到原来要访问的页面 |

## 2. 页面概述

### 2.1 一句话定位

让 wen 建好账号的同事用账号和密码进入系统；没登录的人看不到任何业务数据。

### 2.2 存在理由

1. 系统在 wen 电脑上以局域网共享方式运行，同一网络里的任何人都能打开地址；没有门禁，立项数据和决策卡会被无关人员看到（AC-F15-01）。
2. 审批要留痕：必须知道是谁批准的，才能记录审批人（REQ-F15-01 的价值"老板审批留痕"）。
3. 三类角色可做的事不同，登录后才能按角色显示入口。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 门禁 | 未登录请求任一业务页面，100% 重定向到本页，响应中不含业务数据 |
| 登录效率 | 已知账号密码时，从打开页面到进入工作台 ≤ 15 秒 |
| 会话失效 | 账号停用后，其已登录会话在下一次请求时 100% 回到本页 |

### 2.4 不做什么（范围边界）

- **不做注册**：账号只能由操作者在 PAGE-F15-03 账号管理里新建（AC-F15-04，蓝图 §3）。
- **不做找回密码 / 短信 / 邮件验证码 / 第三方登录**：Source IDs 没有这些能力；忘记密码由操作者在账号管理里重置，本页只显示一句提示文字，不提供任何恢复入口。
- **不做"记住我"或角色选择**：会话时长由系统统一规定（蓝图 §9：7 天），角色由账号决定。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（wen）、审批者（老板）、只读（运营 / 采购 / 研发） |
| 人数 | 公司内部十人以内，每次 1 人登录 |
| 技术熟练度 | 中等，日常用浏览器办公 |
| 使用设备 | 办公电脑浏览器；评审会投屏用同一页面 |
| 使用姿势 | 坐在工位前，键盘输入 |

### 3.2 核心使用场景

**场景 A：正常登录（主场景）**
- 时机：每月数据更新后或评审会前，第一次打开系统，或会话已过 7 天。
- 前置：wen 已在账号管理里为其建账号并告知初始密码。
- 动作：输入账号和密码 → 登录 → 进入工作台。

**场景 B：账号或密码输错（兜底）**
- 时机：输入错误。
- 动作：看到"账号或密码不正确"→ 修正后重试；仍想不起密码 → 按提示联系 wen 重置。

**场景 C：账号被停用后回到本页**
- 时机：wen 在账号管理中停用了该账号（AC-F15-05），此人下一次点击任何页面。
- 动作：被带回本页，页面提示"登录已失效，请重新登录"；用原密码登录时也只看到通用失败提示，不透露账号状态。

**场景 D：直接打开深层地址**
- 时机：同事收到决策卡链接（如 PAGE-F21-02），未登录直接打开。
- 动作：被重定向到本页 → 登录 → 自动回到那张决策卡。

### 3.3 用户核心诉求

1. **快**：两项输入、一个按钮，Enter 即可提交。
2. **清楚**：错了知道怎么办（重试或找 wen 重置）。
3. **安全**：不登录看不到任何数据。

## 5. 界面内容

### 5.1 元素清单

**账号输入框**
- 标签："账号"，必填（星号）。
- 数据来源：用户输入；账号由操作者在 PAGE-F15-03 新建。
- 显示条件：始终显示，页面加载后自动聚焦。

**密码输入框**
- 标签："密码"，必填（星号），输入内容以圆点遮盖。
- 显示条件：始终显示。

**登录按钮**
- 文案："登录"；提交中为"登录中…"并不可重复点击。
- 唯一主按钮。

**会话失效提示（横幅）**
- 文案："登录已失效，请重新登录。" 
- 显示条件：因会话失效（账号停用、7 天到期）被重定向时显示。

**错误提示**
- "请输入账号" / "请输入密码"：对应字段为空时。
- "账号或密码不正确"：服务端校验失败时（包括账号已停用的情况，不区分原因）。
- "无法连接到服务，请确认 wen 的电脑已开机并在同一局域网"：请求无响应时。

### 5.2 辅助信息

- 忘记密码说明（纯文字，不是链接）。
- 局域网运行说明。

## 6. 交互流程

### 6.1 页面加载与初始化

- 已有有效会话 → 直接进入 PAGE-F15-02 工作台（或重定向前的原地址），不展示登录页。
- 无有效会话 → 展示登录页，账号框自动聚焦；若带有"会话失效"原因，显示提示横幅。

### 6.2 核心操作流程

```
用户输入账号、密码 → 点"登录"或按 Enter
    │
    ├─ 有空项 → 在对应字段下提示"请输入账号 / 请输入密码"，不发起请求
    │
    └─ 都已填写 → 系统校验
         ├─ 失败（账号不存在 / 密码错 / 已停用）→ 显示"账号或密码不正确"，清空密码框并聚焦
         ├─ 无响应 → 显示"无法连接到服务…"，可直接重试
         └─ 成功 → 建立 7 天会话，按账号角色进入工作台（或原地址）
```

### 6.3 辅助操作

- Enter 提交；Tab 在账号、密码、按钮之间切换。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 初始态 | 首次打开 | 账号框聚焦，按钮可点 |
| 会话失效态 | 停用或到期后被重定向 | 卡片顶部预警横幅"登录已失效，请重新登录" |
| 字段错误态 | 提交时有空项 | 对应输入框标红，下方给出提示 |
| 提交态（加载） | 已点登录 | 按钮显示"登录中…"，禁止重复提交 |
| 失败态（错误） | 账号或密码不对 / 账号已停用 | 按钮上方阻断提示"账号或密码不正确"，密码框清空 |
| 网络异常态（错误） | 运行机未开机或不在同一局域网 | 提示无法连接，可重试 |
| 成功态 | 校验通过 | 跳转工作台或原地址 |

> 空状态、无权限状态、长任务进度不适用于本页：本页无列表数据，所有人都可访问。

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 已停用账号尝试登录 | 与密码错误相同的提示，不暴露账号状态 |
| 会话失效 | 回到本页并提示，登录后回到原页面 |
| 重复提交 | 请求返回前按钮不可点 |
| 连续输错 | 需求未规定限流或锁定，本页不自行加锁定规则 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 账号 | 操作者建账号时设定的登录名 |
| 密码 | 操作者建账号或重置时设定；服务端加盐哈希保存（蓝图 §9） |
| 会话 | 登录成功后建立，保持 7 天；账号停用后下一次请求即失效（AC-F15-05） |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 账号必填 | 失焦、提交 | 非空 | 请输入账号 |
| 密码必填 | 失焦、提交 | 非空 | 请输入密码 |
| 身份校验 | 服务端 | 账号存在、未停用、密码匹配 | 账号或密码不正确（不区分原因） |

### 8.3 特殊业务规则

- **未登录不可见**：任何业务页面和数据请求在未登录时都重定向到本页，不返回业务数据（AC-F15-01）。
- **审计**：每次登录（成功或失败）记入审计日志，在 PAGE-F15-03 可查（蓝图 §9）。

## 9. 页面流转

### 9.1 流转图

```
局域网内打开任一地址 / 退出登录 / 会话失效
          │
          ▼
   是否有有效会话？── 是 ──→ PAGE-F15-02 工作台（或原地址）
          │
          否
          ▼
   PAGE-F15-01 登录（本页）── 校验成功 ──→ PAGE-F15-02 工作台（或原地址）
```

### 9.2 与其他模块的关系

- 账号与角色来自 PAGE-F15-03 账号管理；登录、停用、重置密码都会进入审计日志。
- 登录后的侧栏入口按角色显示，规则见 PAGE-F15-02。

### 9.3 扩展预案

| 扩展方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 其他认证方式 | PRD 新增并确认对应 REQ | 回到 PRD 增量设计，本页不预埋入口 |

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 未登录重定向 | 未登录打开任一业务页面（如 PAGE-F20-01），被重定向到本页，响应不含业务数据（AC-F15-01） |
| F-02 | 正确登录 | 用操作者建的账号和密码登录后进入工作台，只获得所选角色的权限（AC-F15-04） |
| F-03 | 错误反馈 | 密码错误、账号不存在、账号已停用都显示"账号或密码不正确" |
| F-04 | 空值拦截 | 账号或密码为空时不发起请求，提示对应字段 |
| F-05 | 停用后回到本页 | 账号停用后，其已登录会话下一次请求回到本页并显示"登录已失效"（AC-F15-05） |
| F-06 | 回到原地址 | 由深层地址重定向进入，登录后回到该地址 |
| F-07 | 无注册与找回入口 | 页面上没有注册、找回密码、验证码入口 |

### 11.2 体验验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| U-01 | 自动聚焦 | 打开页面账号框已聚焦，Enter 可提交 |
| U-02 | 网络异常 | 运行机不可达时有明确提示，可直接重试 |

### 11.3 安全验收（产品层）

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| S-01 | 不泄露账号状态 | 失败提示不区分账号不存在、密码错误、已停用 |
| S-02 | 局域网 | 系统只监听局域网地址，不对公网开放（NFR-007） |
| S-03 | 密码不明文 | 前端不把密码写入本地存储；服务端加盐哈希保存 |
