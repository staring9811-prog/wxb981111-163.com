## 2. 页面概述

### 2.1 一句话定位

记下每张批准卡片当时的预测，满 6 个月后按各渠道成功线自动对账，并汇总系统说得准不准。

### 2.2 存在理由

1. 立项时说的"把握 B、做到概率 47%"事后没人回头看，无法知道方法是否有效。
2. 方案书的有效标准（市场层 D 档 ≤ 30%，新品层前 20% ≥ 平均 2 倍）需要真实立项结果来检验。
3. 上架了却没关联到自家 ASIN 的条目会永远对不上账。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 登记完整 | 每条登记都有 AC-F26-01 的 7 项内容 |
| 对账及时 | 满 6 个月且数据已并入的条目 100% 自动判定 |
| 分渠道 | 多渠道条目每个渠道单独给出判定 |

### 2.4 不做什么（范围边界）

- **不手动登记**：登记由决策卡批准自动触发（AC-F25-03）。
- **不改登记内容**：登记的是批准时快照。
- **不合并渠道结论**：多渠道条目不出一个总结论（AC-F26-06）。
- **不在本页改成功线**：成功线在 PAGE-F27-01 修改。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者：查看、关联自家 ASIN、导出；审批者、只读：查看 |
| 使用设备 | 办公电脑浏览器；评审会投屏 |

### 3.2 核心使用场景

**场景 A：月度看对账结果（主场景）**
- 时机：每月数据并入后。
- 动作：打开台账 → 看"本月到期"和新出的判定 → 点条目看分渠道对账与停止条件 → 看准确率汇总是否达到有效标准。

**场景 B：处理待关联**
- 时机：看到"待关联"横幅。
- 动作：点"关联自家 ASIN" → 填子 ASIN 与实际上架月份 → 关联 → 条目转为跟踪中。

**场景 C：评审会回顾**
- 动作：老板看准确率汇总，判断系统给的分级和概率是否可信。

### 3.3 用户核心诉求

1. **准**：按批准时快照对账，不被后来的数据改写。
2. **分开看**：Amazon 和其他渠道各算各的。
3. **不漏**：上架没关联的要提醒。

## 4. 信息架构

### 4.1 区域划分

1. 页头（导出 Excel）
2. 待关联横幅（有待关联时）
3. 统计：已登记、跟踪中、本月到期、已对账
4. 准确率汇总：市场层（按分级）、新品层（按做到概率分档），各带有效标准判断
5. 各渠道成功线（带参数版本，链接品类配置）
6. 台账列表（状态、渠道筛选）
7. 台账明细抽屉；关联自家 ASIN 弹窗

### 4.2 区域内容

**准确率汇总**
- 市场层：分级 A / B / C / D 的已对账条数、份额实际变大比例、实际做到比例（都带分子 / 分母）；有效标准两条："D 档之后变大比例 ≤ 30%"、"把握分档后变大比例逐档上升"，各给达标 / 未达标 / 数据不全。
- 新品层：做到概率分档（≥ 50% / 40%–50% / < 40%，用扣偏差后的值）的已对账条数与实际做到比例；有效标准"打分前 20% 做到率 ≥ 平均 2 倍"，显示倍数与达标判断。

**各渠道成功线**：Amazon 小类 BSR ≤ 50 或 SPU 月销售额 ≥ $10 万；Home Depot 类目 Top Sellers 前 50 或估算月销 ≥ 250 件；Lowe's Best Sellers 前 50 或 ≥ 150 件；Wayfair 主类目前 50 或 ≥ 120 件；同系列合并计算；参数版本。

**台账列表**：编号、决策卡 · 分框（链接）、版本、登记时间、市场把握 · 份额区间、做到概率原值 / 扣偏差、预计上架、状态（跟踪中 / 本月到期 / 已对账 / 待关联）、判定（每个渠道一个徽章：做到 / 未做到 / 观察中 / 数据不全；触发停止条件另标）。

**明细抽屉**：登记内容（登记时间、版本、分框、市场把握与份额区间、做到概率原值与扣偏差、停止条件、预计上架月份、上架渠道、自家商品）；分渠道对账（成功线、6 个月内最好表现、判定，数据性质标"实测 / 估算"）；停止条件是否触发；判定参数版本；打开决策卡。

## 5. 界面内容

### 5.1 元素清单

**待关联横幅**
- 显示条件：有条目超过预计上架月份 3 个月仍未关联自家 ASIN。
- 文案："N 条待关联：{卡片名}。预计 {月份} 上架，已超过 3 个月仍未关联自家 ASIN，无法对账。"
- 横幅常驻，不可关闭。

**判定徽章**
- 做到（命中色 + check-circle）、未做到（中性 + minus，不用红色）、观察中（hourglass）、数据不全（预警 + warning，附原因如"等 10 月并入"）。

**关联自家 ASIN（弹窗）**
- 字段：Amazon 子 ASIN*（多个逗号分隔）、实际上架月份*、其他渠道商品 ID（登记了其他渠道时必填）。
- 显示条件：操作者。

**导出 Excel**
- 导出全部条目与判定。

### 5.2 辅助信息

- 页头说明：批准即登记；满 6 个月且数据已并入自动判定；各渠道分别判定。
- 汇总说明：只计已对账条目；有效标准来自解题方案书。

## 6. 交互流程

### 6.1 页面加载与初始化

- 默认显示全部条目，按登记时间倒序；有待关联时显示横幅。

### 6.2 核心操作流程

```
决策卡在 PAGE-F25-01 / PAGE-F21-02 被批准
    → 自动登记一条（跟踪中）
    │
    ├─ 超过预计上架 3 个月仍未关联 → 待关联（横幅 + 工作台提示）
    │      → 关联自家 ASIN → 跟踪中
    │
    └─ 实际上架后满 6 个月
          ├─ 某渠道对应月份未并入 → 该渠道"数据不全"，状态"本月到期"
          └─ 已并入 → 自动按该渠道成功线判定做到 / 未做到，判断停止条件 → 写回台账 → 已对账
                 → 准确率汇总重算
```

### 6.3 辅助操作

- 状态筛选单选，渠道筛选可多选；登记时间可排序。
- 点条目名打开明细抽屉。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空 | 还没有批准的卡片 | "台账还是空的。决策卡被批准后会自动登记到这里" |
| 加载 | 打开页面 | 统计与列表骨架条 |
| 汇总无数据 | 已对账为 0 | 汇总区显示"还没有已对账的条目"，有效标准标"无数据" |
| 数据不全 | 某渠道月份未并入 | 该渠道徽章"数据不全"并写明缺哪个月 |
| 待关联 | 见 5.1 | 横幅 + 列表状态 |
| 关联失败 | ASIN 格式不对 | 字段标错："ASIN 格式不对：10 位，以 B0 开头" |
| 无权限 | 只读 / 审批者点关联 | 关联按钮不显示 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 成功线在对账后被修改 | 已对账条目保留判定时的参数版本；新判定用新值并注明版本（AC-F27-03） |
| 同系列多个子体 | 合并计算，评论按评论 ID 去重（AC-F26-05、AC-F28-05） |
| 上架月份与预计不同 | 以关联时填写的实际上架月份起算 6 个月 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 登记时间、版本、分框 | 批准时自动写入（AC-F26-01） |
| 市场把握与份额区间 | 分级 A–D 与立项后 6–10 个月份额 80% 区间 |
| 做到概率 | 原值与扣模型偏差后的值 |
| 停止条件 | 卡片"看到什么就停"的条目 |
| 预计上架月份 | 卡片填写 |
| 上架渠道 | Amazon / Home Depot / Lowe's / Wayfair 中的一个或多个 |
| 自家商品 | Amazon 子 ASIN；其他渠道商品 ID |
| 判定 | 每渠道：做到 / 未做到 / 观察中 / 数据不全；是否触发停止条件 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| ASIN | 关联时 | 10 位、以 B0 开头，多个逗号分隔 | "ASIN 格式不对：10 位，以 B0 开头" |
| 实际上架月份 | 关联时 | 必填，不晚于当月 | "请填写实际上架月份" |

### 8.3 特殊业务规则

- **Amazon 判定（AC-F26-02）**：6 个月内任一月小类 BSR ≤ 50 或 SPU 月销售额 ≥ $10 万。
- **其他渠道判定（AC-F26-05）**：6 个月内任一月进入该渠道类目榜前 50，或估算月销达到阈值（默认 Home Depot 250、Lowe's 150、Wayfair 120 件，可在品类配置里改）；同系列合并计算。
- **分渠道显示（AC-F26-06）**：不合并成一个结论。
- **待关联（AC-F26-04）**：超过预计上架月份 3 个月仍未关联，标"待关联"并提示 wen。
- **有效标准（AC-F26-03）**：市场层 D 档之后变大 ≤ 30% 且逐档上升；新品层前 20% 做到率 ≥ 平均 2 倍。
