## 2. 页面概述

### 2.1 一句话定位

让 wen 只看"元素"和低置信度这少数标签，确认后下一次扫描和评分就用确认值。

### 2.2 存在理由

1. 分框和机会扫描都依赖标签；元素靠规则判断不了，错了会把单元归错框或错取值。
2. 每月四个渠道新进几百个子体，全部人工看不现实，必须只看需要判断的那部分。
3. 主图相同的商品（同系列不同尺寸、跨渠道同款）一个个确认既慢又容易前后不一致。
4. 混进镜柜、灯具等非本品类商品会污染份额。
5. （v8）第一版按标题打标曾把 Home Depot 全部误标为拆装；其他渠道商品页有规格字段（宽度、是否需要组装、安装方式、台面、柜体、颜色），要优先用规格，并让 wen 看得到每个标签来自哪里；没有依据的"装"不能默认拆装（AC-F18-08）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 人工量 | 只有"元素"标签和置信度低于阈值（默认 0.80）的标签进入队列 |
| 一致性 | 同图商品选一次即应用到整组 |
| 生效 | 确认或修改后状态为"已确认"，下一次扫描和评分使用确认值 |
| 来源可见 | 队列、已确认记录与回补来源构成里，每个标签都标明来源（规格 / 标题 / 看图 / 人工） |
| 不默认拆装 | 其他渠道"装"无依据的商品 100% 进入队列，原因"装：未知"，确认前不进框 |

### 2.4 不做什么

- **不做**打标规则和阈值的编辑——在 PAGE-F27-01 品类配置里改（AC-F27-01）。
- **不做**重算评分——确认完后去 PAGE-F19-01 重算。
- **不做**删除商品——"不是本品类"只是不进入分析，可恢复。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（wen）。审批者、只读角色不进入本页（蓝图 §4：适用角色为操作者） |
| 使用设备 | 办公电脑，桌面浏览器 |
| 使用时机 | 每月数据并入后，重算模型之前 |

### 3.2 核心使用场景

**场景 A：月初确认新批次（主场景）**
- 前置：2026-10 四个渠道数据已并入，规则打标完成，看图打元素在跑或已跑完。
- 动作：看进度 → 按渠道筛选队列 → 每组选候选值 → "应用到整组"；组内某个不同就在该行单独改。
- 结果：待确认数归零 → 去模型与回测重算。

**场景 B：发现非本品类**
- 动作：在组或单行点"看不出 / 不是本品类" → 确认弹窗 → 该商品不进入任何分析。

**场景 E：渠道调研分框未知（v9）**
- 入口：在 PAGE-F30-01 Wayfair 点"分框待确认 83 个"→ 本页已筛 Wayfair + "分框未知（渠道调研）"，顶部横幅"从渠道调研进来"与"返回渠道调研"。
- 表现：条目按窗口销量从大到小；调研商品没有主图，按"同品牌同标题"合组；卡片显示窗口销量、原值（宽、选项段、颜色 / 台面 / 柜体原值）与来源"调研导入"。
- 多尺寸未拆（例：Andover Mills Kamari 24"–36"，选项段 24″ / 30″ / 36″）：候选只列选项段里出现的尺寸段（全部销量计入），外加"不进框"；选"不进框"后不再进入队列（AC-F30-28）。
- 形态 / 装 / 尺寸段未知：候选为对应取值 + "仍不确定（保持未知，不进框）"，不默认。
- 确认后 Toast"Wayfair 渠道调研已重算（时间），也用于下一次机会扫描"（AC-F30-29、RA-120）。

**场景 D：其他渠道"装：未知"（v8）**
- 前置：Home Depot 新商品页并入（月度或历史回补），按规格优先打标。
- 表现：规格没有 Assembled / Assembly Required 字段、标题也没写的商品（例：Home Decorators Collection Winsome 36 in. / 30 in. Sand "Bath Vanity Cabinet and … Vanity Top Combo"），"装"记为未知，按渠道进入队列，原因筛选"装：未知"。
- 动作：选"整装" / "拆装"，或"仍不确定（保持未知，不进框）"→ 应用到整组；不选不能确认。

**场景 C：未配置大模型（兜底）**
- 结果：规则判断不了元素的商品全部进入人工确认，候选值只来自规则（AC-F18-02）。

### 3.3 用户核心诉求

1. **少**：只看必须看的。
2. **快**：同图一次搞定。
3. **准**：每个候选有置信度，能看到主图和标题。
4. **可控**：确认后什么时候生效说得清楚。

## 4. 信息架构

### 4.1 区域划分

1. 顶栏（品类、看图打元素任务进度、用户）
2. 页头（面包屑、标题、说明、操作）
3. 统计卡（新子体、规则打标、看图打元素、确认队列）
4. 自动打标进度表（按渠道）
5. 确认队列（标签页 + 筛选 + 分组卡片 + 分页）
6. 页脚说明

### 4.2 区域内容

- **统计卡**：本批新子体（按渠道拆分）；规则打标完成数 / 总数；看图打元素完成数 / 需看图数；待确认、已确认、不是本品类条数。
- **进度表**：渠道、数据月份、新子体、规则打标、分框标签来源（v8：Amazon"标题 · 看图"；其他渠道"规格 x · 标题 y · 装未知 z"）、看图打元素（进度）、进入确认队列条数、待确认条数、状态。表头说明当前阈值、规则版本、其他渠道规格优先。
- **标签来源构成（v8，回补批次）**：标签、商品页覆盖、来源构成、主要取值、无依据时怎么办。Home Depot 历史回补 1,904 个商品页（598 个在榜）的真实小试：装 100%（规格 98%、同家族规格补 1%、标题 1%；整装 80%、拆装 19%）；形态 100%（规格 95%、标题 4%）；台面材质 98%；柜体材质 93%；主色 64%；元素 11%（只有标题规则，其余待看图）。页脚说明四种来源。
- **确认队列**：三个标签页"待确认 / 已确认 / 不是本品类"；渠道筛选（全部 / Amazon / Home Depot / Lowe's / Wayfair，带条数）；进队原因筛选（元素 / 低置信度 / 装：未知 / 分框未知（渠道调研），v9）；分组卡片；从渠道调研进入时顶部有"返回渠道调研"横幅。
- **分组卡片**：主图、进队原因（元素 / 低置信度 / 装：未知）、标签名与来源（规格 / 标题 / 看图 · 大模型名；装无依据时写"无依据"）、同图商品数与图指纹、候选值及置信度（单选）、"应用到整组 / 确认"、"看不出 / 不是本品类"；组内表格：渠道、商品 ID、标题、其他自动标签、本条取值（可单独改）、状态、单行"不是本品类"。

## 5. 界面内容

### 5.1 元素清单

**候选值单选**
- 内容：该标签的候选取值，按置信度从高到低，附置信度；末尾"其他…"。
- 数据来源：规则打标或看图打元素的输出（AC-F18-01、AC-F18-02）。

**应用到整组（N）/ 确认**
- 显示条件：组内多于 1 个商品时文案为"应用到整组（N）"，单个商品为"确认"。

**本条取值下拉**
- 用途：组内单独改；改后该行标"单独改为 X"，整组确认时保留这一行的值，记为"人工修改"。

**看不出 / 不是本品类**
- 组级按钮作用于组内未处理的全部商品；行级按钮只作用于该商品；都先弹确认。

**标签来源标识（v8）**
- 四种来源：规格（商品页规格字段，同系列无规格的商品页按同家族已知规格补也算规格）、标题（标题规则，含默认值规则）、看图（大模型看主图）、人工（wen 确认或修改）。
- 显示位置：分组卡片的来源徽章；组内"其他标签（自动）"每个标签后的小标签；已确认页的自动值与确认值；回补批次的来源构成表。

**"装：未知"分组（v8）**
- 候选值：整装、拆装、仍不确定（保持未知，不进框）；没有默认选中，不选点确认提示"先选一个取值"。
- 组内"本条装"下拉默认"未知"，可单独改。

**已确认标签页**
- 列：渠道、商品、标签、自动值（来源 · 置信度）、确认值（来源 = 人工）、确认方式（确认 / 整组确认 · N / 人工修改）、确认人与时间、生效（下一次扫描）。

**不是本品类标签页**
- 列：渠道、商品、标题、标记人与时间、"恢复"。

### 5.2 辅助信息

- 页脚：确认后的值在下一次机会扫描和模型重算中使用；看图打元素按次计费，已记入预算与费用。

## 6. 交互流程

### 6.1 页面加载

- 默认打开"待确认"，渠道和原因都为"全部"，按组内商品数从多到少排。
- 看图打元素仍在跑时，顶栏任务指示显示步骤名与进度，已出结果的商品已在队列里。

### 6.2 核心操作流程

```
选择候选值 → 点"应用到整组"
    │
    ├─ 组内有单独改过的行 → 该行保留自己的值，记"人工修改"
    └─ 其余行 → 写入所选值
         │
         └─ 全组状态"已确认"，待确认数减少，Toast"已确认 N 个商品，下一次扫描和评分使用确认后的值"

点"看不出 / 不是本品类" → 确认弹窗 → 确认标记
    └─ 商品状态"不是本品类"，移入对应标签页，不进入任何分析
```

### 6.3 辅助操作

- 筛选：渠道和进队原因组合筛选，显示当前组数。
- 导出 Excel：导出本批全部队列记录。
- "打标规则与阈值"跳 PAGE-F27-01。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有待确认条目 | 分组卡片列表 |
| 进行中 | 看图打元素未完成 | 顶栏任务指示 + 进度表该渠道"进行中"；已出结果的先入队 |
| 筛选为空 | 当前筛选无条目 | 空状态："这个筛选下没有待确认的标签" |
| 全部确认完 | 待确认 = 0 | 空状态，并提示可去模型与回测重算 |
| 加载 | 首次进入 | 骨架条；再次加载保留上次结果并降低不透明度 |
| 未配置大模型 | 设置里无可用大模型 | 进度表"看图打元素"显示"未连接"，这些商品直接进人工确认，候选只来自规则 |
| 无权限 | 非操作者访问 | 侧栏不显示入口；直接访问显示无权限说明 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 看图打元素中断 | 重跑时已完成的商品不重复调用、不重复计费（NFR-011） |
| 达到大模型月度上限 | 自动停，剩余商品进人工确认，提示已达上限（AC-F16-06） |
| 同图组里混入不同尺寸 | 组内单独改尺寸，其他标签照常整组确认 |
| 规格与标题矛盾 | 用规格，标低置信度进队列，卡片写明两边各写了什么（例：规格 30.5″、标题 31″） |
| 其他渠道"装"无依据 | 记"未知"进队列，不默认拆装；确认前该商品不进任何框（不计入框份额） |
| 选"仍不确定" | 状态"已确认"，取值仍为未知，不进框；以后有规格时自动重打 |
| 误标"不是本品类" | 在"不是本品类"标签页恢复，回到待确认，下一次扫描生效 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 标签 | 尺寸、拆装、形态、台面、台面材质、元素、主色、柜体材质 |
| 标签来源 | 规格 / 标题 / 看图 / 人工（v8） |
| 置信度 | 0–1，规则或大模型给出 |
| 低置信度阈值 | 品类配置项，默认 0.80 |
| 同图分组 | 主图相同（图指纹相同）的商品，跨渠道也分在一组 |
| 状态 | 待确认 / 已确认 / 不是本品类 |
| 进队原因 | 元素 / 低置信度 / 装：未知（v8）/ 分框未知（渠道调研）（v9） |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 选择"其他…" | 点确认时 | 需在本条取值下拉中选具体值 | 提示"选一个具体取值" |
| 未选候选值 | 点确认时 | 必须选一个（"装：未知"组没有默认值） | 提示"先选一个取值；'装'不确定时选'仍不确定'，不默认拆装" |

### 8.3 特殊业务规则

- 四个渠道用同一套打标规则和看图打元素，进入同一个队列并标明渠道（AC-F18-07）。
- 规格优先（AC-F18-08）：Home Depot / Lowe's / Wayfair 有商品页规格时，尺寸段、装、形态、台面材质、柜体材质、主色先按规格字段打标，规格缺失才用标题规则；"装"没有依据时标"未知"并进入确认队列，不默认为拆装。
- 确认后的值在下一次扫描和评分生效，不改已生成的扫描和已批准决策卡快照（AC-F18-05、AC-F25-02）。
- "不是本品类"的商品不进入份额、扫描、评分、决策卡（AC-F18-06）。
