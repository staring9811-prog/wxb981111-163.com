## 2. 页面概述

### 2.1 一句话定位

在系统里完成原利润测算台的全渠道利润测算，方案存在服务端共享，并能把结果回写到决策卡的"钱"一节。

### 2.2 存在理由

1. 决策卡"钱"一节只有销售额没有毛利，评审拍板缺一块。
2. 原工具把方案存在单个浏览器里，换电脑或清缓存就丢，别人也看不到。
3. 从卡片到测算要手抄尺寸和售价，容易抄错。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 功能保留 | 原利润测算台的四步、历史库、导出 Excel 与方案 .json 全部可用（AC-F24-01） |
| 共享 | 保存后局域网内有权限的人打开看到同一份（AC-F24-02） |
| 打通 | 从卡片进入时尺寸、售价已预填；保存回写后卡片显示各渠道利润（AC-F24-03、AC-F24-04） |

### 2.4 不做什么（范围边界）

- **不改计算口径**：所有公式与原利润测算台一致。
- **不在这里改决策卡**：只回写"钱"一节的利润数字，卡片其他内容在 PAGE-F21-02 编辑。
- **不新增原工具没有的渠道或费用项**。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（编辑、保存、回写）；审批者、只读（只看方案与结果，编辑按钮隐藏） |
| 人数 | 编辑 1 人，查看若干人 |
| 技术熟练度 | 高，用过原工具 |
| 使用设备 | 办公电脑浏览器 |

### 3.2 核心使用场景

**场景 A：从决策卡测算利润（主场景）**
- 时机：写完决策卡、提交审批前。
- 前置：决策卡已生成，带分框尺寸和拟定售价。
- 动作：在 PAGE-F21-02"钱"一节点"测算利润" → 本页打开，顶部显示关联卡片，尺寸与售价已预填 → 导入工厂报价表 → 确认尺寸与价格 → 看利润测算表 → "保存并回写决策卡" → 回到卡片。

**场景 B：单独测算一批报价**
- 动作：从侧栏进入 → 导入报价表或打开历史版本 → 调参数 → 保存到历史库 / 导出 Excel。

**场景 C：老板或运营查看方案**
- 动作：打开历史库里的版本，只看不改。

### 3.3 用户核心诉求

1. **对**：和原工具同一口径，数字可复核。
2. **快**：卡片的尺寸、售价不用手抄。
3. **不丢**：方案存在系统上，谁打开都是同一份。

## 4. 信息架构

### 4.1 区域划分

1. 页头（方案名、保存状态、导出 Excel、方案 .json）
2. 关联决策卡条（仅从卡片进入或已关联时显示）
3. 步骤切换：1 导入报价表 / 2 确认尺寸与价格 / 3 参数设置 / 4 利润测算表 / 历史库
4. 各步骤内容区

### 4.2 区域内容

**关联决策卡条**：卡片名"树脂一体 · 30″ 拆装 · 落地式"（链接 PAGE-F21-02）与状态；已带入的尺寸与拟定售价；"保存并回写决策卡"。

**1 导入报价表**：拖放上传（.xlsx / .xls / .csv）、手动新建产品、打开已保存的方案 .json；列对应关系（工作表、表头所在行、尺寸单位、重量单位、出厂价币种、默认品类、导入方式：替换 / 追加；每个字段对应哪一列）；当前方案信息。

**2 确认尺寸与价格**：产品表（品名、材质 / 描述、包裹序号、长 / 宽 / 高 cm、毛重 kg、出厂价、采购成本 $、Amazon 售价 $、各平台上架 / 促销价、品类）；批量设置（品类应用到全部、FBM 旺季 / 非旺季应用到全部）；新增产品；生成利润测算表。

**3 参数设置**：基础变量（汇率、税点、汇损、推广、其他比例、目标利润率、燃油附加、体积重除数）；平台佣金（家具阈值与高低档、其他品类）；海运方案（整柜价、计算体积、每方单价，可新增）；平台参数（Lowe's / Home Depot / Wayfair 的发货方、加价倍率、上架价系数、默认促销折扣、订单费、比例费）；FBA 配送费档位；FBM / CG 尾程费率表；从 Excel 导入运费表；恢复默认参数。

**4 利润测算表**：海运方案选择；全渠道对比（Amazon FBM / CG / FBA 利润与利润率；Lowe's / Home Depot / Wayfair 促销利润与利润率，小字为上架利润率；促销价可直接改）；保本 / 目标价；综合利润（按销量比例，各渠道合计利润、合计销售额、综合利润率，全部恢复 1:1）；利润明细（选渠道，从售价逐项扣到利润）；包裹明细；保存到历史库。

**历史库**：版本列表（名称可改、保存时间、保存人、产品数、包含产品、关联决策卡、打开 / 删除）；保存当前测算为新版本。

## 5. 界面内容

### 5.1 元素清单

**保存状态**
- 文案："已保存到系统 · 11-03 14:20"；数据来源：服务端方案。

**关联决策卡条**
- 显示条件：URL 带决策卡，或当前方案已关联卡片。
- 文案："关联决策卡：树脂一体 · 30″ 拆装 · 落地式"；"已从卡片带入：尺寸 30″、拟定售价 $245"。

**保存并回写决策卡（主按钮）**
- 显示条件：已关联卡片且角色为操作者。
- 点击：弹窗选择回写的产品，预览各渠道单件利润、利润率、保本价 → "保存并回到决策卡"。

**全渠道对比表**
- 数据来源：前端按参数即时计算（计算逻辑保留原工具），存取走服务端。
- 负利润用"−$6.12"显示，不显示为 0。

**历史库列表**
- 数据来源：服务端；每行可改名、打开（先确认"替换当前测算？"）、删除（再点一次确认）。

### 5.2 辅助信息

- 第 2 步顶部说明默认价格与采购成本的换算规则。
- 第 3 步各分区说明公式（结算价、利润、FBA 档位匹配、FBM 尾程合计）。

## 6. 交互流程

### 6.1 页面加载与初始化

- 从决策卡进入：读取卡片的分框尺寸与拟定售价，预填到第 2 步对应产品的 Amazon 售价和尺寸段，显示关联卡片条，默认停在第 1 步（无产品时）或第 4 步（已有方案时）。
- 从侧栏进入：打开最近一次保存的方案，默认第 4 步。

### 6.2 核心操作流程

```
从 PAGE-F21-02 点"测算利润"
    ▼
本页：预填尺寸、售价 → 1 导入报价表（确认列对应）→ 2 确认尺寸与价格
    → 3 参数设置（可跳过）→ 4 利润测算表
    ▼
点"保存并回写决策卡" → 选回写产品 → 预览 → 确认
    ├─ 保存方案到服务端（历史库新增 / 覆盖当前版本）
    ├─ 卡片"钱"一节写入各渠道单件利润、利润率、保本价
    └─ 返回 PAGE-F21-02
之后再次保存同一方案 → 卡片数字随方案更新（已批准的卡片保留快照，只提示"有新数据"）
```

### 6.3 辅助操作

- 导出 Excel：文件名"利润测算_年月日_时分.xlsx"。
- 方案 .json：导出完整方案；第 1 步可打开 .json。
- 改动任一变量，测算表立即重算。

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 采购成本 $ | FOB 美元价直接计入；RMB 含税价 ÷ (1 + 税点) ÷ 汇率；RMB 未税价 ÷ 汇率 |
| 上架价 / 促销价 | 未填时上架价 = Amazon 售价 × 上架价系数；促销价 = 上架价 × (1 − 默认促销折扣) |
| 结算价 | 前台价 ÷ 加价倍率 |
| 平台利润 | 结算价 − 采购成本 − 海运费 − 物流费 − 平台订单费 − 结算价 × 比例费合计 |
| 保本 / 目标价 | 利润为 0 / 达到目标利润率时的前台促销价 |
| 综合利润率 | 合计利润 ÷ 合计销售额（Amazon 按售价，平台按促销价） |
| 方案 | 产品、尺寸、价格、销量与全部参数的完整版本；关联决策卡 ID |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 尺寸、毛重 | 失焦 | 正数 | "包裹尺寸或毛重不完整" |
| 出厂价、售价 | 失焦 | 正数 | "缺出厂价" / "缺售价" |
| 百分比参数 | 失焦 | 0–100 | "请填 0–100 之间的数" |
| 保存 | 点击保存 | 至少 1 个产品 | "没有产品可以保存" |

### 8.3 特殊业务规则

- **存服务端（AC-F24-02）**：方案和历史库保存在系统（wen 电脑）上，不存浏览器。
- **回写（AC-F24-04）**：卡片显示所选产品的各渠道单件利润、利润率、保本价，并随方案更新。
- **权限**：只有操作者能编辑、保存、回写；其他角色只看。
