## 2. 页面概述

### 2.1 一句话定位

让只存在本机的台账、策略库、字段约定、品类配置和确认记录，每月自动留一份备份，并能安全地恢复到任一份。

### 2.2 存在理由

1. **积累不可再生**：快照与立项记录保存后不可改，策略库逐月演进。电脑损坏或误操作一旦丢失，6 个月后的对账就无从进行（US-F10-01、NFR-002）。
2. **失败必须看得见**：静默失败等于没有备份，失败时要显示原因和上次成功时间（AC-F10-07）。
3. **恢复会覆盖当前数据**：必须二次确认，并先把当前状态备份一份，留出撤回的余地（DEC-008）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 自动 | 每次导出当月结果后自动生成一份带时间戳的备份（AC-F10-06） |
| 失败可见 | 失败时显示原因与上次成功时间，已有备份不删除、不改动（AC-F10-07） |
| 恢复一致 | 恢复后 5 类内容与备份时逐条一致（NFR-002） |
| 可撤回 | 每次恢复前都有一份当前状态的备份（DEC-008） |

### 2.4 不做什么

- **不备份数据包原件**：原件较大且 wen 手里都有；备份只附数据包指纹清单，恢复后重新导入时按指纹识别（蓝图 §9）。
- **不删除备份**：第一期不提供删除业务数据的功能；旧备份由 wen 在文件夹中自行管理。
- **不上传、不同步**：只写入指定目录，不调用外部服务（NFR-006）。
- **不做定时备份和手动"立即备份"**：需求只要求导出后自动备份；另外只有恢复前的自动备份和失败后的"重试备份"。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 首次使用前设置目录；导出后确认备份；备份失败时处理；误操作或换电脑后恢复 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：设置目录（首次）**
  - 动作：填入 `D:\机会判定台备份\`，点"检测能否写入"，显示可以写入后保存。
- **场景 B：导出后确认**
  - 动作：导出 2027-05 报告后，"最近一次备份"更新为本次时间，列表顶部多一份。
- **场景 C：备份失败**
  - 动作：看到"备份目录不可写：D:\机会判定台备份\（拒绝访问）"和上次成功时间，换一个可写目录后点"重试备份"。
- **场景 D：恢复**
  - 动作：误改了策略库，选 2027-04-08 15:06 的备份，确认弹窗里看清会覆盖什么，确认恢复。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题、备份内容说明。
2. 恢复结果横幅（恢复完成后出现）。
3. 左："最近一次备份"；右："备份目录"。
4. 备份列表。
5. 页脚：数据目录与备份目录。
6. 恢复确认弹窗。

### 4.2 区域内容

**最近一次备份**
- 成功时：徽章"成功"；时间 2027-04-08 15:06；触发"导出 2027-04 第 2 版后自动备份"；大小 38.2 MB；位置 `D:\机会判定台备份\备份_20270408_1506\`；下次"导出 2027-05 报告后自动备份（本月尚未导出）"。
- 失败时（AC-F10-07）：徽章"失败"；失败时间、原因、上次成功备份时间；说明"已有备份未被删除或改动"；按钮"重试备份"。
- 面板脚注："备份失败时，这里显示失败原因和上次成功备份的时间；已有备份不会被删除或改动。"

**备份目录**
- 路径输入（必填）。
- "检测能否写入"：结果写在输入框下方，成功为"可以写入 · 可用空间 186.4 GB · 检测于 2027-05-08 09:12"，失败写原因（目录不存在、拒绝访问、空间不足）。
- "保存目录"：保存前自动检测一次，不能写入时不保存。
- 说明：建议选本机另一块磁盘或移动硬盘上的文件夹；数据包原件不进入备份。

**备份列表**（新的在上；每份都包含 5 类内容和数据包指纹清单）

| 列 | 内容 |
| :--- | :--- |
| 备份时间 | 时间戳；下一行为备份文件夹名，如"备份_20270408_1506" |
| 触发 | "导出 2027-04 第 2 版"、"恢复前自动备份" |
| 内容范围 | 台账（快照数、立项记录数）· 策略库（规则数）；下一行：字段约定版本 · 品类配置版本 · 确认记录条数 |
| 数据包指纹 | 指纹个数；点开浮层列出每个数据包版本与指纹前 8 位 |
| 大小 | 如 38.2 MB |
| 操作 | "恢复"（红色描边按钮） |

当前 6 份：2027-04-08 15:06 · 2027-03-05 15:44 · 2027-02-05 14:16 · 2027-01-07 16:29 · 2026-12-04 15:58 · 2026-11-10 17:11（首跑导出）。

**恢复确认弹窗**（DEC-008 的二次确认）
- 标题："恢复到 2027-04-08 15:06 的备份？"；副标题为备份位置与大小。
- 警示："将覆盖当前的台账、策略库、字段约定、品类配置和确认记录"，并说明该备份之后新增或修改的内容会被替换。
- "当前 → 恢复后"对比（5 行，取值不同的旧值划线、新值高亮，相同的写"不变"）：

| 内容 | 当前 | 恢复后（2027-04-08 15:06） |
| :--- | :--- | :--- |
| 台账 | 快照 10 · 立项记录 6 | 快照 9 · 立项记录 5 |
| 策略库 | 18 条 · 最近修改 2027-05-08 | 18 条 · 最近修改 2027-04-08 |
| 字段约定 | v7 | v6 |
| 品类配置 | v2 | 不变 |
| 确认记录 | 1,342 条 | 1,286 条 |

- "确认后系统会"：① 先把当前状态自动备份到备份目录（不能跳过，需要撤回时从它恢复）；② 用所选备份覆盖 5 类内容并逐条核对；③ 完成后在本页显示所恢复备份的时间，字段约定或品类配置与当前结果所用版本不同时，相关结果标为需重算。
- 按钮："取消"、"确认恢复"（红色描边）。

**恢复结果横幅**（AC-F10-08）
- "已恢复到 2027-04-08 15:06 的备份"；说明恢复时间、5 类内容已与该备份逐条核对一致、恢复前自动备份的时间。

## 6. 交互流程

### 6.1 加载与初始化

- 读取备份目录设置、最近一次备份记录、目录中由本系统生成的备份清单。
- 没有设置目录时，目录输入为空，最近备份区显示"还没有设置备份目录"。

### 6.2 核心操作流程

```
设置目录：填路径 → "检测能否写入" → 可以写入 → "保存目录"（保存前再检测一次）
                                    └─ 不能写入 → 显示原因，不保存

自动备份（AC-F10-06）：
PAGE-F12-01 导出完成 → 在备份目录生成"备份_年月日_时分" → 成功：更新最近一次备份与列表
                                                       └─ 失败：显示原因与上次成功时间，不动旧备份（AC-F10-07）
                                                                → 工作台待处理出现"备份失败"

恢复（AC-F10-08，DEC-008）：
点某份备份的"恢复" → 确认弹窗（覆盖说明 + 当前→恢复后对比）
  ├─ 取消 → 关闭，不做任何改动
  └─ 确认恢复 → 先自动备份当前状态（失败则停止，不恢复）
              → 覆盖 5 类内容 → 逐条核对与备份一致
              → 关闭弹窗；页顶显示"已恢复到 xx 的备份"；列表顶部出现"恢复前自动备份"
              → 写入操作记录（操作人、时间、所恢复备份、恢复前备份）
```

### 6.3 辅助操作

- 点指纹小标签查看清单，再点一次或点别处收起。
- Esc 或点遮罩关闭确认弹窗（恢复进行中除外）。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未设置目录 | 首次使用 | 最近备份区"还没有设置备份目录"；目录区提示"导出前请先设置备份目录"；导出弹窗同样提示 |
| 还没有备份 | 已设置目录、尚未导出 | 列表空态："还没有备份。导出本月报告后会自动备份到这里。" |
| 正常 | 有成功备份 | 见 4.2 |
| 目录检测失败 | 目录不存在、拒绝访问或空间不足 | 输入框下方显示原因，不保存目录 |
| 备份失败 | 自动备份时目录不可写或过程出错 | 最近备份区为"失败"：原因（如"备份目录不可写：D:\机会判定台备份\（拒绝访问）"）、失败时间、上次成功时间 2027-04-08 15:06；"重试备份"；已有备份原样保留（AC-F10-07） |
| 恢复中 | 确认恢复后 | 按钮"恢复中…"；期间不能启动计算任务 |
| 恢复完成 | 恢复成功 | 恢复结果横幅；"最近一次备份"更新为恢复前自动备份 |
| 恢复失败 | 覆盖或核对出错 | 当前数据保持恢复前的状态，显示原因；恢复前的自动备份保留 |
| 计算任务运行中 | 有计算或回测在跑（DEC-010） | "恢复"不可用，悬停提示"回测正在运行，完成后再试" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 恢复前的自动备份失败 | 不执行恢复，显示原因（DEC-008 的前提不满足） |
| 恢复的字段约定、品类配置与当前结果所用版本不同 | 相关结果标为需重算，旧结果仍可看，由 wen 在工作台"全部重算"（DEC-016） |
| 备份之后导入的数据包 | 数据包留在本机数据目录，不被恢复删除；需要时按指纹清单核对，缺的重新导入 |
| 同月多次导出 | 每次导出都备份一份，按时间戳区分 |
| 备份目录里有别的文件 | 只列出本系统生成的备份（按文件夹命名与内部清单识别） |
| 连续点击"确认恢复" | 只执行一次 |

## 8. 业务规则与校验

- **自动备份时机**（AC-F10-06）：每次导出当月结果完成后，在指定目录生成一份带时间戳的备份，并显示备份完成时间。
- **内容范围**（REQ-F10-04）：
  - 台账：月度快照、立项记录与更正、自家上架数据、对账结果；
  - 策略库：全部规则及全部版本；
  - 字段约定、品类配置：全部版本；
  - 全部确认记录：字段确认、合并建议的确认与拒绝、归并修改与拆分、体检"已知晓"等；
  - 附数据包指纹清单。
- **失败处理**（AC-F10-07）：目录不可写或备份过程失败时，显示失败原因和上次成功备份的时间；不删除、不改动任何已有备份；未完成的这一份不出现在列表中。
- **恢复**（AC-F10-08、DEC-008）：选中备份 → 二次确认 → 自动备份当前状态 → 覆盖 5 类内容 → 显示所恢复备份的时间。
- **一致性**（NFR-002）：恢复后台账、策略库、字段约定、品类配置与确认记录与备份时逐条一致，系统核对后才显示完成。
- **单任务**（DEC-010）：恢复与计算任务不能同时进行。
- **留痕**：恢复写入操作记录（操作人、时间、所恢复备份、恢复前自动备份）（蓝图 §9）。

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 备份目录 | 检测、保存时 | 路径存在且可写，可用空间足够 | "不能写入：拒绝访问。请换一个目录，或检查该目录的权限" |

## 9. 页面流转

```
PAGE-F12-01 导出报告 ──导出完成──→ 自动备份 ──→ 本页"最近一次备份"、列表
PAGE-F03-01 工作台（备份区 / 待处理"备份失败"）──→ 本页
本页 ──"恢复"──→ 确认弹窗 ──确认──→ 恢复前自动备份 → 覆盖 → 本页显示结果
                                      └─ 有结果需重算 → PAGE-F03-01 全部重算
```

### 10.2 页面提交的数据

| 数据 | 触发时机 | 用途 |
| :--- | :--- | :--- |

- 不读取备份里的业务明细，只读取清单摘要；不加载数据包原件。

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
