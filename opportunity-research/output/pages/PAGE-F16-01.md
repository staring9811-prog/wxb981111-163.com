## 2. 页面概述

### 2.1 一句话定位

wen 自己配置四个外部服务的密钥并选定大模型提供方，页面只露后 4 位。

### 2.2 存在理由

1. 拉 Amazon 数据、采其他渠道评论、看图打标、差评归类、起草叙述都依赖外部服务；没有自助配置，换账号就要改代码。
2. 密钥一旦外泄会被盗刷费用，必须本机加密存储、页面只露后 4 位（AC-F16-01、AC-F16-05、NFR-008）。
3. 密钥过期或额度用完时要能快速判断原因（AC-F16-02）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 不外泄 | 页面、导出、日志中出现完整密钥的次数为 0 |
| 可诊断 | 测试失败时 100% 给出原因类别：认证失败 / 网络 / 额度 |
| 生效 | 更换后的下一次调用即使用新密钥 |

### 2.4 不做什么（范围边界）

- **不显示完整密钥、不提供"显示密钥"或复制功能**（AC-F16-05）。
- **不在本页设预算**：月度上限在 PAGE-F16-02。
- **大模型提供方第一版只列 Claude、OpenAI**（AC-F16-04"至少两家"），不做按任务分别选提供方。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 仅操作者 wen；其他角色无入口，直接访问显示无权限 |
| 使用频次 | 低频：首次部署、换账号、密钥失效时 |

### 3.2 核心使用场景

**场景 A：联调前填大模型密钥**：选提供方"Claude"→ 粘贴密钥 → 保存 → 显示"••••Xc4M"→ 点"测试"→"可用"。
**场景 B：Bright Data 报错**：评论采集提示"Bright Data 认证失败"→ 来到本页点"测试"→ 显示"认证失败：密钥无效或已被撤销"→ 点"更换"→ 粘贴新密钥 → 测试可用。
**场景 C：不再用 OpenAI**：删除 OpenAI 密钥 → 确认弹窗列出受影响功能 → 删除后显示"未连接"。

### 3.3 用户核心诉求

1. **安全**：完整密钥只在输入那一刻出现。
2. **知道能不能用**：每个服务的连接状态和最近一次测试结果一目了然。
3. **知道影响**：删除前知道哪些功能会停。

**测试按钮**
- 点击后按钮显示"测试中…"，调用该服务的最小只读请求（AC-F16-02）。
- 结果：可用（绿）；失败显示原因类别与一句说明：
  - 认证失败："密钥无效或已被撤销，请更换"
  - 网络："连接超时，请确认运行机能访问外网"
  - 额度："账户额度不足，请到服务商后台充值"

**填写 / 更换密钥弹窗**
- 字段：密钥*（遮盖输入，不可显示）。
- 说明："保存后只保存在本机加密存储，页面此后只显示后 4 位。"
- 按钮：取消 / 保存（保存后自动测试一次）。

**删除确认弹窗**
- 文案："删除 OpenAI 密钥？删除后依赖该服务的功能显示'未连接'，不会发起调用：……（列出依赖功能）"。
- 若删除的是当前所选提供方的密钥，额外提示"大模型将显示未连接：元素全部进入人工确认、差评只显示原文、不起草叙述"（需求前置能力 fallback）。
- 按钮：取消 / 删除（危险样式）。

**提供方切换**
- 单选 Claude / OpenAI，切换即保存；选中未填写密钥的一家时，同时提示"OpenAI 尚未填写密钥，大模型功能将显示未连接"。
- 切换即保存，Toast"大模型提供方已改为 Claude，看图打标、差评归类、叙述草稿都将使用 Claude"。

### 5.2 辅助信息

- 页脚："密钥只保存在本机加密存储；页面、导出文件、日志中都不会出现完整密钥。"

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者 → 无权限页。
- 操作者 → 读取四个服务的掩码、保存时间、最近测试结果（不读取明文）。

### 6.2 核心操作流程

```
填写/更换 → 输入密钥 → 保存
  ├─ 空值 → "请填写密钥"
  └─ 保存成功 → 只显示后 4 位 → 自动测试
        ├─ 可用 → 状态"可用"
        └─ 失败 → 状态"失败：认证失败/网络/额度" + 处理建议
     → 写审计日志"密钥变更"（只记后 4 位）

删除 → 确认弹窗（列出受影响功能）→ 删除 → 状态"未连接"
     → 依赖功能显示"未连接"并不发起调用（AC-F16-03）
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载态 | 首次进入 | 卡片骨架 |
| 未连接（空） | 未填写或已删除 | 徽章"未连接"，按钮"填写密钥"，说明依赖功能当前不可用 |
| 测试中 | 点"测试" | 按钮"测试中…"，不可重复点 |
| 可用 | 测试成功 | 绿色"可用"，显示测试时间 |
| 失败（错误） | 测试失败 | 阻断色徽章"失败"，原因类别和处理建议 |
| 保存失败 | 写入本机存储失败 | 弹窗内阻断提示，不关闭弹窗 |
| 无权限 | 非操作者访问 | "无权限：密钥设置仅操作者可用"，按钮回工作台 |

> 本页无列表分页和长任务。

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 更换时有任务正在运行 | 已开始的任务用旧密钥跑完；之后的调用用新密钥（AC-F16-03） |
| 删除正在使用的密钥 | 依赖功能立刻显示"未连接"，运行中的任务在下一次调用前停止并保留已采数据 |
| 粘贴含空格 | 保存前去除首尾空格 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 密钥 | 只写不读；页面只显示"••••"+后 4 位 |
| 连接状态 | 可用 / 失败（认证失败、网络、额度）/ 未连接 |
| 大模型提供方 | Claude / OpenAI，全局一个，三类大模型任务共用 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 密钥必填 | 保存 | 非空 | 请填写密钥 |
| 测试 | 点击测试 / 保存后 | 最小只读请求 | 可用 / 认证失败 / 网络 / 额度 |

### 8.3 特殊业务规则

- 密钥本机加密存储，不进入代码仓库、导出文件、日志（NFR-008、AC-F16-05）。
- 保存、更换、删除、切换提供方都写入审计日志"密钥变更"，日志只含后 4 位。
