| 字段 | 内容 |
| :--- | :--- |

| 功能范围 | 关联 ASIN 或 SPU、上架月；月龄 1–6：每月录入月销量、月销售额、小类 BSR，留空表示缺数据，不按 0 处理；保存后按成功线即时判定 |

## 2. 页面概述

### 2.1 一句话定位

把自家立项上架后 6 个月的销量、销售额和 BSR 录进来，用与竞品新品同一条成功线判定成没成。

### 2.2 存在理由

1. **自家结果才是最终检验**：判定卡说某细分好，自家在这个细分立的项到底成没成，要用自家数据判定（AC-F10-05）。
2. **同一把尺**：自家与竞品用同一条成功线，结果才能和当时的排名、锦囊对照。
3. **缺数据要如实**：某月没拿到数据就留空，不能当成 0，否则会把"不知道"判成"失败"。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 判定一致 | 判定规则与竞品新品成败判定相同（REQ-F05-01） |
| 缺失不失真 | 留空的格子按缺数据处理，不按 0 处理 |
| 即时可见 | 保存后立即显示命中 / 未命中 / 观察中 / 数据不全及依据 |

### 2.4 不做什么

- **不修改立项记录**：立项内容在 PAGE-F10-04，录错走更正。
- **不录入子体级明细**：只录 SPU 层面的月度合计与当月最好 BSR。
- **不连外部数据源**：第一期只手工录入或从数据包 C7 导入（DEC-012）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 自家产品上架后，每月月更时补一个月；满 6 个月时得到最终结果 |

- **场景 A：逐月补录**：D-0001 2026-09 上架，每月拿到后台数据后补一列，期间显示"观察中 · 还剩 n 个月"。
- **场景 B：满 6 个月出结果**：2027-03 补完第 6 个月（2027-02），最好 BSR 112、最高月销售额 $46,800，两项都未达标，判为未命中。
- **场景 C：数据包已带数据**：数据包含 C7 的上架后月度数据时，网格带出导入值，只需核对。

## 4. 信息架构

### 4.1 区域划分

1. 弹窗头：标题"录入自家上架数据"；副标题为立项编号、名称、关联细分、来源与立项日期；关闭。
2. 关联 ASIN 或 SPU、上架月。
3. 月龄 1–6 网格。
4. 判定结果。
5. 弹窗脚："取消"、"保存并判定"。

### 4.2 区域内容

**月龄 1–6 网格**：列为第 1–6 个月（列头写月份，由上架月推出），行为三项指标：

| 指标 | 填什么 | 格式 |
| :--- | :--- | :--- |
| 月销量（件） | SPU 当月销量合计 | 非负整数 |
| 月销售额（$） | SPU 内各子体当月销售额合计，美元 | 非负数，可带千分位 |
| 小类 BSR | 当月最好的子 ASIN 的小类排名 | 正整数 |

数字右对齐；网格下注明"月销售额填 SPU 内各子体合计；小类 BSR 填当月最好的子 ASIN 名次"。

**判定结果**：标题"按成功线判定"并注明"品类配置 v2，与竞品新品同一条"，右侧为结果徽章；逐条列出两项成功线的窗口内最好值（带证据小标签）、出现的月份与是否达标；底部说明判定理由、"保存时按所填数据重新判定，结果同步到到期对账"和上次保存时间与操作人。

## 6. 交互流程

### 6.1 加载与初始化

- 带出立项记录信息与已保存的上架数据（含来自 C7 的数据），并显示当前判定。
- 首次录入：网格为空，判定区写"填写上架月和月度数据后，保存时按成功线判定"。
- 上架月之后尚未到来的月份（超过当前数据月）的格子不可填。

### 6.2 核心操作流程

```
打开弹窗
  ├─ 填写或修改上架月 → 网格列头月份随之更新
  ├─ 在网格中填写数字（留空 = 缺数据）
  └─ 点"保存并判定"
       ├─ 格式错误 → 对应格子标红并提示，不保存
       └─ 通过 → 保存（记操作人与时间；修改已有值时记录前后值）
            → 按成功线判定 → 关闭弹窗，回到 PAGE-F10-04
            → 轻提示"已保存 D-0001 上架数据：未命中"；状态列与到期对账同步更新
点"取消"、关闭或按 Esc → 有未保存修改时提醒，否则直接关闭
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 首次录入 | 该立项还没有上架数据 | 网格为空，判定区为说明文字 |
| 观察中 | 上架不满 6 个月且尚未达标 | 徽章"观察中"，写"还剩 n 个月" |
| 命中 | 任一月 BSR ≤ 50 或销售额 ≥ $100,000 | 徽章"命中"，写首次达成的月份与指标 |
| 未命中 | 6 个月数据齐全，两项都未达标 | 徽章"未命中"（中性），两项最好值与月份 |
| 数据不全 | 窗口内有月份缺销量或 BSR，且尚未达标 | 徽章"数据不全"，列出缺失月份 |
| 校验失败 | 格式不对 | 格子标红，下方提示 |
| 保存中 | 点保存后 | 按钮"保存中…"，不能重复提交 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 填 0 与留空 | 0 表示当月真实为 0（如断货无销量），留空表示没有数据；两者判定不同 |
| 已命中后又补后续月份 | 仍记录，结果保持"命中"（首次达成即命中） |
| 上架月改动 | 网格月份整体随之对应；已填的值按月龄保留，保存前提示确认 |
| 修改已保存的值 | 允许，写入操作记录（前后值、操作人、时间），判定随之更新 |
| 数据来自 C7 | 带出导入值并标注来源；手工修改后来源改记为手工录入 |

## 8. 业务规则与校验

### 8.1 判定规则（与竞品新品相同，REQ-F05-01）

- 判定窗口：上架当月起连续 6 个自然月（上架当月为第 1 个月）。
- 命中：窗口内任一月小类 BSR ≤ 品类配置阈值（50），或 SPU 任一月销售额 ≥ 品类配置阈值（$100,000）。
- 观察中：窗口未结束且尚未命中。
- 未命中：窗口结束、每月都有销量与 BSR，两项都未达标。
- 数据不全：尚未命中且窗口内有月份缺销量或 BSR，列出缺失月份。
- 阈值取保存时的品类配置版本，并随结果记录配置版本号。

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 关联 ASIN 或 SPU | 提交时 | 非空；ASIN 为 10 位、B0 开头，或自家 SPU 编号 | "请填写父 ASIN 或自家 SPU 编号" |
| 上架月 | 失焦、提交时 | YYYY-MM，不早于立项月份，不晚于本月 | "请按 2026-09 的格式填写上架月" |
| 月销量 | 失焦 | 留空，或非负整数 | "请填写整数；没有数据就留空" |
| 月销售额 | 失焦 | 留空，或非负数，可带千分位 | "请填写金额数字；没有数据就留空" |
| 小类 BSR | 失焦 | 留空，或正整数 | "小类 BSR 应为正整数；没有数据就留空" |

| 当前数据月份 | F01 | 判断观察中、限制可填月份 |

### 10.2 页面提交的数据

| 数据 | 触发时机 | 用途 |
| :--- | :--- | :--- |
| 关联 ASIN 或 SPU、上架月、月龄 1–6 的三项指标（留空保存为缺失） | 点"保存并判定" | 保存上架数据，生成自家对账结果，写入操作记录 |

- 不提交立项记录的任何字段；不保存子体级数据。
