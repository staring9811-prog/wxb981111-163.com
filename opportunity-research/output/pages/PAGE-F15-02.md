## 2. 页面概述

### 2.1 一句话定位

登录后一眼看清"这个月还有哪些事没做完"，并一步跳到要处理的页面。

### 2.2 存在理由

1. 每月流程跨多个页面（拉数据 → 核对 → 打标确认 → 重算 → 扫描 → 决策卡 → 审批 → 对账），没有聚合页时 wen 要逐页检查哪一步卡住。
2. 市场评分有效性告警必须出现在首页（AC-F19-04），否则可能拿未通过检验的评分去立项。
3. 老板登录后要直接看到待他审批的事项；只读同事只需看到能看的入口。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 发现待办 | 本月未完成的数据、标签、审批、对账事项 100% 在本页出现 |
| 跳转效率 | 每个待办一次点击到达处理页面 |
| 权限一致 | 角色无权进入的页面，本页不出现其入口或数字 |

### 2.4 不做什么（范围边界）

- **不在本页执行任务**：拉取、并入、审批、对账都在各自页面完成，本页只显示状态和入口。
- **不做自定义看板、图表配置**：没有对应需求。
- **不汇总跨渠道绝对销量**：各渠道口径不同，只显示数据状态（AC-F29-02）。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者 wen、审批者老板、只读（运营 / 采购 / 研发） |
| 使用频次 | 操作者每月数据更新时和评审前多次；审批者每次评审；只读评审会前后 |
| 使用设备 | 办公电脑；评审会投屏 |

### 3.2 核心使用场景

**场景 A：wen 月初开工（操作者）**
- 时机：11 月初，上月（2026-10）数据该更新了。
- 动作：看到 Amazon 2026-10 被拦截为"疑似月份错误"→ 点进 Amazon 月度数据页处理；看到 37 条标签待确认 → 去打标确认；看到 Bright Data 已用 82% → 留意预算。

**场景 B：老板审批（审批者）**
- 时机：wen 提交了决策卡。
- 动作：登录看到"待我审批 2"→ 点进审批页。看到市场评分本月通过有效性检验，放心看卡。

**场景 C：采购看台账（只读）**
- 动作：只看到有效性状态、本月到期对账和机会扫描 / 决策卡入口；没有数据、标签、费用、审批相关内容。

### 3.3 用户核心诉求

1. **一眼看全**：本月进度和卡点集中在一屏。
2. **少点击**：每项都能直接跳过去。
3. **不越权**：看不到与自己无关、无权操作的入口。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题"工作台"、当前月份说明
2. 有效性横幅（常驻，不可关闭）
3. 主栏：本月数据状态（四渠道）
4. 主栏：待确认标签、本月到期对账
5. 侧栏：待我审批、本月各服务花费 / 上限
6. 常用入口（只读角色的主要内容）

### 4.2 区域内容与角色可见性

| 区块 | 内容 | 操作者 | 审批者 | 只读 | 依据 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| 有效性横幅 | 本月市场评分是否通过有效性检验，D 档之后变大比例与阈值 | 显示 | 显示 | 显示 | AC-F19-04（首页显示告警） |
| 本月数据状态 | Amazon、Home Depot、Lowe's、Wayfair 各自月份、状态、核对结论 | 显示 | 隐藏 | 隐藏 | 数据页仅操作者（蓝图 §4） |
| 待确认标签 | 待确认条数、按渠道分布 | 显示 | 隐藏 | 隐藏 | 打标确认仅操作者 |
| 待审批 | 待审批的决策卡与策略库"已验证"申请 | 显示为"等待审批"（我提交的） | 显示为"待我审批" | 隐藏 | 审批页面向审批者、操作者（蓝图 §4） |
| 本月到期对账 | 满 6 个月到期的台账条目与对账状态 | 显示 | 显示 | 显示（只看） | AC-F26-02；台账全员可看 |
| 本月花费 / 上限 | 四个服务本月已花与月度上限 | 显示 | 隐藏 | 隐藏 | 设置分区仅操作者（蓝图 §3） |

> 侧栏同样按角色隐藏：审批者不显示"数据""工具"中的评论 VP 追踪和"设置"分组，可见模型与回测（只读）、利润测算（只看）；只读角色只显示工作台、机会扫描、决策卡、策略库、预测台账、利润测算（只看）。无权限的入口直接隐藏，不置灰（蓝图 §3）。

## 5. 界面内容

### 5.1 元素清单

**页头**
- 标题"工作台"；副标题"2026-11-03 · 本月处理上月（2026-10）数据"。
- 无主按钮（本页不执行任务）。

**有效性横幅**
- 通过时：通过横幅"市场评分本月通过有效性检验"，说明"D 档之后变大 24%（阈值 ≤ 30%），把握分档逐档上升，n=186"，链接"查看回测"→ PAGE-F19-01。
- 未通过时：预警横幅"市场评分本月未通过有效性检验"（原文照 AC-F19-04），说明哪一条未通过，常驻不可关闭。
- 未重算时：横幅"本月尚未重算，以下沿用 2026-09 结论"。

**本月数据状态（四行）**
- 每行：渠道名、数据月份、状态徽章、核对说明、最近更新时间、"去处理"或"查看"链接。
- 示例：
  - Amazon：2026-10 "疑似月份错误"（阻断）——"与 2026-09 小类排名完全相同的 ASIN 占 99.9%（阈值 10%），未并入"；上一个已并入月 2026-09*（带 * 标记）。→ PAGE-F17-01
  - Home Depot：2026-10 已采集并入，"评论 VP 追踪 2026-11-02 完成"。→ PAGE-F28-01
  - Lowe's：2026-10 已采集并入。
  - Wayfair：2026-10 已采集并入；注明"VP 口径不同，只在渠道内比较"。

**待确认标签**
- 大数字 37 条；分布：Amazon 21、Home Depot 6、Lowe's 4、Wayfair 6；构成：元素 29、低置信度 8；→ PAGE-F18-01。

**待审批**
- 条数 2；列表：类型（决策卡立项 / 策略库申请）、标题、提交人、提交时间；→ PAGE-F25-01（审批者点行直接进入该决策卡 PAGE-F21-02 审批）。
- 示例：决策卡"30 英寸 · 整装 · 落地｜台面材质 = 岩板"；策略库"带抽屉的 24 英寸窄柜在 Wayfair 份额更稳定"申请改为"已验证"。

**本月到期对账**
- 列表：台账编号、决策卡名、预计上架月、满 6 个月月份、对账状态。
- 状态词：等待数据（对应月份数据未并入）、已自动对账（做到 / 未做到）、待关联（超过预计上架 3 个月未关联自家 ASIN）。
- 示例：TZ-2026-004 "36 英寸 · 整装 · 落地｜双盆"，满 6 个月于 2026-10，状态"等待数据：Amazon 2026-10 未并入"；Home Depot 已判定"做到"（估算月销 268 件 ≥ 250）。

**本月花费 / 上限**
- 每个服务一行：服务名、已花 / 上限、进度条、占比；达到 80% 用预警色，达到 100% 显示"已达上限，已停止新调用"（AC-F16-06）。
- 示例：卖家精灵 3,120 / 5,000 次（62%）；Bright Data $65.60 / $80（82%，预警）；Apify $27.90 / $60（47%）；大模型（Claude）$18.75 / $50（38%）。→ PAGE-F16-02

**常用入口**：机会扫描、决策卡、预测台账、策略库四个卡片链接。

### 5.2 辅助信息

- 每个数字旁带证据小标签（样本量、估算 / 实测），与全站一致。
- 页脚："数据每月由 wen 手动发起更新，系统不做定时任务。"

## 6. 交互流程

### 6.1 页面加载与初始化

- 校验会话；未登录重定向 PAGE-F15-01（AC-F15-01）。
- 读取当前账号角色，只请求并渲染该角色可见区块（无权限区块不渲染、不返回数据）。

### 6.2 核心操作流程

```
进入工作台
  ├─ 看到阻断 / 预警 → 点"去处理" → 对应页面（F17 / F28 / F18 / F16-02）
  ├─ 待审批 → 点行 → PAGE-F21-02 决策卡详情 或 PAGE-F25-01 审批
  ├─ 到期对账 → 点行 → PAGE-F26-01 预测台账
  └─ 有效性横幅"查看回测" → PAGE-F19-01
```

### 6.3 辅助操作

- 长任务（拉取、采集、打标）完成后，工作台对应区块显示"刚完成"提示（蓝图 §5）。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载态 | 首次打开 | 各区块骨架条；再次进入时保留上次结果降低透明度 |
| 正常态 | 数据齐全 | 见第 5 节 |
| 空状态 | 系统刚部署、尚无任何月份数据 | 数据状态区显示"还没有任何月份的数据。先在 Amazon 月度数据页拉取第一批。"按钮"去拉取"（仅操作者） |
| 无待办 | 待确认 0、待审批 0、到期 0 | 对应区块显示"本月没有待确认标签" 等一句话，不隐藏区块 |
| 长任务进行中 | 拉取或采集正在运行 | 对应渠道行显示"拉取中 64%"和步骤名；顶栏任务指示同步 |
| 错误态 | 某区块数据读取失败 | 该区块显示"读取失败，刷新重试"，其他区块照常 |
| 无权限 | 角色无权的区块 | 不渲染（不是置灰） |
| 有效性未通过 | AC-F19-04 条件成立 | 预警横幅常驻顶部，不可关闭 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 某渠道本月无数据（采集失败） | 该行标"本月无数据"，其他渠道照常（PRD §5.3） |
| 服务达到上限 | 花费行显示"已达上限，已停止新调用" |
| 服务未连接（密钥删除） | 花费行显示"未连接"，链接到 PAGE-F16-01 |
| 账号在浏览中被停用 | 下一次请求回到登录页（AC-F15-05） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 本月 | 当前自然月；"数据月份"指上一个自然月（PRD §3.2.1） |
| 数据状态 | 未拉取 / 拉取中 / 核对异常待确认 / 疑似月份错误 / 已并入 / 已并入* / 本月无数据 |
| 有效性 | 通过 / 未通过（D 档之后变大比例 > 30% 或把握分档不再逐档上升） |
| 到期对账 | 预计上架后满 6 个月落在本月的台账条目 |

### 8.2 特殊业务规则

- 角色权限以服务端为准；只读或审批者即便直接请求隐藏区块的数据，也返回"无权限"（AC-F15-02、AC-F15-03）。
- 有效性横幅文案和判定照抄 AC-F19-04，只读角色同样可见。

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 未登录 | 未登录打开工作台被重定向到登录页，不返回任何数据（AC-F15-01） |
| F-02 | 有效性告警 | 回测 D 档之后变大比例 > 30% 或分档不再逐档上升时，顶部显示"市场评分本月未通过有效性检验"，不可关闭（AC-F19-04） |
| F-03 | 数据状态 | 四个渠道各自显示最新月份与状态；Amazon 疑似月份错误时显示阻断和原因 |
| F-04 | 到期对账 | 满 6 个月的台账出现在本区；对应月份数据未并入时显示"等待数据"，并入后显示自动判定结果（AC-F26-02） |
| F-05 | 跳转 | 每个待办一次点击进入处理页面 |

### 11.2 权限验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| P-01 | 只读角色 | 只显示有效性、到期对账、常用入口；数据状态、标签、审批、花费区块及侧栏设置分组不出现（AC-F15-02，蓝图 §3） |
| P-02 | 审批者 | 显示"待我审批"、有效性、对账；不显示数据状态、标签、花费、设置分组；本页无任何编辑入口（AC-F15-03） |
| P-03 | 隐藏而非置灰 | 无权限的入口不以置灰形式出现 |

### 11.3 体验验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| U-01 | 区块独立失败 | 一个区块读取失败不影响其他区块 |
| U-02 | 无待办 | 无待办的区块显示一句说明而非空白 |
