## 2. 页面概述

### 2.1 一句话定位

在系统内保留原"评论月度 VP 追踪器"的全部能力，按月统计 Home Depot / Lowe's / Wayfair 的 VP / 非 VP 评论数，密钥、上限和记账与设置页共用。

### 2.2 存在理由

1. 原工具单独运行，密钥、预算、记账各管各的，月底对不上总花费。
2. 其他渠道的销量估算（F28）依赖这里的月度评论数，两边口径必须一致。
3. 采集 Lowe's / Wayfair 要花钱且耗时数小时，必须先评估、可中断续跑。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 口径一致 | 同一项目设置下，导出结果与原工具一致（Wayfair 只有 Verified Purchase 计 VP） |
| 不重复花钱 | 中断后重跑，已成功商品的调用次数与计费为 0（NFR-011） |
| 先知后花 | 100% 的花钱步骤在开始前弹出费用评估确认（AC-F16-07） |

### 2.4 不做什么（范围边界）

- **不保存密钥**：密钥只在 PAGE-F16-01 填写，本页只显示连接状态和后 4 位。
- **不做销量换算**：VP × 系数的估算在 PAGE-F28-01 与 PAGE-F27-01，本页只统计条数。
- **不做定时采集**：所有采集由 wen 手动发起（蓝图 §7）。
- **不新增原工具没有的设置项**。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（wen）；审批者、只读看不到本页入口 |
| 人数 | 1 人 |
| 技术熟练度 | 高，用过原工具 |
| 使用设备 | 办公电脑浏览器 |
| 使用姿势 | 每月初一次，采集期间偶尔回来看进度 |

### 3.2 核心使用场景

**场景 A：月初采上月评论（主场景）**
- 时机：每月 1–3 日，上月成为完整月。
- 前置：Bright Data、Apify 密钥已在设置页连接。
- 动作：选项目"浴室柜_2026" → 把"最后一个完整月的月底"改为上月月底 → 保存 → ① 采集列表 → ② 评估费用 → 看弹窗确认 → ③ 采集评论 → 完成后 ④ 导出 Excel。

**场景 B：采集中断后续跑**
- 时机：电脑休眠、网络中断或达到上限。
- 动作：回到本页 → 看到各平台进度 → 再点"③ 采集评论"，只采剩余商品。

**场景 C：新开一个品类**
- 动作：复制为新项目（如"马桶架_2026"）→ 改品类、入口、筛选词 → 保存。

### 3.3 用户核心诉求

1. **准**：和原工具一个口径，Wayfair 不能多算 VP。
2. **省**：不重复花钱，花之前知道多少钱。
3. **稳**：长任务能断点续跑，进度一眼可见。

## 4. 信息架构

### 4.1 区域划分

1. 顶栏（品类、正在运行的任务、用户）
2. 页头（标题、项目选择、复制为新项目、保存设置）
3. 服务连接横幅
4. 四步进度条
5. 左：项目设置（5 个分区）
6. 右：运行、费用评估、本月已花费、导出文件、日志
7. 底部：入口月度汇总（上一次完整导出）

### 4.2 区域内容

**页头**：项目下拉（浴室柜_2026、马桶架_2026）、"复制为新项目"、"保存设置"。

**服务连接横幅**：Bright Data / Apify 连接状态与密钥后 4 位；Home Depot 直连免费；链接到密钥与大模型、预算与费用。

**四步进度条**：每步显示状态（已完成 / 进行中 / 待开始）和一行结果摘要。

**项目设置**：
1. 项目与时间窗：项目名、品类、起始日期、最后一个完整月月底、是否单列当月未完整数据。
2. 渠道与落地页：入口表（启用、名称、平台、落地页类型、网址 / 关键词、前 N、排除广告、父体去重、选中 / 目标）；添加 / 删除入口；跨入口去重。
3. 品类筛选：内置规则、必含词、排除词、保留词。
4. 评论少的商品：阈值 + 三选一（照常区分 VP / 只计月度合计 / 不采集）。
5. 本项目预算：BD · Lowe's、BD · Wayfair、Apify · Lowe's、Apify · Wayfair（美元）；Excel 是否附评论明细。

**运行区**：四步按钮、各平台采集进度、暂停、一键全部；费用评估结果表；本月 Bright Data / Apify 已花 / 上限；导出文件列表；运行日志。

**入口月度汇总**：各渠道 1–10 月逐月评论数、合计、VP / 非 VP、VP 占比、当月未完整数（参考）。

## 5. 界面内容

### 5.1 元素清单

**项目下拉**
- 内容：已有项目名；数据来源：服务端项目设置。
- 切换后载入该项目设置与运行状态。

**服务连接状态**
- 内容：`已连接 ···· 7f3a` / `未连接`；数据来源：PAGE-F16-01 的密钥状态。
- 显示条件：始终显示；未连接时链接直达 PAGE-F16-01。

**入口表**
- 字段见 8.1；"选中 / 目标"来自 ① 的结果，未跑 ① 时显示"无数据"标签。

**四步按钮**
- ① 采集列表：始终可点。
- ② 评估费用：①完成后可点，打开费用评估确认弹窗（CMP-F16-01）。
- ③ 采集评论：②完成后可点；运行中不可点；点后先弹费用评估确认。
- ④ 导出 Excel：有已采集数据时可点。
- 一键全部：依次执行四步，花钱步骤仍先弹确认。

**费用评估确认弹窗（CMP-F16-01）**
- 内容：各平台待采商品数、预计窗口内评论数区间、BD 请求 / 费用、Apify 费用、预计耗时、合计；本次新增费用；各服务本月已花 / 上限；"达到上限即停，已采数据保留"。
- 按钮："取消"、"确认并开始"。

**本月已花费**
- 内容：Bright Data、Apify 本月累计 / 月度上限与进度条；本次运行明细；链接到费用记录。

**导出文件**
- 内容：每平台一个 .xlsx，含"月度趋势、入口月度汇总、商品、评论明细（可关）"四张表。

**入口月度汇总**
- 内容：逐月去重评论数（示例：2026 年 1–10 月合计 Home Depot 3,325、Lowe's 3,850、Wayfair 7,394）、VP / 非 VP、VP 占比（带样本量）、未完整月数（标"参考"）。

### 5.2 辅助信息

- VP 口径说明：HD、Lowe's 用 verifiedPurchaser 标记；Wayfair 只有 "Verified Purchase" 计 VP，其余徽章计非 VP。
- 落地页类型说明：有 BSR 用 BSR / 热销榜；没有 BSR 用类目或关键词落地页。

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者访问 → 显示"无权限"。
- 载入最近使用的项目设置、运行状态、费用评估结果、本月花费与导出列表；有运行中任务时顶栏显示任务进度。

### 6.2 核心操作流程

```
保存设置 → ① 采集列表（Lowe's / Wayfair 列表经 Bright Data，计费）
    │  先弹费用评估确认
    ▼
② 评估费用 → 显示各平台费用与耗时区间
    ▼
③ 采集评论 → 弹费用评估确认（只计未完成部分）
    ├─ 取消 → 不开始
    └─ 确认 → 开始采集，进度实时更新
          ├─ 达到项目预算或月度上限 → 自动停，已采保留，提示"已达上限"
          ├─ 中断 → 进度保存；再点 ③ 从断点继续
          └─ 完成 → ④ 可用
④ 导出 Excel → 生成每平台一个文件 → 完整月份可并入 PAGE-F28-01
```

### 6.3 辅助操作

- 复制为新项目：输入新项目名 → 复制全部设置。
- 保存设置：有未保存修改时离开页面会拦截。
- 暂停：保存进度后停止。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空项目 | 新项目还没跑 ① | 四步均为待开始；汇总区显示"还没有采集结果。先点 ① 采集列表" |
| 加载 | 打开页面 / 切换项目 | 设置区与汇总表骨架条 |
| 运行中 | 任一步执行中 | 顶栏任务指示 + 运行区进度；对应按钮不可点 |
| 已中断 | 任务中途停止 | 第 ③ 步标"待继续"，显示已完成数 / 总数 |
| 达到上限 | 项目预算或月度上限用尽 | 警告横幅"Apify 本月已达上限 $60.00，已采数据已保存"，链接到预算与费用 |
| 密钥未连接 | Bright Data 或 Apify 未连接 / 失效 | 对应服务显示"未连接"；只能采 Home Depot，Lowe's / Wayfair 入口标"跳过" |
| 错误 | 某商品采集失败 | 日志写明商品 ID 与原因；该商品标"失败"，可重试 |
| 无权限 | 非操作者 | 页面显示"无权限"，侧栏不显示入口 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同一项目重复点 ③ | 运行中不可点，同时只运行一个任务 |
| 评论超过平台上限 | Home Depot 约 17 页、Lowe's / Wayfair 每商品 1000 条，超过标"部分" |
| 当月未完整 | 单列"未完整"，只作参考，不并入分析库 |
| 项目名重复 | 复制时提示"项目名不能和已有项目重复" |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 项目名 / 品类 | 必填，项目名唯一 |
| 起始日期 / 最后完整月月底 | 必填，决定统计的月份 |
| 单列未完整数据 | 勾选后当月未完整评论单列 |
| 入口 | 启用、名称、平台（Lowe's / Home Depot / Wayfair）、落地页类型（BSR / 热销榜、类目落地页、关键词落地页）、网址或关键词、前 N、排除广告、父体去重 |
| 跨入口去重 | 同一商品 / 父体已被前面入口选中时跳过并顺延 |
| 品类筛选 | 内置规则（浴室柜）、必含词、排除词、保留词 |
| 评论少的商品 | 阈值（0 = 不启用）+ 处理方式三选一 |
| 本项目预算 | 4 项美元上限 |
| VP / 非 VP | 见 5.2 口径 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 必填项 | 失焦 / 保存 | 项目名、品类、日期不为空 | "请填写项目名"等 |
| 时间窗 | 保存 | 起始日期早于完整月月底 | "起始日期要早于最后一个完整月的月底" |
| 入口网址 / 关键词 | 保存 | 启用的入口不为空 | "第 3 个入口缺少网址" |
| 前 N | 失焦 | 正整数 | "前 N 要填正整数" |

### 8.3 特殊业务规则

- **共用设置（AC-F23-02）**：调用 Bright Data / Apify 用 PAGE-F16-01 的密钥；本项目预算与设置页月度上限任一先到即停；每次调用计入 PAGE-F16-02 同一记账。
- **断点续跑（NFR-011）**：已成功的商品不重复调用、不重复计费。
- **去重**：入口与渠道合计按评论 ID 去重，同系列共享评论不重复算。
