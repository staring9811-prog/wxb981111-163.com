## 2. 页面概述

### 2.1 一句话定位

在系统内保留原"评论月度 VP 追踪器"的全部能力，按月统计 Home Depot / Lowe's / Wayfair 的 VP / 非 VP 评论数，密钥、上限和记账与设置页共用。

### 2.2 存在理由

1. 原工具单独运行，密钥、预算、记账各管各的，月底对不上总花费。
2. 其他渠道的销量估算（F28）依赖这里的月度评论数，两边口径必须一致。
3. 采集 Lowe's / Wayfair 要花钱且耗时数小时，必须先评估、可中断续跑。
4. （v8）其他渠道只有 2026 年 10 个月的评论，回测要约 20 个月历史；评论带日期，回补前 N 个商品页的全部历史评论就能重建 2024 年以来的月度历史（方案书 §10.3）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 口径一致 | 同一项目设置下，导出结果与原工具一致（Wayfair 只有 Verified Purchase 计 VP） |
| 不重复花钱 | 中断后重跑，已成功商品的调用次数与计费为 0（NFR-011） |
| 先知后花 | 100% 的花钱步骤在开始前弹出费用评估确认（AC-F16-07） |
| 回补不截断 | 回补结束时报告仍被截断的商品页数；Home Depot 小试 598 个商品页、219 个家族，分片后 0 截断（AC-F23-04） |
| 礼貌限速 | 直连相邻请求间隔 ≥ 1 秒，失败重试 ≤ 3 次，403 / 429 次数可见（NFR-013） |

### 2.4 不做什么（范围边界）

- **不保存密钥**：密钥只在 PAGE-F16-01 填写，本页只显示连接状态和后 4 位。
- **不做销量换算**：VP × 系数的估算在 PAGE-F28-01 与 PAGE-F27-01，本页只统计条数。
- **不做定时采集**：所有采集由 wen 手动发起（蓝图 §7）。
- **不新增原工具没有的设置项**。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（wen）；审批者、只读看不到本页入口 |
| 人数 | 1 人 |
| 技术熟练度 | 高，用过原工具 |
| 使用设备 | 办公电脑浏览器 |
| 使用姿势 | 每月初一次，采集期间偶尔回来看进度 |

### 3.2 核心使用场景

**场景 A：月初采上月评论（主场景）**
- 时机：每月 1–3 日，上月成为完整月。
- 前置：Bright Data、Apify 密钥已在设置页连接。
- 动作：选项目"浴室柜_2026" → 把"最后一个完整月的月底"改为上月月底 → 保存 → ① 采集列表 → ② 评估费用 → 看弹窗确认 → ③ 采集评论 → 完成后 ④ 导出 Excel。

**场景 B：采集中断后续跑**
- 时机：电脑休眠、网络中断或达到上限。
- 动作：回到本页 → 看到各平台进度 → 再点"③ 采集评论"，只采剩余商品。

**场景 D：为回测补历史（v8）**
- 时机：某个其他渠道要做分渠道回测，但只有 2026 年 10 个月评论。
- 动作：历史回补区选渠道 → 起始月份（默认 2024-01）、商品页数 N（默认每个类目 300）→ "评估并回补" → 费用评估确认弹窗（Home Depot 显示 $0、预计请求数与耗时）→ 确认 → 看进度（商品页、评论数、分片补采、截断数、失败数、403 / 429 次数），需要时暂停、续采。
- 结果：回补完成后去 PAGE-F28-01 看历史重建，再去 PAGE-F19-01 发起渠道重算。
- 示例（真实小试，2026-11-03）：Home Depot 两类目各前 300 → 598 个商品页、219 个评论家族、共 19,359 条评论（2024-01 至 2026-10 14,397 条，VP 79%）；7 个家族按星级分片补全，0 截断；请求 2,884 次，失败 3 次，403 / 429 0 次。

**场景 C：新开一个品类**
- 动作：复制为新项目（如"马桶架_2026"）→ 改品类、入口、筛选词 → 保存。

### 3.3 用户核心诉求

1. **准**：和原工具一个口径，Wayfair 不能多算 VP。
2. **省**：不重复花钱，花之前知道多少钱。
3. **稳**：长任务能断点续跑，进度一眼可见。

## 4. 信息架构

### 4.1 区域划分

1. 顶栏（品类、正在运行的任务、用户）
2. 页头（标题、项目选择、复制为新项目、保存设置）
3. 服务连接横幅
4. 四步进度条
5. 左：项目设置（5 个分区）
6. 右：运行、费用评估、本月已花费、导出文件、日志
7. 历史回补（v8）：渠道参数表 + 回补进度
8. 底部：入口月度汇总（上一次完整导出）

### 4.2 区域内容

**页头**：项目下拉（浴室柜_2026、马桶架_2026）、"复制为新项目"、"保存设置"。

**服务连接横幅**：Bright Data / Apify 连接状态与密钥后 4 位；Home Depot 直连免费；链接到密钥与大模型、预算与费用。

**四步进度条**：每步显示状态（已完成 / 进行中 / 待开始）和一行结果摘要。

**项目设置**：
1. 项目与时间窗：项目名、品类、起始日期、最后一个完整月月底、是否单列当月未完整数据。
2. 渠道与落地页：入口表（启用、名称、平台、落地页类型、网址 / 关键词、前 N、排除广告、父体去重、选中 / 目标）；添加 / 删除入口；跨入口去重。
3. 品类筛选：内置规则、必含词、排除词、保留词。
4. 评论少的商品：阈值 + 三选一（照常区分 VP / 只计月度合计 / 不采集）。
5. 本项目预算：BD · Lowe's、BD · Wayfair、Apify · Lowe's、Apify · Wayfair（美元）；Excel 是否附评论明细。

**运行区**：四步按钮、各平台采集进度、暂停、一键全部；费用评估结果表；本月 Bright Data / Apify 已花 / 上限；导出文件列表；运行日志。

**入口月度汇总**：各渠道 1–10 月逐月评论数、合计、VP / 非 VP、VP 占比、当月未完整数（参考）。

**历史回补（v8）**：
- 说明横幅：取数范围（类目榜单前 N 个商品页，排除广告位；全部历史评论 + 商品页规格）、限速（NFR-013）、计费方式、翻页上限与分片规则。
- 渠道参数表：渠道、起始月份（默认 2024-01）、商品页数 N（每个类目，默认 300）、采集方式（Home Depot 直连免费；Lowe's / Wayfair 经 Bright Data + Apify）、状态（已完成 / 进行中 / 已暂停 / 未回补 · 未验证）、上次回补摘要、"评估并回补"。
- 回补进度面板：商品页、评论家族两条进度；评论数（含 2024-01 起条数与 VP 占比）、分片补采家族数、截断商品页数、失败数 / 403 · 429 次数四张统计卡；暂停、续采；"去看历史重建"。

## 5. 界面内容

### 5.1 元素清单

**项目下拉**
- 内容：已有项目名；数据来源：服务端项目设置。
- 切换后载入该项目设置与运行状态。

**服务连接状态**
- 内容：`已连接 ···· 7f3a` / `未连接`；数据来源：PAGE-F16-01 的密钥状态。
- 显示条件：始终显示；未连接时链接直达 PAGE-F16-01。

**入口表**
- 字段见 8.1；"选中 / 目标"来自 ① 的结果，未跑 ① 时显示"无数据"标签。

**四步按钮**
- ① 采集列表：始终可点。
- ② 评估费用：①完成后可点，打开费用评估确认弹窗（CMP-F16-01）。
- ③ 采集评论：②完成后可点；运行中不可点；点后先弹费用评估确认。
- ④ 导出 Excel：有已采集数据时可点。
- 一键全部：依次执行四步，花钱步骤仍先弹确认。

**费用评估确认弹窗（CMP-F16-01）**
- 内容：各平台待采商品数、预计窗口内评论数区间、BD 请求 / 费用、Apify 费用、预计耗时、合计；本次新增费用；各服务本月已花 / 上限；"达到上限即停，已采数据保留"。
- 按钮："取消"、"确认并开始"。

**历史回补费用评估确认（CMP-F16-01 复用）**
- 触发：渠道参数表"评估并回补"。
- Home Depot：列表 + 规格、全部历史评论两行与合计：待采商品页、预计请求数、BD / Apify 费用 $0.00、预计耗时；估算依据"598 个商品页共 2,884 次请求"按新增商品页折算；N 不变且已完成时提示"本次没有要采的商品页"。
- Lowe's / Wayfair：分两次确认，先确认列表 + 规格（Bright Data 请求数与费用），评论（Apify）费用显示"列表采完后估算"，列表采完再弹一次；显示各服务本月已花 / 上限。
- 按钮："取消"、"确认并开始"。

**本月已花费**
- 内容：Bright Data、Apify 本月累计 / 月度上限与进度条；本次运行明细；链接到费用记录。

**导出文件**
- 内容：每平台一个 .xlsx，含"月度趋势、入口月度汇总、商品、评论明细（可关）"四张表。

**入口月度汇总**
- 内容：逐月去重评论数（示例：2026 年 1–10 月合计 Home Depot 3,325、Lowe's 3,850、Wayfair 7,394）、VP / 非 VP、VP 占比（带样本量）、未完整月数（标"参考"）。

### 5.2 辅助信息

- VP 口径说明：HD、Lowe's 用 verifiedPurchaser 标记；Wayfair 只有 "Verified Purchase" 计 VP，其余徽章计非 VP。
- 落地页类型说明：有 BSR 用 BSR / 热销榜；没有 BSR 用类目或关键词落地页。
- 回补参数说明：起始月份与 N 的默认值来自 PAGE-F27-01（参数版本注明）；本页修改只作用于本次回补。N 加大时只采新增排名的商品页。

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者访问 → 显示"无权限"。
- 载入最近使用的项目设置、运行状态、费用评估结果、本月花费与导出列表；有运行中任务时顶栏显示任务进度。

### 6.2 核心操作流程

```
保存设置 → ① 采集列表（Lowe's / Wayfair 列表经 Bright Data，计费）
    │  先弹费用评估确认
    ▼
② 评估费用 → 显示各平台费用与耗时区间
    ▼
③ 采集评论 → 弹费用评估确认（只计未完成部分）
    ├─ 取消 → 不开始
    └─ 确认 → 开始采集，进度实时更新
          ├─ 达到项目预算或月度上限 → 自动停，已采保留，提示"已达上限"
          ├─ 中断 → 进度保存；再点 ③ 从断点继续
          └─ 完成 → ④ 可用
④ 导出 Excel → 生成每平台一个文件 → 完整月份可并入 PAGE-F28-01
```

**历史回补（v8）**

```
选渠道 → 改起始月份 / N（可不改）→ 评估并回补
    ▼
费用评估确认弹窗（CMP-F16-01）
    ├─ 取消 → 不开始
    └─ 确认 → 采列表（前 N，排除广告位）与商品页规格 → 按评论家族采全部历史评论
          ├─ 某家族到单一排序翻页上限 → 按 1–5 星分片；某星级仍到上限 → 加"仅 VP"分片；仍到上限 → 记截断
          ├─ 遇 403 / 429 → 间隔翻倍、暂停 30 秒起，记次数；重试 3 次仍失败 → 记失败，渠道回补暂停并提示，已采保留
          ├─ 暂停 / 中断 → 进度保存；续采不重复请求已完成的商品页
          └─ 完成 → 报告商品页、家族、评论、截断、失败 → PAGE-F28-01 历史重建
```

### 6.3 辅助操作

- 复制为新项目：输入新项目名 → 复制全部设置。
- 保存设置：有未保存修改时离开页面会拦截。
- 暂停：保存进度后停止。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空项目 | 新项目还没跑 ① | 四步均为待开始；汇总区显示"还没有采集结果。先点 ① 采集列表" |
| 加载 | 打开页面 / 切换项目 | 设置区与汇总表骨架条 |
| 运行中 | 任一步执行中 | 顶栏任务指示 + 运行区进度；对应按钮不可点 |
| 已中断 | 任务中途停止 | 第 ③ 步标"待继续"，显示已完成数 / 总数 |
| 达到上限 | 项目预算或月度上限用尽 | 警告横幅"Apify 本月已达上限 $60.00，已采数据已保存"，链接到预算与费用 |
| 密钥未连接 | Bright Data 或 Apify 未连接 / 失效 | 对应服务显示"未连接"；只能采 Home Depot，Lowe's / Wayfair 入口标"跳过" |
| 错误 | 某商品采集失败 | 日志写明商品 ID 与原因；该商品标"失败"，可重试 |
| 无权限 | 非操作者 | 页面显示"无权限"，侧栏不显示入口 |
| 回补：未回补 | 渠道从未回补 | 状态"未回补 · 未验证"，上次回补显示"无数据"（第一版 Lowe's / Wayfair 当前即此状态） |
| 回补：进行中 | 回补任务运行 | 顶栏任务指示"历史回补 · 渠道 x/N"；进度面板实时更新六项计数；"暂停"可点 |
| 回补：已暂停 / 中断 | 手动暂停、网络中断或达到上限 | 状态"已暂停"，显示已完成商品页数；"续采"从断点继续 |
| 回补：被拦截 | 403 / 429 降速重试后仍失败 | 警告横幅"Home Depot 回补已暂停：连续被拦截（429 × 5），已采部分保留"；可稍后续采 |
| 回补：有截断 | 分片后仍有商品页到上限 | 进度面板截断数 > 0，标出"完整到"日期；历史重建对这些家族早于该日期的月份标"评论不全" |
| 回补：已完成 | 全部商品页处理完 | 状态"已完成"，上次回补摘要；"去看历史重建" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同一项目重复点 ③ | 运行中不可点，同时只运行一个任务 |
| 评论超过平台上限 | Home Depot 约 17 页、Lowe's / Wayfair 每商品 1000 条，超过标"部分" |
| 当月未完整 | 单列"未完整"，只作参考，不并入分析库 |
| 回补时 N 改大 | 只采新增排名的商品页，已完成的不重复请求、不重复计费 |
| 回补时 N 改小 / 起始月改晚 | 不删已采数据，重建时按新参数取用 |
| 回补中密钥失效 | Lowe's / Wayfair 回补暂停，提示去 PAGE-F16-01；Home Depot 不受影响 |
| 项目名重复 | 复制时提示"项目名不能和已有项目重复" |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 项目名 / 品类 | 必填，项目名唯一 |
| 起始日期 / 最后完整月月底 | 必填，决定统计的月份 |
| 单列未完整数据 | 勾选后当月未完整评论单列 |
| 入口 | 启用、名称、平台（Lowe's / Home Depot / Wayfair）、落地页类型（BSR / 热销榜、类目落地页、关键词落地页）、网址或关键词、前 N、排除广告、父体去重 |
| 跨入口去重 | 同一商品 / 父体已被前面入口选中时跳过并顺延 |
| 品类筛选 | 内置规则（浴室柜）、必含词、排除词、保留词 |
| 评论少的商品 | 阈值（0 = 不启用）+ 处理方式三选一 |
| 本项目预算 | 4 项美元上限 |
| VP / 非 VP | 见 5.2 口径 |
| 回补起始月份 | 年-月，默认 2024-01，必填，不晚于最后一个完整月 |
| 商品页数 N | 每个类目取前 N 个商品页（排除广告位），正整数，默认 300 |
| 截断 | 按星级、仅 VP 分片后某排序仍到翻页上限的商品页；记"完整到"日期 |
| 分片补采 | 到上限的家族按 1–5 星各自翻页，某星级仍到上限加"仅 VP"分片 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 必填项 | 失焦 / 保存 | 项目名、品类、日期不为空 | "请填写项目名"等 |
| 时间窗 | 保存 | 起始日期早于完整月月底 | "起始日期要早于最后一个完整月的月底" |
| 入口网址 / 关键词 | 保存 | 启用的入口不为空 | "第 3 个入口缺少网址" |
| 前 N | 失焦 | 正整数 | "前 N 要填正整数" |
| 回补 N | 失焦 | 正整数 | "商品页数 N 要填正整数" |
| 回补起始月份 | 失焦 | 不晚于最后一个完整月 | "起始月份要早于最后一个完整月" |

### 8.3 特殊业务规则

- **共用设置（AC-F23-02）**：调用 Bright Data / Apify 用 PAGE-F16-01 的密钥；本项目预算与设置页月度上限任一先到即停；每次调用计入 PAGE-F16-02 同一记账。
- **断点续跑（NFR-011）**：已成功的商品不重复调用、不重复计费。
- **去重**：入口与渠道合计按评论 ID 去重，同系列共享评论不重复算。
- **历史回补（AC-F23-03）**：按类目榜单排序取前 N 个商品页（排除广告位），采每个商品页的全部历史评论（日期、星级、是否 Verified Purchase）与商品页规格；Home Depot 直连，Lowe's / Wayfair 经 Bright Data / Apify；先评估费用再确认，可断点续采。
- **翻页上限（AC-F23-04）**：评论超过站点单一排序可翻到的上限时按星级、再按是否 Verified Purchase 分片补采，并报告仍被截断的商品页数。
- **礼貌限速（NFR-013）**：直连同一站点相邻请求间隔 ≥ 1 秒；单个请求失败重试 ≤ 3 次；遇 403 / 429 自动降速并记录次数；续采不重复请求已完成的商品页。

## 9. 页面流转

### 9.1 流转图

```
侧栏 / PAGE-F28-01 其他渠道数据
        │
        ▼

        ▼
```

### 9.2 与其他模块的关系

- 关联：F16 密钥、上限、记账；F28 并入月度数据、历史重建；F22 差评取本页已采的评论明细；F27 回补默认参数。
- 隔离：不改分析库里已并入的数据，并入动作在 PAGE-F28-01 完成。
