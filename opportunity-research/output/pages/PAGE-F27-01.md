## 2. 页面概述

### 2.1 一句话定位

把浴室柜的分框、属性、打标规则和各渠道换算与成功线都做成可查看、可修改、带版本的配置，以后加品类只改配置。

### 2.2 存在理由

1. 分框维度和打标规则写死在脚本里，改一次要改代码，也说不清哪次结果用的哪套规则。
2. 其他渠道的换算系数（VP 50 / 非 VP 20）和成功线是 AI 按 1–10 月数据提议、wen 授权先定的一版，后续一定会调。
3. 改了参数之后，估算、扫描、台账判定必须注明用的哪一版，否则无法复核。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可配置 | AC-F27-01 的 4 类配置与 AC-F27-03 的 2 类渠道参数都能在页面查看和修改 |
| 可追溯 | 每次保存生成参数版本，结果页 100% 注明所用版本 |
| 范围 | 第一版页面上不出现新建品类入口 |

### 2.4 不做什么（范围边界）

- **不新建品类**：第一版只有浴室柜，新建入口不出现（AC-F27-02）。
- **不在本页重算**：保存后由下一次估算、扫描、判定使用新值。
- **不回滚已用于判定的结果**：旧版本只供查看。
- **不配置 Amazon 换算系数**：Amazon 销量来自卖家精灵月销。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（wen）；其他角色看不到设置分区 |
| 人数 | 1 人 |
| 技术熟练度 | 高 |
| 使用设备 | 办公电脑浏览器 |

### 3.2 核心使用场景

**场景 A：调整成功线或换算系数（主场景）**
- 时机：积累了新月份数据，发现默认值偏高或偏低。
- 动作：进入"渠道参数" → 改 Wayfair 月度门槛 → 保存为新版本 → 写修改说明 → 确认 → 之后台账判定、销量估算使用新值并注明版本。

**场景 B：切换估算方法**
- 动作：把某渠道从"评论换算"切到"榜单排名平滑"（拟合商品 ≥ 10 个才可选）→ 保存 → 到 PAGE-F28-01 对照两种方法。

**场景 C：调低置信度阈值**
- 动作：拖动阈值，看进入确认队列的条数变化 → 保存。

**场景 D：修改分框或打标规则**
- 动作：在"分框与属性"或"打标规则"点编辑 → 改取值或规则 → 保存为新版本。

### 3.3 用户核心诉求

1. **改得了**：不改代码就能调。
2. **说得清**：每个结果都知道用的哪版参数。
3. **改之前看得到影响**：阈值改动能看到队列数量变化。

## 4. 信息架构

### 4.1 区域划分

1. 顶栏（品类、当前参数版本）
2. 页头（保存为新版本）
3. 品类说明横幅（只有浴室柜、当前在用版本）
4. 标签：分框与属性 / 打标规则 / 渠道参数 / 参数版本
5. 保存确认弹窗；维度 / 规则编辑抽屉

### 4.2 区域内容

**分框与属性**
- 分框维度：顺序、维度、取值、来源标签、编辑（默认尺寸段 24″ / 30″ / 36″ / 48″ / 60″ / 72″ × 拆装 / 整装 × 落地式 / 悬浮式）；框数说明。
- 扫描属性：是否参与扫描、属性、取值、打标方式（台面材质、元素、主色、柜体材质、价格档）；新增属性。

**打标规则**
- 低置信度阈值（滑杆 + 数值）与按当前数据进入确认队列的条数；说明元素始终进入确认。
- 规则表：标签、方式（规则 / 看图 / 规则 + 看图）、规则摘要、规则数、编辑；四个渠道同一套规则。

**渠道参数**
- 销量估算：Amazon（不换算）；Home Depot / Lowe's / Wayfair 的估算方法（评论换算 / 榜单排名平滑）、VP 系数、非 VP 系数、排名平滑可用性（拟合商品数）。
- 成功线：每渠道榜单类型、名次上限、月度门槛（Amazon 为 SPU 月销售额美元，其他为估算月销件数）、依据。

**参数版本**：版本、保存人、时间、修改内容、状态（当前在用 / 已被替代）。

## 5. 界面内容

### 5.1 元素清单

**品类标识**
- 内容："浴室柜 Bathroom Vanity"；无品类切换、无新建入口（AC-F27-02）。

**保存为新版本（主按钮）**
- 点击打开弹窗：本次修改的前后对比、修改说明*、"已对账结果不改写"提示；"保存 vN"。

**估算方法切换**
- 选项：评论换算 / 榜单排名平滑。
- 拟合商品少于 10 个时，"榜单排名平滑"不可选并提示"拟合商品不足 10 个，暂不能用排名平滑"（AC-F28-04）。

**换算系数**
- 默认 VP 50 件 / 条、非 VP 20 件 / 条（AC-F27-03）。

**成功线**
- 默认：Amazon 小类 BSR ≤ 50 或 SPU 月销售额 ≥ $100,000；Home Depot Top Sellers 前 50 或 ≥ 250 件；Lowe's Best Sellers 前 50 或 ≥ 150 件；Wayfair 主类目前 50 或 ≥ 120 件。

**低置信度阈值**
- 范围 0.50–0.95，步长 0.05，默认 0.75。

### 5.2 辅助信息

- 页头说明：保存后生成新参数版本，之后的估算、扫描和判定使用新值。
- 成功线依据：2026 年 1–10 月 Home Depot 3,325、Lowe's 3,850、Wayfair 7,394 条去重评论。

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者访问显示"无权限"。
- 载入浴室柜当前在用的参数版本，默认"分框与属性"。

### 6.2 核心操作流程

```
修改任一配置 → 页头出现"有未保存的修改"
    ▼
保存为新版本 → 弹窗显示前后对比 → 填修改说明
    ├─ 说明为空 → 提示，不保存
    └─ 保存 → 生成 vN+1，标为"当前在用"
          → 之后的销量估算（PAGE-F28-01）、机会扫描（PAGE-F20-01）、台账判定（PAGE-F26-01）用新值，并注明版本
```

### 6.3 辅助操作

- 离开页面时有未保存修改会拦截。
- 编辑分框维度或规则在抽屉中完成，"完成"后仍需保存为新版本。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 打开页面 | 表格骨架条 |
| 正常 | 有当前版本 | 各分区显示当前值 |
| 未保存 | 有修改 | 页头"有未保存的修改"，离开拦截 |
| 方法不可用 | 某渠道拟合商品 < 10 | 排名平滑选项不可选并说明原因 |
| 保存失败 | 服务端异常 | "保存失败，参数仍为 vN，请重试"，修改保留 |
| 无权限 | 非操作者 | "无权限"，侧栏不显示设置分区 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 系数或门槛填 0 / 负数 | 拦截 |
| 尺寸段区间重叠 | 拦截："24″ 与 30″ 的宽度区间重叠" |
| 修改后已对账的台账 | 保留判定时版本，不改写 |
| 修改分框维度 | 下一次扫描起生效；已批准决策卡快照不变 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 分框维度 | 维度名、取值、来源标签与取值规则 |
| 扫描属性 | 属性名、取值、打标方式、是否参与扫描 |
| 打标规则 | 每个标签的规则（关键词、区间、看图） |
| 低置信度阈值 | 0.50–0.95 |
| 估算方法 | 评论换算 / 榜单排名平滑（每个其他渠道） |
| VP / 非 VP 系数 | 件 / 条，正数 |
| 成功线 | 名次上限 + 月度门槛 |
| 参数版本 | 版本号、保存人、时间、修改说明、全量参数 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 系数、门槛、名次 | 失焦 | 正数 | "请填正数" |
| 尺寸段区间 | 完成编辑 | 不重叠、下限 < 上限 | "24″ 与 30″ 的宽度区间重叠" |
| 修改说明 | 保存 | 必填 | 输入框标错 |

### 8.3 特殊业务规则

- **可配置（AC-F27-01）**：分框维度、扫描属性、打标规则、低置信度阈值可查看和修改。
- **只开浴室柜（AC-F27-02）**：只有浴室柜可运行，新建品类入口不出现。
- **新值生效（AC-F27-03）**：修改换算系数或成功线后，之后的销量估算、机会扫描和台账判定使用新值，并在页面上注明参数版本。

### 9.1 流转图

```
侧栏"设置 · 品类配置" / PAGE-F26-01 成功线链接
        │
        ▼
品类配置（本页）── 保存新版本 ──→ 影响：
```
