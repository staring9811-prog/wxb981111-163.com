## 2. 页面概述

### 2.1 一句话定位

月更的入口：把按约定准备的数据包导进来，并看清已有哪些版本、哪个是当前版本。

### 2.2 存在理由

1. **只让合格的数据进入计算**：导入时按清单声明的类型选择约定并逐项校验（REQ-F01-01、REQ-F01-03），结论直接进入校验报告。
2. **结果要能追到具体数据**：每个版本有版本号和每个文件的 SHA-256 指纹，后续计算只读取导入时保存的只读副本（REQ-F01-02）。成败、信号、回测记录的"数据包版本"都指向这里。
3. **同一份数据不能出现两个版本**：重复导入若新建版本，台账和回测会引用两个"不同"的同一份数据（AC-F01-05）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 导入前心里有数 | 开始导入前就能看到清单声明的类型、品类、站点、覆盖月份，以及必需文件是否齐全 |
| 不重复 | 全部文件指纹与已有版本相同的数据包，100% 不新建版本 |
| 可核对 | 每个版本都能看到类型、覆盖月份、导入时间与操作人、指纹和校验结论 |

### 2.4 不做什么

- **不在本页展示逐项校验结果**：在 PAGE-F01-02 校验报告中查看。
- **不提供删除或修改数据包**：版本只追加（DEC-014）；第一期没有删除业务数据的需求。
- **不拉取数据**：数据包由 wen 从数据项目拿到后手动导入（D-19），系统不调用任何外部服务。
- **不确认字段**：字段约定在 PAGE-F02-01 中完成。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen（第一期唯一操作者） |
| 使用时机 | 每月拿到新数据包后（例：2027-05-08 拿到数据至 2027-04 的包）；首跑时导入第一个数据包 |
| 使用设备 | Windows，Chrome / Edge，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：月更导入（主场景）**
  - 动作：拖入 zip → 看清单预览（类型、月份、文件是否齐全）→ "开始导入并校验" → 自动进入校验报告。
  - 期望：导错包（品类或月份不对）在导入前就能发现。
- **场景 B：不确定这个包导过没有**
  - 动作：再次选择同一个包并开始导入 → 系统提示"该数据包已导入"，给出已有版本号，不新建版本。
- **场景 C：首次使用**
  - 前提：还没有任何数据包。
  - 页面表现：说明约定 v1 和 v1.1 各需要哪些文件。
- **场景 D：回看旧版本**
  - 动作：点版本行，查看当时的校验报告。

## 4. 信息架构

### 4.1 区域划分

1. 页头。
2. 导入区：选择区 → 清单预览 → 导入结果提示 → 操作 → "数据包需要哪些文件"说明。
3. 数据包版本列表：类型筛选 + 表格。
4. 页脚。

### 4.2 区域内容

**页头**
- 标题"数据包"。
- 副标题：只读保存与指纹说明，以及当前历史数据包、当前截面数据包的版本号。

**导入区**
- 选择区：拖入 zip 或数据包文件夹，或点"选择 zip""选择文件夹"；说明根目录需有清单文件（写明类型、品类、站点、覆盖月份和文件列表）。
- 清单预览（选择后出现）：
  - 文件名、大小、读取时间。
  - 清单文件是否找到、类型能否识别；类型（历史 / 截面）及对应约定；品类与类目节点；站点；覆盖月份与月数；文件数与必需文件是否齐全。
  - 文件清单表：清单中的文件、必需 / 可选、行数、指纹前 8 位（开始导入后计算）。
- 导入结果提示：重复导入、清单阻断、文件无法读取（见第 7 节）。
- 操作："重新选择"、"开始导入并校验"。
- 折叠说明"数据包需要哪些文件"：约定 v1（C1–C6 必需，C7 可选）；约定 v1.1（S1–S3、C4 必需，C5–C7 可选，没有 C6 时缺少痛点信号）。

**数据包版本列表**

| 列 | 内容 |
| :--- | :--- |
| 版本 | P-xxxx；每种类型的当前版本标"当前"（DEC-011） |
| 类型 | 历史（约定 v1）或截面（约定 v1.1，用截面标签） |
| 覆盖月份 | 起止月份与月数 |
| 文件 | C1–C7 或 S1–S3、C4，及文件数；截面包没有 C6 时注明"缺少痛点信号" |
| 导入 | 导入时间与操作人 |
| 指纹 | 数据包指纹前 8 位 |
| 校验结论 | 通过 / 有警告 / 阻断。有警告时写警告数与排除行数，并注明"可计算"；阻断时注明"不可计算" |
| 操作 | "校验报告" |

- 类型筛选：全部 / 历史 / 截面，带数量。
- 排序：导入时间从新到旧。

## 5. 界面内容

### 5.1 元素清单

**开始导入并校验（主按钮）**
- 显示条件：始终显示。
- 不可用：未选择数据包、清单缺失或类型无法识别、已判定为重复导入、正在导入或校验时；悬停提示原因。

**重复导入提示**
- 标题："该数据包已导入"。
- 正文："7 个文件的指纹与 P-0008（2027-05-08 09:14 导入）完全相同，没有新建版本。"
- 操作："查看 P-0008"，进入该版本的校验报告。

**清单阻断提示**
- 清单缺失："未找到清单文件，无法识别数据包类型。请在数据包根目录放入清单文件后重新选择。"
- 类型无法识别："清单中的类型"xxx"无法识别，应为"历史"或"截面"。"
- 两种情况都附清单需要写明的内容：类型、品类、站点、覆盖月份、文件列表。

**版本行**
- 整行可点，进入该版本的校验报告。

### 5.2 辅助信息

页脚：只读副本目录 `D:\机会判定台\数据包\`；指纹为 SHA-256，列表显示前 8 位；数据包原件不进入备份，恢复后需要时重新导入，指纹会自动识别。

## 6. 交互流程

### 6.1 页面加载与初始化

- 读取全部数据包版本，新的在上；历史、截面各标出一个当前版本。
- 没有任何版本：显示空态。
- 有导入正在进行：导入区显示进度，顶栏任务指示同步。

### 6.2 核心操作流程

```
选择 zip / 文件夹（或拖入）
  │
  ├─ 读取根目录清单文件
  │    ├─ 清单缺失或类型无法识别 → 导入区显示阻断原因，"开始导入并校验"不可用（AC-F01-06）
  │    └─ 读取成功 → 清单预览（类型、品类、站点、覆盖月份、文件清单）
  │
  └─ 点"开始导入并校验" → 计算每个文件的 SHA-256 → 与已有版本比对
       ├─ 全部文件指纹与某个已有版本相同 → 提示"该数据包已导入"并显示版本号，不新建版本（AC-F01-05）
       └─ 否则 → 按清单类型选择约定校验（REQ-F01-03）→ 显示进度
            ├─ 没有阻断项 → 保存只读副本、每个文件的指纹和新版本号（AC-F01-04）→ 自动进入 PAGE-F01-02
            └─ 有阻断项 → 进入 PAGE-F01-02，结论为"阻断"，不能计算（AC-F01-02）
```

### 6.3 辅助操作

- 类型筛选。
- "重新选择"：清空当前预览，回到选择区。
- 导入与校验期间可以离开本页，任务在后台继续，完成后轻提示"P-xxxx 校验完成"。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空态 | 还没有任何数据包 | 导入区照常显示；列表区显示"还没有数据包"，并列出约定 v1（C1–C6 必需、C7 可选）与 v1.1（S1–S3、C4 必需，C5–C7 可选）需要的文件 |
| 待导入 | 清单读取成功 | 清单预览；"开始导入并校验"可用 |
| 导入中 | 复制文件、计算指纹 | 显示当前文件和"已处理 n / 总数 个文件"；主按钮变为"导入中…"且不可用 |
| 校验中 | 按约定逐文件校验 | 显示当前文件与检查项；完成后自动进入校验报告 |
| 重复导入 | 全部文件指纹与已有版本相同 | 提示"该数据包已导入"、已有版本号与导入时间、"查看 P-xxxx"；版本数不变 |
| 清单阻断 | 清单缺失或类型无法识别 | 红色阻断提示，说明缺什么；不能开始导入 |
| 文件无法读取 | zip 损坏、文件被其他程序占用、文件不是 CSV（UTF-8）或 Excel | 指出哪个文件、什么原因，例"C6 评论痛点.csv 无法读取：文件被其他程序占用"；可重新选择 |
| 正常 | 已有版本 | 版本列表；导入区为选择区 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 只有部分文件指纹相同 | 按新数据包导入；只有全部文件指纹都相同才判为重复（AC-F01-05） |
| 清单列出的文件包里没有 | 预览中标出缺失文件；必需文件缺失在校验中记为阻断（REQ-F01-01） |
| 截面数据包没有 C6 | 允许导入；列表与校验报告注明"缺少痛点信号"，回测先用另两类信号（PRD §5.3） |
| 有阻断项的导入 | 进入校验报告并禁止计算；不会成为当前版本（DEC-011）。是否占用版本号见 8.3 |
| 清单中的品类或站点与当前品类配置不一致 | 记为阻断，提示切换品类或检查数据包；预览中标出差异（DEC-020） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 数据包版本号 | "P-" 加 4 位序号，按导入先后递增 |
| 文件指纹 | 每个文件的 SHA-256，导入时计算并保存 |
| 数据包指纹 | 由全部文件指纹合成，任一文件变化即不同；列表显示前 8 位 |
| 当前版本 | 历史、截面各一个：该类型最新一个通过校验的版本（DEC-011） |
| 覆盖月份 | 清单声明的起止月份，校验时与 C1 / S1 的实际月份核对 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 清单文件 | 选择后读取 | 根目录有清单文件，类型为"历史"或"截面" | 清单阻断提示（AC-F01-06） |
| 选择约定 | 开始导入时 | 历史 → 约定 v1（C1–C7）；截面 → 约定 v1.1（S1–S3、C4，C5–C7 可选） | — |
| 重复导入 | 计算指纹后 | 全部文件指纹与某个已有版本相同 | "该数据包已导入"（AC-F01-05） |
| 逐项校验 | 导入后 | 见 PAGE-F01-02 | 校验报告 |

### 8.3 特殊业务规则

- **只读**：导入后的副本不被任何步骤修改；体检完成后核对指纹（AC-F03-03，见 PAGE-F03-02）。
- **只追加**：版本不删除、不覆盖（DEC-014）。
- **阻断的导入也占用版本号**（DEC-018）：REQ-F01-02 规定每次导入生成版本号，AC-F01-04 规定无阻断时保存只读副本。因此阻断的导入同样分配版本号、保留校验报告与指纹（用于识别重复导入），但不保存只读副本、不成为当前数据包，列表中标"阻断 · 不可计算"。

## 9. 页面流转

### 9.1 流转图

```
侧栏 / 工作台第 1 步 / 顶栏版本号 ──→ 数据包（本页）
                                         ├─ 导入完成（自动）──→ PAGE-F01-02 校验报告
                                         ├─ 点版本行 ──→ PAGE-F01-02 校验报告（该版本）
                                         └─ 重复导入"查看 P-xxxx" ──→ PAGE-F01-02 校验报告
PAGE-F01-02 校验报告 ──"去确认字段约定"──→ PAGE-F02-01 字段约定
```

### 9.2 与其他模块的关系

- 新版本导入后，PAGE-F02-01 只把变化字段列为待确认（AC-F02-06），PAGE-F03-02 自动运行体检。
- 计算、回测、快照都记录所用的数据包版本号。

### 9.3 扩展预案

| 扩展方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 多平台数据包 | 第三期接入 HDP、Lowe's、Wayfair（PAGE-F16-01 planned） | 清单增加平台，按平台选择约定；列表增加平台列与筛选 |
| 多品类 | 第二期接入第二个品类 | 列表按顶栏当前品类过滤；清单品类与当前品类不一致时拦截 |

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 按类型校验 | 清单声明"历史"时按 C1–C7 校验，声明"截面"时按 S1–S3、C4 校验（AC-F01-06） |
| F-02 | 清单阻断 | 清单缺失或类型无法识别时显示阻断，不能开始导入（AC-F01-06） |
| F-03 | 只读副本与指纹 | 没有阻断项的导入保存只读副本、每个文件的 SHA-256 和新版本号，列表出现新版本（AC-F01-04） |
| F-04 | 重复导入 | 全部文件指纹与已有版本相同时提示"该数据包已导入"并显示已有版本号，版本数不变（AC-F01-05） |
| F-05 | 当前版本 | 历史、截面各只有一个"当前"，为该类型最新通过校验的版本（DEC-011） |
| F-06 | 导入前预览 | 选择后、导入前显示类型、品类、站点、覆盖月份和文件清单（REQ-F01-03） |
| U-01 | 进度 | 导入与校验时显示当前文件与进度，完成后自动进入校验报告 |
| U-02 | 空态 | 没有数据包时说明约定 v1 / v1.1 需要的文件 |
