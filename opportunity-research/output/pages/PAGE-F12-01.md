## 2. 页面概述

### 2.1 一句话定位

一键把本月快照导出成 Excel 和单文件网页报告，导出后自动备份，并把结果和备份情况交代清楚。

### 2.2 存在理由

1. **第一期没有服务器**：老板和开发、采购、运营只能通过文件看结论（US-F12-01）。
2. **导出前要确认口径**：导出的是哪个月、哪一版快照、判定卡是否达标，发出去之前必须看清；未验证时必须醒目提醒（AC-F12-02）。
3. **本机数据要有备份**：台账和规则只存在本机，每次导出后自动备份，失败时要知道原因且不能损坏旧备份（AC-F10-06、AC-F10-07）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 一步完成 | 确认后一次点击生成两个文件并自动备份 |
| 状态不丢 | 判定卡状态出现在确认步骤和两个文件的首页 |
| 结果可找 | 结果页显示两个文件的完整路径，可直接打开所在文件夹 |
| 备份可知 | 每次导出都显示备份成功时间，或失败原因与上次成功时间 |

### 2.4 不做什么

- **不选择导出范围或格式**：每次固定导出 Excel 与网页报告两个文件，内容见第 8.3、8.4 节。
- **不发送文件**：第一期不调用外部服务，分发由 wen 手动完成。
- **不导出原始数据**：不含原始数据表和评论原文。
- **不在此恢复备份**：恢复在 PAGE-F10-03。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen（导出操作者）；结果接收方只接收文件 |
| 使用时机 | 月更最后一步；立项评审前需要更新文件时 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：月更导出（主场景）**
  - 动作：在本月排序点"导出报告" → 核对月份、快照、判定卡状态 → 开始导出 → 打开文件夹，把文件发给老板和下游。
- **场景 B：判定卡未验证时导出**
  - 动作：确认步骤看到醒目的"未验证"提示，仍可导出；文件首页写明"未验证，不可作为立项结论"。
- **场景 C：备份失败**
  - 动作：结果步骤看到备份失败原因与上次成功时间，去备份与恢复页修改目录后重试备份。

## 4. 信息架构

### 4.1 区域划分

1. 弹窗头：标题"导出报告"、月份与快照、关闭。
2. 步骤标签：1 确认内容 → 2 生成中 → 3 结果（只显示当前步骤的内容）。
3. 步骤内容区。
4. 弹窗脚：当前步骤的操作。

### 4.2 区域内容

**第 1 步 · 确认内容**
- 键值：
  - 排序月份："2027-05（数据至 2027-04）"。
  - 快照：锁图标 +"第 1 版 · 2027-05-08 10:46 保存，不可修改"。
  - 判定卡："v4"+ 状态徽章 +"回测 BT-0031 · 倍数 2.24×"。
  - 口径："历史（判定卡状态以历史口径为准）"。
  - 参照人群："起量新品（任一月父体月销 ≥ 60 件）"。
  - 版本：数据包 P-0008 · 字段约定 v7 · 品类配置 v2。
- 将生成的内容：Excel（9 张工作表名称）、网页报告（单个 HTML 文件）、保存目录、导出后自动备份的内容与目录。
- 醒目提示（按判定卡状态，常驻在键值上方）：
  - 未验证：预警色横幅"判定卡未验证，不可作为立项结论"，正文写未达标原因，并说明"导出文件首页将显示'未验证，不可作为立项结论'"（AC-F12-02）。
  - 达标（截面）：截面横幅"截面口径，待历史回测确认"，说明文件首页将显示同一句。
  - 已达标：不加横幅。
- 弹窗脚："取消"、主按钮"开始导出"。

**第 2 步 · 生成中**
- 总进度条与百分比、已用时间。
- 子步骤列表：读取快照（核对内容指纹）→ 写入 Excel（第 x / 9 张工作表）→ 生成网页报告 → 自动备份；每项显示已完成 / 进行中 / 等待。
- 说明"可以关闭此窗口，导出在后台继续，进度显示在顶栏，完成后提示"。
- 弹窗脚："在后台继续"。

**第 3 步 · 结果**
- 结果横幅："导出完成 · 2027-05-08 11:32"，正文写月份、快照、判定卡状态、口径，以及"快照已标为'已导出'，对账用本月最后一次导出的快照"（DEC-006）。
- 文件：
  - Excel：工作表数、大小、完整路径 `D:\机会判定台\导出\2027-05\浴室柜_机会判定_2027-05_快照1.xlsx`。
  - 网页报告：大小、完整路径 `D:\机会判定台\导出\2027-05\浴室柜_机会判定_2027-05_快照1.html`，操作"打开网页报告"。
  - 操作"打开所在文件夹"。
- 自动备份（AC-F10-06）：成功图标 +"备份完成 · 2027-05-08 11:33 · 38.6 MB"、备份内容、备份位置 `D:\机会判定台备份\备份_20270508_1133\`；链接"备份与恢复"。
- 弹窗脚："完成"。

## 6. 交互流程

### 6.1 加载与初始化

- 打开时读取本月最新快照、判定卡状态、版本号、备份目录设置。
- 默认进入第 1 步。

### 6.2 核心操作流程

```
点"导出报告"
  │
  ▼
第 1 步 确认内容 ──取消──→ 关闭弹窗
  │（未验证 / 截面时有醒目提示，仍可导出）
  │ 开始导出
  ▼
第 2 步 生成中 ──在后台继续──→ 关闭弹窗，顶栏显示进度，完成后轻提示
  │
  ├─ 生成失败 → 显示原因与"重试"；不留下不完整的文件；快照不标"已导出"
  │
  └─ 两个文件生成完成 → 快照标"已导出" → 自动备份
                                          │
                                          ├─ 成功 → 第 3 步显示备份完成时间与目录
                                          └─ 失败 → 第 3 步显示失败原因与上次成功时间；旧备份不动
```

### 6.3 辅助操作

- 结果步骤"打开所在文件夹"、"打开网页报告"可反复点击。
- 按 Esc 或点遮罩关闭弹窗（生成中关闭等同"在后台继续"）。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 确认（已达标） | 判定卡已达标 | 键值与将生成的内容；无横幅 |
| 确认（未验证） | 判定卡未验证 | 预警色横幅"判定卡未验证，不可作为立项结论"，写明原因（AC-F12-02） |
| 确认（截面） | 判定卡为达标（截面） | 截面横幅"截面口径，待历史回测确认" |
| 确认（需重算） | 依赖版本在快照之后变了 | 预警横幅"当前结果需重算，本次导出的是快照第 n 版（重算前生成）"；仍可导出 |
| 未设置备份目录 | 还没设置备份目录 | 确认步骤提示"导出前请先设置备份目录"，链接 PAGE-F10-03；仍可导出，备份结果按失败显示 |
| 任务冲突 | 有计算任务在运行 | "开始导出"不可用，提示"回测正在运行，完成后再试"（DEC-010） |
| 生成中 | 已开始导出 | 进度与子步骤；可在后台继续 |
| 生成失败 | 写文件失败，例如文件被占用、磁盘空间不足 | 显示原因（例："浴室柜_机会判定_2027-05_快照1.xlsx 正在被 Excel 打开，关闭后重试"）与"重试"；不留下不完整文件 |
| 完成 · 备份成功 | 两个文件已生成，备份成功 | 结果横幅、文件路径、备份完成时间与目录（AC-F10-06） |
| 完成 · 备份失败 | 备份目录不可写或备份过程出错 | 文件部分照常显示；备份区显示失败图标、原因（例："备份目录不可写：D:\机会判定台备份\（拒绝访问）"）、"上次成功备份：2027-04-08 15:06"、"已有备份未改动"；操作"重试备份""去设置备份目录"（AC-F10-07）；工作台待处理区出现"备份失败" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同一快照再次导出 | 允许；同名文件已存在时另存为带序号的新文件（例：`…_快照1_2.xlsx`），不覆盖已发出的文件 |
| 同月有多个快照 | 导出最新一版；对账用该月最后一次导出的快照（DEC-006） |
| 备份失败 | 只影响备份，不影响已生成的文件；不删除、不改动任何已有备份（AC-F10-07） |
| 导出目录不存在 | 自动创建 `导出\{月份}\` 目录；无法创建时按生成失败处理 |

### 8.3 Excel 工作表结构（AC-F12-01）

每张工作表第 1 行为说明行（品类 · 排序月份 · 快照 · 判定卡版本与状态），第 2 行为列名并冻结。数值写成数字格式；不给值的单元格留空并在对应标记列说明，缺数据的单元格写"无数据"，不写 0。

**1. 首页**（两列：项目 | 内容）
- 第 1 行：状态句（见 8.2）。
- 行：品类（亚马逊美国 · 浴室柜，节点 6810202011）、排序月份与数据截止月、快照（序号、保存时间、内容指纹）、判定卡（版本、状态、口径）、回测（编号、倍数与 90% 区间、检验组样本量）、参照人群、成功线、全类目平均命中率（分子 / 分母）、生成时间、操作人。

### 8.5 备份规则

- 导出完成后自动备份到指定目录，生成一份带时间戳的备份，并显示完成时间（AC-F10-06）。
- 备份内容：台账、策略库、字段约定、品类配置和全部确认记录，附数据包指纹清单；数据包原件不进备份。
