## 2. 页面概述

### 2.1 一句话定位

用一份带版本的配置描述一个品类，换品类只加配置、不改程序（US-F13-01）。

### 2.2 存在理由

1. **口径必须集中且有版本**：成功线、起量门槛、分档直接决定命中与否和细分划分。散在各处就无法追溯某个结论用的是哪套口径（NFR-003）。
2. **改了要有后果提示**：配置一改，旧的成败、信号、回测就不再对应当前口径，必须标为需重算，不能悄悄混用（AC-F13-02）。
3. **第二个品类直接复用**：新建品类时复制浴室柜配置，逐项改成新品类的取值（AC-F13-01）。
4. **体检阈值在这里设**：体检项超过阈值时要在工作台持续提示，阈值按品类设置（AC-F03-02）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 完整 | REQ-F13-01 列出的配置项全部可见、可改，且都为必填 |
| 可追溯 | 每次保存生成新版本，版本历史可看每版改了什么、谁改的、为什么 |
| 不混用 | 保存前列出变动摘要和将标为需重算的结果；保存后依赖旧版本的结果 100% 标为需重算 |

### 2.4 不做什么

- **不自动重算**：只标记需重算，由 wen 在工作台点"全部重算"（DEC-016）。
- **不在本页切换品类开展工作**：第一期日常只用浴室柜；多品类总览与顶栏品类切换在第二期（PAGE-F15-03，planned）。
- **不做权限控制**：第一期单用户；"负责人"为第二期按品类控制编辑权限预留（DEC-014）。
- **不删除旧版本**：配置版本只追加。
- **不改字段约定或数据包**：分别在 PAGE-F02-01、PAGE-F01-01。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen（浴室柜负责人） |
| 使用时机 | 首跑前确认模板默认值；回测提示细分太细或样本不足时调整分档；调整信号窗口或体检阈值；准备第二个品类 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：调整一个参数（主场景）**
  - 例：wen 想把需求动量窗口从 4 个月改为 6 个月。改完后页面出现草稿横幅；点"保存为新版本"，确认弹窗列出"需求动量窗口 4 个月 → 6 个月"和将标为需重算的结果；确认后生成 v3，页顶出现需重算横幅。
- **场景 B：回看为什么改**
  - 例：在版本历史展开 v2，看到 2026-12-03 把细分从 5 个维度改为宽度档 × 形态 × 价格带，原因是多数细分样本不足。
- **场景 C：准备第二个品类**
  - 例：点"新建品类"，填名称、站点、节点，选"复制浴室柜配置 v2"，创建草稿后逐项改好，保存为 v1。

## 6. 交互流程

### 6.1 加载与初始化

- 载入当前品类的当前版本；本机有草稿时载入草稿，显示草稿横幅并标出改过的项。
- 侧栏停靠，表单很长时品类卡与版本历史仍在视野内。

### 6.2 核心操作流程

```
进入品类配置
  ├─ 修改任一配置项 → 自动存为本机草稿；该项标"已修改"；出现草稿横幅
  ├─ 点"保存为新版本"或横幅"查看变动" → 确认弹窗
  │     ├─ 没有修改 → "与 v2 相比没有修改"，不能保存
  │     ├─ 有配置项不合法 → 关闭弹窗并定位到该项，显示错误
  │     └─ 确认 → 生成 v3（修改说明、操作人、时间）
  │              → 依赖 v2 的成败判定、信号、回测标为需重算（AC-F13-02）
  │              → 草稿横幅消失，出现需重算横幅；版本历史顶部多出 v3；顶栏版本号变为"配置 v3"
  ├─ 需重算横幅"去工作台" → PAGE-F03-01，点"全部重算"
  ├─ 点"新建品类" → 填名称、站点、节点，选起点 → "创建草稿"
  │     → 进入新品类的配置（复制时带入浴室柜取值）→ 逐项填写或核对 → 全部填完才能保存为 v1（AC-F13-01）
  └─ 有未保存的修改时离开 → 离开提示；草稿保留在本机
```

### 6.3 辅助操作

- 版本历史中每个版本可展开"与上一版对比"。
- 体检阈值表的当前值小标签可点开看分子分母。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 没有草稿 | 显示当前版本取值，无横幅 |
| 草稿 | 有与当前版本不同的修改 | 草稿横幅；改过的项标"已修改" |
| 校验失败 | 有配置项为空或不合法 | 该项下方显示错误；保存时定位到第一个错误 |
| 已保存，需重算 | 保存新版本后 | 需重算横幅常驻，不可关闭，直到全部重算完成 |
| 计算任务运行中 | 有计算或回测在跑（DEC-010） | "保存为新版本"不可用，悬停提示"回测正在运行，完成后再试"，避免同一任务混用两个版本；可继续编辑草稿 |
| 新品类草稿 | 新建后尚未保存 v1 | 未填的配置项标"必填"；保存按钮在全部填完前不可用，并列出还缺哪几项 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 改了成功线或起量门槛 | 全部成败判定需重算；已保存的月度快照不变（快照不可改，DEC-006），快照记录生成时的配置版本 |
| 改了分档，而策略库规则引用了被改的分档 | 确认弹窗列出受影响的规则编号，规则本身不自动修改，由 wen 到策略库处理 |
| 只改体检预警阈值 | 当前数据包的体检值按新阈值重新判断是否预警（体检数值不重算） |
| 回看期与判定窗口 | 新品回看的终点随判定窗口变化，始终保证窗口在 T 月前结束 |
| 新品类节点与数据包不一致 | 在导入校验时阻断，不在本页处理（PAGE-F01-02） |

## 8. 业务规则与校验

### 8.1 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 必填 | 离开输入框、保存时 | 全部配置项不能为空（AC-F13-01） | "必填" |
| 数值 | 离开输入框 | BSR、GMV、门槛、窗口、回看为正数；GMV 可带千分位；月数为正整数 | "请填正数" |
| 分档 | 离开输入框 | 分档之间用" / "分隔，不重叠、不留空档 | "分档有重叠或空档" |
| 体检阈值 | 离开输入框 | 百分比在 0–100 之间；个数、条数为非负整数 | "请填 0–100 之间的数" |
| 新品类名称 | 创建时 | 不能与已有品类重名 | "已有同名品类" |

### 8.2 特殊业务规则

- **浴室柜默认值**（REQ-F13-01）：美国站、节点 6810202011、BSR 阈值 50、月度 GMV 阈值 100,000 美元、起量门槛 60 件/月、判定窗口 6 个月。
- **版本**：每次保存生成新版本，只追加；全部结果记录所用配置版本（NFR-003、DEC-014）。
- **需重算**（AC-F13-02、DEC-016）：保存后把依赖旧版本的成败判定、信号和回测标为需重算；旧结果仍可查看；不自动重算。
- **类型属性**（REQ-F06-07）：勾选"可回填"的属性，子体没有确认值、但父体有候选值时用父体值并标"父体回填"；颜色、尺寸、盆数不回填。
- **体检预警**（AC-F03-02）：任一体检项超过阈值，就在工作台显示预警，直到在 PAGE-F03-02 标为已知晓并填写说明。
- **新建品类**（AC-F13-01）：必须填写全部配置项；提供浴室柜配置作为可复制的模板，只复制配置取值，不复制数据包、结果、台账和规则；负责人默认为当前操作人。

### 10.2 页面提交的数据

| 数据 | 触发时机 | 用途 |
| :--- | :--- | :--- |
| 草稿 | 修改任一项 | 本机保存，离开不丢 |
| 新版本（全部配置项、修改说明） | 确认保存 | 生成新版本，并把依赖旧版本的结果标为需重算 |
| 新品类（名称、站点、节点、起点） | 创建草稿 | 建立新品类配置草稿 |

### 10.3 明确排除的数据

- 不加载成败、信号、回测的明细，只取数量。

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 默认值 | 浴室柜配置显示 REQ-F13-01 的默认值 |
| F-02 | 配置项完整 | 站点、节点、细分维度与分档、成功线、起量门槛、关键词映射、信号窗口与回看期、回测切分比例、体检预警阈值全部可改（REQ-F13-01） |
| F-03 | 新建品类 | 必须填写全部配置项才能保存；可复制浴室柜配置作为模板（AC-F13-01） |
| F-04 | 保存与需重算 | 保存生成新版本，依赖旧版本的成败判定、信号和回测标为需重算（AC-F13-02） |
| F-05 | 变动摘要 | 确认弹窗按实际修改列出旧值与新值；没有修改时不能保存 |
| F-06 | 版本历史 | 每个版本显示时间、操作人、说明，可展开与上一版对比 |
| F-07 | 体检阈值 | 体检项超过本页设置的阈值时在工作台预警（AC-F03-02） |
| F-08 | 类型属性 | 勾选的类型属性在信号计算中使用父体回填；颜色、尺寸、盆数不回填 |
| F-09 | 离开拦截 | 有未保存修改时离开出现提示 |
| U-01 | 强调色 | 任一时刻最多一个主按钮：页面主体不放主按钮，主按钮只出现在打开的弹窗里（"保存为 v3"、"创建草稿"）；需重算横幅不可关闭 |
