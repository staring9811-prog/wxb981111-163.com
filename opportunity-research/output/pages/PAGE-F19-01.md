## 2. 页面概述

### 2.1 一句话定位

新月份并入并确认标签后，按第九版规则重算两层评分，并用滚动回测告诉 wen"这个月的评分还能不能信"。

### 2.2 存在理由

1. 模型每月要随新数据重算，否则扫描和决策卡用的是旧评分。
2. 新品层模型系统性偏高，不显示偏差会高估做到概率。
3. 不做样本外检验就不知道评分是否失效，可能据此立项。
4. （v8）其他渠道原来一律"未验证"；有了评论重建的历史后，每个渠道要单独重算、单独回测，并因幸存者偏差同时给出打折后的读法，决定该渠道机会能不能标"经回测（打折）"（AC-F19-05、AC-F19-06）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可信 | 每次重算都给出有效性结论（通过 / 未通过） |
| 对比 | 回测结果与上一版并排 |
| 偏差透明 | 显示近批预测、实际与模型偏差 |
| 渠道等级有据 | 每个其他渠道都显示证据等级与依据（重建月份、回测原值与打折后、两条判定规则）；不满足时写明"未验证"的原因 |

### 2.4 不做什么

- **不做**规则和特征的编辑——第九版规则来自预登记，改规则不在本期页面范围。
- **不做**单元级明细浏览——单元评分在机会扫描和决策卡里看。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 操作者（重算）；审批者只读（看不到"重算"按钮，蓝图 §4） |
| 使用时机 | 每月打标确认完之后；评审会前看有效性 |

### 3.2 核心使用场景

**场景 A：月度重算（主场景）**
- 前置：新月份 Amazon 与其他渠道已并入，打标确认队列清零。
- 动作：点"重算（含 2026-10）"→ 任务进度 → 结果刷新，有效性结论更新。

**场景 B：前置未满足**
- 表现：重算按钮不可用，悬停 / 点击提示"2026-10 还有 37 条标签待确认，确认完才能重算"，前置清单给"去确认"链接。

**场景 C：检验未通过**
- 表现：顶部横幅变为阻断样式"市场评分本月未通过有效性检验"；工作台和每张决策卡顶部同样显示（AC-F19-04）。

**场景 D：看 Home Depot 渠道回测（v8）**
- 前置：Home Depot 历史回补完成，重建 2024-01 至 2026-10 共 34 个月（≥ 20）。
- 动作：顶栏切 Home Depot → 看重建历史与前置、渠道证据等级、回测原值与打折后 → 标签确认完后点"重算 Home Depot"。
- 结果（真实小试）：框 × 属性，把握四档之后变大 36% / 43% / 53% / 61%（逐档上升），D 档 22%（≤ 30%）→ 证据等级"经回测（打折）"；秩相关 全部 / 大单元 +0.12 / +0.39，打折后 +0.02 / +0.29；方向对（大单元）67% → 按 ≤ 60% 看；≥ 70% 档 61% → 46%。

**场景 E：Lowe's / Wayfair 未回补（v8）**
- 表现：顶栏切 Lowe's → 横幅"Lowe's 渠道未验证 · 未回补：重建月份 10 个（2026-01 至 10，只有月度追踪），不到 20 个月"；空状态与"去历史回补"；不显示任何回测数字。

## 4. 信息架构

### 4.1 区域划分

1. 页头（标题、当前结果说明、导出、重算）
2. 有效性结论横幅
3. 下一次重算的前置清单 ｜ 有效性检验规则（含未通过时的样式）
4. 市场层：本次评分（分级统计 + 回归系数）
5. 新品层：模型偏差、校准方式、按立项时点的检验表
6. 滚动回测：把握分档 ｜ 分级；与第八版并排表
7. （v8）顶栏渠道切换 Amazon / Home Depot / Lowe's / Wayfair；切到其他渠道时 2–6 换成：渠道结论横幅 → 重建历史与重算前置 ｜ 渠道证据等级（两条规则 + 打折规则）→ 滚动回测：把握分档条形图 ｜ 回测表（原值、打折后两列）→ 信号表

### 4.2 区域内容

- **有效性横幅**：结论、D 档之后变大比例（附样本量）、把握四档比例。
- **前置清单**：各渠道并入状态、打标确认剩余条数；重算内容说明。
- **检验规则卡**：两条规则（D 档 ≤ 30%、把握逐档上升）各自达标状态；未通过时横幅样式预览。
- **市场层**：A / B / C / D 单元数与回测变大比例；特征表（b6 份额斜率、x5 新品占比、x3 搜索同比、x4 体量、x2 新进家族、截距；b、c、k = 6 / 8 合计）。
- **新品层**：近批预测 4.8、实际 3.6、偏差 +1.2（每 10 个）；校准方式 (a)(b)(c) 平均绝对误差与选用；T0 表（训练 / 检验新家族、实际、AUC、前 30% / 后 30%、三种校准平均、用途）。
- **回测**：把握分档条形图（≤30% 25%、30–50% 44%、50–70% 60%、≥70% 63%，带 n）；分级表（A 78%、B 60%、C 42%、D 19%）；秩相关；第八版 / 第九版并排表（秩相关、方向对、80% 覆盖、把握 ≥70% / ≤30% 之后变大）。

- **（v8）其他渠道 · 已回测**：
  - 结论横幅：达标 → 成功样式 + "经回测（打折）"徽标 + 把握四档与 D 档（带 n）；不达标 → 警示样式"未验证"+ 哪条规则没过。
  - 重建历史与前置：重建月份范围与月数、回补摘要（商品页、家族、截断）、本渠道打标待确认数；重算内容说明（只用该渠道数据，信号 b6、x5、Amazon 侧丰富度）。
  - 渠道证据等级卡：把握逐档上升、D 档 ≤ 30% 两条规则各自达标状态；打折规则（秩相关减 0.1、把握 ≥ 70% 档减 15 个百分点、方向对按 ≤ 60% 看，注明参数版本）。
  - 回测表：秩相关（全部 / 大单元）、方向对（大单元）、把握 ≥ 70% / ≤ 30% 之后变大、D 档之后变大，"原值""打折后"两列。
  - 信号表：b6、x5、Amazon 侧丰富度的单信号秩相关；Amazon 侧丰富度显示加入前后的交叉验证秩相关。
- **（v8）其他渠道 · 未验证**：横幅写原因（未回补 / 重建 < 20 个月 / 回测未达标），空状态与"去历史回补"，不显示把握与分级。

## 5. 界面内容

### 5.1 元素清单

**重算按钮（主按钮）**
- 文案："重算（含 2026-10）"。
- 显示条件：仅操作者；前置未满足时不可用并说明原因。
- 重算不调用外部服务、不花钱，不弹费用评估。

**证据小标签**
- 所有比例带样本量；可点开看时点、结果月份、样本数、规则版本。

**渠道切换（v8）**
- 位置：顶栏，与机会扫描、决策卡同一组件；选项 Amazon / Home Depot / Lowe's / Wayfair，默认 Amazon。
- 切换后页头标题加渠道名，说明行换成该渠道当前结果（例："渠道模型 · 重建历史 2024-01 至 2026-10（34 个月）· 2026-11-03 回测 · 打折规则参数 v3"）。
- 主按钮随渠道：Amazon"重算（含 2026-10）"；已重建渠道"重算 Home Depot"（前置未满足不可用并说明）；未回补渠道换成"去历史回补"。

**渠道证据等级徽标（v8）**
- "经回测（打折）"：沿用"达标 / 经回测"的成功色徽章与 seal-check 图标，文字带"（打折）"以示区别；"未验证"：未验证徽章。

**回测表原值 / 打折后（v8，示例 Home Depot）**

| 指标 | 原值 | 打折后 |
| :--- | ---: | ---: |
| 秩相关 · 全部单元 | +0.12 | +0.02 |
| 秩相关 · 大单元 | +0.39 | +0.29 |
| 方向对 · 大单元 | 67% | ≤ 60% |
| 把握 ≥ 70% 之后变大 | 61%（n=23） | 46% |
| 把握 ≤ 30% 之后变大 | 36%（n=821） | 36% |
| D 档之后变大 | 22%（n=193） | 22% |

- 打折规则只调三项；其他指标两列相同。数字来自 `solution-v2/开发建议/小平台_HD回测小试.md` §5.1（11 个时点合计）。

**未通过告警样式**
- 文案固定："市场评分本月未通过有效性检验"，阻断色，不可关闭。

### 5.2 辅助信息

- 页脚：x5 和窗口是看过 2026 年诊断后定的，严格样本外检验等 2026-10 起的数据；2026-06 至 09 带 * 打折看。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 通过 | 两条规则都达标 | 成功横幅 |
| 未通过 | D 档变大 > 30% 或把握不逐档上升 | 阻断横幅，不可关闭 |
| 前置未满足 | 打标未确认完 / 渠道未并入 | 重算按钮不可用，清单标出缺项 |
| 重算中 | 任务运行 | 页面保留上次结果、降低不透明度；任务栏进度 |
| 重算失败 | 计算出错 | 横幅说明失败步骤，可重试，上次结果保留 |
| 空 | 从未重算 | 空状态："还没有重算结果。并入数据并确认标签后，在这里重算。" |
| 无权限 | 只读角色 | 侧栏不显示入口 |
| 渠道：经回测（打折） | 该渠道最近一次回测把握逐档上升且 D 档 ≤ 30% | 成功横幅 + 徽标；回测表两列 |
| 渠道：回测未达标 | 任一规则不满足 | 警示横幅"未验证：D 档之后变大 34% > 30%"等；回测表照常显示，扫描与决策卡不显示该渠道把握与分级 |
| 渠道：历史不足 | 重建月份 < 20 | 横幅"未验证：重建 14 个月，不到 20 个月"；不能重算 |
| 渠道：未回补 | 从未历史回补（第一版 Lowe's / Wayfair） | 横幅"未回补"、空状态、"去历史回补"；不显示任何回测数字 |
| 渠道：重算前置未满足 | 本渠道打标未确认完 | "重算 Home Depot"不可用，提示待确认条数 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 重算中再次点击 | 同时只运行一个任务，提示正在运行 |
| 检验时点样本少 | 该行标"样本不足"（如 T0 2025-10 检验 15 个） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 把握 | 市场层给出的"之后份额变大"的概率 |
| 分级 | A / B / C / D |
| 份额预测 | 立项后 6–10 个月份额与 80% 区间 |
| 模型偏差 | 新品层近批预测平均 − 实际（每 10 个） |
| 秩相关 | 把握与实际份额变化的秩相关，全部 / ≥ 300 件 |
| 重建月份 | 其他渠道由评论重建的历史月数；≥ 20 才能做渠道回测 |
| 打折后读法 | 按打折规则调整后的指标：秩相关减 0.1、把握 ≥ 70% 档之后变大减 15 个百分点、方向对按 ≤ 60% 看（默认值，品类配置可改） |
| 渠道证据等级 | 经回测（打折）/ 未验证 |
| 大单元（其他渠道） | 近 3 个月月均 ≥ 200 件（约为品类月销的 1%，与 Amazon 300 件同比例） |

### 8.3 特殊业务规则

- 第九版：份额斜率、新品占比、搜索同比、体量；按体量档 × 预测窗口校准（AC-F19-01）。
- 新品层只用开发能定的属性，按最近半年做到率校准（AC-F19-02）。
- 有效性告警规则：D 档之后变大 > 30%，或把握分档不再逐档上升（AC-F19-04）。
- 分渠道回测（AC-F19-05）：其他渠道重建历史 ≥ 20 个月、wen 发起该渠道重算时，只用该渠道数据，按"尺寸 × 拆装 × 形态"框 × 属性取值重算评分（信号：份额斜率、新品占比、Amazon 侧丰富度）并滚动回测，显示把握分档之后变大比例、D 档之后变大比例、秩相关（全部 / 大单元），同时显示打折后的读法。
- 渠道证据等级（AC-F19-06）：最近一次回测把握分档逐档上升且 D 档之后变大 ≤ 30% → 该渠道机会"经回测（打折）"；不满足或尚未回测 → "未验证"，扫描与决策卡不显示把握与分级。
