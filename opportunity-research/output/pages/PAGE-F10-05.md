## 2. 页面概述

### 2.1 一句话定位

6 个月后检验当时的预测：快照里排前 20% 的细分，新品是否真的更容易成；自家立项的结果是否与当时的排名、锦囊一致。

### 2.2 存在理由

1. **检验判定卡在真实决策中有没有用**：回测只用历史数据，对账才是对"当时的预测"的检验（US-F10-01、AC-F10-04）。
2. **规则状态的升级依据**：每条"历史观察"规则按自己的规则倍数和动作判断——立项候选 ≥ 2、放弃 ≤ 0.5 才升为"已验证"，观察规则只记录（AC-F11-03、AC-F11-06）。页面要写明每条规则的倍数、升级了哪条、依据哪次对账。
3. **自家与竞品用同一把尺**：自家立项按同一条成功线判定，并与当时的排名、锦囊放在一起看（AC-F10-05）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 自动 | 对应批次判定完成后的那次月更自动出现对账结果，不需手工操作 |
| 可核对 | 每个命中率都有命中数 / 新 SPU 数和样本量；实际值与预期区间画在同一条区间条上 |
| 可预期 | 每份未到期快照都显示预计可对账月份和批次判定进度 |

### 2.4 不做什么

- **不手动触发对账**：对账在月更计算成败后自动生成。
- **不在本页改规则状态**：状态由对账自动更新，规则在 PAGE-F11-01 查看。
- **不在本页编辑立项记录或上架数据**：分别在 PAGE-F10-04、PAGE-F10-06。

```

  └─ 点"查看全部立项记录" → PAGE-F10-04
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 暂无到期 | 还没有快照到期 | 竞品新品对账区显示"还没有到期的快照。最早可对账：2027-06（2026-12 · 第 1 版）"；其余区块照常 |
| 可对账，待计算 | 批次已满 6 个月，但本月还没运行成败计算 | 该快照在未到期表中写"可对账，待本月计算"，并链接本月工作台 |
| 正常 | 有对账结果 | 全部区块 |
| 区间外 | 实际命中率低于或高于预期区间 | 结论写"低于区间"或"高于区间"，用中性样式，不用红色 |
| 规则未达验证条件 | 立项候选规则倍数 < 2，或放弃规则倍数 > 0.5 | 规则对账表结果写"未达条件，状态不变" |
| 观察规则 | 动作为观察 | 规则对账表记录规则倍数，结果写"已记录，状态不变"（AC-F11-06） |
| 截面快照 | 快照来自截面回测 | 带截面标签；结论写"截面对账仅作参考，不改变规则状态" |
| 自家观察中 | 上架不满 6 个月且未达标 | 自家结果"观察中 · 还剩 n 个月" |
| 自家数据不全 | 窗口内有缺月且未达标 | 自家结果"数据不全"，列出缺失月份 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同月多版快照 | 只对账当月最后一次导出的那版；从未导出用最后一版；其余在表下注明"不用于对账"（DEC-006） |
| 品类配置已变更 | 对应批次的新 SPU 按快照当时的配置划分细分（例：2026-11 快照用配置 v1 的 5 个维度） |
| 补录的自家立项 | 没有对应快照，"当时的排序与锦囊"显示"无对应快照（补录）"和当时依据 |
| 被更正的立项 | 按最新的更正记录对账，原记录不再出现 |

## 8. 业务规则与校验

- **对账触发**（AC-F10-04）：快照对应批次（快照月份当月上架的起量新 SPU）全部完成 6 个月判定后，在那次月更计算成败时自动生成；预计可对账月份 = 快照月份 + 6 个月。
- **对账版本**（DEC-006）：当月最后一次导出时的快照；当月从未导出取最后一版。
- **前 20%**：快照中有效细分（不含样本不足）按排名取前 20%，向上取整（有效 8 或 9 个 → 前 2 名）。
- **命中率口径**：参照人群为起量新品；观察中、数据不全的新 SPU 不计入分母（AC-F05-03、AC-F05-05、AC-F05-11）。
- **倍数** = 前 20% 细分实际命中率 ÷ 全类目实际命中率。
- **规则倍数**（REQ-F11-01）= 快照中适用该规则的细分，其对应批次起量新 SPU 的实际命中率 ÷ 同批次全类目平均命中率。
- **落在区间内**：实际命中率在快照保存时回测给出的预期区间之内（含端点）。
- **规则升级**（AC-F11-03，D-27）：快照锦囊引用的每条"历史观察"规则单独计算规则倍数——立项候选 ≥ 2、放弃 ≤ 0.5 时升为"已验证"（生成新版本），并记录依据的对账月份和规则倍数（例：R-012 适用前 2 名细分，依据 2027-05 对账 2026-11 快照，规则倍数 2.07×）。
- **观察规则**（AC-F11-06）：只记录规则倍数和对账月份，不改变状态（例：R-015 0.78×）。
- **截面快照**：锦囊来自截面回测（规则同为"历史观察"，带"截面"标签，DEC-029），对账只作参考，不改变规则状态。
- **自家对账**（AC-F10-05）：按品类配置的成功线判定，与竞品新品同一条；"当时的排序与锦囊"取立项记录对应的快照，规则状态取快照保存时的状态。
