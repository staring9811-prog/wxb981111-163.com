## 2. 页面概述

### 2.1 一句话定位

在每个渠道、每个"尺寸 × 拆装 × 形态"框里，先看清机会在哪，再挑一个去做决策卡。

### 2.2 存在理由

1. 跨框比较会得出错误结论（大尺寸拉高价格、悬浮和落地混在一起），必须框内比。
2. 四类机会的证据分量不同，不标等级容易把"老板假设"当"经回测"用。
3. 其他渠道方向可能和 Amazon 相反，需要分渠道单独扫。
4. （v8）其他渠道有了评论重建历史和渠道回测，证据等级要按渠道回测结果给（经回测（打折） / 未验证）；Home Depot 检验显示"Amazon 侧款多、份额大 → 本渠道之后份额上升"，需要在每个其他渠道单元旁并排看 Amazon 侧丰富度和差距值（AC-F29-05）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 响应 | 24 个月数据下打开 10 秒内出结果（NFR-009） |
| 口径 | 100% 指标只在同框、同渠道内比较 |
| 转化 | 任一单元一步生成决策卡草稿 |

### 2.4 不做什么

- **不做**跨渠道合并或比较绝对销量（AC-F29-02）。
- **不做**修改四类规则阈值——规则同 `机会扫描_202610.md`，属性列表在 PAGE-F27-01 配置。
- **不做**近 6 个月月销 < 200 件框的扫描，只在汇总里说明。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |

### 3.2 核心使用场景

**场景 A：找增长机会做卡（主场景）**
- 动作：Amazon → 机会类型勾"增长型"→ 看 30″ 拆装落地式 → 台面材质：树脂 → "做决策卡"。
- 结果：生成草稿并进入 PAGE-F21-02。

**场景 B：看其他渠道**
- 动作：顶栏切 Wayfair → 同样的框与规则，只用 Wayfair 数据；横幅说明估算口径与"未验证"。

**场景 D：看 Home Depot 的 Amazon 侧丰富度（v8）**
- 动作：顶栏切 Home Depot → 横幅说明本渠道"经回测（打折）"→ 证据等级筛"经回测（打折）"→ 看"30″ · 整装 · 落地式 · 主色：黑"：Amazon 121 家族 / 6 价位段、框内份额 13% → 18%；Home Depot 3 家族 / 1 价位段；差距 G +3.42（点"来源"看两侧事实）。
- 读法：Amazon 结构领先，作加分信号，不作独立立项理由。

**场景 E：本渠道没有的单元（v8）**
- 表现："36″ · 整装 · 落地式 · 台面材质：陶瓷"在 Home Depot 两类目前 300 里没有家族 → 行弱化显示并标"该渠道样本外，仅参考"，只列 Amazon 侧事实（112 家族 / 4 价位段，框内 60%）与 G +4.73，不给把握与分级，不提供"做决策卡"。

**场景 C：只看某个框**
- 动作：在"按框汇总"点框名或用"框"下拉 → 只显示该框。

## 4. 信息架构

### 4.1 区域划分

1. 顶栏（品类、渠道切换 Amazon / Home Depot / Lowe's / Wayfair、用户）
2. 页头（标题含当前渠道、期间与范围说明、显示全部列、导出）
3. 口径横幅（Amazon：* 月份；其他渠道：估算口径、仅渠道内比较；v8 按渠道写证据等级：Home Depot"经回测（打折）"、Lowe's / Wayfair"未回补 · 未验证"）
4. 四类机会与证据等级说明（v8 增加其他渠道证据等级与 Amazon 侧丰富度的说明段）
5. 筛选区（关注属性、框、机会类型、证据等级、显示数、清除）
6. 扫描结果表（按框分组）
7. 按框汇总（Amazon）

### 4.2 区域内容

- **四类说明卡**：增长型（经回测）、评分缺口型（历史观察；"做好就起量"未验证）、价格缺口型（历史观察）、坑（经回测），各写判定规则。
- **结果表列**：机会类型、属性：取值、月销（其他渠道为估算月销，带证据小标签）、份额 前 → 近、家族*、单款 ÷ 同框*、评分（同框）、溢价 / 中位价、新品占比（同框）、新家族做到（同框）*、证据等级、操作。（* 为次要列，宽度 < 1600 像素时收起，"显示全部列"展开。）
- **其他渠道增加的列（v8，AC-F29-05）**：两列四个值——"Amazon 家族 / 价位段"（下行小字：Amazon 框内份额 前 → 近）、"差距 G"（下行小字：本渠道家族 / 价位段）；1440 宽下不出横向滚动。四个值都按"同尺寸段 × 形态 × 属性取值、不分拆装"对齐，窗口为近 6 个月；G 旁"来源"小标签点开看两侧家族、子体、价位段分布、月均与公式。
- **样本外行（v8，AC-F29-06）**：本渠道前 N 里没有家族的单元，整行弱化（次要文字色 + 暖灰底），机会类型列为"样本外"徽章，本渠道指标全部"无数据"，证据等级列写"该渠道样本外，仅参考；不给把握与分级"，没有"做决策卡"。
- **其他渠道的次要列（v8）**：为放下丰富度两列，其他渠道表里"评分（同框）""溢价 / 中位价"也归为次要列（宽度 < 1600 像素收起，"显示全部列"展开）；Amazon 表不变。
- **分组行**：框名 + 框月销。
- **操作列**：未做卡 →"做决策卡"；已有卡 →"查看决策卡"；有相关卡 →"有相关卡"链接 +"做决策卡"。
- **按框汇总**：16 个框的框月销与四类个数；无机会的框弱化显示。

## 5. 界面内容

### 5.1 元素清单

**渠道切换**
- 选项：Amazon / Home Depot / Lowe's / Wayfair；默认 Amazon；切换后同样的框与规则只用该渠道数据（AC-F29-01）。

**证据等级徽章**
- 经回测 / 经回测（打折）/ 历史观察 / 未验证（AC-F20-03）。
- 其他渠道按该渠道最近一次回测（PAGE-F19-01）：把握逐档上升且 D 档 ≤ 30% →"经回测（打折）"（沿用成功色徽章与 seal-check 图标，文字带"（打折）"）；未回补、重建 < 20 个月或未达标 →"未验证"，不显示把握与分级（AC-F19-06）。
- 第一版示例：Home Depot 经回测（打折）；Lowe's / Wayfair 未回补 · 未验证。

**Amazon 侧丰富度（v8）**
- 定义：Amazon 同尺寸段 × 形态 × 属性取值（不分拆装）近 6 个月有销量的家族数、价位段数（7 段绝对价位：$0–200 / 200–300 / 300–450 / 450–650 / 650–900 / 900–1,300 / 1,300+）、框内份额走势；本渠道同口径家族数、价位段数；差距 G = ln((Amazon 家族数 + 1) / (本渠道家族数 + 1))。
- 示例（真实，HD 检验 §5，窗口 2026-04 至 09）：30″ · 落地式 · 主色：黑：Amazon 121 家族 / 6 价位段，月均 606 → 630 → 1,074 件（框内 14% → 13% → 18%）；Home Depot 3 家族 / 1 价位段，月均 107 件（框内 4%）；G +3.42。36″ · 落地式 · 台面材质：陶瓷：Amazon 112 家族 / 4 价位段、框内 60%，Home Depot 前 300 无家族 → 样本外。
- 证据等级随该渠道（F19）；Amazon 侧丰富度是该渠道评分的信号之一，读作"Amazon 结构领先"，不作独立立项理由。

**证据小标签（月销旁）**
- 点开显示：框、渠道、近期与前期月份、在榜家族数；其他渠道另显示估算口径与参数版本。

**关注属性勾选**
- 台面材质、元素、主色、柜体材质（来自品类配置的扫描属性）。

**分框锁定提示**
- "分框控制变量（尺寸段 × 拆装 × 形态）保持不变"。

**做决策卡**
- 仅操作者可见；点后创建草稿并跳详情。

### 5.2 辅助信息

- 页脚：柱状盆、转角式量太小不扫；Lowe's 30″ 拆装落地式估算 140 件 / 月不扫描等说明。

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 框 | 尺寸段 × 拆装 × 形态 |
| 单元 | 框 × 属性取值 |
| 近期 / 前期 | 2026-04 至 09 / 2025-10 至 2026-03 |
| 份额 | 取值在框内的销量占比 |
| 溢价 | 中位价 ÷ 同框中位价 |
| 新品占比 | 近 6 个月上架 ≤ 6 个月家族的销量占比 |
| Amazon 家族数 / 价位段数 | 同尺寸段 × 形态 × 属性取值（不分拆装）近 6 个月有销量的 Amazon 家族 / 绝对价位段个数 |
| 本渠道家族数 / 价位段数 | 同口径，本渠道评论家族 / 价位段个数（价位用当日价） |
| 差距 G | ln((Amazon 家族数 + 1) / (本渠道家族数 + 1)) |
| 样本外 | 该单元在本渠道前 N 个商品页里没有任何家族 |

### 8.3 特殊业务规则

- 只扫近 6 个月月销 ≥ 200 件的框（AC-F20-01）。
- 一切指标只和同框其他取值比（AC-F20-02）；其他渠道只在本渠道内比（AC-F29-02）。
- 其他渠道月销 = VP × 50 + 非 VP × 20（参数版本标注）。
- 证据等级（AC-F20-03，revision 2）：经回测 / 经回测（打折）/ 历史观察 / 未验证；其他渠道按该渠道最近一次回测结果给出（F19）。
- Amazon 侧丰富度（AC-F29-05）：扫描显示其他渠道单元时同时显示 Amazon 侧家族数、价位段数、份额走势，以及本渠道家族数、价位段数和差距值；证据等级随该渠道。
- 样本外（AC-F29-06）：本渠道前 N 里没有任何家族的单元标"该渠道样本外，仅参考"，只显示 Amazon 侧事实，不给该渠道的把握与分级。
