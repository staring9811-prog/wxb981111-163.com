## 2. 页面概述

### 2.1 一句话定位

用系统自动记下的步骤起止时间，检验"首跑 ≤ 5 个工作日、月更 ≤ 4 小时"的效率目标（US-F14-01）。

### 2.2 存在理由

1. **效率是业务目标**：原先一次品类研究约 20 天，本产品承诺首跑 ≤ 5 个工作日、月更 ≤ 半天（D-14、D-20），没有记录就无法证明。
2. **知道时间花在哪**：月更超时时，要能看出是某一步慢，还是步骤之间等得久。
3. **与工作台同一口径**：工作台"用时"区的数字来自这里，口径必须一致（AC-F14-02）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 记录完整 | 导入、字段确认、体检、SPU 审核、计算、回测、导出每次开始和结束都有记录（AC-F14-01） |
| 口径一致 | 首跑与月更按 REQ-F14-01 计算，与工作台显示一致 |
| 超时可见 | 超过目标 80% 显示预警色，超过目标显示阻断色并写出超出的分钟数 |

### 2.4 不做什么

- **不统计数据准备时间**：数据拉取与整理由数据项目另计（D-20）。
- **不允许手动修改记录**：起止时间由系统写入。
- **不做多品类对比**：记录已带品类编号（DEC-014），按品类对比在第二期。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen；汇报效率时把数字转述给老板 |
| 使用时机 | 月更结束后；某月超时后复盘；季度汇报效率 |
| 使用设备 | Windows，宽 1366–1920 |

### 3.2 核心使用场景

- **场景 A：月更结束后自查**
  - 动作：导出后看本月是否 ≤ 4 小时。
- **场景 B：超时复盘**
  - 动作：2027-02 用了 4 小时 25 分，切到该月步骤明细，看哪一步慢、步骤之间空了多久。
- **场景 C：汇报效率**
  - 动作：引用"首跑 3 个工作日、近 5 次月更 4 次达标"。

## 6. 交互流程

### 6.1 加载与初始化

- 汇总与月更列表按当前品类读取；步骤明细默认本月。
- 本月进行中时，时长截至打开页面的时间，停留期间每分钟更新一次。

### 6.2 核心操作流程

```
进入运行记录
  ├─ 看汇总：首跑、本月、最近完成的月更
  ├─ 在步骤明细右上角选月份 → 明细切换到该月
  └─ 点步骤名 → 对应页面（如"回测" → PAGE-F07-01）
```

### 6.3 辅助操作

- 进度轨带读屏文字，如"已用 126 分钟，目标 240 分钟"；超出时写明超出分钟数。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空态 | 还没有导入过数据包 | "还没有运行记录。导入第一个数据包后，从这里开始记录首跑用时。" |
| 首跑进行中 | 已导入、尚未生成首次回测报告 | 首跑卡显示"进行中 · 已用 n 个工作日"；月更列表为空，说明"首跑完成后开始统计月更" |
| 本月进行中 | 本月已导入、未导出 | 本月行"进行中"，时长截至当前；导出步骤"尚未开始" |
| 接近或超出目标 | 用时 > 80% 或 > 4 小时 | 进度轨变预警色或阻断色；超出时写"超出 x 分钟" |
| 步骤失败 | 某步运行失败 | 结果为"失败"并写原因；重试记为同一步骤的新一行，失败那次保留 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 同一步骤多次运行（如"全部重算"后再次计算、回测） | 每次单独一行，按开始时间排序；时长分别计算 |
| 步骤跨天 | 开始、结束显示日期和时间 |
| 自动步骤 | 体检、排序与快照由系统随前一步自动运行，操作人记"系统" |
| 工作日计算 | 只数周一至周五，起止当天都算（2026-11-06 周五至 2026-11-10 周二 = 3 个工作日）；不扣法定节假日 |
| 同月多次导入或多次导出 | 月更起点取当月第一次导入，终点取当月最后一次导出（含返工时间，与对账取最后一次导出的快照一致；DEC-031） |

## 8. 业务规则与校验

- **记录**（AC-F14-01）：导入、字段确认、体检、SPU 审核、计算、回测、导出中任一步骤开始或结束时，记录开始时间、结束时间和操作人。
- **首跑**（REQ-F14-01）：某品类首次导入到首次生成回测报告之间的工作日数（周一至周五），目标 ≤ 5 个工作日。
- **月更**（REQ-F14-01）：某月导入到该月导出之间的时长，目标 ≤ 4 小时；进行中按导入至当前计。
- **显示**（AC-F14-02）：按品类显示首跑用时和每次月更用时；工作台"用时"区与本页使用同一数据。
- **只统计系统内时间**：数据准备不计（D-20）。
- **不可编辑**：记录只追加，不提供修改入口（DEC-014）。

## 9. 页面流转

                                       └─ 步骤名 ──→ PAGE-F01-02 / PAGE-F03-02 / PAGE-F02-01 / PAGE-F04-02 /

**扩展预案**：第二期多品类后，汇总按品类分组，可对比各品类首跑与月更用时。
