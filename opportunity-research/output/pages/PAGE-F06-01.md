## 2. 页面概述

### 2.1 一句话定位

按细分看第 T 月"当时"能看到的三类信号和 4 个现用指标。这张表是回测和本月排序的输入。

### 2.2 存在理由

1. **只用当时可见的数据**：信号若用到 T 月之后的数据，回测会虚高。页面要把时点说清楚（REQ-F06-02）。
2. **每个信号要能核对**：同比要配关键词数，命中率要配分子分母，占比要配样本，才知道信号可不可信（AC-F06-04–AC-F06-07）。
3. **新信号要和现用指标并排**：4 个现用指标作为候选，回测才能比较谁更准（AC-F06-08）。
4. **影响可信度的因素要常驻**：父体回填占比、被排除的未确认字段（AC-F06-02、AC-F02-04）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 时点清楚 | 页面始终写明 T 与截断日期（早于 T 月第一天） |
| 数字可核对 | 每个信号都带分子分母或参与数量，并有证据小标签 |
| 缺失不误读 | 缺数据一律显示"无数据"，悬停说明原因，不显示 0 |

### 2.4 不做什么

- **不编辑细分定义**：在品类配置（PAGE-F13-01）中改维度与分档。
- **不打分排序**：得分与排名在本月排序（PAGE-F09-01）。
- **不展示趋势和商品明细**：趋势、痛点构成、细分内新 SPU 在细分详情（PAGE-F06-02）。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 产品经理 wen |
| 使用时机 | 每月计算后核对信号；立项评审前看某个细分的支撑数字；回测结果异常时追查信号 |
| 使用设备 | Windows，宽 1366–1920；宽度小于 1600 时候选信号列默认收起 |

### 3.2 核心使用场景

- **场景 A：月更后核对（主场景）**：默认 T = 2027-05，按排名看前几个细分的需求在涨、新品进得去是否有足够的关键词和已判定新品支撑，回填占比高的细分点进详情看回填维度。
- **场景 B：对照现用指标**：点"候选信号列"展开 4 个现用指标，和新信号并排比较。
- **场景 C：截面口径**：只有样例包或要看截面结果时，顶栏切到"截面"，看批次上架月之前的信号和老品计算的现用指标。

## 6. 交互流程

### 6.1 加载与初始化

- 默认 T = 数据最新月的下一个月（DEC-005：数据至 2027-04 → T = 2027-05）。
- 默认历史口径；只有截面数据包时默认截面，顶栏不出现口径切换（DEC-011）。
- 默认按本月排序名次排列，样本不足的细分在后。

### 6.2 核心操作流程

```
进入信号
  ├─ 选月份 T → 表格切换为该月已算好的信号（时点横幅同步更新）
  ├─ 点表头 → 按该列升序 / 降序排序（无数据视为最小值）
  ├─ 点"候选信号列" → 展开 / 收起 4 个候选列
  ├─ 点证据小标签 → 浮层：口径、分子分母、来源文件、数据包
  ├─ 点一行 → PAGE-F06-02 细分详情（抽屉），关闭后回到本页原位置
  ├─ 点"去确认" → PAGE-F02-01 字段约定
  └─ 切换顶栏口径 → 截面横幅与截面信号表
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未计算 | 还没运行过成败与信号计算 | 空状态："还没有信号结果。确认字段约定、审核合并建议后运行计算。"按钮"运行计算" |
| 正常 | 有当月结果 | 时点横幅、表格 |
| 有未确认字段 | 计算时存在未确认字段 | 未确认字段横幅列出被排除的字段名（AC-F02-04） |
| 部分无数据 | 某细分某信号所需数据缺失 | 该格显示"无数据"，悬停说明原因 |
| 样本不足 | 细分的新 SPU 少于 20 个 | 细分下方写"样本不足"，信号照常显示 |
| 计算中 | 有计算任务在运行（DEC-010） | 表格保留上次结果；"运行计算"不可用，提示"计算正在运行，完成后再试" |
| 需重算 | 字段约定、归并或品类配置变了 | 需重算横幅，按钮"重新计算"；表格仍显示旧结果（DEC-016） |
| 截面口径 | 顶栏切到截面 | 截面横幅；"新品进得去"为"截面模式不适用"；候选信号显示老品数；缺评论痛点时相关列为"无数据" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 关键词月份不够 | 同比需要 T−4 至 T−1 月及上一年同期；缺任一月份时"需求在涨"为无数据（REQ-F06-03） |
| 泛词 | 没有映射到任何细分维度的关键词不计入细分信号（REQ-F06-03） |
| 回看期内没有已判定新 SPU | "新品进得去"为无数据；有已判定但都没命中时显示 0.0% 和"命中 0 / 已判定 n"（这是真实的 0） |
| 父体级评论 | 只计入该父体 T−1 月销量最大的子体所在细分，不重复计入（REQ-F06-05） |
| 早期月份 | 数据包更早月份覆盖不足时，相应信号显示无数据，不影响其他信号 |

## 8. 业务规则

- **细分**：每个子体按品类配置的维度与分档归入唯一细分；属性为"未知"的子体归入该维度的"未知"档（REQ-F06-01）。
- **时点**：第 T 月的任一信号只使用日期早于第 T 月第一天的记录：评论按评论日期，关键词按统计月份，月度商品数据按所属月份（REQ-F06-02、AC-F06-03）。
- **需求在涨**：映射到该细分的关键词在 T−4 至 T−1 月的搜索量合计，相对上一年同期的同比变化；窗口月数在品类配置中可改（REQ-F06-03）。
- **新品进得去**：上架于 T−12 至 T−7 月的该细分新 SPU 中，命中数 ÷ 已判定数（不含观察中与数据不全）（REQ-F06-04）。
- **结构类痛点占比**：评论日期早于 T 月的评论中，标为结构类痛点的占比（REQ-F06-05）。
- **高销低评占比**：T−1 月销量处于细分前 25%、且此前评论均分低于 4.0 的商品，其销量占细分 T−1 月销量的比例（REQ-F06-05）。
- **候选信号**：单位 ASIN 贡献、属性溢价、属性趋势、低分高销，口径见 REQ-F06-06，表中标"候选"（AC-F06-08）。
- **截面口径**：不计算"新品进得去"；需求在涨与现有产品没做好按批次上架月之前的数据计算；4 个现用指标只用老品在观察月份的数据计算（REQ-F06-08）。
- **未确认字段**：不参与任何计算，结果中列出被排除的字段名（AC-F02-04）。
