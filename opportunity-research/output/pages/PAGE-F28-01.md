## 2. 页面概述

### 2.1 一句话定位

把 Home Depot / Lowe's / Wayfair 的月度评论数据并进分析库，并看清每个渠道的月销是怎么估出来的。

### 2.2 存在理由

1. 其他渠道没有月销数据，只能用评论数估算；不说明方法和系数，估算值会被当成实测（AC-F28-03）。
2. 同系列多个尺寸共享一批评论，不去重会把同一条评论算好几次（AC-F28-05）。
3. wen 提出排名平滑作为第二种方法，需要和评论换算并排对照才能判断哪个更可信（AC-F28-04）。
4. 历史数据来自追踪器导出的 Excel，需要上传并入且排除未完整月份（AC-F28-02）。
5. （v8）回测要约 20 个月历史；回补的全部历史评论要按评论日期重建成逐月估算月销、合并成评论家族，并让 wen 看清覆盖够不够、幸存者偏差有多大（AC-F28-06～08）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 完整并入 | 评论 VP 追踪完成一个月份后，该月三个渠道的商品、排名、VP / 非 VP 数 100% 进入分析库 |
| 去重 | 渠道或单元合计中同一评论 ID 只计 1 次 |
| 方法透明 | 每个估算月销都注明方法与系数（参数版本） |
| 重建透明 | 每个已回补渠道显示月份范围、商品页 / 家族 / 评论数、截断数、前 N 覆盖估计、前 50 半年重合率，并常驻幸存者偏差说明 |

### 2.4 不做什么（范围边界）

- **不在本页采集评论**：采集在 PAGE-F23-01 评论 VP 追踪。
- **不在本页改系数或切换方法**：在 PAGE-F27-01 品类配置中修改（AC-F27-03、AC-F28-04），本页只显示当前值并提供入口。
- **不跨渠道比较绝对销量**：Wayfair 的 VP 口径不同，各渠道只在渠道内比较（AC-F29-02）。
- **不处理 Amazon**：Amazon 在 PAGE-F17-01。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 仅操作者 wen；其他角色无入口，直接访问显示无权限 |
| 使用频次 | 每月评论采集后查看 1 次；调整估算方法前对照 |

### 3.2 核心使用场景

**场景 A：月度采集后确认并入**：评论 VP 追踪 2026-11-02 完成 2026-10 采集 → 系统自动并入 → wen 打开本页看到三个渠道 2026-10 都"已并入"，去重后评论 HD 412、Lowe's 455、Wayfair 871 条。
**场景 B：补历史数据**：上传追踪器 10 月 12 日导出的 Excel → 系统识别 2026-01 至 09 为完整月并入，2026-10（截至 10-12）为未完整月，只作参考不计入。
**场景 C：对照两种方法**：切到 Home Depot → 看到排名平滑法可用（锚点 46 个）→ 逐个商品对照两种估算差异，排名靠后的小商品平滑法偏高 30–40% → 决定仍用评论换算法。
**场景 D：Wayfair 不能用排名平滑**：锚点只有 8 个，页面提示"少于 10 个，不提供该方法"。
**场景 E：看回补后的历史够不够做回测（v8）**：Home Depot 回补完成 → 历史重建表显示 2024-01 至 2026-10 共 34 个月、598 个商品页、219 个评论家族、14,397 条评论、0 截断；前 N 覆盖带台面约 73%、无台面约 58%（201–300 名仍贡献 9%，未饱和）；前 50 半年重合 78%（上限）→ 历史 ≥ 20 个月，去模型与回测发起 Home Depot 渠道重算。Lowe's / Wayfair 显示"未回补 · 未验证"，只有 10 个月月度追踪，点"去回补"。
**场景 F：查一个家族合并了哪些商品页（v8）**：评论家族列表点 Doveton"看全部"→ 抽屉列出 18 个商品页（60 / 48 / 36 / 30 / 24 in. × 4 色）、合并依据、首条评论 2025-04-09。

### 3.3 用户核心诉求

1. **知道数据齐不齐**：每渠道每月是否已并入、来自哪里。
2. **知道估算怎么来的**：方法、系数、版本随数字出现。
3. **不重复计数**：系列去重有说明、有数字。

- 规则："同一系列的多个商品共享同一批评论时，渠道或单元合计按评论 ID 去重，不重复计入。"

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者 → 无权限页。
- 操作者 → 概览、月度状态表；估算对照默认 Home Depot、最近完整月 2026-10。

### 6.2 核心操作流程

```
评论 VP 追踪完成一个月份（PAGE-F23-01）
   └→ 系统自动并入：商品、排名、月度 VP / 非 VP → 按商品 ID 与渠道关联打标结果（AC-F28-01）
        └→ 本页该月显示"已并入"；新商品进入打标（PAGE-F18-01）

上传追踪器导出 → 识别"商品月度明细" → 逐月判断是否完整
   ├─ 缺表 → 阻断
   └─ 并入完整月；未完整月只作参考（AC-F28-02）

估算对照 → 切换渠道 / 月份 → 并排看两种方法
   └→ 要改系数或在用方法 → PAGE-F27-01 品类配置

历史回补完成（PAGE-F23-01）→ 按评论日期逐月换算估算月销、首评月作上架月（AC-F28-06）
   └→ 按评论重叠合并评论家族（AC-F28-07）→ 计算覆盖与换手（AC-F28-08）→ 历史重建区刷新
        └→ 新商品页按规格打标（PAGE-F18-01）→ 历史 ≥ 20 个月 → PAGE-F19-01 渠道重算
```

## 7. 状态与边界

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 上传与已有月份重叠 | 按同一口径覆盖，评论按 ID 去重 |
| 系列共享评论 | 合计按评论 ID 去重；单个商品仍显示其页面上的评论数 |
| Wayfair VP 口径 | 只在 Wayfair 内比较，页面常驻说明 |
| 系数被修改 | 之后的估算使用新值，页面显示参数版本（AC-F27-03） |
| 首条评论早于回补起点 | 抓取起点前已有评论的商品页算老品；上架月不早于首条评论月 |
| 家族里有不在前 N 的商品页 | 2024 年起有评论的同家族商品页补抓页面规格并计入家族（Home Depot 共 1,904 个商品页，其中 598 个在榜）；已下架页面用评论里记的商品名 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| VP / 非 VP | 评论是否为 Verified Purchase；Wayfair 只有 Verified Purchase 计 VP |
| 评论换算月销 | VP 条数 × VP 系数 + 非 VP 条数 × 非 VP 系数，默认 50 / 20（AC-F28-03） |
| 排名平滑月销 | 用同时有排名和评论换算销量的商品拟合排名—销量平滑曲线后，按排名换算（AC-F28-04） |
| 锚点 | 同时有榜单排名和评论换算销量的商品；少于 10 个不提供排名平滑法 |
| 完整月 | 自然月已结束且采集覆盖整月；未完整月只作参考 |
| 参数版本 | 换算系数与估算方法的版本号，修改后递增 |
| 重建月销 | 按评论日期，每个商品页每月 VP 条数 × VP 系数 + 非 VP 条数 × 非 VP 系数（同 AC-F28-03 口径） |
| 上架月 | 商品页（变体）首条评论月 |
| 评论家族 | 首页评论 ID 重叠 ≥ 一半、或评论里记着对方商品页 ID 的商品页合并为一个家族；家族是该渠道分析与份额计算单位，评论只计一次（AC-F28-07） |
| 前 N 覆盖估计 | 按排名分段的家族重建月销，用 51–300 名拟合 ln(月销) = a + b·ln(排名) 外推长尾，前 N 占类目估计总量的比例；只给量级 |
| 前 50 半年重合率 | 前后两个窗口按重建月销排的前 50 家族重合比例；只含今天仍在前 N 的家族，是上限 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 上传文件 | 上传 | .xlsx，含"商品月度明细"表 | 阻断并说明重新导出方式 |
| 完整月 | 并入 | 月份已结束且覆盖整月 | 标"仅参考"，不计入 |
| 去重 | 合计 | 按评论 ID 唯一 | — |

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 从评论追踪进入 | 评论 VP 追踪完成一个月份后，各渠道商品、排名、月度 VP / 非 VP 数并入分析库，并按商品 ID 与渠道关联打标结果（AC-F28-01） |
| F-02 | 上传导出 | 上传含"商品月度明细"表的 Excel 后按同一口径并入；未完整月份标"仅参考"且不计入（AC-F28-02） |
| F-03 | 评论换算法 | 任一其他渠道商品或单元的月销 = VP × VP 系数 + 非 VP × 非 VP 系数（默认 50 / 20），并注明方法与系数（AC-F28-03） |
| F-04 | 排名平滑法 | 锚点 ≥ 10 的渠道可在本页对照两种方法；锚点 < 10 时不提供该方法并提示（AC-F28-04） |
| F-05 | 系列去重 | 同系列共享评论的商品，渠道或单元合计按评论 ID 去重（AC-F28-05） |
| F-06 | 渠道内比较 | 页面不出现跨渠道绝对销量对比；Wayfair 有口径说明（AC-F29-02） |
| F-07 | 按评论日期重建（AC-F28-06） | 回补完成后，每个商品页 2024-01 起逐月 VP / 非 VP 评论数换算成估算月销并入该渠道分析库，首条评论月作上架月 |
| F-08 | 评论家族（AC-F28-07） | 共享评论的商品页合并为一个家族；家族列表与抽屉能看到家族包含哪些商品页；合计时评论只计一次 |
| F-09 | 覆盖与换手（AC-F28-08） | 每个渠道显示月份范围、商品页数、家族数、评论数、前 N 覆盖估计、前 50 半年重合率，并常驻"只含当前仍在榜的商品"的幸存者偏差说明 |
| F-10 | 未回补状态 | Lowe's / Wayfair 未回补时显示"未回补 · 未验证"，不编造重建数字，提供"去回补" |
