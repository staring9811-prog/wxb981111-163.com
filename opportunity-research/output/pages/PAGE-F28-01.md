## 2. 页面概述

### 2.1 一句话定位

把 Home Depot / Lowe's / Wayfair 的月度评论数据并进分析库，并看清每个渠道的月销是怎么估出来的。

### 2.2 存在理由

1. 其他渠道没有月销数据，只能用评论数估算；不说明方法和系数，估算值会被当成实测（AC-F28-03）。
2. 同系列多个尺寸共享一批评论，不去重会把同一条评论算好几次（AC-F28-05）。
3. wen 提出排名平滑作为第二种方法，需要和评论换算并排对照才能判断哪个更可信（AC-F28-04）。
4. 历史数据来自追踪器导出的 Excel，需要上传并入且排除未完整月份（AC-F28-02）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 完整并入 | 评论 VP 追踪完成一个月份后，该月三个渠道的商品、排名、VP / 非 VP 数 100% 进入分析库 |
| 去重 | 渠道或单元合计中同一评论 ID 只计 1 次 |
| 方法透明 | 每个估算月销都注明方法与系数（参数版本） |

### 2.4 不做什么（范围边界）

- **不在本页采集评论**：采集在 PAGE-F23-01 评论 VP 追踪。
- **不在本页改系数或切换方法**：在 PAGE-F27-01 品类配置中修改（AC-F27-03、AC-F28-04），本页只显示当前值并提供入口。
- **不跨渠道比较绝对销量**：Wayfair 的 VP 口径不同，各渠道只在渠道内比较（AC-F29-02）。
- **不处理 Amazon**：Amazon 在 PAGE-F17-01。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 仅操作者 wen；其他角色无入口，直接访问显示无权限 |
| 使用频次 | 每月评论采集后查看 1 次；调整估算方法前对照 |

### 3.2 核心使用场景

**场景 A：月度采集后确认并入**：评论 VP 追踪 2026-11-02 完成 2026-10 采集 → 系统自动并入 → wen 打开本页看到三个渠道 2026-10 都"已并入"，去重后评论 HD 412、Lowe's 455、Wayfair 871 条。
**场景 B：补历史数据**：上传追踪器 10 月 12 日导出的 Excel → 系统识别 2026-01 至 09 为完整月并入，2026-10（截至 10-12）为未完整月，只作参考不计入。
**场景 C：对照两种方法**：切到 Home Depot → 看到排名平滑法可用（锚点 46 个）→ 逐个商品对照两种估算差异，排名靠后的小商品平滑法偏高 30–40% → 决定仍用评论换算法。
**场景 D：Wayfair 不能用排名平滑**：锚点只有 8 个，页面提示"少于 10 个，不提供该方法"。

### 3.3 用户核心诉求

1. **知道数据齐不齐**：每渠道每月是否已并入、来自哪里。
2. **知道估算怎么来的**：方法、系数、版本随数字出现。
3. **不重复计数**：系列去重有说明、有数字。

## 5. 界面内容

### 5.1 元素清单

**页头**
- 主按钮"上传追踪器导出"→ 打开上传抽屉。
- 链接"评论 VP 追踪"→ PAGE-F23-01。
- 汇总："2026-01 至 2026-10 · 3 个渠道 · 650 个商品 · 去重评论 14,569 条"。

**渠道概览卡（示例）**

| 渠道 | 商品 | 去重评论（1–10 月） | 覆盖月份 | 当前估算方法 | 排名平滑 |
| :--- | ---: | ---: | :--- | :--- | :--- |
| Home Depot | 210 | 3,325 | 10 / 10 | 评论换算 VP×50 + 非 VP×20（参数 v1） | 可用（锚点 46 个） |
| Lowe's | 190 | 3,850 | 10 / 10 | 同上 | 可用（锚点 31 个） |
| Wayfair | 250 | 7,394 | 10 / 10 | 同上；VP 仅 Verified Purchase | 不可用（锚点 8 个，需 ≥ 10） |

- Wayfair 卡上常驻说明："Wayfair 只有 Verified Purchase 计 VP，口径与另两个渠道不同，绝对销量只在 Wayfair 内比较。"

**月度并入状态表**
- 行：三个渠道；列：2026-01 至 2026-10；单元格：去重评论数 + 状态（已并入 / 未完整月仅参考 / 本月无数据）+ 来源标记（追踪 / 上传）。
- 示例 2026-10：HD 412、Lowe's 455、Wayfair 871，来源"评论 VP 追踪"；2026-01 至 09 来源"上传"。

**并入来源记录（示例）**

| 时间 | 来源 | 月份 | 渠道 | 结果 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-11-02 14:30 | 评论 VP 追踪（2026-10 采集） | 2026-10 | HD / Lowe's / Wayfair | 已并入：650 个商品，去重评论 1,738 条 |
| 2026-10-12 16:05 | 上传 `评论月度VP_导出_20261012.xlsx`（商品月度明细） | 2026-01 至 2026-09 | HD / Lowe's / Wayfair | 已并入 9 个完整月；2026-10（截至 10-12）未完整，只作参考，不计入 |

**估算方法对照**（渠道切换：Home Depot / Lowe's / Wayfair；月份选择，默认 2026-10）
- 方法说明行："评论换算：VP 条数 × 50 + 非 VP 条数 × 20（参数 v1，2026-11-03）"；"榜单排名平滑：用同时有排名和评论换算销量的 46 个商品拟合排名—销量曲线"；入口"在品类配置中修改"→ PAGE-F27-01。
- 当前在用方法用徽章标出。
- 对照表字段：商品（名称、渠道商品 ID、系列）、榜单排名、VP、非 VP、评论换算月销、排名平滑月销、差异。全部月销带"估算"标签。
- 示例（Home Depot 2026-10）：

| 商品 | 排名 | VP | 非 VP | 评论换算 | 排名平滑 | 差异 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| Glacier Bay Bannister 36 in. 单盆带台面 | 3 | 6 | 4 | 380 | 352 | −7.4% |
| Home Decorators Collection Sonoma 48 in. 双盆（系列 4 款共享评论） | 7 | 3 | 5 | 250 | 268 | +7.2% |
| Glacier Bay Everdean 30 in. | 12 | 2 | 6 | 220 | 205 | −6.8% |
| Home Decorators Collection Merryfield 24 in. | 18 | 1 | 7 | 190 | 171 | −10.0% |
| Eviva Smile 30 in. 壁挂 | 35 | 1 | 2 | 90 | 118 | +31.1% |
| Glacier Bay Shaila 61 in. 双盆 | 52 | 0 | 3 | 60 | 84 | +40.0% |

- 锚点少于 10 个的渠道（Wayfair）：排名平滑列显示"不可用"，提示"同时有排名和评论换算销量的商品只有 8 个，少于 10 个，不提供榜单排名平滑法"（AC-F28-04）。

**同系列去重说明**
- 规则："同一系列的多个商品共享同一批评论时，渠道或单元合计按评论 ID 去重，不重复计入。"
- 示例："Home Decorators Collection Sonoma 系列 30 / 36 / 48 / 60 in. 共 4 个商品共享评论；2026-10 每个商品页都显示同样 8 条评论，去重前合计 32 条，去重后 8 条。"
- 本月统计：Home Depot 去重前 503 条 → 去重后 412 条（23 个系列 / 71 个商品共享评论）；Lowe's 521 → 455；Wayfair 902 → 871。

### 5.2 上传追踪器导出（抽屉）

- 文件*：评论 VP 追踪器导出的 .xlsx，需含"商品月度明细"表（AC-F28-02）。
- 上传后显示识别结果：渠道、月份清单、每月是否完整（完整月并入；未完整月只作参考、不计入）、商品数、评论数。
- 缺少"商品月度明细"表时阻断："文件里没有'商品月度明细'表，请用评论 VP 追踪器的'导出 Excel'重新导出"。
- 与已有月份重叠时提示："2026-09 已有数据（来源：上传 10-12），按同一口径覆盖，评论按 ID 去重"。
- 按钮：取消 / 并入。

### 5.3 辅助信息

- 所有估算月销旁带"估算"标签与参数版本；缺失值显示"无数据"。

## 6. 交互流程

### 6.1 页面加载与初始化

- 非操作者 → 无权限页。
- 操作者 → 概览、月度状态表；估算对照默认 Home Depot、最近完整月 2026-10。

### 6.2 核心操作流程

```
评论 VP 追踪完成一个月份（PAGE-F23-01）
   └→ 系统自动并入：商品、排名、月度 VP / 非 VP → 按商品 ID 与渠道关联打标结果（AC-F28-01）
        └→ 本页该月显示"已并入"；新商品进入打标（PAGE-F18-01）

上传追踪器导出 → 识别"商品月度明细" → 逐月判断是否完整
   ├─ 缺表 → 阻断
   └─ 并入完整月；未完整月只作参考（AC-F28-02）

估算对照 → 切换渠道 / 月份 → 并排看两种方法
   └→ 要改系数或在用方法 → PAGE-F27-01 品类配置
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 空状态 | 还没有任何其他渠道数据 | "还没有 Home Depot / Lowe's / Wayfair 的数据。在评论 VP 追踪里采集一个月份，或上传追踪器导出的 Excel。"按钮：去评论 VP 追踪、上传 |
| 加载态 | 首次进入 | 卡片与表格骨架条 |

| 某渠道本月无数据 | 采集失败（如 Bright Data 失败只采了 HD） | 单元格"本月无数据"，扫描和决策卡标"该渠道本月无数据"，其他渠道照常（PRD §5.3） |

| 排名平滑不可用 | 锚点 < 10 | 对照表该列"不可用"+ 原因 |
| 错误态 | 上传文件缺表 / 格式不对 | 抽屉内阻断，写明缺什么、怎么重新导出 |
| 无权限 | 非操作者 | "无权限：其他渠道数据仅操作者可用" |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 上传与已有月份重叠 | 按同一口径覆盖，评论按 ID 去重 |
| 系列共享评论 | 合计按评论 ID 去重；单个商品仍显示其页面上的评论数 |
| Wayfair VP 口径 | 只在 Wayfair 内比较，页面常驻说明 |
| 系数被修改 | 之后的估算使用新值，页面显示参数版本（AC-F27-03） |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| VP / 非 VP | 评论是否为 Verified Purchase；Wayfair 只有 Verified Purchase 计 VP |
| 评论换算月销 | VP 条数 × VP 系数 + 非 VP 条数 × 非 VP 系数，默认 50 / 20（AC-F28-03） |
| 排名平滑月销 | 用同时有排名和评论换算销量的商品拟合排名—销量平滑曲线后，按排名换算（AC-F28-04） |
| 锚点 | 同时有榜单排名和评论换算销量的商品；少于 10 个不提供排名平滑法 |
| 完整月 | 自然月已结束且采集覆盖整月；未完整月只作参考 |
| 参数版本 | 换算系数与估算方法的版本号，修改后递增 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 上传文件 | 上传 | .xlsx，含"商品月度明细"表 | 阻断并说明重新导出方式 |
| 完整月 | 并入 | 月份已结束且覆盖整月 | 标"仅参考"，不计入 |
| 去重 | 合计 | 按评论 ID 唯一 | — |

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 从评论追踪进入 | 评论 VP 追踪完成一个月份后，各渠道商品、排名、月度 VP / 非 VP 数并入分析库，并按商品 ID 与渠道关联打标结果（AC-F28-01） |

| F-05 | 系列去重 | 同系列共享评论的商品，渠道或单元合计按评论 ID 去重（AC-F28-05） |
| F-06 | 渠道内比较 | 页面不出现跨渠道绝对销量对比；Wayfair 有口径说明（AC-F29-02） |
