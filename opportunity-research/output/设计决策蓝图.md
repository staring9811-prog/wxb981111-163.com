## 1 盘子

- **scope**：第一期（与 requirements Metadata 一致，全部条目 Stage = 第一期）。功能 F01–F14，品类为亚马逊美国 · 浴室柜（节点 6810202011）。
- **端形态**：只有一个操作端——wen 的 Windows 电脑上、只在本机可访问的网页（Chrome / Edge），不设登录（NFR-006）。对外只有两种导出文件：Excel 和单文件网页报告；网页报告要在 Windows / macOS 的 Chrome、Edge、Safari 上离线打开（AC-F12-03）。
- **屏幕适配（DD-3）**：
  - 应用按 1366–1920 宽设计。宽度 ≥ 1600 时显示全部列；1366–1599 时收起次要列（表头"列"菜单可调出），侧栏可收成图标栏。
  - 小于 1366 不专门适配，只让表格区域横向滚动，页面本身不横向滚动。
  - 网页报告单栏居中、最大宽度 1200，1024 宽以上完整可读，可直接打印。
- **工作台聚合（DD-1，PAGE-F03-01 本月工作台）**：打开系统的第一屏，回答"这个月做到哪一步、有什么要处理、结论是什么"。
  - **页头**：本月是哪个月、数据到哪个月（例："2026-10 月更 · 数据至 2026-09"，见 DEC-005），当前口径，判定卡状态。
  - **8 步进度条**：导入校验 → 字段约定 → 数据体检 → SPU 归并 → 成败与信号 → 回测 → 判定卡与排序 → 记录与导出。每步显示状态、用时，并给出去处理的按钮。
  - **待处理区**：阻断项、未确认字段、未"已知晓"的体检预警、待审合并建议、"需重算"、到期对账、备份失败。
  - **本月结论**：排名前 5 的细分及区间、锦囊动作；判定卡未验证时只显示"未验证，不可作为立项结论"和原因。
  - **用时**：本次月更已用时间对照 4 小时目标；首跑工作日对照 5 天目标。
  - **备份状态**：上次成功备份时间；失败时显示原因。

- **主流程走向**（PRD §4.1）：
  1. 工作台点"导入数据包"，进入数据包页，导入后自动跳到校验报告。
  2. 没有阻断项时，校验报告页给出"去确认字段约定"。
  3. 依次处理字段约定、体检预警和合并建议。
  4. 在工作台点"运行计算"，算出成败与信号；再点"运行回测"，自动生成判定卡、锦囊和排序，并保存当月快照。
  5. 在本月排序页记录立项决定、导出报告，导出后自动备份。

## 4 页面地图与设计深度

### 4.1 本期页面（第一期，26 个）

通用状态：
- 每页都有加载态：骨架屏，数字区显示占位。
- 第一期没有"无权限"态（单用户）。
- 下面只写各页特有的空态、错误态和特殊状态。

**F01 数据导入与约定校验**
- **PAGE-F01-01 数据包（列表 + 导入）**
  - **骨架**：导入区 → 数据包版本列表。
  - **导入区**：选择 zip 或文件夹；读出清单文件后，预览类型（历史 / 截面）、品类、覆盖月份和文件清单。
  - **版本列表**：版本号、类型、覆盖月份、导入时间、指纹前 8 位、校验结论、"查看校验报告"。
  - **空态**：说明数据包需要哪些文件（约定 v1 的 C1–C7、v1.1 的 S1–S3 + C4）。
  - **特殊状态**：
    - 上传中、校验中：显示进度。
    - 重复导入：提示"该数据包已导入"，并链接到已有版本（AC-F01-05）。
    - 清单缺失或类型无法识别：显示阻断（AC-F01-06）。
    - 文件无法读取：显示原因。
- **PAGE-F01-02 校验报告**
  - **骨架**：结论条（通过 / 有警告 / 阻断、类型、版本号、能否计算）→ 文件 × 检查项矩阵（必需文件、必需字段、主键唯一、日期与数值解析、月份覆盖，每项给结果和受影响行数）→ 阻断明细（文件、字段、不超过 5 个示例行号）→ 警告排除行号（可展开）→ "去确认字段约定"。
  - **状态**：有阻断时禁用后续计算，提示修好数据后重新导入（AC-F01-02）。
  - **截面数据包**：缺评论痛点表时，在结论条注明"缺少痛点信号，回测先用另两类信号"（PRD §5.3）。

**F02 字段约定确认**
- **PAGE-F02-01 字段约定（含"版本记录"抽屉）**
  - **骨架**：
    1. 页头：当前约定版本、待确认数量（新数据包只列变化字段，AC-F02-06）、已确认比例。
    2. 筛选：全部 / 待确认 / 变化字段 / 快照 / 按规则用。
    3. 字段表：文件、字段、含义、粒度、时点、性质、建议用法、体检证据、确认状态与来源（逐项 / 批量）。
    4. 行内展开：可修改含义和用法。
    5. 批量操作："按建议批量确认"（AC-F02-03）。
    6. "保存为新版本"：先列出变动摘要，再提示依赖旧约定的结果将标为需重算（AC-F02-07）。
    7. "版本记录"抽屉：每版变动字段的前后值、操作人、时间。
  - **重点提示**：已知口径疑点固定置顶，包括上架日期取最早时间、首次评分可能是父体口径、子体销量为估算、价格和评分为快照。
  - **空态**：还没有数据包时，引导去导入。
  - **未确认提示**：只要有未确认字段，页头常驻"未确认的字段不参与计算"（AC-F02-04）。
  - **离开拦截**：有未保存修改时离开，弹窗提示。

**F03 自动体检与异常提示**
- **PAGE-F03-01 本月工作台**：骨架见 §1。
  - **空态**：首次使用、没有数据包时，显示 8 步说明和"导入第一个数据包"。
  - **计算中**：对应步骤显示进行中，并显示任务进度。
  - **步骤失败**：该步标红，显示原因，可重试。
  - **需重算**：页顶横幅加"全部重算"（DEC-016）。
- **PAGE-F03-02 数据体检**
  - **骨架**：6 个固定体检项（REQ-F03-01），每项给数值、分母、预警阈值、状态（正常 / 预警 / 已知晓）和不超过 5 条样例。
  - **预警处理**：预警项可"标为已知晓"，必须填写说明（AC-F03-02）。
  - **只读证明**：页脚写明"体检不修改源数据"，并显示导入时和当前的指纹比对结果（AC-F03-03）。
  - **特殊状态**：数据里没有"过去一个月购买"标签时，该项显示"不适用"。

**F04 新品判定与 SPU 归并**
- **PAGE-F04-01 新品与 SPU**
  - **骨架**：
    1. 批次概览条：按上架月份显示起量新品数、命中、未命中、观察中、数据不全，以及未起量排除数（AC-F05-12）；截面口径显示截面命中、截面未命中、观察中、老品。
    2. 筛选：批次、成败、标记（新变体 / 疑似重新上架）、归并来源（编号 / 已确认建议 / 暂按父体）。
    3. SPU 表：SPU、品牌、代表标题、子体数、上架日（来自哪个子 ASIN）、批次、标记、成败、命中方式与月份、证据小标签。
    4. 点击一行，进入 SPU 成败明细。
  - **未确认建议提示**：页头提示"x 条合并建议未确认，相关子体暂按父 ASIN 计"（AC-F04-03），并链接到合并建议页。
  - **口径标注**：参照人群标注常驻（AC-F05-11）。
- **PAGE-F04-02 合并建议**
  - **骨架**：
    1. 计数：待审 / 已确认 / 已拒绝。
    2. 按匹配依据筛选（DEC-009）。
    3. 建议表：品牌、涉及父 ASIN、子 ASIN 数、匹配依据、标题对照（AC-F04-02）。
    4. 行展开：逐个父体对照标题主干、类型属性、五点摘要。
    5. 操作：单条确认或拒绝；筛选后批量确认（AC-F04-04）。
    6. "已生效归并"分栏：可拆分或修改，并留痕（AC-F04-05）。
  - **空态**：数据包已提供 SPU 编号时，显示"已按编号归并，无需审核"（AC-F04-01）。
- **PAGE-F05-01 SPU 成败明细**（F04 与 F05 共用）
  - **骨架**：
    1. 页头：SPU、品牌、批次、成败状态与口径标注、是否起量。
    2. 判定说明句，例："第 3 个月（2026-03）SPU 销售额 $112,400 ≥ $100,000 → 命中"。
    3. 月龄 1–6 网格：每格显示最好 BSR 及对应子 ASIN、SPU 月销售额、父体月销量；达成的格子高亮；缺数据的格子注明"缺数据"。
    4. 子体表：子 ASIN、父 ASIN、颜色 / 尺寸、上架日、首评日、新变体标记、属性（父体回填标记）、月销量和销售额。
    5. 归并来源：编号或建议 ID，以及确认人和时间。
    6. 疑似重新上架的原因。
    7. 追溯信息：数据包、约定、配置版本和来源记录主键（NFR-003）。
  - **按状态显示**：
    - 观察中：显示还剩几个月。
    - 数据不全：列出缺的月份（AC-F05-05）。
    - 截面未命中：列出没观察到的月龄（AC-F05-07）。
    - 老品：只展示，不判定（AC-F05-10）。

**F06 信号计算**
- **PAGE-F06-01 信号**
  - **骨架**：
    1. 选月份 T 和口径。
    2. 细分表：细分（维度组合）、样本量、需求在涨（同比 + 关键词数）、新品进得去（命中 / 已判定）、结构类痛点占比（分子 / 分母）、高销低评占比（商品数）、4 个候选信号（标"候选"）、父体回填占比。
    3. 列可排序；点击一行打开细分详情。
    4. 页头列出本次计算排除的未确认字段（AC-F02-04）。
  - **口径规则**：缺数据显示"无数据"，不显示 0。截面口径下，"新品进得去"列显示"截面模式不适用"，候选信号显示参与计算的老品数（AC-F06-11、AC-F06-12）。
  - **空态**：还没计算时，给出"运行计算"。
- **PAGE-F06-02 细分详情（抽屉）**
  - **骨架**：
    1. 细分定义（各维度取值）。
    2. 各信号随月份的小趋势图。
    3. 当月各信号的值与分子分母。
    4. 痛点构成（结构类痛点代码的前几名）。
    5. 父体回填占比。
    6. 细分内的新 SPU 及成败（链接到成败明细）。
    7. 适用锦囊。

**F07 时间切分回测**
- **PAGE-F07-01 回测**
  - **骨架**：
    1. 口径切换。两种结论都有时，顶部并列显示两张结论卡，并注明"以历史模式为准"（AC-F07-12）。
    2. 结论卡：达标 / 达标（截面）/ 未达标；未达标时按"数据不足 / 细分样本不足 / 信号无区分度"给出原因和数值。旁边固定列出局限（AC-F07-07）。
    3. 批次切分：两组的月份范围，各组新 SPU 数或"新品-月"行数（AC-F07-01、AC-F07-09）。
    4. 信号与规则评估表：前 20% 命中率 [Wilson 90%]、全类目平均、倍数 [重抽样 90%]、样本量，与 4 个现用指标对比。
    5. 控制干扰因素前后对比（AC-F07-06）。
    6. 样本不足的细分，以及可合并的相邻分档。
    7. 截面口径：细分 × 月龄 1–6 达标率表，显示达标数和观察数（AC-F07-13）。
    8. 被拒绝的快照字段（AC-F02-05）。
    9. "运行回测"按钮，以及本次运行的随机种子与各项版本号。
  - **状态**：
    - 未运行：给出"运行回测"。
    - 运行中：显示进度，同时只能跑一个任务（DEC-010）。
    - 批次少于 3 个：直接显示"未达标：数据不足"和已判定批次数（AC-F07-08）。
    - 失败：显示原因并可重试。

**F08 判定卡与立项锦囊**

**F09 细分排序与区间**
- **PAGE-F09-01 本月排序**
  - **骨架**：

**F10 预测台账与对账**
- **PAGE-F10-01 台账 · 月度快照**
  - **骨架**：
    1. 台账三个标签：月度快照 / 立项记录 / 到期对账。

### 4.3 后续不可逆约束（DEC-014）

现在不预留、以后返工代价高的只有下面几项，本期按它们建数据和代码，不提前建设第二、三期功能：

1. **商品身份**：商品身份 = 平台 + 站点 + 商品编号（本期为 amazon / US / ASIN）。
2. **品类编号**：品类编号贯穿全部业务数据，包括数据包、约定、配置、SPU、信号、回测、快照、立项和规则。
3. **操作留痕**：每条写入记录都带操作人和时间；品类配置带负责人。
4. **计算与网页分离**：业务计算独立于网页；命令行能跑完整流程，结果与网页一致（NFR-004）。
5. **存储可迁移**：数据库结构由迁移脚本管理，不依赖只有 SQLite 才有的特性，可迁到 PostgreSQL。文件按相对路径和指纹存放。
6. **只追加不覆盖**：版本类记录（约定、配置、规则、判定卡、快照、立项记录）只追加；快照存内容指纹。

## 5 通用交互范式

- **列表**：
  - **分页**：每页 50 行（可选 100 / 200），不用无限滚动；表头固定。
  - **查找**：筛选条件以标签形式放在表格上方，可按列排序，搜索框支持 ASIN / 品牌 / 标题。
  - **批量操作**：勾选后底部出现批量操作条。
  - **数字显示**：数字右对齐、等宽，数字旁带证据小标签。
- **表单**：
  - **校验时机**：离开输入框时校验，提交时再整体校验一次；必填项标"*"。
  - **草稿与版本**：
    - 字段约定、品类配置、规则在"保存为新版本"之前都是草稿，存在本机，离开页面不丢；有未保存修改时离开会提示。
    - 立项记录和自家上架数据在弹窗里一次提交。
- **反馈**：
  - **轻提示**：例如"已确认 12 个字段"。
  - **确认弹窗**：用于会产生后果的操作——保存新版本（会触发需重算）、批量确认、拆分归并、恢复备份。
  - **常驻横幅**：用于持续状态——未验证、截面口径、需重算、阻断。
  - **长任务**：顶栏任务指示加页面内进度。没有站内信。
- **统一状态词**：
  - 成败：命中 / 未命中 / 观察中 / 数据不全；截面口径为截面命中 / 截面未命中 / 观察中 / 老品。
  - 回测结论：达标 / 达标（截面）/ 未达标；判定卡多一个"未验证"。
  - 其他标记：需重算、样本不足、无数据、候选。
- **需重算（DEC-016）**：
  - 字段约定、SPU 归并或品类配置变了，依赖它们的结果显示"需重算"横幅，但仍可查看旧结果。
  - 由你在工作台点"全部重算"，或在页内点"重新计算"；系统不自动重算，以免悄悄覆盖。
- **单任务（DEC-010）**：
  - 同一时间只运行一个计算任务。
  - 再次发起时提示"x 正在运行，完成后再试"。
  - 任务失败时保留上一次成功的结果。

## 6 视觉风格锚点

- **明暗**：只做浅色（DD-2）。白天办公长时间看表格，导出物也要打印，深色没有好处。
- **风格**：冷静数据台——中性灰白占画面 80% 以上，信息密度高但留白规整，几乎不用装饰。参考 Linear 的克制和 Stripe 后台的表格清晰度。
- **Category**：Backend & Data（以数据表格、数字证据为中心的分析工作台）。
- **情绪**：冷静的掌控感和可信——每个数字都说得出出处。
- **交互哲学**：色彩响应。悬停、选中、展开只改变底色和边框，不用阴影抬升，也不用位移动画。
- **字体**：全部用系统字体，本机应用和离线报告都不加载外部字体。
  - 正文：Segoe UI、微软雅黑 UI、苹方、Noto Sans SC。
  - 数字：使用等宽数字。
  - 编号、ASIN、指纹和证据小标签：Cascadia Mono、Consolas。
- **色彩方向**（精确色值和对比度在 DESIGN.md 中核验）：
  - 强调色为深钢蓝，每屏最多 2 处。
  - 语义色只用于状态：命中为绿，预警为琥珀，阻断为红；截面口径用一种低饱和的紫色标签。
  - "未命中"用中性灰，不用红色——它是结果，不是错误。
- **设计签名（DD-2）**：证据小标签。关键数字旁都有一个小号等宽标签，写明样本量（n=128）、数据性质（估算 / 实测 / 推导 / 人工）、快照、父体回填占比、截面、候选；点开可看来源。命中率区间统一画成"区间条"。截图给外人看，能从这两点认出是这个产品。

  - 数据导入：数据包版本、文件与指纹、校验结果。

  - 分析结果：细分、信号值（月份、细分、信号、值、分子、分母、标记）、回测（口径、种子、版本、切分、结果、结论）。

  - 规则与运行：规则与规则版本、体检结果与"已知晓"、步骤运行记录、计算任务、备份记录。

  - 出口：Excel 和网页报告文件，以及备份目录。

  - **适用条件**：只在同品牌、不同父 ASIN 之间提建议，每条建议注明依据。

    3. **五点描述相同**：五点描述去掉格式后完全相同。
  - **生效规则**：只有确认后才生效。可以按依据批量确认，例如先批量确认"标题主干相同"，再逐条看其余两类。

## 8 技术栈 & 架构 & 部署

具体版本和维护状态在《技术方案》中从官方来源核实，这里只定方向。

- **语言与计算**：Python。和现有小试脚本、旧技能包一致，统计库成熟。
  - 计算库：pandas、numpy、statsmodels（逻辑回归、Wilson 区间）、scipy。
  - 可复现：重抽样用固定随机种子。
- **后端**：FastAPI，只监听 127.0.0.1（NFR-006）。业务逻辑是独立的 Python 包，配一个命令行入口，网页和命令行调用同一套代码（NFR-004）。
- **前端**：服务端渲染页面（Jinja2 模板）加 HTMX，做局部刷新和任务进度。
  - 所有前端文件随程序带在本地，不走任何网络加载。
  - 图表由服务端直接生成 SVG。
  - 不需要 Node 构建链。
- **存储**：
  - 数据库：SQLite 单文件，经 SQLAlchemy 访问，用 Alembic 管理结构迁移；第二期可迁 PostgreSQL。
  - 文件：数据包只读副本、导出文件和日志放在本机数据目录。
- **导出**：Excel 用 openpyxl；网页报告用模板生成单个 HTML，样式和 SVG 内嵌，展开用原生 `<details>`，不依赖脚本。
- **部署（DEC-015，已确认）**：
  - **采用**：给 wen 一个离线安装包 zip，自带 Python 运行环境和全部依赖，解压后双击"启动"。脚本会启动本机服务并自动打开浏览器，安装和运行都不需要联网，也不受电脑上已有 Python 版本影响。
  - 未采用的备选：wen 自己装官方 Python，再用国内镜像（清华 / 阿里云 PyPI）在线安装依赖。
- **国内可达**：运行时零外网依赖；安装时最多用到国内 PyPI 镜像。代码托管在 GitHub（staring9811-prog/wxb981111-163.com），GitHub 访问不稳定时，离线包可以用任意方式拷到 wen 的电脑上。
- **第二期**：迁到国内云主机或香港服务器（大陆服务器需备案，见 `evidence/额度测算.md`），换 PostgreSQL，加登录与权限。本期不建设。

  - 每次导出后，自动在指定目录生成带时间戳的备份，内容为台账、策略库、字段约定、品类配置和全部确认记录，并附数据包指纹清单。
  - 失败时显示原因和上次成功时间，不动旧备份。
  - 恢复前先自动备份当前状态（DEC-008）。
  - 数据包原件较大且你手里都有，不进入备份；恢复后需要时重新导入，指纹会自动识别。
- **审计与日志**：
  - 每一次确认、修改、批量操作、立项记录、恢复都写入操作记录（操作人、时间、前后值）。
  - 步骤用时写入运行记录（F14）。
  - 程序日志按天滚动，存在本机。
- **可逆性**：
  - 版本类记录只追加，可回看历史版本。
  - 归并可以拆分，拆分会留痕并标需重算。
  - 快照不可改。
  - 立项记录不可改，可追加更正（DEC-007）。
  - 第一期不提供删除业务数据的功能（没有对应需求）。
