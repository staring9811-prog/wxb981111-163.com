# 输入清单

开工前确认以下资料。已有的直接用，缺的只问会改变结论的。

## 用户提供
| 资料 | 用途 | 缺了怎么办 |
|---|---|---|
| 历史立项 / 发布文件（飞书链接或 docx） | 格式和口吻的第一参考 | 用本 skill 的结构 |
| 本产品的立项文件（发布时） | 需求判断、差异化、产品定义 | 问 |
| 利润测算（截图 / xlsx / JSON） | 各平台上架价、促销价、结算价、利润、利润率 | 必须问，不能自己定价 |
| 渲染图、结构图 | 封面、产品定义 | 留位置 |
| 规格：尺寸、材质（每个部位）、抽屉结构、台面、包装、毛重、出厂价、供应商 | 规格章节 | 列"待补" |
| 款式差异（如两款材质不同） | 分列写 | 问 |
| 调研（红人、问卷） | 差异化依据 | 可省 |

## 自己取
| 数据 | 来源 |
|---|---|
| 各渠道商品表：ID、品牌、标题、主图、链接、价格、评分、评论数、月销、尺寸、拆装、形态、台面、柜体、元素 | 项目已有数据（卖家精灵导出、小平台抓取表） |
| 关键词搜索量趋势 | 卖家精灵关键词工具 |
| 竞品评论原文 | 商品页抓取 / 卖家精灵评论工具 |

## 商品表最少字段（cross_matrix.py 的输入）
`channel, pid, brand, title, price, rating, reviews, sales, 尺寸, 拆装, 形态, 台面, 柜体`
列名可以不同，用脚本参数映射。
