# 数据口径

## 月销
- 默认最近 3 个月月均（如 2026-08 至 10），文中注明月份。
- Amazon：卖家精灵类目导出的子体月销；按子体统计 ASIN 数。
- Home Depot / Wayfair：按评论推算。VP 评论 × 50 + 非 VP 评论 × 20，所以单月销量都是 10 的倍数，3 个月平均会出现个位数不为 0 的情况（如 357），这是平均造成的，不是错误。近一年无新评论 → 月销按 0，注明"2026 年无新评论"。
- Lowe's：带台面 Best Sellers 前 100，按排名档位估（5,000 / 1,000 / 500 / 125 等档），是估算，必须注明；无价格的链接单独注明不进价格图。
- 搜索范围：小平台通常是某关键词搜索前 150；样本只覆盖前 150，某材质"没有"要写"前 150 里没有"。

## 价格
- 竞品用当前售价；我们用**促销价**做差价比较，表里写上架价 / 促销价。
- 价格带分箱默认 <$200、$200–299、$300–399、$400–599、$600–899、≥$900，可按品类调整，确保我们的价格单独落在一档。

## 利润率
- Amazon、Lowe's SC：利润 ÷ 促销价。
- Home Depot、Wayfair、Lowe's VC：利润 ÷ 结算价；结算价 = 零售价 ÷ 加价倍数（常见 VC 1.7、HD 1.6、WF 2.1，以用户测算表为准）。
- 利润数字以用户的测算截图 / xlsx 为准；自己用测算台复算的结果和用户的不一致时，用用户的，并说明差异。
- 注明出厂价口径（FOB / 国内出货、是否去税）、头程、尾程、超重/超尺寸附加费；亏损渠道写"不做"。

## 打标
- 台面/台盆：陶瓷、树脂、人造大理石（Cultured Marble）、岗石、石英石、岩板、天然大理石、木板、未标。
- 柜体：刨花板（含）、MDF、胶合板、实木框架、实木。
- 拆装 / 整装 / 半整装；形态：落地式、悬浮式、开放式等。
- 标题里的英文材质（Cultured Marble）在中文文档里翻成中文。

## 常见坑
- 一句话结论前先查数据：写"没有""最便宜""第一"之前确认。
- 尺寸标真实值（25″、23.6″），归入尺寸段时注明。
- 多渠道同一产品不要重复计数。
- 评论按系列合并时（多尺寸共用评论），星级分布不能当单一尺寸的数据。
