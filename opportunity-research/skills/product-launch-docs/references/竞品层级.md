# 竞品层级与信息需求

## 为什么要分层
只放头部会让结论偏：头部往往是低价自营款，和我们不是同一个规格。必须同时摆出"同尺寸、同规格"的贵价款，读者才能看到我们的价格落在哪里、凭什么卖。

## 层级（每个渠道至少覆盖两层）

| 层级 | 怎么找 | 用来说明 |
|---|---|---|
| 同尺寸销量头部 | 目标尺寸 + 形态里月销最高的 3–5 款 | 这个渠道的需求主体是什么价格、什么配置 |
| 低价走量款 / 平台自营 | 自营品牌（Glacier Bay、Project Source、Style Selections、Home Decorators 等）或最低价段 | 量从哪来、品质短板（差评） |
| 同规格贵价款 | 同尺寸 + 同柜体/台盆材质，价格高于我们 | 我们便宜多少（价格优势） |
| 价格最接近款 | 和我们促销价相差最小的 1–2 款，不论配置；同尺寸没有时可跨尺寸，在"和我们比"里注明尺寸 | 同价位消费者还能选什么 |
| 同元素 / 同形态款 | 同元素（竖棱、藤编）或同形态（悬浮、开放式），跨尺寸也可 | 元素在该渠道有没有、卖不卖 |
| 跨形态参考（Amazon 常用） | 同尺寸的拆装款 | 拆装价格锚，说明整装的溢价是否合理 |

渠道里某层为空时要写出来（"Lowe's 前 100 没有 24″ MDF + 陶瓷盆的整装"），空本身就是结论。

## 每个竞品收集的字段

| 字段 | 说明 |
|---|---|
| 主图 | 下载到本地，表内宽约 2 cm |
| 品牌 · 型号 · 标题 · 链接 | 标题 HTML 转义要还原（`&quot;`→`"`），截断约 48 字；链接可点；品牌为空或"未知品牌"时从标题开头补 |
| 售价 | 当前售价；有促销写促销价 |
| 评分 / 评论数 | 评论数为页面显示的总数 |
| 月销 | 最近 3 个月月均，口径见 `数据口径.md` |
| 配置 | 拆装/整装、形态、台面/台盆材质、柜体材质（刨花板/MDF/实木/胶合板）、元素、颜色 |
| 尺寸 | 实际宽度（25″、23.6″ 这种要标真实值） |
| 上架时间 / 评论时间分布 | 判断新品还是老链接、近期是否还在卖（近一年无新评论 → 月销按 0） |
| 推荐率、星级分布 | 平台页面能取就取（Home Depot 有推荐率） |
| 差评原文 | 低分评论按问题归类，保留原话 + 年月 |

## 竞品表格式

列：主图 | 品牌 · 型号 · 链接 | 售价 | 评分 / 评论数 | 月销 | 配置 | 和我们比

"和我们比"写法（一句话，先说它是谁，再说差价和差异）：
- `24″ 第一，月销 1,350 件；刨花板 + 人造大理石，1–2 星占 10%；我们贵 $121，多 MDF、陶瓷盆、抽屉`
- `同规格（MDF + 陶瓷盆），评分 3.9；我们便宜 $149`
- `价位最接近，MDF + 岗石，月销 103 件；我们便宜 $69`
- 差价一律按**我们的促销价**算；多款式/多渠道价格时写区间（"我们贵 $61–78"）。
- 同规格的标粗"**同规格**"。

## 差评分析（对手评分差时必须做）
1. 星级分布表：评分/评论数、推荐率、5–1 星、1–2 星占比。
2. 抓最低分评论，按问题归类（评论文件里混有好评、无文字的，只用负面内容；星级、评论数以商品页为准，和商品表不一致时注明）：材质（刨花板发胀）、到货破损、安装（台面无法固定、挂墙不稳、下水对不上）、做工、尺寸/盆小、与描述不符。
3. 每类保留 1–3 条原话（英文原文 + 年月），注明产品。
4. 结论框：买家为什么买、不满意什么、哪几点我们能拉开。
5. 评论按系列合并（多尺寸共用）时注明。

## 各渠道取数提示
- Home Depot 商品页可抓（点 Customer Reviews → Lowest rating）；Lowe's 常返回 403，无法抓时如实注明。
- Wayfair 用搜索结果代表链接，SKU 号作为型号。
- Amazon 用 ASIN；同一父体多子体时按子体统计。
