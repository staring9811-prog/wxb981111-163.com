# 交叉看板图（市场格局 + 我们在哪）

一张二维表，让人一眼看到三件事：**需求集中在哪些格、哪些格是空的、我们插在哪一格**。

图的维度没有固定答案。不是默认"价格 × 台面"，要从这份立项 / 发布的**机会点**倒推：机会点在说明什么，图就要把那件事画出来。

## 一、怎么选维度：四步判断

### 第 1 步：把机会点写成一句"在 A 上，B 是空的 / 少的 / 贵的，我们补上"
从立项"机会点"、发布"核心结论"或用户的话里提炼。例：
- "小平台 24″ 整装在 $250–400 价位是空的，我们用同规格配置卡进去" → A = 价格，B = 台盆材质（同规格）
- "悬浮式的石材台面只有高价整装，我们用拆装价格做岗石台面" → A = 尺寸，B = 台面材质
- "大尺寸整装里没有藤编元素，石英石台面在大尺寸效率高" → A = 尺寸，B = 元素 / 台面
- "小平台头部全是刨花板，我们用 MDF" → A = 台面/台盆，B = 柜体材质

### 第 2 步：A、B 就是两条轴
- **我们的差异点所在的维度放横轴（列）**：材质、元素、柜体、形态。读者横着看，一眼看到"这一列很空 / 很贵"。
- **决定"在哪里比"的维度放纵轴（行）**：价格带、尺寸。我们的位置在这一维上是一行。
- 两条轴之一必须能定位我们（价格、尺寸或差异点本身），否则标不出黄框。

| 机会点在说明什么 | 纵轴 | 横轴 | 范围（固定条件） |
|---|---|---|---|
| 价位空档：某价位没有我们这种配置 | 价格带 | 台面/台盆 或 柜体 | 固定尺寸段 + 拆装方式 |
| 配置空档：某尺寸没有这种台面/材质，或只有高价 | 尺寸 | 台面/台盆材质 | 固定形态或拆装方式 |
| 元素空档：某元素在哪些尺寸没人做 | 尺寸 | 元素 | 固定形态/拆装 |
| 元素和价位：同元素在各价位的供给 | 价格带 | 元素 | 固定尺寸段 |
| 品质分层：低价靠差材料，我们用好材料 | 台面/台盆 | 柜体材质 | 固定尺寸段 |
| 形态机会：某形态在某尺寸少 | 尺寸 | 形态（落地/悬浮/开放） | 固定拆装方式 |
| 品牌格局：谁占着哪些尺寸 | 尺寸 | 品牌（前 6 + 其他） | 固定品类 |

### 第 3 步：定范围和每渠道几张
- 范围和正文口径一致，写进标题（"30″ 及以下整装""悬浮式"）。
- 每个渠道单独一张，不同渠道不要合并。
- 某渠道数据太少（几十款、多数格为空）时，换颗粒更粗的轴（尺寸改尺寸段、价格带合并），或只在正文用一张分档表说明。
- 机会点涉及两件事时可以出两张，例：Amazon 既要说"同价位没有整装"（价格 × 台面）又要说"整装集中在大尺寸石材"（尺寸 × 台面）。

### 第 3.5 步：空档在哪一维，哪一维就必须在图上
- 黄框必须落在"空档"上，或者落在能直接比出我们优势的格里。黄框落在别人已经卖得很好的格里，图就在说反话。
- 渠道里几乎没有我们这种形态（如 Home Depot、Lowe's 几乎没有悬浮式）：空档是"形态"，横轴就用形态（尺寸 × 形态），让"悬浮式"一列空出来；台面价格对比放到竞品表和正文，不要改用尺寸 × 台面把空档藏掉。
- 我们的差异列不能和其他类合并。例：我们是岗石，就不能把岗石和岩板并成"石材"，因为 Amazon 悬浮式里有 $370–540 的拆装岩板，而岗石只有 $484 以上的整装，并起来会把这个差别抹掉。
- 范围里混进非目标尺寸会让我们那一格失真（如 30″ 及以下的范围被 18–20″ 小柜灌满陶瓷盆格）：收窄到目标尺寸，或者在图注里写明。

### 价格分箱
- 每个渠道单独定分箱。我们的价格要单独落在一档，这一档不能同时装进对手主力价位。例：Home Depot 我们 $280，自营款 $219，默认的 $200–299 会把两者混在一起，要改成 $200–249 / $250–299。
- 同一渠道有两个价（Lowe's VC $280、SC $297），让它们落在同一档。

### 版面可读性
- 图要缩到 17–18 cm 宽放进 Word：横轴最多 4–5 个类，每类 4 个子指标（月销、款数、单款月销、评分）；超过 4 类就去掉"销量第一"。
- 类太多时合并和我们无关的小类（如"木板/其他"），我们的差异列保持单独。实在要放更多列，就把这一页设成横版。

### 第 4 步：自检——图能不能单独讲清楚机会点
看图的人只看这一张，能否说出"市场主要在 X，空档在 Y，我们在 Y"？不能就换轴。常见错误：
- 轴选了我们没有差异的维度（例：差异是柜体材质，却画了价格 × 台面，图上看不出差异）。
- 黄框落在一个本来就很大的格里，却没有说明我们凭什么在这一格卖（要在正文补价差或配置差）。
- 列太多（> 7）导致图太宽：合并小列（"其他石材"），或拆两张。

## 二、实际例子（来自已交付文件）

| 文件 | 机会点 | 图 | 我们的位置 |
|---|---|---|---|
| 24″ 半整装立项 | 小平台 24″ 整装两档：$159–219 刨花板自营 vs $429+ 同规格，中间空 | 每个小平台一张"价格带 × 台面"（30″ 及以下整装，分箱让我们单独一档）；Amazon 加一张"尺寸 × 台面"（全部整装） |
| 悬浮式发布：Home Depot / Lowe's | 渠道里几乎没有悬浮式 | "尺寸 × 形态"，悬浮式一列空着，黄框落在空格；不要用尺寸 × 台面（黄框会落在落地岗石款上，看不出空档） | 我们各尺寸行 × 悬浮式列 | 黄行 = 我们的促销价档（HD $280、Lowe's $280/$297、WF $337、AMZ $249）；黄框 = 陶瓷盆列 |
| 悬浮式 reeded 发布 | 悬浮式岗石台面只有 $484 以上的整装款（拆装岩板 $370–540 另算），陶瓷/树脂盆才是主量 | Amazon 悬浮式"尺寸 × 台面"，格内加"加权均价"；右侧加一列"我们售价" | 24/30/36/48″ 四行 × 岗石台面列各一个黄框，右列写我们各尺寸价格 |
| 藤编整装发布 | 大尺寸整装元素集中在 farmhouse/shaker，藤编几乎没有；石英石在大尺寸效率高 | "尺寸 × 元素"（整装）或"尺寸 × 台面"（整装） | 我们的尺寸行 × 藤编列 / 石英石列 |

## 三、格内指标
月销 | 款数（Amazon 写 ASIN 数）| 单款月销 | （价格不是轴时加：加权均价）| 加权评分 | 销量第一（品牌 售价 · 月销，可选）

- 底色深浅：看"量在哪"按月销；看"单链接能卖多少"按单款月销。副标题写明。
- 加权评分 < 4.0 标红；无评分写"—"。
- 末行合计：每列月销 + 占比；末列合计月销。
- 需要时右侧加"我们"列（我们各行的售价 / 款式）。

## 四、我们的位置（必须有）
- 我们所在行：行头黄底 + "我们"标签。
- 我们所在格：黄色粗框；格子为空时在格内写"我们"。可以有多个格（多尺寸、多款式）。
- 副标题写出我们的价格 / 配置。
- 正文配一句读图结论：黄框是空的 → "无直接对手"；黄框有量 → 写格内款数、均价、我们的价差。

## 五、放置位置
- 立项：每个渠道小节的两条要点之后、竞品表之前。
- 发布：需求分析里说明格局的那一节；"锚定各渠道竞对"每个渠道开头。
- 图宽铺满版心（约 17–18 cm）。

## 六、生成
`scripts/cross_matrix.py`，输入一张商品表（CSV / XLSX / JSON）。行、列可以是任何字段，`price` 可分箱。示例：

```bash
# 价格带 × 台面，我们 $280 陶瓷盆
python cross_matrix.py --input hd.csv --filter "拆装=整装" --filter "尺寸in18″,24″,28″,30″" \
  --rows price --price-bins 0,200,300,400,600,900 --cols 台面 \
  --our "280:陶瓷" --our-note '我们 $280，陶瓷盆' --unit 款 \
  --title "Home Depot 小尺寸整装（30″ 及以下）：价格 × 台面" \
  --source "Home Depot 搜索前 150，销量按评论推算" --out hd_price_top

# 尺寸 × 台面，我们 4 个尺寸都是岗石，右侧加我们售价列
python cross_matrix.py --input amz.csv --filter "形态=悬浮式" --rows 尺寸 \
  --row-order "18″,24″,28″,30″,36″,42″,48″,60″,72″+" --cols 台面 --show-price \
  --our "24″:岗石" --our "30″:岗石" --our "36″:岗石" --our "48″:岗石" \
  --our-col-values "24″=$245,30″=$299,36″=$339,48″=$439" --shade per \
  --title "Amazon 悬浮式浴室柜：尺寸 × 台面" --source "卖家精灵子体月销" --out amz_float
```

输出 `<out>.html` 和 `<out>.png`（2 倍清晰度）。出图后必须打开 PNG 看一遍。

## 七、其他常用图
- 趋势折线（月份 × 搜索量 / 销量 / 比值）：比值单独一张，不和量放双坐标轴；只画用户关心的对象。
- 价格分档表（渠道 × 价格档，格内"件数 · 款数"）：数据少、只需说明"中间价位空"时，比交叉图更直接。
- 多品类对比看板（如浴室柜 vs 灯镜）：月份对齐，只用两者共有的月份。
