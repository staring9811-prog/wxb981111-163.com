# 验收标准

两种文件侧重点不同，分开验收。A 类由 `check_doc.py` 自动检查；B 类转成 PDF 后逐页看图人工检查。

## 侧重点

| | 立项 | 发布 |
|---|---|---|
| 回答的问题 | 值不值得做、机会在哪、做成什么样 | 怎么卖：卖给谁、对标谁、卖多少钱、能赚多少、预计卖多少 |
| 读者 | 老板、开发 | 运营、同事 |
| 重心 | 需求分析 + 机会方向 + 差异化 + 产品定义 | 锚定竞对 + 售价利润 + 销量预估 + 写全规格 |
| 不能有 | 销量预估、"核心结论"大框 | 不写待补项以外的编造规格 |

## 立项（L）

| 编号 | 检查项 | 类 |
|---|---|---|
| L1 | 有一级章节：一、需求分析；二、差异化元素；三、产品定义；四、产品落地价格（打样前） | A |
| L2 | 需求分析里有"机会点""危机点""两大方向" | A |
| L3 | 全文不出现"销量预估""第三个月""直接竞对："，不出现"核心结论" | A |
| L4 | 产品定义有一句"要…、要…、要…"口号，有"外观设计理念""使用性设计理念" | A |
| L5 | 落地价格章节第一句写"利润率 X–Y%，利润额 $A–B"，有利润表（上架价/促销价/结算价/利润/利润率） | A |
| L6 | 每个渠道至少一张交叉看板图（图片数 ≥ 渠道数 + 渲染图数） | A |
| L7 | 竞品表表头含"和我们比"，至少 3 张竞品表 | A |
| L8 | 有差评分析：星级/推荐率表 + 买家原话表 | A |
| L9 | 看板图维度与机会点一致（本例机会点是价位空档 → 小平台用价格 × 台面），有黄行 + 黄框标出我们 | B |
| L10 | 竞品覆盖至少两层，含同尺寸同规格的贵价款，不只放低价头部 | B |
| L11 | "和我们比"的差价按我们的促销价算对（抽 3 条核对） | B |
| L12 | 结论数字和数据一致（抽 3 个数字回查 products.csv） | B |

## 发布（R）

| 编号 | 检查项 | 类 |
|---|---|---|
| R1 | 封面有"核心结论"，其中一条是销量预估（"第三个月"+ 件/月） | A |
| R2 | 有一级章节：需求分析、差异化、产品定义与规格、锚定的各渠道竞对、各平台售价与利润、销量预估、风险 | A |
| R3 | 规格写全：结构与功能、材质与表面处理、尺寸重量与包装、出厂价；未给的写"待补" | A |
| R4 | 售价按尺寸表 + 每个 SKU 利润表（行数 ≥ SKU 数） | A |
| R5 | 销量预估每个渠道都有，"直接竞对："4 行格式（价格｜月销｜评分、配置、估算） | A |
| R6 | "锚定的各渠道竞对"每个渠道标题带"我们：$" | A |
| R7 | 竞品表表头含"和我们比"，交叉看板图 ≥ 1 张 | A |
| R8 | 看板图维度与机会点一致：Amazon 用尺寸 × 台面（我们 4 个尺寸 × 岗石各一个黄框）；Home Depot、Lowe's 几乎没有悬浮式，要用尺寸 × 形态，黄框落在空的悬浮式列 | B |
| R9 | 销量预估的理由是竞品的价格、销量、配置，不是"市场潜力大" | B |
| R10 | 规格没有编造（未给的柜体尺寸、装柜量写待补） | B |
| R11 | 利润数字与输入一致（抽 3 个） | B |

## 共用（C）


| 编号 | 检查项 | 类 |
|---|---|---|
| C1 | 不出现 AI 腔词：一页看完、赋能、抓手、闭环、痛点直击、极致、全方位、助力 | A |
| C2 | 不出现 emoji | A |
| C3 | 每张表都设了固定列宽（PDF 中不挤成一列） | B |
| C4 | 数据来源 / 口径注释存在（"数据来源"或"数据："） | A |
| C5 | 每张看板图的黄框落在空档或能直接比出我们优势的格，不落在对手大量销售、但和我们形态不同的格 | B |
