# v1.3.0：整装浴室柜 + LTL
- 产品新增“包装”（分包 / 整包 / 整装，品名或描述含“整装”自动识别）和“尾程”（自动 / LTL / 快递），在第 2 步“包装 / 尾程”列设置，走 LTL 时可填 LTL 报价。
- 自动走 LTL：整装且毛重合计 > 48 kg，或任一包裹超出 FedEx 上限（最长边 > 108 in、长+围长 > 165 in、计费重 > 150 lb）。
- LTL 运费 = 填写的报价；没填按估算：92.5 + 0.43 × 毛重 lb + 54 × 体积 m³（用越南佳和 19 条整装柜 LTL 报价拟合，平均误差约 $15 / 7%，最大约 $28）。系数在变量 → 通用费用里可改。
- 走 LTL 时 FBM 尾程 = LTL 运费，不再加订单处理、尾程异常、燃油；自己发货的平台（Lowe's SC）同样按 LTL。CG / FBA 不变。
- 整装海运按装柜率 70% 计（海运费 ÷ 0.7），可在变量里改。
- 第 4 步新增“整装浴室柜 / LTL”板块：判定原因、LTL 报价 / 估算 / 采用、换成快递的运费、海运费、FBM 和 CG 利润。导出 Excel 增加“FBM尾程方式”列。
- 用表格参数（推广 8%、退款 8%、汇损 1%、每方 $283、燃油 0）核对：16 个产品中 15 个 FBM 利润与原表一致（差 ≤ $0.1）；24 寸 shaker 毛重 40 kg 按规则走快递，原表按 LTL，需要时手动设为 LTL。

# v1.3.1：整装尾程 快递 vs LTL 对比

# v1.4.0：整装尾程对比重新设计
- 规则：FedEx 规则走不了快递的（最长边 > 108 in、长+围长 > 165 in、计费重 > 150 lb、尾程表没有价格）只能 LTL；能走快递的（哪怕要收 OS 超重等附加费），整装产品默认采用快递和 LTL 中便宜的一种。非整装照常走快递。不再用“整装 > 48 kg 一律 LTL”。
- 第 4 步顶部“整装尾程对比：快递（FBM）vs LTL”是唯一的操作面板：按尺寸分组，每个整装产品一行，快递（金额 + 派送 / 处理 / 异常附加费 / 燃油拆分 + FBM 利润率）和 LTL（金额 + 报价输入 + FBM 利润率）并排，差额（哪种省多少）、采用（LTL / 快递单选，标“推荐”，手动后可“恢复自动”）。计费重接近 150 lb 的提示。
- 第 2 步“包装 / 尾程”列只保留“包装”下拉和当前结论标签（“LTL $191 ›”/“快递 $108.70 ›”），点标签跳到对比面板。删除页面底部重复的整装表。
- 利润明细中走 LTL 的产品名后加“LTL”标签。

# v1.4.1：只有人民币价的产品按国内出货
- 每个产品单独决定出货方式：顶部选 FOB 时，只填了国内出货价（人民币含税）、没有 FOB 价的产品按国内出货算（退税后成本 + 国内头程方案）；顶部选国内出货时，只有 FOB 价的按 FOB 算。两种价都有的按顶部选择。
- 第 2 步“采购成本 $”显示实际采用的成本，只有国内价的标“按国内出货”，FOB 出厂价不再标红；第 4 步“当前口径”提示有几个产品按另一种方式算、用的是哪个头程方案。

# v1.4.2：“半整装”不再被当成整装
- 包装自动识别时，品名里的“半整装”不算整装（之前被误判为整装，海运费多除了 70% 装柜率，并进了 LTL 对比）。手动设过“整装”的产品不受影响，需要在第 2 步把包装改回“整包”。
