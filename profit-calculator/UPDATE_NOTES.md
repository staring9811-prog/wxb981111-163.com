# v1.1.1：VC 佣金按原批发价
- 渠道费用表新增“佣金基数”列：实际结算价 / 原批发价（促销不降）。
- Lowe's VC 默认“原批发价”：佣金 = 上架价 ÷ 加价倍率 × 5.2%，促销时结算价下降但佣金不变（与 LOWESHDPWF 表 AN 列一致）；其他渠道默认按实际结算价。
- 保本价/目标价按固定佣金重新求解；明细表列名显示“（按原批发价）”；计算说明与 Excel 参数页同步。
- 旧数据自动补上该字段，不覆盖已保存的其他参数。

# v1.1.3：一键更新（覆盖当前文件）
- Chrome / Edge 打开本地 HTML 时，发现新版后点“立即更新”：选中正在用的这个文件 → 点“保存更改”，程序直接覆盖它并自动刷新，不再需要下载新文件、替换、再打开。数据在同一文件路径下保持不变。

# v1.2.0：产品库、产品矩阵、导入带产品图片
- 新增“产品库”页：长期保存全部在售 / 开发中 / 停产产品。第 2 步或产品库页点“存入产品库”（已在库里的按关联更新），在产品库勾选后“加入当前测算”。
- 产品矩阵：行 = 系列，列 = 尺寸；每格是产品卡片（图片、包裹数、颜色、状态、所选渠道促销利润率），绿 / 黄 / 红 = 达标 / 赚钱未达标 / 亏损，空格标“缺”。可按渠道利润率、采购成本、Amazon 售价查看，可按状态筛选、搜索。
- 系列和尺寸从品名自动识别（24寸 / 30" / shaker-mix36），AI 识别时也会返回系列；在产品库清单里可改系列、尺寸、颜色、状态。
- 产品图片：Excel 导入和 AI 识别 Excel 时自动带出 WPS 单元格图片（DISPIMG）和浮动图片，按行对应到产品；AI 识别时每行带行号，图片按行号对位，不会串到下一个产品。第 2 步、AI 核对表、产品库里点图片可换图（选文件或粘贴）。
- 图片压缩为 ≤360px 小图存在浏览器 IndexedDB；完整备份包含产品库和图片，恢复时一并写回。超过 30 天且没有任何产品引用的图片自动清理。
- 截图 / PDF 报价单暂不自动裁图，可手动加图。

# v1.2.1：从历史库 / 报价库添加到产品库
- 产品库页新增“从历史库 / 报价库添加”：选一个历史版本或报价版本，勾选产品加入产品库；已在库里的（同品名、同系列、同尺寸）标“已在库”、默认不勾，勾上则用该版本数据更新。
