# 已确认的精简输出规范

确认日期：2026-10-21。适用范围：用户提供父ASIN，拓展子体并按同月流量词分摊父体月销量。
确认来源：用户“首次评分日期 品牌链接这两个保留剩下的按照你的意思来”。继承前一轮完整结构草案，采用随后精简建议，唯独保留首次评分日期及品牌链接。

下列是固定展示结构。所有开放字段无下拉；状态字段单选，完整选项在表内。字段存在不代表每个ASIN都能返回有效值。接口null、缺失和负数哨兵不伪造为有效值。不要新增日销量或关键词明细Sheet。业务身份优先使用子ASIN；SKU属性不是卖家内部SKU编码。

## 时间与展示约束

- 主表以目标月份统一表示销量及词数月份；实际请求及返回月份证据在JSON/日志中继续保存。发现月份不一致时不得用合并表头掩盖，应阻止分摊并记录异常。
- 当前价格、当前详情BSR、上架日期和更新时间不得被描述为目标月历史快照。
- 父级或家庭级重复字段不可跨子体求和。最终结果为估算而非真实销量。
- 本规范确认的是展示结构，不自动启用旧版4.5/1.5修正、区间约束等计算选项；须按已授权算法执行，并填写实际采用规则。
- 文件默认存D:/Codex/Outputs，原始数据默认D:/Codex/Data或已有D盘项目。输出路径链接应可追溯，不包含凭证。
